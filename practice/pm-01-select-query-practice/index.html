1. 조건 연결: OR 키워드 사용#

왜 이걸 보게 됐나#

데이터베이스에서 여러 조건을 동시에 만족하는 레코드를 검색하는 방법을 배우기 위해 OR 키워드를 활용한 SELECT 문을 살펴보게 되었습니다.

내가 헷갈린 지점#

처음에는 OR을 사용할 때 각 조건 사이에 공백 없이 바로 연결하면 된다고 오해했습니다. 하지만, 여러 값을 동일한 컬럼에 대해 비교할 때는 IN 키워드가 더 간결하고 명확하다는 사실을 깨닫지 못했습니다.

시도한 코드 / 예시#

-- 잘못된 접근 방식
SELECT *
FROM customers
WHERE Country = 'USA' OR Country = 'Canada';

-- 올바른 접근 방식
SELECT *
FROM customers
WHERE Country IN ('USA', 'Canada');

결과와 해석#

IN 키워드를 사용하면 코드가 더 간결해지고 읽기 쉬워집니다. 이로 인해 동일한 컬럼에 대한 여러 값의 비교가 훨씬 효율적으로 이루어집니다.

정리된 이해#

OR 키워드는 조건 중 하나라도 참이면 결과에 포함되지만, IN 키워드는 지정된 리스트 내의 값을 쉽게 다룰 수 있게 해줍니다. 특히 여러 값을 비교할 때 IN이 더 적합합니다.

2. 와일드카드 % 사용 이해#

왜 이걸 보게 됐나#

LIKE 연산자에서 와일드카드 %의 정확한 사용 방법을 이해하기 위해 다양한 패턴 매칭 사례를 탐색했습니다.

내가 헷갈린 지점#

% 와일드카드의 위치와 의미에 대해 명확한 이해가 부족했습니다. 특히, 패턴 매칭의 범위를 정확히 파악하는 데 어려움을 겪었습니다.

시도한 코드 / 예시#

-- '%K%': 이름이 "K"로 시작하는 경우
SELECT * FROM customers WHERE Name LIKE '%K%';
