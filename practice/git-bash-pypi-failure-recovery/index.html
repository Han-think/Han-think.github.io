## 2. 환경 변수 설정 차이#

### 왜 이걸 보게 됐나#

환경 변수 설정 방법이 환경에 따라 다르다는 점에서 혼란이 발생했다. 특히, 환경 변수 설정 시 명령어 사용법의 차이를 이해하지 못한 것이 문제였다.

### 내가 헷갈린 지점#

  • > 기호의 역할 이해 부족 (Git Bash에서는 계속 입력 대기 상태)
  • 환경 변수 설정 명령어 (예: export)의 사용법 차이 인식 부족

### 시도한 코드 / 예시#

  • 혼란 사례: 환경
