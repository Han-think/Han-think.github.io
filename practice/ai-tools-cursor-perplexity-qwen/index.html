1. Cursor 이해하기#

왜 이걸 보게 됐나#

프로그래밍 작업 중 특정 코드 라인의 수정이 필요할 때 효율적인 방법을 찾다가 Cursor 도구의 역할과 사용법에 대해 더 깊게 이해하고자 학습을 시작했습니다. 특히 실시간 코드 수정 기능이 프로젝트 진행에 어떻게 도움이 되는지 알아보고 싶었습니다.

내가 헷갈린 지점#

Cursor와 다른 코드 보조 도구들 간의 역할 구분이 명확하지 않았습니다. 특히, 실시간 수정 기능을 제공하는 다른 도구들과 어떻게 다른지 이해하는 데 어려움이 있었습니다.

시도한 코드 / 예시#

# 예시 코드 상황: Python 함수 내에서 특정 부분 수정 필요
def example_function(x):
    result = x * 2 + 5  # 수정 필요 부분
    return result

# Cursor를 사용한 수정 예시 명령어
# (실제로는 인터페이스를 통해 명령어 입력)
"Modify line containing 'result = x * 2 + 5' to 'result = x * 2 + 10'"

결과와 해석#

Cursor를 사용하여 특정 코드 라인을 선택하고 명령을 통해 원하는 대로 수정할 수 있었습니다. 이 과정에서 실시간으로 코드 변경 사항을 확인하며 작업의 효율성이 크게 향상되었습니다. 특히, 반복적인 코드 수정 작업에서 시간을 크게 절약할 수 있음을 확인했습니다.

정리된 이해#

Cursor는 코드 편집 과정에서 실시간 수정과 제안을 통해 개발자의 작업 효율성을 극대화하는 도구입니다. 주로 코드 내 특정 부분을 직접 수정하거나 제안된 수정 사항을 적용하는 데 사용됩니다.

2. Perplexity 이해하기#

왜 이걸 보게 됐나#

다양한 정보와 데이터를 효과적으로 분석하고 수집하는 방법에 대해 더 알아보고자 Perplexity의 기능과 활용법을 학습했습니다. 특히 복잡한 데이터 세트에서 의미 있는 정보를 빠르게 추출하는 데 관심이 있었습니다.

내가 헷갈린 지점#
