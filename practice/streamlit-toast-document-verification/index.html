1. Streamlit Toast 기본 사용법#

왜 이걸 보게 됐나#

  • Streamlit 애플리케이션에서 사용자 피드백을 제공하기 위해 Toast 메시지 기능을 탐색하고자 했습니다.

내가 헷갈린 지점#

  • 공식 문서에 나열된 다양한 옵션들이 실제 실습 환경에서 일관되게 작동하지 않았습니다. 특히 여러 토스트 메시지를 동시에 표시하는 기능이 불안정했습니다.

시도한 코드 / 예시#

if st.button("여러 개 토스트 표시"):
    st.toast("첫 번째 메시지")
    st.toast("두 번째 메시지")
    st.toast("작업 완료")

결과와 해석#

  • 예상과 달리 일부 토스트 메시지만 표시되거나 전혀 표시되지 않는 문제 발생. 이는 환경 설정이나 Streamlit 버전 차이 때문일 수 있다는 추측이 들었습니다.

정리된 이해#

  • Toast 메시지의 일관된 동작이 환경 설정이나 버전에 크게 영향을 받는다는 점을 인지하였습니다.

2. 환경 및 버전 확인과 문제 해결 전략#

왜 이걸 보게 됐나#

  • 혼란스러운 동작 원인을 파악하고 해결 방안을 모색하기 위해 환경 설정과 Streamlit 버전을 확인하였습니다.

내가 헷갈린 지점#

  • 실제 코드에는 문제가 없는 것으로 보였지만, 환경과 버전 차이로 인해 예상과 다른 결과가 나타났습니다.

시도한 코드 / 예시#

python3 -c "import streamlit as st; print(st.__version__)"

결과와 해석#

  • 현재 사용 중인 Streamlit 버전을 확인하여 문서와 일치하는지 확인하였습니다. 버전 차이가 문제의 원인일 가능성이 높다는 결론을 내렸습니다.

정리된 이해#

  • 정확한 버전 확인과 기본 기능 검증을 통해 문제 원인을 명확히 파악할 수 있음을 확인하였습니다.
