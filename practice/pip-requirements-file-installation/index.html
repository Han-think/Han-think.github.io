1. pip 명령어 이해하기#

왜 이걸 보게 됐나#

Python 프로젝트를 시작하면서 필요한 라이브러리를 효율적으로 설치하고 관리하는 방법을 알고 싶어졌습니다. 특히, pip 명령어의 다양한 옵션들이 혼란스러웠습니다.

내가 헷갈린 지점#

  • pip install 명령어의 옵션들 사이에서 정확한 역할 차이를 이해하는 데 어려움이 있었습니다. 예를 들어, 특정 버전의 패키지를 설치하는 방법이나 requirements.txt 파일을 활용하는 방법 등이 명확하지 않았습니다.

시도한 코드 / 예시#

# 특정 버전의 패키지 설치
pip install pandas==1.5.3

# 패키지 목록 확인
pip list

# 패키지 업그레이드
pip install --upgrade pandas

# 패키지 제거
pip uninstall pandas

# requirements.txt 파일을 이용한 패키지 설치
pip install -r requirements.txt

# 현재 환경 패키지 목록 내보내기
pip freeze > requirements.txt

결과와 해석#

  • pip install pandas==1.5.3 명령어를 실행한 결과, pandas 라이브러리 버전 1.5.3이 성공적으로 설치되었습니다.
  • pip list 명령어를 통해 현재 설치된 패키지 목록과 버전을 확인할 수 있었고, 이를 통해 패키지 상태를 명확히 파악할 수 있었습니다.
  • requirements.txt 파일을 이용해 여러 패키지를 일괄 설치하는 방법을 통해 프로젝트 의존성 관리가 훨씬 간편해졌습니다.

정리된 이해#

  • pip install <package_name>: 지정한 패키지의 최신 버전을 설치합니다.
    • 예시: pip install pandas
  • pip install <package_name>==<version>: 특정 버전의 패키지를 설치합니다.
    • 예시: pip install pandas==1.5.3
  • pip list: 현재
