1. DISTINCT 개념 이해하기#

왜 이걸 보게 됐나#

데이터셋에서 중복 데이터를 제거하고 유일한 결과만을 얻고자 할 때 사용할 수 있는 기능을 이해하고자 했습니다.

내가 헷갈린 지점#

중복 값을 제거하는 방식에 대해 명확한 이해가 필요했습니다. 특히, 특정 조건에 맞는 중복 제거 방법에 대해 혼란스러웠습니다.

시도한 코드 / 예시#

SELECT DISTINCT category FROM book;

결과와 해석#

category 컬럼에서 각 카테고리가 한 번씩만 나타나는 결과를 얻었습니다. 이로써 중복 데이터가 제거된 유일한 카테고리 목록을 확인할 수 있었습니다.

정리된 이해#

DISTINCT 키워드는 지정된 컬럼에서 중복 값을 제거하여 유일한 결과 집합을 반환합니다.

2. WHERE 절과 비교 연산자 활용하기#

왜 이걸 보게 됐나#

데이터를 특정 조건에 맞게 필터링하여 필요한 정보만을 추출하고자 했습니다.

내가 헷갈린 지점#

WHERE 절 내에서 다양한 비교 연산자를 어떻게 적용할지에 대한 이해가 필요했습니다.

시도한 코드 / 예시#

SELECT * FROM book WHERE price >= 40 AND author LIKE '%이%';

결과와 해석#

가격이 40 이상이고 저자 이름이 특정 패턴을 포함하는 책들만 선별되었습니다. 조건을 결합하여 원하는 데이터를 정확하게 추출할 수 있음을 확인했습니다.

정리된 이해#

WHERE 절은 특정 조건에 맞는 데이터만을 필터링하며, 다양한 비교 연산자를 조합하여 복잡한 조건을 설정할 수 있습니다.
