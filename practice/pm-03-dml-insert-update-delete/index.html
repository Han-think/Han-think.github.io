초보자를 위한 SQLite DML 실습 워킹 노트: INSERT, UPDATE, DELETE

SQL의 기본 데이터 조작 언어(DML) 중 INSERT, UPDATE, DELETE를 이용한 데이터베이스 실습 경험과 학습 내용 정리

목차#

  • INSERT: 데이터 추가
  • UPDATE: 데이터 수정
  • 총평

INSERT: 데이터 추가#

왜 이걸 보게 됐나#

SQL을 배우면서 데이터베이스에 새로운 레코드를 추가하는 방법을 이해하고자 INSERT 명령을 집중적으로 학습했습니다.

내가 헷갈린 지점#

특히 문자열 데이터에 대한 작은따옴표 사용 방법이 명확하지 않았습니다. 여러 예시에서 일관된 적용 방법을 찾는 데 어려움을 겪었습니다.

시도한 코드 / 예시#

다음과 같이 'It''s Only the Himalayas'와 같은 문자열 값을 삽입하려고 시도했습니다.

INSERT INTO book (title, category, price, rating, stock)
VALUES ('It''s Only the Himalayas', 'Travel', 45.17, 2, 19);

결과와 해석#

SQL 오류 메시지를 확인한 결과, 작은따옴표 내부의 작은따옴표를 어떻게 처리해야 하는지 알게 되었습니다. 두 번의 작은따옴표 사용이 필요하다는 것을 배웠습니다.

정리된 이해#

문자열 값을 삽입할 때는 내부 따옴표를 두 번 사용하여 탈출 처리해야 한다는 점을 명확히 이해했습니다. 이를 통해 데이터 타입에 맞는 올바른 값 삽입이 가능해졌습니다.

UPDATE: 데이터 수정#

왜 이걸 보게 됐나#

데이터베이스 내 특정 조건에 맞는 레코드를 수정하는 방법을 익히기 위해 UPDATE 명령을 학습했습니다.

내가 헷갈린 지점#

기존 값에 대한 연산을 적용하는 방법이 불분명했습니다. 특히, 숫자 값을 증가시키는 방법에 대해 확신이 없었습니다.

시도한 코드 / 예시#

stock 값을 증가시키는 코드를 작성하면서 어려움을 겪었습니다.

UPDATE book SET stock = stock + 5 WHERE category = 'Poetry';
