1. 패키지 버전 관리와 배포 이해#

왜 이걸 보게 됐나#

Python 패키지를 실제 프로젝트에 적용해 보며, 단순히 기능 개발 뿐 아니라 버전 관리와 배포 과정의 중요성을 깨달았습니다. 효과적인 개발 워크플로우를 구축하는 데 필요한 기술을 습득하고자 했습니다.

내가 헷갈린 지점#

특히 혼동스러웠던 부분은 다양한 이름 규칙과 형식들 간의 차이점이었습니다. 패키지 이름, import 이름, GitHub 저장소 이름 등이 서로 어떻게 연관되고 차이가 있는지 명확히 이해하지 못했습니다.

시도한 코드 / 예시#

다음과 같이 각 버전별 패키지 기능을 구현하고 테스트했습니다:

# Arithmetic 모듈 예시
def add(a, b):
    return a + b  # 출력: # 결과: a + b

# GeometricSequence 모듈 예시
def geometric_mean(a, r, n):
    return (a * pow(r, n)) ** (1/n)  # 출력: # 결과: (a * r^n)^(1/n)

# Trigonometry 모듈 예시
import math
def sine(angle):
    return math.sin(math.radians(angle))  # 출력: # 결과: sin 값

결과와 해석#

테스트 코드 실행 결과 각 기능이 기대대로 동작하는 것을 확인했습니다. 그러나 각 버전별로 Git에 커밋하고 태그를 추가하는 과정에서 오류가 발생하여 배포 전에 문제를 해결해야 했습니다. 특히, mathlib-hanthink와 mathlib_hanthink 간의 이름 혼동으로 인해 import 시 문제가 생겼습니다.

정리된 이해#

패키지 개발은 단순히 코드 작성 이상의 과정입니다. 버전 관리와 정확한 이름 지정 규칙 준수는 성공적인 배포에 필수적입니다. 각 단계에서 정확한 형식을 따르는 것이 향후 프로젝트에서의 오류를 최소화하는 데 중요합니다.

2. PyPI에 패키지 배포#

왜 이걸 보게 됐나#

실제 코드를 개발하고 테스트한 후에는 이를 다른 개발자들과 공유하고자 PyPI에 배포하는 과정을 학습했습니다. 이를 통해 오픈 소스 커뮤니티에 기여하고, 라이브러리의 접근성을 높이는 방법을 익혔습니다.
