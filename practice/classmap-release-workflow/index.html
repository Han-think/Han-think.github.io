1. GitHub 저장소 생성 및 설정#

왜 이걸 보게 됐나#

클래스맵 프로젝트를 공개적으로 관리하고 배포하기 위해 GitHub 저장소를 생성하고 설정하는 방법을 학습하게 되었습니다.

내가 헷갈린 지점#

git init 명령어만으로 GitHub 저장소가 자동 생성된다고 오해했습니다. 실제로는 로컬 저장소만 생성되고 원격 저장소 설정이 필요했습니다.

시도한 코드 / 예시#

# 로컬 저장소 초기화
$ git init
# GitHub 웹사이트에서 새로운 레포지토리 생성 후 URL 얻기
# 로컬 저장소와 GitHub 저장소 연결
$ git remote add origin <GitHub_URL>

결과와 해석#

로컬 저장소와 원격 GitHub 저장소를 성공적으로 연결하여 코드 관리가 가능해졌습니다.

정리된 이해#

GitHub 저장소 생성은 로컬 작업 환경과 원격 저장소 간의 연결을 의미합니다. 이를 통해 협업과 버전 관리가 용이해집니다.

2. 메인 브랜치 푸시 및 태그 생성#

왜 이걸 보게 됐나#

프로젝트의 초기 커밋을 GitHub 저장소에 푸시하고 버전 관리를 위해 태그를 생성하는 과정을 학습했습니다.

내가 헷갈린 지점#

git push 명령어로 초기 커밋을 푸시하려고 했으나, 이미 존재하는 원격 저장소의 초기 커밋으로 인해 푸시가 거절되었습니다.

시도한 코드 / 예시#

# 초기 커밋 생성 및 푸시 시도 (거절됨)
$ git commit -m "Initial commit"
$ git push -u origin main

# 강제 푸시 (주의 필요)
$ git push -u origin main --force
# 태그 생성
$ git tag v0.1.0
$ git push origin v0.1.0

결과와 해석#

git push --force 명령어를 사용하여 강제로 푸시를 시도했으나
