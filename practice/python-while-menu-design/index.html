1. while 루프 이해#

왜 이걸 보게 됐나#

프로그래밍 기초를 다지면서 반복적인 작업을 처리하는 방법을 배웠습니다. 특히, 사용자와 상호작용하는 프로그램에서 while 루프가 얼마나 중요한지 깨달았습니다.

내가 헷갈린 지점#

while True 구조를 처음 접할 때, 무한 반복이라는 점 때문에 종료 조건을 명확히 설정하지 않으면 프로그램이 계속 실행되는 문제에 대해 이해가 필요했습니다. 사용자 입력에 따른 종료 로직을 어떻게 구현할지 어려웠습니다.
