개인 개발 기록: SNS 화면 개념 학습 시안#

배경과 목표#

2026년 10월 14일 수업에서 다룬 SA와 SNS 논리 ERD의 개념을 실제 HTML 화면으로 표현해 보면 어떨까 하는 생각에서 시작했다. 수업 개념을 화면과 데이터의 관계로 이해하기 위한 개인 학습 시안이다.

완성된 SNS 서비스를 만들었다는 이야기가 아니라, 요구사항이 화면의 동작과 데이터 구조로 어떻게 이어지는지를 표현해 보는 개발 기록으로 남기려 한다.

설계와 구현에서 표현한 범위#

현재 로컬 시안에는 피드, 친구 목록, 프로필, 데이터 설계 보기, 화면 꾸미기 구획이 있다. HTML은 화면 구조, CSS는 시각적 표현, JavaScript는 학습용 화면 반응을 담당하도록 구성돼 있다.

게시글·좋아요·댓글을 화면에서 표현하는 것과 실제 서버에 저장하는 것을 구분하는 것이 중요하다. 친구 목록과 프로필도 화면의 임시 상태와 실제 서비스의 저장·권한 처리를 같은 것으로 설명하지 않는다.

이 시안은 화면 요소와 데이터 개념을 대응시켜 보는 도구다. 가입·로그인·인증, 실제 API와 DB 연결, 여러 사용자의 동시 이용이 구현됐다고 주장하지 않는다.

확인한 결과와 미확인 사항#

현재 확인한 것은 로컬에 HTML·JavaScript·CSS와 관련 자료가 있고, 소스에 위 화면 구획과 클릭·입력에 대응하는 코드가 있다는 점이다. 이것은 파일·소스를 읽어 확인한 정적 근거다.

시안 자체에도 입력·좋아요·댓글은 브라우저에서 임시로 다루는 학습용 예시이며 실제 서버에 저장되지 않는다는 안내가 있다. 프로필 편집 코드에도 서버 저장이 아니라는 안내가 있다.

브라우저에서 각 버튼과 입력을 실제로 조작해 정상 동작했는지는 아직 확인하지 않았다. 실제 DB 생성, FK·유일 제약 검증, 로그인·API 연결 성공도 확인하지 않았다. 소스에 기능 코드가 있다는 사실만으로 실행 성공이나 서비스 완성을 단정하지 않는다.

한계와 다음 작업#

다음에는 브라우저에서 화면 전환, 게시글 입력, 좋아요 취소, 댓글 입력, 친구 목록 변경, 프로필 편집을 차례로 확인하려 한다. 정상 동작뿐 아니라 빈 입력·취소 같은 경우도 실제 결과를 기록한 뒤 글에 반영한다.

다음 ERD 수업에서는 화면에서 필요해진 데이터와 키·관계·제약 조건이 어떻게 연결되는지 이어서 검토한다. 아직 정하지 않은 정책이나 검증하지 않은 결과는 미확인으로 남긴다.

이 글과 실행 데모의 공개는 별개다. 데모는 아직 웹에 배포하지 않았으며, 공개 자산 범위와 실제 동작을 확인한 뒤 별도로 결정한다. 지금은 개인 개발 설명 글의 초안을 작성하고, 내 의도와 다른 표현을 직접 수정하는 단계다.
