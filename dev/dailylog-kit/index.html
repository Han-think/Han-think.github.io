DailyLog Kit — 하루를 포인트로 정리하는 텍스트 브이로그

2026년 6월 9일 · 2 min

하루 메모를 던지면 카테고리별 포인트로 정리해주는 작은 키트. 텍스트 브이로그처럼, 그날 있었던 일의 포인트만 잡아 Markdown으로 남긴다. 업로드/배포는 없고 로컬에 정리만 해준다.

다운로드#

DailyLog Kit v1.2 (zip)

압축 안에 DailyLog.bat, dailylog.ps1, README.md 세 개가 들어 있다.

v1.2에서는 Ollama뿐 아니라 Google AI Studio의 Gemini API 키로도 하루 메모를 정리할 수 있게 했다.

GitHub 저장소는 Han-think/learninglog-kit이며, DailyLog Kit 소스는 dailylog_kit/ 폴더에 있다.

LearningLog와 구분#

도구 용도 결과
DailyLog Kit 개인 하루 회고, 일상 메모 정리 로컬 output/*.md
LearningLog LearningLog 메뉴 수업/학습 노트 처리와 learning 발행 04_blog_drafts/learning
LearningLog Projects 메뉴 프로젝트 회고/분석을 여러 편으로 정리 04_blog_drafts/projects

DailyLog Kit은 블로그 발행 안전장치가 필요한 글을 다루지 않는다. 블로그에 올릴 학습 글이나 프로젝트 시리즈는 LearningLog Kit의 Windows runner를 사용한다.

Gemini API 키 사용#

Gemini 키는 Google AI Studio에서 받을 수 있다.

한 번만 직접 쓰려면:

.\dailylog.ps1 -Provider gemini -GeminiApiKey "YOUR_KEY"

로컬 설정 파일에 저장하려면:

.\dailylog.ps1 -Provider gemini -GeminiApiKey "YOUR_KEY" -SaveGeminiKey

저장되는 dailylog.config.json은 Git에 올리지 않는 개인 설정 파일이다. 환경변수를 쓰고 싶다면 GEMINI_API_KEY를 설정해도 된다.

어떻게 쓰나#

  1. DailyLog.bat 더블클릭
  2. 오늘 기록할 요소 고르기 — 학습, 개발, 요리, 운동, 독서, 음악, 게임, 일상, 생각
  3. 오늘 있었던 일을 자유롭게 적기
  4. output/YYYY-MM-DD-daily.md 저장

세 가지 모드#

  • Gemini 정리: Google API 키로 카테고리별 포인트 + 한 줄 회고 생성
  • Ollama 정리: 로컬 Ollama 모델로 카테고리별 포인트 + 한 줄 회고 생성
  • 양식 채우기: LLM 없이 빈 양식만 만들어 직접 채우기

LLM이 없어도 바로 쓸 수 있게 만든 게 포인트다.

결과 예시#

## 오늘의 포인트
- 학습: SQL 문제 풀이 감각을 정리함
- 개발:
  - LearningLog와 DailyLog 역할을 분리함
  - Gemini API 키 사용 흐름을 추가함

## 한 줄 회고
도구의 역할을 나누면서 기록 흐름이 덜 헷갈리게 됐다.

만든 이유#

복잡한 자동 발행 파이프라인 말고, “오늘 뭐 했지"를 포인트로 가볍게 남기는 가장 단순한 도구가 필요했다. LearningLog는 공개 가능한 학습/프로젝트 글을 다루고, DailyLog는 내 하루를 로컬에서 가볍게 정리하는 쪽으로 역할을 나누었다.
