DailyLog Kit — 하루를 포인트로 정리하는 텍스트 브이로그

하루 메모를 던지면 카테고리별 포인트로 정리해주는 작은 키트. 텍스트 브이로그처럼, 그날 있었던 일의 포인트만 잡아 Markdown으로 남긴다. 업로드/배포는 없고 로컬에 정리만 해준다. 다운로드 DailyLog Kit v1.0 (zip) 압축 안에 DailyLog.bat, dailylog.ps1, README.md 세 개. 어떻게 쓰나 DailyLog.bat 더블클릭 오늘 기록할 요소 고르기 — 📚학습 💻개발 🍳요리 🏃운동 📖독서 🎵음악 🎮게임 🌿일상 💡생각 오늘 있었던 일을 자유롭게 적기 → output/YYYY-MM-DD-daily.md 저장. 끝. 두 가지 모드 자동 정리 (Ollama 있을 때): 자유 메모 → LLM이 카테고리별 포인트 + 한 줄 회고로 정리 양식 채우기 (LLM 없을 때): 빈 양식만 만들어줌 → 직접 채우는 구조화 일기장 LLM이 없어도 바로 쓸 수 있게 만든 게 포인트다. ...
