Kaggle Playground S6E7 개인 도전 회고 - 3. 앙상블: CatBoost 블렌드와 스태킹, 그리고 XGBoost 기각

목차 계기: 보정 개선폭이 줄어들 때 CatBoost 추가 LightGBM + CatBoost 선형 블렌드 스태킹으로 일반화 XGBoost 추가 시도 — 실패 총평 1. 계기: 보정 개선폭이 줄어들 때 확률 보정 범위를 넓히는 방식은 라운드마다 개선폭이 줄고 있었다(+0.5 → +0.3 → +0.1점). 같은 모델의 확률을 계속 쥐어짜는 대신, 진짜 새로운 정보 — 즉 다른 모델 — 를 추가하는 쪽으로 방향을 틀었다. 2.
