Kaggle Playground S6E7 개인 도전 회고 - 2. 베이스라인 버그 수정과 보정 루프

목차 기존 코드 진단 — 실제로 검증된 것과 아이디어뿐인 것 치명적 버그: 수치형 컬럼까지 LabelEncoder 보정 루프 분리와 nested CV 자잘한 사고들 총평 1. 기존 코드 진단 — 실제로 검증된 것과 아이디어뿐인 것 기존 GPT 패키지 두 개를 먼저 뜯어봤다. 실제로 실행되고 숫자가 나온 건 SGD 베이스라인 하나뿐이었다(80/20 홀드아웃 balanced accuracy 0.884453). LightGBM·CatBoost 후보 설정이나 클래스별 확률 곱셈 보정 템플릿은 코드로는 있었지만 한 번도 전체 데이터로 실행된 적이 없었다. 두 번째 패키지(advanced_package)는 전체의 3%에 해당하는 2만 행 서브샘플로 “방향성 벤치마크"만 해둔 상태였다. 여기서 중요한 사실 두 가지를 확인했다. 첫째, 클러스터 거리 피처를 추가하거나 클러스터별 모델을 블렌딩하는 시도는 오히려 점수를 깎아먹었다(0.855577, 0.852388 — 글로벌 모델의 0.862922보다 낮음). 둘째, 클래스별 확률에 곱셈 가중치를 주는 방식만 유일하게 개선 효과가 있었다(0.869910). 이 두 결론이 이후 하루 종일의 방향을 실질적으로 정했다 — 클러스터링 계열은 이미 실패로 확인됐으니 다시 시도하지 않고, 확률 보정 쪽을 정식화하는 데 집중한다는 원칙이었다. ...
