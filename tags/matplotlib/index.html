데이터 + 로컬 AI의 조합 분석 파이프라인에 LLM을 붙이는 것이 점점 자연스러워지고 있다. pandas로 데이터를 가공하고, 로컬 LLM으로 해석·요약하는 흐름이다. 기본 환경 구성 conda create -n data-ai python=3.11 -y conda activate data-ai # 데이터 분석 핵심 conda install pandas=2.2.1 numpy=1.26.4 matplotlib=3.8.3 seaborn -y # Jupyter conda install jupyter jupyterlab -y # Ollama 연동 pip install ollama requests 검증된 버전 조합 패키지 버전 비고 Python 3.11.8 3.12 일부 호환성 이슈 pandas 2.2.1 안정적 numpy 1.26.4 pandas와 궁합 최적 matplotlib 3.8.3 seaborn 0.13과 호환 scikit-learn 1.4.1 추가 선택 로컬 LLM으로 데이터 해석하기 import pandas as pd import requests df = pd.read_csv("data.csv") summary = df.describe().to_string() # Ollama 로컬 LLM에 전달 response = requests.post( "http://localhost:11434/api/generate", json={ "model": "qwen3:4b-instruct", "prompt": f"다음 데이터 요약을 분석해줘:\n{summary}", "stream": False } ) print(response.json()["response"]) 시각화 + LLM 해석 자동화 import matplotlib.pyplot as plt # 그래프 생성 fig, ax = plt.subplots() df.plot(ax=ax) plt.savefig("chart.png") # 그래프 설명 요청 (멀티모달 모델 사용 시) # llava:7b 같은 비전 모델과 연동 가능 다음 ChromaDB를 이용한 벡터 검색 + LLM RAG 파이프라인 pandas 데이터프레임을 LLM 컨텍스트로 변환하는 패턴 🤖 이 글은 로컬 LLM(AI)의 도움을 받아 작성되었습니다.
