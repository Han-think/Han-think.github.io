SQLTools와 SQLite를 활용한 데이터베이스 기초 학습 노트

목차 SQL 명령어의 기본 실행 이해 총평 1. SQL 명령어의 기본 실행 이해 왜 이걸 보게 됐나 SQL (Structured Query Language)을 활용한 데이터베이스 관리에 대한 기초를 다지고자 이 개념을 학습하게 되었습니다. 특히, 실시간 코딩 도구인 SQLTools를 활용하여 SQLite 데이터베이스를 다루는 방법을 익히고자 했습니다. 내가 헷갈린 지점 명령어 순서 오류: 테이블 생성(CREATE TABLE) 이후에 바로 데이터 조회(SELECT)를 시도했을 때 오류가 발생하는 이유를 이해하지 못했습니다. 결과 없음 인식: SQL 쿼리가 정상적으로 실행되었음에도 불구하고 결과가 나타나지 않거나 오류 메시지가 표시되는 상황에서 어떻게 대처해야 하는지 혼란스러웠습니다. 시도한 코드 / 예시 -- 테이블 생성 시도 (오류 발생) CREATE TABLE IF NOT EXISTS example_table ( id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT NOT NULL ); -- 바로 조회 시도 (오류 발생) SELECT * FROM example_table WHERE id = 1; -- 이 쿼리 실행 전에 데이터 삽입이 필요 -- 올바른 순서로 실행 CREATE TABLE IF NOT EXISTS example_table ( id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT NOT NULL ); INSERT INTO example_table (name) VALUES ('학습노트'); -- 데이터 삽입 SELECT * FROM example_table WHERE id = LAST_INSERT_ROWID(); -- 최신 삽입된 행 조회 결과와 해석 오류 원인 확인: 테이블 생성 후 데이터 삽입 없이 조회를 시도한 결과 오류가 발생한 것을 확인했습니다. 명령어의 실행 순서가 중요함을 깨달았습니다. 데이터 삽입 후 조회: 테이블에 데이터를 먼저 삽입한 후에 조회를 시도하니 원하는 결과를 얻을 수 있었습니다. 정리된 이해 명령어 실행 순서: 총평 오늘 전체에서 배운 것 정리 필요. ...
