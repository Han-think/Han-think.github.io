PyTorch 2.6.0+ nightly: xpu 관련 빌드 변화가 있었으나, Arc GPU(opencl) 기반 실행에 대한 공식 호환성 선언이 부족한 상태임. Hugging Face Transformers 최신 버전: XPU 토크나이저 및 모델 로딩 파이프라인 업데이트가 있었으나, 실제 xpu 장치에서의 device_map="auto" 동작 여부는 추가 검증 필요. 실무 검증된 개선 [검증됨] Optimum Intel 1.20.0: optimum.intel 패키지에 xpu 지원 관련 코드 및 문서가 공식 merged되었습니다. PyTorch XPU 실행 시 from optimum.intel import ... 경로 사용이 가능해졌으나, 실제 장치 테스트는 제한적임. [검증됨] PyTorch 2.6.0 안정판 출시: xpu 관련 내부 변경사항이 포함되었으나, Arc GPU(opencl 기반) 지원은 community 레벨이며, 공식 문서에 Arc 명시가 없는 상태입니다. 초기·추정 단계 연구 [초기] torch.compile + XPU: PyTorch 2.x의 torch.compile이 xpu 백엔드와 상호작용할 경우 속도 향상 또는 오류 발생 가능성이 언급된_initial PR들이 있으나, 재현 가능한 벤치마크는 현재 제공되지 않았습니다. [확인 필요] Arc GPU OneAPI 드라이버: Intel Arc GPU에서 PyTorch를 구동하기 위한 oneAPI 드라이버 버전과 PyTorch wheel 호환성에 대한 이슈가 GitHub에 다수 열려 있으나, 아직 공식적인 해결안이나 릴리스는 없습니다. 호환성·성능·메모리 영향 PyTorch XPU: torch.cuda.is_available() 대신 torch.xpu.is_available()를 사용해야 하며, device="xpu" 인자 전달이 필수적임. Arc GPU의 경우 opencl 기반 포트가 별도 필요하며, 현재 PyTorch 공식 wheel에서는 기본 지원되지 않을 수 있음. 메모리 관리: XPU 위에서의 텐서 할당 및 캐시 플러시는 CPU 기반 PyTorch와 패턴이 다를 수 있습니다. torch.cuda.empty_cache()에 해당하는 XPU 전용 정리 함수는 현재 확인된 바가 limited합니다. 모델 호환성 관찰 모델 유형 XPU 가능성 메모리 예상 현재 상태 테스트 가치 Time Series (Granite PatchTST-FM-r2) indirect (Hugging Face 호스팅) N/A Practically Tested 낮음 (XPU 직접 실행 아님) Vision/Language Transformers conditional (Optimum Intel 경로) 높음 (16GB 이상 권장) 초기 / 확인 필요 높음 (Optimum Intel 경로 시도 예정) 로컬 양자화 모델 가능하지만 코드 수정 필요 변동 큼 초기 중간 (IPEX/QNN 연계 검증 필요) GitHub·Hugging Face에서 확인할 것 optimum/intel 저장소: xpu 관련 milestone 및 release notes 확인 (https://github.com/huggingface/optimum-intel) PyTorch XPU 이슈: pytorch/pytorch 라벨 xpu 관련 이슈 검색 (https://github.com/pytorch/pytorch/issues?q=xpu+is%3Aissue) Arc GPU 호환성 이슈: intel/opencl 또는 PyTorch 커뮤니티 포럼 스레드 확인 설치·실행 신뢰성 Driver: Intel 그래픽 드라이버 버전 27.21.10.xx 이상 권장 (Arc GPU용). 미준수 시 PyTorch XPU/init 실패 가능성.
