[LLM] Ollama 로컬 설치 — Windows에서 모델 내려받고 바로 쓰기

왜 로컬 LLM인가 API 비용, 프라이버시, 응답 속도. 이 세 가지가 로컬 LLM을 선택하는 이유다. Ollama는 이 세 가지를 가장 낮은 진입 장벽으로 해결한다. 준비물 항목 최소 사양 RAM 8 GB (4b 모델 기준) VRAM 4 GB (GPU 가속 시) 디스크 모델 크기 × 2 여유 OS Windows 10 22H2 이상 설치 # 1. Ollama 공식 설치 # https://ollama.com/download 에서 Windows 버전 다운로드 후 실행 # 2. 설치 확인 ollama --version # 3. 서버 실행 (백그라운드) ollama serve 모델 내려받기 # 가벼운 4B 모델 (추천 시작점) ollama pull qwen3:4b-instruct # 좀 더 나은 품질 ollama pull gemma3:4b # 고품질 (24B — 16GB RAM 이상) ollama pull mistral:24b GPU 가속 확인 ollama run qwen3:4b-instruct "GPU 사용 중인가?" # 응답 속도로 GPU 가속 여부 체감 가능 Intel Arc GPU의 경우 별도 설정이 필요할 수 있다. → PyRecipe 를 사용하면 환경별 최적 패키지를 자동 추천해준다. ...
