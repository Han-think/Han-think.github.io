1. 엔티티와 관계 이해하기#

왜 이걸 보게 됐나#

데이터베이스 설계 과정에서 엔티티-관계 다이어그램(ERD)의 구조와 Crow’s Foot 표기법을 정확히 이해하지 못하면 설계의 정확성과 효율성이 저하될 수 있다는 것을 깨달았습니다. 특히 복잡한 관계를 표현하는 데 어려움이 있어 이 주제에 집중하게 되었습니다.

내가 헷갈렸던 지점#

  • 엔티티와 관계의 구체적인 표현 방식: 엔티티 간의 관계를 단순히 직관적으로 이해하기보다는 정확한 표기법이 필요하다는 점을 깨달았습니다.
  • 카디널리티의 다양한 표기법: 여러 관계 유형을 표시하는 Crow’s Foot 표기법의 각 기호 의미를 명확히 이해하는 것이 어려웠습니다.

시도한 코드 / 예시#

다음은 간단한 ERD 예시를 통해 관계를 표현한 사례입니다:

-- 예시 데이터베이스 테이블 정의
CREATE TABLE Users (
    UserID INT PRIMARY KEY,
    Username VARCHAR(50)
);

CREATE TABLE Orders (
    OrderID INT PRIMARY KEY,
    UserID INT,
    FOREIGN KEY (UserID) REFERENCES Users(UserID)
);

-- Crow's Foot 표기법 적용 예시
Users --(O)--> Orders --(1)--> OrderItems

결과와 해석#

시도한 예시를 통해 다음과 같은 이해를 얻었습니다:

  • 일대다 관계 (1:N): Users 테이블에서 여러 Orders가 생성될 수 있음을 명확히 표현할 수 있었습니다.
  • Crow’s Foot 기호 이해: O는 선택적 연결을 의미하며, 여러 Orders가 한 User에 연결될 수 있음을 보여주었습니다.
