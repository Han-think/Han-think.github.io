왜 이걸 보게 됐나#

파이썬의 기본 문법과 데이터 처리 기능을 이해함으로써 코드 작성 능력을 향상시키고 싶었습니다. 함수, 데이터 포맷팅, 정확한 수치 계산 등 기본적인 기술을 확실히 다지는 것이 향후 복잡한 프로젝트를 위한 토대가 될 것으로 생각했습니다.

내가 헷갈린 지점#

오전 세션에서 파이썬의 다양한 내장 함수와 특수 문자열 포맷팅 기법을 학습하면서, 실제 코드에서 어떻게 적절히 활용할지에 대한 명확한 연결성이 부족했습니다. 특히 float와 Decimal의 차이와 적절한 사용 시점에 대해 혼란스러웠습니다.

시도한 코드 / 예시#

  • 데이터 정렬 및 출력 예시: 
    data = [3.1415, 2.7182]
sorted_data = sorted(data, key=lambda x: round(x, 2))
for index, value in enumerate(sorted_data, start=1):
    print(f"{index}: {value:.2f}")  # 출력: 1: 2.72, 2: 3.14
  • lambda 함수 활용 예시: 
    multiplier = lambda x: x * 2
print(multiplier(5))  # 출력: 10

결과와 해석#

코드 예시를 통해 데이터 처리와 간단한 함수 생성의 필요성을 체감했습니다. 특히 f-string을 이용한 포맷팅은 가독성을 크게 향상시켰습니다. float과 Decimal의 차이는 정확한 수치 계산이 필요한 상황에서 중요한 고려사항임을 확인했습니다.
