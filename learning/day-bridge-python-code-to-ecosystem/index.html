1. 함수 활용#

왜 이걸 보게 됐나#

데이터를 효율적으로 처리하고 코드를 재사용 가능하게 만들기 위해 함수 활용을 배우게 됐어. 함수를 사용하면 반복되는 작업을 줄이고, 코드를 더 깔끔하고 이해하기 쉽게 만들 수 있어서, 프로젝트 규모가 커질수록 필수적인 기술이라고 생각했어. 특히 복잡한 데이터 분석이나 웹 애플리케이션 개발에서는 함수의 중요도가 더욱 커지는 것 같아.

내가 헷갈린 지점#

처음에는 함수가 단순히 코드 블록을 묶는 역할만 하는 줄 알았습니다. 하지만 함수를 활용해서 코드를 재사용하고, 복잡한 작업을 더 작고 관리하기 쉬운 부분으로 나누는 것을 이해하는 데 시간이 걸렸습니다. 특히 lambda 함수는 익명 함수라는 개념이 생소해서, 어떤 상황에서 사용해야 하는지 파악하는 데 어려움을 겪었습니다.

시도한 코드 / 예시#

data = [3.1415, 2.7182]
sorted_data = sorted(data, key=lambda x: round(x, 2))
for index, value in enumerate(sorted_data, start=1):
    print(f"{index}: {value:.2f}")

결과와 해석#

함수를 활용하면 코드를 더 효율적으로 만들 수 있고, 재사용성도 높아져서 반복되는 작업을 줄일 수 있어 좋았습니다. 예를 들어 데이터 리스트를 정렬하고 포맷팅할 때, lambda 함수를 사용하여 정렬 기준을 정의하고 enumerate를 사용해서 인덱스와 값을 함께 출력하는 코드를 작성해 봤습니다. 이러한 방법은 데이터 분석 과정에서 유용하게 활용될 것 같습니다.

정리된 이해#

함수 활용은 코드의 재사용성을 높이고 복잡한 작업을 단순화하는 데 핵심적인 역할을 하며, 데이터 처리 과정을 효율적으로 만들어줍니다. 특히, lambda 함수를 활용하면 간단한 기능을 익명으로 만들어 코드를 더욱 간결하게 만들 수 있습니다. 이처럼 함수를 효과적으로 사용하면 가독성이 좋고 유지보수가 용이한 코드를 작성할 수 있습니다.

2. 라이브러리 관리#

왜 이걸 보게 됐나#

혼자서 파이썬 코드를 작성하는 것만으로는 더 복잡하고 실용적인 프로젝트를 진행하기 어렵다는 것을 깨달았습니다. 다른 사람의 코드를 가져와서 함께 사용하거나, 내가 만든 코드를 다른 환경에서도 동일하게 실행할 수 있도록 의존성을 관리하는 방법이 필요했습니다. 가상 환경과 라이브러리 관리 도구를 사용하면 이러한 문제들을 해결하고, 프로젝트의 안정성과 재사용성을 높일 수 있습니다.

내가 헷갈린 지점#

처음에는 라이브러리 관리라는 것이 왜 필요한지, 그리고 venv나 pip가 단순히 코드를 더 복잡하게 만드는 도구처럼 느껴졌습니다. 특히 requirements.txt 파일이 어떤 역할을 하는지, 왜 프로젝트의 의존성을 기록해야 하는지 이해하는 데 어려움이 있었습니다. 프로젝트를 다른 환경에서 실행할 때 어떤 문제가 발생할 수 있는지, 그리고 이러한 도구들이 그 문제를 해결하는 방법이 명확하지 않았습니다.

시도한 코드 / 예시#

# 가상 환경 설정 및 라이브러리 설치 예시:
# 가상 환경 생성
# python -m venv myenv
# 가상 환경 활성화
# source myenv/bin/activate  # Linux/Mac
# myenv\Scripts\activate     # Windows
# 라이브러리 설치
# pip install streamlit
# requirements 파일 생성
# pip freeze > requirements.txt

결과와 해석#

라이브러리 관리는 프로젝트별로 필요한 패키지를 독립적으로 설치하고 관리할 수 있도록 해줘서, 다른 프로젝트에 영향을 주지 않고 특정 버전의 패키지를 사용하게 해줍니다. venv와 pip를 사용하면 이러한 환경을 쉽게 만들고 패키지를 설치할 수 있으며, requirements.txt 파일은 프로젝트에 필요한 모든 패키지와 버전을 기록하여 협업이나 재구현을 용이하게 합니다. 이를 통해 프로젝트의 일관성과 유지보수성을 높일 수 있습니다.

정리된 이해#

라이브러리 관리는 프로젝트별로 필요한 외부 코드를 깔끔하게 관리하고, 다른 환경에서도 동일하게 실행될 수 있도록 의존성을 기록하는 작업이야. venv와 pip를 사용하면 프로젝트 환경을 격리하고 필요한 라이브러리를 쉽게 설치/관리할 수 있으며, requirements.txt는 이러한 의존성을 문서화하여 유지보수를 용이하게 해줘.

3. 의존성 관리#

왜 이걸 보게 됐나#

프로젝트를 진행하다 보면 여러 외부 라이브러리를 사용하게 되는데, 이 라이브러리들의 버전이 충돌하거나 다른 프로젝트에 영향을 줄 수 있어서, 각각의 프로젝트를 독립적으로 관리할 필요성이 생겼습니다. 의존성 관리 도구를 사용하면 어떤 라이브러리를 어떤 버전으로 사용할지 기록하고, 다른 개발자가 동일한 환경을 쉽게 구축할 수 있도록 도와줍니다. 결국, 프로젝트의 일관성과 재현성을 확보하고 협업을 원활하게 하기 위해 의존성 관리 개념을 배우게 되었습니다.

내가 헷갈린 지점#

처음에는 requirements.txt 파일이 단순히 설치된 라이브러리의 목록이라고 생각했지만, 실제로는 프로젝트의 재현 가능성을 보장하는 중요한 역할, 즉 다른 환경에서도 동일한 버전을 유지하여 코드가 실행될 수 있도록 하는 요소라는 것을 알게 되었습니다. 의존성 관리 자체를 단순히 라이브러리를 설치하는 것 이상으로, 프로젝트의 일관성과 안정성을 위한 필수적인 절차라는 것을 깨달았습니다. 또한, 이 파일이 버전 정보까지 포함하는 이유가, 라이브러리 버전에 따라 코드 동작이 달라질 수 있기 때문이라는 점이 신기했습니다.

시도한 코드 / 예시#

# requirements 파일 생성
# pip freeze > requirements.txt
# 실제 파일 내용은 다음과 같을 수 있다:
# streamlit==1.25.0
# numpy==1.24.3
# pandas==2.0.3

결과와 해석#

requirements.txt 파일은 현재 가상 환경에 설치된 모든 라이브러리와 버전을 기록하는 목록인데, 다른 사람이나 다른 환경에서도 동일한 프로젝트를 실행할 때 필요한 라이브러리들을 쉽게 설치할 수 있도록 도와주는 역할을 합니다. 이를 통해 프로젝트의 의존성을 명시하고, 개발 환경의 일관성을 유지할 수 있어서 유지보수성을 높일 수 있습니다. 예를 들어, pip install -r requirements.txt 명령어를 사용하면 이 파일에 명시된 라이브러리들을 한 번에 설치할 수 있습니다.

정리된 이해#

프로젝트에서 사용되는 외부 라이브러리를 requirements.txt 파일에 기록하고, 가상환경을 통해 프로젝트별로 독립적인 환경을 만들어 서로 충돌하지 않도록 관리하는 것을 의미합니다. 이를 통해 프로젝트의 안정성을 높이고, 다른 개발자와 협업할 때 동일한 개발 환경을 유지할 수 있습니다.

4. f-string 포매팅#

왜 이걸 보게 됐나#

기존의 % 포매팅이나 .format() 방식보다 훨씬 직관적이고 가독성이 좋아서, 코드를 읽는 사람이 더 쉽게 이해할 수 있도록 하기 위해 f-string 포매팅을 배우게 됐어. 특히 변수 값을 문자열 안에 직접 삽입해야 하는 상황에서, 코드의 가독성을 높이고 간결하게 만들 수 있다는 장점이 커서 중요하게 다뤄졌어. 복잡한 문자열을 만들 때도 훨씬 효율적으로 작업할 수 있게 해주는 유용한 기능이야.

내가 헷갈린 지점#

처음에는 f-string이 문자열 안에 변수를 넣는 방법 정도로만 생각했는데, 실제로 코드를 작성하면서 데이터 타입에 따른 자동 변환이나 복잡한 포맷팅 옵션을 활용할 수 있다는 점이 놀라웠어. 특히, 소수점 자릿수를 지정하거나 정렬하는 기능은 예상하지 못했던 부분이라서, 예제를 통해 익혀야겠다고 생각했어. :.2f 같은 문법이 처음에는 생소했지만, 활용법을 알게 되니 코드 가독성이 훨씬 좋아지는 것을 느꼈어.

시도한 코드 / 예시#

data = [3.1415, 2.7182]
sorted_data = sorted(data, key=lambda x: round(x, 2))
for index, value in enumerate(sorted_data, start=1):
    print(f"{index}: {value:.2f}")

결과와 해석#

f-string 포매팅은 변수를 문자열 안에 직접 넣어 출력하는 편리한 방법인데, 예를 들어 f"{index}: {value:.2f}" 처럼 변수와 값을 결합하고 소수점 자리수를 지정할 수 있어서 출력 형식을 자유롭게 제어할 수 있습니다. 이 방식을 사용하면 print 함수에서 별도의 문자열 포맷팅 작업을 줄여 코드를 간결하게 만들 수 있습니다. 특히 value:.2f처럼 값을 포맷팅하여 소수점 둘째 자리까지만 표시할 때 유용합니다.

정리된 이해#

f-string 포매팅은 변수를 문자열 안에 직접 삽입하여 가독성 좋고 효율적인 문자열을 만들 수 있는 파이썬의 강력한 기능이야. 특히 출력 형식을 지정하여 데이터의 정확성을 확보하고, 템플릿처럼 활용할 수 있어 다양한 상황에서 유용하게 사용할 수 있어. 예를 들어, 숫자 값을 특정 소수점 자리수로 맞춰서 출력하거나, 리스트의 항목을 템플릿 문자열에 넣어 깔끔하게 보여줄 수 있어.

총평#

오늘 전체에서 배운 것#

파이썬 코드 작성 능력 향상과 함께, 외부 라이브러리 활용을 위한 가상환경 설정 및 의존성 관리의 중요성을 알게 되었습니다. 특히 requirements.txt 파일을 통해 프로젝트의 재현성을 확보하는 방법을 익혔습니다.

가상 환경 설정과 라이브러리 설치 과정을 좀 더 자주 반복해서 직접 해봐야겠어. requirements.txt 파일의 역할과 실제 프로젝트에서 어떻게 활용되는지 구체적인 예제를 찾아봐야 할 것 같아.

다음 복습 주제#

Streamlit을 활용한 간단한 웹 앱 개발 실습을 통해 실제 활용 방안을 익혀보고 싶다. requirements.txt 파일의 역할과 버전 관리가 프로젝트 유지보수에 어떤 영향을 미치는지 자세히 알아봐야겠다. venv를 사용하는 이유와 장점을 좀 더 명확하게 이해하고 다양한 시나리오에서 어떻게 활용되는지 확인하고 싶다.
