1. 다운로드 진행률 시뮬레이션: 타이머 활용 핵심 원리#

무엇을 배웠나#

setInterval과 clearInterval을 사용하여 다운로드 진행률을 시뮬레이션하는 코드를 이해하는 데 어려움을 겪었지만, 각 단계별 역할을 분리하여 학습하면서 타이머 관련 함수들의 연동 방식을 파악할 수 있었다. 특히 setInterval 함수의 반복 실행과 clearInterval으로 타이머를 멈추는 과정을 명확히 이해하게 되었고, 템플릿 리터럴 사용법과 오타 수정의 중요성도 깨달았다. 이 과정을 통해 웹 개발에서 타이머를 활용하는 기본적인 원리를 익힐 수 있었다.

헷갈렸던 점#

타이머 함수들이 어떻게 연결되는지, 특히 setInterval과 setTimeout의 역할이 명확하지 않았습니다. 또한, per++를 통해 진행률 값을 증가시켜야 한다는 점을 간과하여 코드가 제대로 동작하지 않았고, 템플릿 리터럴 사용법도 헷갈려서 변수값이 제대로 표시되지 않았습니다.

정리된 이해#

다운로드 진행률 시뮬레이션은 setInterval을 사용하여 주기적으로 진행률을 증가시키고, clearInterval로 타이머를 멈추는 방식으로 구현됩니다. setTimeout은 시뮬레이션 시작을 위한 약간의 지연 시간을 주는 역할을 하며, 템플릿 리터럴을 사용하여 변수 값을 화면에 정확하게 표시하는 것이 중요합니다. 이 과정을 통해 setInterval, setTimeout, clearInterval 함수의 역할과 사용법을 익힐 수 있었습니다.

let per = 0;
let time = null;

function download() {
  time = setInterval(function() {
    per++;
    progress.value = per;
    h1.innerHTML = `${per}%`;

    if (per >= 100) {
      clearInterval(time);
      h1.innerHTML = "다운로드 완료!";
    }
  }, 1000);
}

2. 이벤트 위임으로 색상 팔레트 상호작용 구현하기#

무엇을 배웠나#

이벤트 위임을 통해 부모 요소에 이벤트 리스너를 등록하고, 자식 요소에서 발생하는 이벤트가 부모 핸들러를 통해 처리될 수 있다는 것을 알게 되었습니다. evt.target을 활용하면 어떤 요소에서 이벤트가 발생했는지 파악하고, 그에 따라 필요한 동작을 수행할 수 있습니다. 또한, 변수 이름의 중요성을 깨닫고, 일관성 있는 작명을 통해 오류를 방지해야 함을 배웠습니다.

헷갈렸던 점#

처음에는 각 색상 div마다 mouseover 이벤트를 등록해야 해서 코드가 복잡해 보였고, evt.target이 정확히 무엇을 의미하는지 바로 이해하기 어려웠습니다. 또한 변수 이름을 제대로 지어서 사용하지 않아 예상치 못한 오류가 발생하기도 했습니다.

정리된 이해#

이벤트 위임을 사용하면 여러 자식 요소에 대해 반복적으로 이벤트 등록을 할 필요 없이 부모 요소에 한 번만 이벤트 핸들러를 등록하여 효율적으로 상호작용을 처리할 수 있다는 것을 알게 되었습니다. evt.target 속성을 통해 이벤트가 발생한 정확한 요소를 확인하고, 이를 기반으로 다양한 작업을 수행할 수 있습니다. 변수 이름의 일관성 또한 코드를 이해하고 오류를 방지하는데 중요합니다.

3. 카 레이싱 실습, 도착 조건 코드 정의 및 이해#

무엇을 배웠나#

카 레이싱 실습에서 게임 종료 조건을 코드로 명확하게 정의하는 방법을 익혔다. 도착 지점 위치, 차량 이동량, 타이머 주기 등을 변수로 설정하고, 조건문으로 종료 조건을 구현하는 방법을 이해했다. 실습 설명에 명시되지 않은 세부 사항들을 스스로 정의하고 코드로 반영하는 과정에서 문제 해결 능력을 키울 수 있었다.

헷갈렸던 점#

실습 설명이 너무 추상적이라, 차량의 정확한 위치나 이동량, 타이머 주기 같은 중요한 정보가 명확하게 주어지지 않았어요. 그래서 어떤 값을 넣어야 코드가 제대로 작동할지, 그리고 도착했을 때 어떻게 초기화해야 할지 감이 잘 안 잡혔습니다. 결과적으로 기본 구조 요소를 이해하고 예시 코드를 통해 좀 더 명확하게 정의할 수 있었습니다.

정리된 이해#

카 레이싱 실습에서 도착 조건을 코드로 정의하려면 차량의 초기 위치, 이동량, 반복 주기, 도착 지점, 그리고 종료 조건을 명확히 설정해야 합니다. setInterval 함수를 사용하여 주기적으로 차량의 위치를 업데이트하고, 차량의 왼쪽 위치가 도착 지점의 픽셀 값을 넘어서면 타이머를 중지시켜 종료 조건을 만족시키면 됩니다. 예시 코드를 통해 이러한 요소들을 결합하여 작동하는 레이싱 게임을 구현할 수 있습니다.

4. ES6 변수 선언과 스코프 체인 완벽 이해#

무엇을 배웠나#

ES6 변수 선언 방식인 let과 const의 차이점을 명확히 이해하게 되었고, 재할당 가능성 및 초기화 시점에 대한 혼란을 해결했습니다. 스코프 체인을 통해 변수 검색 순서를 파악하며, 코드에서 변수들이 어떻게 값을 가져오는지 추적하는 능력이 향상되었습니다. 마지막으로, 코드 작성 시 오타로 인한 오류를 방지하는 작은 실수를 줄이는 방법도 배웠습니다.

헷갈렸던 점#

var, let, const의 차이점을 명확히 구분하지 못했고, 특히 let과 const가 초기화 시점과 재할당 가능성에 어떤 차이가 있는지 헷갈렸습니다. 함수 내에서 변수를 선언할 때 스코프 체인이 어떻게 작동하는지 시각적으로 따라가기가 어려웠고, 변수 이름 오타로 인한 오류를 잡아내는 데 시간이 오래 걸렸습니다.

정리된 이해#

let은 값을 변경할 수 있는 변수, const는 초기화 후 변경 불가능한 상수를 선언할 때 사용하며, 변수를 찾을 때는 현재 스코프부터 시작하여 외부 스코프를 거슬러 올라가면서 전역 스코프까지 탐색하는 Scope Chain을 이해하는 것이 중요하다. 변수 이름 겹침 현상에서는 먼저 선언된 변수가 우선적으로 참조된다는 점을 기억해야 하며, 코드 작성 시 오타를 주의해야 한다.

  const global = 10;

  function outerFunc() {
      const global = 20;  // 외부 스코프의 global과 이름이 겹치지만 다른 변수
      const local1 = 10;

      console.log('=== 함수 밖 ===');
      console.log(global);  // 10 (전역 변수)

      console.log('=== OUTER FUNCTION ===');
      console.log(global);  // 20 (내부 스코프 변수)

다음에 조심할 것#
