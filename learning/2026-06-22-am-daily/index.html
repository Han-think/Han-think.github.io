2. Pandas loc 필터링: 초보자를 위한 완벽 이해#

무엇을 배웠나#

Pandas의 loc를 사용한 조건 필터링을 할 때, filtered 변수는 데이터프레임을 임시 저장하는 일반적인 변수라는 것을 이해하게 되었고, 줄바꿈 후 바로 함수를 사용하면 문법 오류가 발생할 수 있다는 점을 알게 되었다. 특히 Fare 컬럼이 승객 요금 정보를 담고 있으며, 평균을 계산하려면 .mean() 함수를 사용해야 한다는 점을 명확히 알게 되었다. 이 내용을 바탕으로 loc를 활용한 데이터 필터링 실습을 진행할 수 있을 것 같다.

헷갈렸던 점#

loc을 사용할 때 SyntaxError가 나서 정확한 문법이 무엇인지 파악하는 데 시간이 걸렸고, 임시 변수 filtered가 특별한 pandas 기능인지 몰라서 혼란스러웠습니다. 또한 Fare 컬럼이 정확히 어떤 정보를 담고 있는지 명확하게 이해하지 못해서 데이터 분석 과정에서 오류가 발생하기도 했습니다.

정리된 이해#

filtered 변수는 단순히 loc를 사용하여 조건에 맞는 데이터프레임을 임시로 저장하는 변수일 뿐이며, 특별한 기능은 없습니다. Fare 컬럼은 데이터프레임 내에서 요금 정보를 담고 있는 컬럼이고, 평균을 구하려면 .mean() 함수를 사용해야 합니다. 이제 loc 조건 필터링과 임시 변수의 역할을 좀 더 명확하게 이해하게 되었습니다.

import pandas as pd

# 예시 데이터프레임 생성
data = {
    "Survived": [0, 1, 1, 0, 1],
    "Name": ["Alice", "Bob", "Charlie", "David", "Eve"],
    "Sex": ["female", "male", "male", "male", "female"],
    "Age": [25, 35, 22, 40, 30],
    "Pclass": [1, 3, 1, 3, 2],
    "Fare": [71.2833, 7.9250, 71.2833, 7.8952, 53.1000]
}
df = pd.DataFrame(data)

# 생존자 정보 필터링 및 정렬
filtered = df.loc[df["Survived"] == 1].sort_values("Age")
print(filtered["Fare"])
print(filtered["Fare"].mean())

3. 대용량 데이터 처리, 벡터화 기법 활용 가이드#

무엇을 배웠나#

대용량 데이터 처리 시 for 문 사용의 비효율성을 깨닫고, 벡터화 기법인 np.where()와 조건 기반 불리언 시리즈 활용의 중요성을 알게 되었다. 특히, 개별 값에 적용하는 apply()와 전체 컬럼을 처리하는 벡터화 방식의 성능 차이를 명확히 이해하게 되었고, 앞으로는 성능을 고려하여 코드를 작성해야 함을 알게 되었다. 불리언 시리즈를 직접 새 컬럼으로 활용하는 방법도 새롭게 배울 수 있었다.

헷갈렸던 점#

처음에는 pandas에서 for 문을 사용하는 것이 직관적이고 이해하기 쉬웠는데, 대용량 데이터를 처리할 때 얼마나 비효율적인지 몰랐습니다. 특히, lambda 함수나 np.where 같은 벡터화 기법이 전체 컬럼에 어떻게 적용되는지, 그리고 왜 반복문보다 빠른지 감이 잘 오지 않았습니다. 개별 값에 대한 apply와 전체 컬럼을 처리하는 벡터화 방법의 차이도 명확하게 이해하지 못했습니다.

정리된 이해#

대용량 데이터 처리 시 for 문 대신 벡터화 기법을 사용하는 것이 중요하며, np.where()와 같이 컬럼 전체를 한 번에 처리하는 방식이 효율적이다. lambda 함수와 apply()는 개별 값에 대한 조건 적용에 유용하지만, 전체 컬럼을 처리할 때는 벡터화 기법이 성능 면에서 훨씬 유리하며, 조건식 결과를 바로 새로운 컬럼으로 활용하는 방법도 존재한다. 앞으로는 코드의 가독성뿐만 아니라 성능까지 고려하여 데이터 처리 방식을 선택해야겠다.

df["HighFare"] = np.where(df["Fare"] > 50, True, False)

df["HighFare"] = df["Fare"].apply(lambda x: True if x > 50 else False)

df["HighFare"] = df["Fare"] > 50

4. 통계 가설 검정, 귀무가설부터 p-value까지 완벽 이해#

무엇을 배웠나#

통계 가설 검정에서 귀무가설은 절대적인 진리가 아니라 “아무 변화가 없다"는 상대적인 기준선이라는 것을 깨달았습니다. 특히 p-value와 유의수준을 통해 귀무가설 기각 여부를 판단하는 방식에 대한 이해도가 높아졌습니다. 독립표본 t-검정과 같이 두 그룹 간의 관계를 검증하는 경우 귀무가설의 유연성을 고려해야 한다는 점을 명확히 알게 되었습니다.

헷갈렸던 점#

귀무가설을 고정된 절대 진리처럼 생각해서 통계 검정의 유연성을 제대로 이해하지 못했고, 특히 독립표본 t-검정에서 두 그룹 간의 관계를 나타내는 귀무가설의 의미를 파악하는 데 어려움을 겪었습니다. p-value와 유의수준의 관계를 명확히 이해하지 못해 귀무가설 기각 여부를 판단하는 데 어려움이 있었습니다.

정리된 이해#

통계 가설 검정에서 귀무가설은 단순히 고정된 절대 기준이 아니라, ‘아무런 효과나 변화가 없다’는 가정을 나타내는 상대적인 기준선입니다. p-value는 귀무가설이 참이라고 가정했을 때 관찰된 결과보다 더 극단적인 결과가 나올 확률을 의미하며, 이 값이 설정된 유의수준보다 작으면 귀무가설을 기각할 수 있습니다. 따라서 가설 검정은 귀무가설을 기각할 충분한 증거가 있는지 판단하는 과정입니다.

# 예시: Python을 이용한 단일표본 t-검정
import scipy.stats as stats

# 데이터
data = [85, 90, 92, 88, 95, 89, 91, 87, 93, 90]
mu0 = 92  # 귀무가설의 평균

# t-검정 수행
t_statistic, p_value = stats.ttest_1samp(data, mu0)

print(f"T-statistic: {t_statistic}")
print(f"P-value: {p_value}")

alpha = 0.05
if p_value < alpha:
    print("귀무가설 기각")
else:
    print("귀무가설 채택")

5. 정규분포와 중심극한정리, 모수/비모수검정 이해하기#

무엇을 배웠나#

데이터가 많다고 해서 원본 데이터 자체가 정규분포를 따르는 것이 아니고, 표본 평균의 분포가 정규분포에 가까워지는 중심극한정리의 개념을 제대로 이해해야 한다는 것을 알게 되었다. 또한 모수검정과 비모수검정은 단순히 절대적/상대적 지표의 차이가 아니라, 분포의 특성에 대한 가정이 다른 검정 방법임을 명확히 했다. 이제 데이터 분석 시 데이터의 분포와 표본 크기를 고려하여 적절한 검정 방법을 선택해야 할 것 같다.

헷갈렸던 점#

데이터가 많으면 자동으로 정규분포를 따른다고 생각했고, 모수검정과 비모수검정을 단순히 ‘절대적인 것’과 ‘상대적인 것’으로 구분해서 이해하고 있었어. 이 때문에 실제 데이터 분석에서 어떤 검정 방법을 선택해야 할지 혼란스러웠던 부분이 있었어.

정리된 이해#

데이터가 많다고 해서 원본 데이터 자체가 정규분포를 따르는 건 아니고, 오히려 표본 평균의 분포가 정규분포에 가까워지는 게 중심극한정리의 핵심 내용이다. 모수검정은 평균이나 분산과 같은 모수를 가정하고 검정하는 방식이고, 비모수검정은 이러한 가정이 필요 없을 때 데이터의 순위를 활용한다. 이제 데이터의 특성과 검정 목적에 맞게 적절한 검정 방법을 선택할 수 있을 것 같다.

6. 독립표본 t검정: 가정 확인 및 혼란 해결 가이드#

무엇을 배웠나#

독립표본 t검정의 가정 확인이 단순히 ‘3가지 확인 사항’이 아니라, 검정의 신뢰도를 높이기 위한 필수적인 사전 검사라는 점을 명확히 알게 되었다. 특히 각 검정의 귀무가설이 다르고, Shapiro-Wilk 검정과 Levene 검정을 통해 정규성과 분산 동질성을 어떻게 검증하는지 이해하게 되었다. 이를 통해 데이터 분석 결과의 정확성을 높이는 데 필요한 부분을 학습했다.

헷갈렸던 점#

t검정 가정 확인이 정확히 뭘 의미하는지, 그리고 각 검정마다 귀무가설이 왜 다른지 처음에는 잘 몰랐습니다. 특히 정규성 검정과 t검정의 귀무가설이 다르다는 점이 헷갈렸고, 각 가정의 중요성을 명확히 이해하지 못했습니다. 독립표본 t검정을 수행하기 전에 데이터를 꼼꼼히 확인해야 한다는 점을 다시 한번 강조해야겠습니다.

정리된 이해#

독립표본 t검정은 데이터가 특정 조건을 만족해야 제대로 된 결과를 얻을 수 있는데, 이 조건들을 확인하는 사전 검사가 필요하다는 점을 알게 되었다. 각 검정마다 귀무가설이 다르지만, 결국 t검정은 데이터의 특성을 정확히 파악하고 검정 전후에 적절한 가정을 확인하는 과정이 중요하다는 것을 깨달았다. 특히 Shapiro-Wilk 검정이나 Levene 검정과 같은 도구를 사용하여 가정을 확인하는 방법을 익혀야겠다.

from scipy import stats
stat, p = stats.shapiro(sample_data)
print('Statistics=%.3f, p=%.3f' % (stat, p))

stat, p = stats.levene(group1, group2)
print('Statistic=%.3f, p=%.3f' % (stat, p))
