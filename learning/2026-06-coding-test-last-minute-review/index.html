Python 기본 문법#

입력값과 비교#

input()의 결과는 항상 문자열이다. 숫자 계산이 필요하면 먼저 int() 또는 float()로 변환한다. =는 값을 저장하는 대입 연산자이고, ==는 두 값이 같은지 확인하는 비교 연산자다.

count = int(input())

if count == 0:
    print("비어 있음")
elif count < 10:
    print("10개 미만")
else:
    print("10개 이상")

반복문과 함수#

range(start, stop)에서 stop은 포함되지 않는다. while문은 조건에 쓰인 값이 반복 중에 변하지 않으면 무한 반복이 될 수 있다. 함수가 계산 결과를 바깥에서 사용하게 하려면 return이 필요하며, 반환문이 없으면 결과는 None이다.

def total_until(stop):
    total = 0
    for number in range(1, stop + 1):
        total += number
    return total

문자열과 리스트는 모두 인덱스로 접근할 수 있지만 수정 가능 여부가 다르다. 문자열은 불변이고, 리스트는 append, insert, remove, sort 등으로 직접 변경할 수 있다.

pandas, NumPy, 시각화#

데이터 확인과 필터링#

데이터를 받으면 바로 복잡한 연산을 시작하지 않고 head(), info(), describe(), shape로 구조와 결측치, 자료형을 먼저 확인한다. pandas에서 여러 조건을 결합할 때는 and, or가 아니라 &, |를 사용하고 각 조건을 괄호로 감싼다.

import pandas as pd

df = pd.read_csv("data.csv")
selected = df.loc[(df["score"] >= 80) & (df["status"] == "active")]
summary = selected.groupby("team")["score"].mean()

loc는 행과 열을 이름 기반으로 선택할 때 유용하다. 값 치환에는 map, 행 단위 규칙 적용에는 apply와 lambda, 테이블 결합에는 merge를 사용할 수 있다. 다만 apply는 편리함만 보고 남용하기보다 벡터화 연산으로 풀 수 있는지 먼저 살펴보는 편이 좋다.

NumPy와 그래프 선택#

NumPy에서는 shape, dtype, reshape로 배열의 구조를 확인하고 바꾼다. 대표값은 mean, median, percentile을 상황에 맞게 구분한다.

Linux 명령어#

현재 위치는 pwd, 목록은 ls, 이동은 cd로 확인한다. 파일과 디렉터리를 다루는 명령은 mkdir, touch, cp, mv, rm이며, 삭제 명령은 휴지통을 거치지 않을 수 있으므로 대상 경로를 먼저 확인해야 한다.

pwd
ls -la
find . -name "*.py"
grep -in "error" app.log

권한에서 r=4, w=2, x=1이다. 644는 소유자만 쓰고 나머지는 읽는 일반 파일에, 755는 소유자가 수정하고 모두가 실행하는 디렉터리나 실행 파일에 자주 쓰인다. 777은 모든 사용자에게 모든 권한을 주므로 편의상 습관적으로 사용하면 안 된다.

>는 출력을 새로 쓰고, >>는 뒤에 추가하며, 2>는 오류 출력을 보낸다. 파이프 |는 앞 명령의 출력을 다음 명령의 입력으로 연결한다.

grep -i "warning" app.log | sort | uniq -c

SQL 핵심 문법#

조회와 그룹 집계#

WHERE는 그룹을 만들기 전의 행을 거르고, HAVING은 GROUP BY로 집계한 뒤의 그룹을 거른다. 별칭과 정렬 방향, 제한 행 수까지 한 번에 읽는 연습이 필요하다.

SELECT department, COUNT(*) AS employee_count
FROM employees
WHERE active = 1
GROUP BY department
HAVING COUNT(*) >= 5
ORDER BY employee_count DESC;

INNER JOIN은 양쪽에 일치하는 행만, LEFT JOIN은 왼쪽 테이블의 모든 행을 남긴다. 서브쿼리는 한 쿼리의 결과를 다른 쿼리의 조건이나 데이터 원천으로 사용한다.

윈도우 함수와 변경 쿼리#

윈도우 함수는 행을 한 줄로 축약하지 않고 순위, 이전 값, 구간 등을 계산한다. ROW_NUMBER, RANK, DENSE_RANK는 동점 처리 방식이 다르고, LAG, LEAD는 이전·다음 행을 비교할 때 유용하다.

SELECT customer_id,
       order_date,
       amount,
       LAG(amount) OVER (
           PARTITION BY customer_id
           ORDER BY order_date
       ) AS previous_amount
FROM orders;

UPDATE와 DELETE에서 WHERE를 빠뜨리면 전체 행이 영향을 받는다. 변경 전에 같은 조건의 SELECT로 대상 행을 확인하는 습관이 중요하다. 기본키, 외래키, NOT NULL, UNIQUE 같은 제약조건은 데이터가 잘못 들어오는 것을 데이터베이스 단계에서 막아준다.

네트워크와 보안#

구분 핵심 차이
TCP / UDP TCP는 연결과 신뢰성을 중시하고, UDP는 단순하고 빠른 전달을 중시한다.
DNS / DHCP DNS는 도메인을 IP 주소로 찾고, DHCP는 장치에 네트워크 설정을 할당한다.
인증 / 인가 인증은 누구인지 확인하고, 인가는 무엇을 할 수 있는지 결정한다.
암호화 / 해시 암호화는 키로 복호화할 수 있고, 해시는 원래 값 복원을 목적으로 하지 않는다.
쿠키 / 세션 / 토큰 쿠키는 브라우저 저장 방식, 세션은 서버 측 상태 관리, 토큰은 요청에 실어 보내는 자격 증명 방식이다.

HTTP 상태 코드는 2xx 성공, 3xx 리다이렉션, 4xx 클라이언트 오류, 5xx 서버 오류로 먼저 묶어 기억한다. 자주 만나는 코드는 200, 201, 400, 401, 403, 404, 500이다. CORS는 브라우저가 서로 다른 출처의 자원 요청을 허용할지 판단하는 정책과 관련된다.

DHCP의 기본 흐름은 Discover, Offer, Request, Acknowledge의 앞글자를 딴 DORA로 정리할 수 있다. JWT는 토큰 형식 중 하나이며, 토큰을 쓴다고 해서 자동으로 안전해지는 것은 아니다. 서명 검증, 만료 시간, 저장 위치를 함께 고려해야 한다.
