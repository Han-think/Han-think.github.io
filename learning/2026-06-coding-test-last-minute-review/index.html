Python 기본 문법#

입력값과 비교#

input()의 결과는 항상 문자열이다. 숫자 계산이 필요하면 먼저 int() 또는 float()로 변환한다. =는 값을 저장하는 대입 연산자이고, ==는 두 값이 같은지 확인하는 비교 연산자다.

count = int(input())

if count == 0:
    print("비어 있음")
elif count < 10:
    print("10개 미만")
else:
    print("10개 이상")

반복문과 함수#

range(start, stop)에서 stop은 포함되지 않는다. while문은 조건에 쓰인 값이 반복 중에 변하지 않으면 무한 반복이 될 수 있다. 함수가 계산 결과를 바깥에서 사용하게 하려면 return이 필요하며, 반환문이 없으면 결과는 None이다.

def total_until(stop):
    total = 0
    for number in range(1, stop + 1):
        total += number
    return total

문자열과 리스트는 모두 인덱스로 접근할 수 있지만 수정 가능 여부가 다르다. 문자열은 불변이고, 리스트는 append, insert, remove, sort 등으로 직접 변경할 수 있다.

데이터 확인과 필터링#

데이터를 받으면 바로 복잡한 연산을 시작하지 않고 head(), info(), describe(), shape로 구조와 결측치, 자료형을 먼저 확인한다. pandas에서 여러 조건을 결합할 때는 and, or가 아니라 &, |를 사용하고 각 조건을 괄호로 감싼다.

import pandas as pd

df = pd.read_csv("data.csv")
selected = df.loc[(df["score"] >= 80) & (df["status"] == "active")]
summary = selected.groupby("team")["score"].mean()

SQL 핵심 문법#

조회와 그룹 집계#

WHERE는 그룹을 만들기 전의 행을 거르고, HAVING은 GROUP BY로 집계한 뒤의 그룹을 거른다. 별칭과 정렬 방향, 제한 행 수까지 한 번에 읽는 연습이 필요하다.

SELECT department, COUNT(*) AS employee_count
FROM employees
WHERE active = 1
GROUP BY department
HAVING COUNT(*) >= 5
ORDER BY employee_count DESC;

INNER JOIN은 양쪽에 일치하는 행만, LEFT JOIN은 왼쪽 테이블의 모든 행을 남긴다. 서브쿼리는 한 쿼리의 결과를 다른 쿼리의 조건이나 데이터 원천으로 사용한다.

윈도우 함수와 변경 쿼리#

윈도우 함수는 행을 한 줄로 축약하지 않고 순위, 이전 값, 구간 등을 계산한다. ROW_NUMBER, RANK, DENSE_RANK는 동점 처리 방식이 다르고, LAG, LEAD는 이전·다음 행을 비교할 때 유용하다.

SELECT customer_id,
       order_date,
       amount,
       LAG(amount) OVER (
           PARTITION BY customer_id
           ORDER BY order_date
       ) AS previous_amount
FROM orders;

UPDATE와 DELETE에서 WHERE를 빠뜨리면 전체 행이 영향을 받는다. 변경 전에 같은 조건의 SELECT로 대상 행을 확인하는 습관이 중요하다. 기본키, 외래키, NOT NULL, UNIQUE 같은 제약조건은 데이터가 잘못 들어오는 것을 데이터베이스 단계에서 막아준다.

네트워크와 보안#

구분 핵심 차이
TCP / UDP TCP는 연결과 신뢰성을 중시하고, UDP는 단순하고 빠른 전달을 중시한다.
DNS / DHCP DNS는 도메인을 IP 주소로 찾고, DHCP는 장치에 네트워크 설정을 할당한다.
인증 / 인가 인증은 누구인지 확인하고, 인가는 무엇을 할 수 있는지 결정한다.
암호화 / 해시 암호화는 키로 복호화할 수 있고, 해시는 원래 값 복원을 목적으로 하지 않는다.
쿠키 / 세션 / 토큰 쿠키는 브라우저 저장 방식, 세션은 서버 측 상태 관리, 토큰은 요청에 실어 보내는 자격 증명 방식이다.

HTTP 상태 코드는 2xx 성공, 3xx 리다이렉션, 4xx 클라이언트 오류, 5xx 서버 오류로 먼저 묶어 기억한다. 자주 만나는 코드는 200, 201, 400, 401, 403, 404, 500이다. CORS는 브라우저가 서로 다른 출처의 자원 요청을 허용할지 판단하는 정책과 관련된다.

DHCP의 기본 흐름은 Discover, Offer, Request, Acknowledge의 앞글자를 딴 DORA로 정리할 수 있다. JWT는 토큰 형식 중 하나이며, 토큰을 쓴다고 해서 자동으로 안전해지는 것은 아니다. 서명 검증, 만료 시간, 저장 위치를 함께 고려해야 한다.

초보자용 문제 풀이 가이드#

문제를 읽고 바로 코드를 쓰려 하면 문장이 길어질수록 막히기 쉽다. 먼저 문제를 입력, 처리, 출력 세 줄로 바꾸면 필요한 문법이 보인다.

예를 들어 “점수를 입력받아 60점 이상이면 합격을 출력하라”는 문제는 다음과 같이 나눈다.

구분 확인할 내용
입력 점수 하나, 정수 변환 필요
처리 60 이상인지 비교
출력 조건에 따라 Pass 또는 Fail 
score = int(input())       # 입력

if score >= 60:           # 처리
    result = "Pass"
else:
    result = "Fail"

print(result)              # 출력

코딩 문제를 푸는 5단계#

  1. 입력값의 개수와 자료형에 밑줄을 긋는다.
  2. 조건, 반복, 집계 중 어떤 작업인지 한 단어로 적는다.
  3. 예상 결과를 손으로 한 번 계산한다.
  4. 가장 단순한 코드부터 실행한 뒤 한 줄씩 추가한다.
  5. 경계값과 빈 값처럼 틀리기 쉬운 경우를 다시 넣어본다.

조건이 이상, 초과, 이하, 미만 중 무엇인지 특히 조심한다. 25 이상은 >= 25, 25 초과는 > 25다. 구간이 여러 개라면 가장 좁거나 큰 조건부터 검사해야 앞 조건이 뒤 조건을 가리지 않는지도 확인한다.

분야별 시작 틀#

Python 기본 문제는 다음 네 줄을 먼저 떠올리면 된다.

value = int(input())  # 1. 입력과 형 변환
result = None         # 2. 결과를 담을 변수
# 3. 조건문, 반복문 또는 함수

pandas 문제는 파일을 읽고 구조를 확인한 뒤, 선택 → 변환 → 집계 순서로 접근한다.

import pandas as pd

df = pd.read_csv("data.csv")
print(df.head())
print(df.shape)
print(df.dtypes)

SQL은 문장에 등장하는 요구를 절에 대응시킨다. “어느 테이블에서”는 FROM, “행 조건”은 WHERE, “무엇별로”는 GROUP BY, “집계 결과 조건”은 HAVING, “어떤 순서”는 ORDER BY다.

SELECT group_column, SUM(value_column)
FROM table_name
WHERE row_condition
GROUP BY group_column
HAVING SUM(value_column) >= 기준값
ORDER BY SUM(value_column) DESC;

1번부터 7번은 Python 기본 문법, 8번부터 19번은 데이터 분석, 20번은 SQL 문제다. 처음에는 각 문제에 10분을 주고, 막히면 풀이 방향에서 함수 이름만 확인한 뒤 다시 작성해보자. 완성 코드를 그대로 외우는 것보다 “왜 이 문법을 골랐는지”를 말할 수 있는지가 더 중요하다.

그래프 공통 순서#

plt.figure(figsize=(7, 4))  # 1. 그림 크기

# 2. 여기에 plot, bar, scatterplot 같은 그래프 함수

plt.title("Graph title")    # 3. 제목
plt.xlabel("X axis")       # 4. x축 이름
plt.ylabel("Y axis")       # 5. y축 이름
plt.tight_layout()          # 6. 글자 잘림 방지

figsize=(7, 4)는 가로 7인치, 세로 4인치 크기다. x와 y에는 열 이름 또는 실제 값을 넣는다. hue는 한 열의 범주에 따라 점의 색을 나눈다. annot=True는 히트맵 칸에 숫자를 표시하고, fmt=".2f"는 소수 둘째 자리까지 보이게 한다.

17번: 월별 매출 선 그래프 완성 예시#

선 그래프를 그리기 전에 월별 매출 합계부터 만들어야 한다.

sales["revenue"] = sales["quantity"] * sales["unit_price"]

monthly = (
    sales.groupby("order_month", as_index=False)["revenue"]
    .sum()
    .sort_values("order_month")
)

plt.figure(figsize=(7, 4))
plt.plot(monthly["order_month"], monthly["revenue"], marker="o")
plt.title("Monthly revenue")
plt.xlabel("Month")
plt.ylabel("Revenue")
plt.grid(alpha=0.3)
plt.tight_layout()
plt.show()

groupby는 같은 월의 행을 묶고, sum은 월별 매출을 더한다. sort_values는 월 순서가 뒤섞이지 않도록 정렬한다. marker="o"는 각 월의 위치를 점으로 보여준다.

  2. 큰 금액 조건부터 비교해야 중간 구간이 가려지지 않는다.
  3. 문자열과 찾을 문자에 lower()를 적용한 뒤 count()를 사용한다.
  4. split("@", 1)로 두 부분을 분리한다.
  5. range(3, n + 1, 3) 또는 나머지 조건을 사용한다.
  6. set으로 중복을 제거한 뒤 sorted()를 적용한다.
  7. price * (1 - rate / 100)을 return한다.
  8. pd.read_csv, head, shape, dtypes를 사용한다.
  9. df["revenue"] = df["quantity"] * df["unit_price"]로 계산한다.
  10. 각 조건을 괄호로 감싸고 &로 연결한다.
  11. 딕셔너리를 전달한 map()을 사용한다.
  12. 조건 함수 또는 apply(lambda ...)로 구간을 나눈다.
  13. pd.merge(..., how="left", on="customer_id")를 사용한다.
  14. groupby와 agg로 합계와 평균을 함께 구한다.
  15. 숫자 열을 선택한 뒤 corr()를 호출한다.
  16. np.mean, np.median, np.percentile(..., 75)를 사용한다.
  17. plt.plot과 title, xlabel, ylabel을 사용한다.
  18. sns.scatterplot(..., hue="channel")을 사용한다.
  19. sns.heatmap(corr, annot=True, fmt=".2f")를 사용한다.
  20. JOIN, WHERE IN, GROUP BY, HAVING, ORDER BY 순서로 구성한다.

객관식 정답#

번호 정답 핵심
1 B int는 정수 변환이며 float는 실수 변환이다.
2 A range의 시작은 포함하고 stop은 제외한다.
3 C print는 화면 출력, return은 호출한 곳으로 값 반환이다.
4 A 파일 하나는 모듈, 모듈을 묶은 디렉터리는 패키지다.
5 B 가상환경은 프로젝트별 Python과 패키지 의존성을 격리한다.
6 C pd는 pandas, np는 NumPy, plt는 pyplot, sns는 Seaborn이다.
7 C pandas Series 조건은 괄호로 묶고 & 또는 `
8 B merge는 키 기반 결합, concat은 축을 따라 이어 붙일 때 주로 쓴다.
9 A 히스토그램은 연속형 값의 구간별 빈도를 보여준다.
10 C NumPy는 관례적으로 np라는 별칭을 사용한다.
11 B pwd는 현재 경로, cd는 이동, ls는 목록 확인이다.
12 A -a는 숨김 파일, -l은 상세 형식이다.
13 D 소유자 숫자 7은 읽기 4, 쓰기 2, 실행 1의 합이다.
14 B >는 덮어쓰기, >>는 추가, 2>는 오류 출력 전환이다.
15 C WHERE는 집계 전 행, HAVING은 집계 후 그룹을 거른다.
16 B LEFT JOIN은 일치 여부와 관계없이 왼쪽 행을 유지한다.
17 C LAG는 이전 행, LEAD는 다음 행의 값을 참조한다.
18 B DNS는 이름 해석, DHCP는 주소 할당, ARP는 같은 네트워크의 주소 대응과 관련된다.
19 B 인증은 신원 확인이고 인가는 허용된 권한 확인이다.
20 C 해시는 복호화가 목적이 아니며 무결성 확인과 비밀번호 검증 등에 쓰인다.
