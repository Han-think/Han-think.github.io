1. type() 개념#

왜 이걸 보게 됐나#

코드를 작성하면서 type() 함수의 필요성을 느끼게 되었습니다. 객체의 실제 클래스 유형을 확인하는 것이 중요했기 때문입니다.

내가 헷갈린 지점#

type() 함수가 반환하는 클래스 이름이 이해하기 어려운 경우가 있었습니다. 특히 상속 구조에서 자식 클래스의 정확한 유형을 확인하는 데 어려움이 있었습니다.

시도한 코드 / 예시#

class Animal:
    def speak(self):
        return "동물 소리"

class Dog(Animal):
    def speak(self):
        return "멍멍"

class Cat(Animal):
    def speak(self):
        return "야옹"

# 객체 생성
dog = Dog()
cat = Cat()

# 확인 코드
print(type(dog))  # <class '__main__.Dog'>
print(type(cat))  # <class '__main__.Cat'>

결과와 해석#

type() 함수는 각 객체가 정확히 어떤 클래스의 인스턴스인지 명확하게 보여주었습니다. 상속 구조에서도 부모 클래스와 자식 클래스의 차이를 구분할 수 있었습니다.

정리된 이해#

  • type() 함수는 객체의 클래스 유형을 확인하는 데 사용됩니다.
  • 상속 관계에서도 부모 클래스와 자식 클래스의 차이를 명확히 구분할 수 있습니다.

2. isinstance() 개념#

왜 이걸 보게 됐나#

isinstance() 함수를 통해 객체가 특정 클래스나 그 하위 클래스의 인스턴스인지 검증하는 방법을 이해하고자 했습니다.
