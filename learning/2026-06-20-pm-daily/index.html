1. 데이터 문제 정의 및 품질 이해#

무엇을 배웠나#

데이터 분석 프로젝트는 데이터의 상태에서 시작되어야 하며, 문제 정의는 확보 가능한 데이터를 기반으로 설정해야 한다는 점을 배웠다. 데이터가 부족한 경우, 획득 가능한 데이터와 향후 수집 가능성을 고려하여 문제 정의를 조정해야 한다는 것을 알게 되었다. 또한 데이터 품질 검증과 처리 과정을 통해 “Garbage In, Garbage Out” 문제를 해결하는 것이 중요하다는 것을 이해했다.

헷갈렸던 점#

데이터가 부족하거나 없을 때 문제 정의를 어떻게 해야 할지, 그리고 문제 정의를 유지해야 할지 기다려야 할지 혼란스러웠습니다. 초기에는 ‘있는 데이터에 억지로 맞추는 것’과 ‘기다리는 것’ 두 가지 선택지만 생각했는데, 둘 다 현실적인 방법이라고 생각하지 못했습니다.

정리된 이해#

데이터 분석 프로젝트는 현재 확보 가능한 데이터 상태에서 시작해야 하며, 부족한 데이터는 수집 가능성을 고려하여 문제 정의를 수정하거나 추가적인 데이터 확보 계획을 세워야 합니다. 데이터 품질은 분석 결과에 직접적인 영향을 미치므로, 수집부터 검증, 처리, 저장까지 체계적인 과정을 거쳐야 합니다. 핵심은 “쓰레기 입력하면 쓰레기 출력"이라는 점을 명심하고 데이터 중심적인 접근법을 취하는 것입니다.

import numpy as np

# 예시 데이터 수집
raw_data = np.array([[1, 2], [2, np.nan], [3, 4]])  # 결측치 포함

# 결측치 처리
validated_data = raw_data[~np.isnan(raw_data).any(axis=1)]
print("검증된 데이터:\n", validated_data)

헷갈렸던 점#

처음 Pandas 파일 입출력을 할 때, to_csv나 to_excel 함수를 실행하면 파일이 바로 열릴 거라고 생각했어요. 그리고 Colab을 다시 시작할 때마다 드라이브 마운트와 경로 설정을 계속 해야 한다는 점이 번거롭게 느껴졌습니다.

3. Pandas 표의 핵심 개념과 혼란 해결하기#

무엇을 배웠나#

pandas DataFrame과 Series의 차이점을 명확히 이해하게 되었고, Index와 Columns의 역할이 어떻게 작동하는지 파악하게 되었다. 특히, loc 함수를 사용할 때 단순히 데이터 선택을 넘어, DataFrame 내에서 특정 조건에 맞는 데이터에 접근하는 방법을 이해하게 되었다. 앞으로 pandas를 활용한 데이터 분석 작업을 더욱 효율적으로 수행할 수 있을 것 같다.

헷갈렸던 점#

pandas를 처음 배울 때 DataFrame과 Series가 어떻게 다른지 감이 잘 안 잡혔어요. 특히 Series가 행인지 열인지 혼동될 때가 많았고, index와 columns의 역할도 명확하게 이해하지 못해서 데이터를 잘못 선택하는 실수를 종종 했습니다.

정리된 이해#

pandas에서 DataFrame은 표 전체를 나타내고, Series는 DataFrame 내의 특정 열이나 행을 나타내는 1차원 데이터라는 것을 명확히 이해하게 되었습니다. Index는 행을 식별하는 번호이고, Columns는 열을 식별하는 이름이라는 점도 이제는 헷갈리지 않습니다. 특히, loc 함수를 사용할 때 Index와 Columns의 역할을 고려해야 한다는 것을 깨달았습니다.

  print(df.index)  # 행 번호표

  print(df.columns)

4. Pandas 조건 필터링: loc 사용법과 Boolean Mask 활용#

무엇을 배웠나#

Pandas에서 컬럼을 추출할 때 loc를 잘못 사용했던 오류를 바로잡았고, 조건 필터링 시 between() 함수와 AND, OR 연산자를 활용하여 Boolean Mask를 적용하는 방법을 익혔습니다. .head() 함수가 데이터프레임의 앞부분을 미리 확인하는 용도로 사용된다는 점도 알게 되었습니다. 이제 Pandas 데이터프레임에서 원하는 데이터를 더 정확하게 필터링하고 분석할 수 있게 되었습니다.

헷갈렸던 점#

처음에는 loc를 컬럼 선택에 사용하려다가 KeyError가 발생했고, .head()가 단순히 결과를 출력하는 기능이라고 생각해서 데이터프레임의 처음 몇 줄을 확인하는 용도로 활용하지 못했습니다. 컬럼을 추출하고 조건 필터링을 적용하는 과정에서 정확한 구문과 개념을 혼동했습니다.

정리된 이해#

Pandas에서 컬럼을 추출할 때는 df["컬럼명"]과 같이 컬럼명을 직접 사용해야 하며, loc를 사용할 때는 인덱스 라벨이 아닌 컬럼명을 사용해야 한다는 점을 알게 되었습니다. 조건 필터링 시 Boolean Mask를 활용하여 between() 함수와 AND, OR 연산자를 조합하면 다양한 조건을 만족하는 데이터를 추출할 수 있습니다. 특히, 조건을 조합할 때는 괄호를 사용하여 정확한 결과를 얻도록 주의해야 합니다.

mental_scores = df_wel["mental_wellbeing_score"]

mask = df_wel["mental_wellbeing_score"].between(6, 8)
filtered_df = df_wel.loc[mask, :]

combined_mask = (df_wel["mental_wellbeing_score"] > 5) & (df_wel["mental_wellbeing_score"] <= 7)
filtered_df = df_wel.loc[combined_mask, :]

5. Pandas read_excel 함수 활용법: 초보자를 위한 핵심 옵션 가이드#

무엇을 배웠나#

Pandas 공식 문서의 read_excel 함수를 읽으면서 다양한 옵션 때문에 어려움을 겪었지만, 필수적인 옵션인 io와 sheet_name을 중심으로 핵심 개념을 파악할 수 있었다. Excel 파일을 읽고 데이터프레임을 생성하는 기본적인 과정을 이해했으며, 향후 header, usecols 등 추가적인 옵션들을 학습할 필요가 있다는 것을 알게 되었다. 간단한 예시를 통해 파일 읽기와 데이터 내보내기를 경험하면서 Pandas 사용의 기초를 다졌다.

헷갈렸던 점#

read_excel 함수의 다양한 옵션들이 너무 많아서 어떤 옵션이 실제로 중요한지, 그리고 각 옵션이 어떤 역할을 하는지 파악하는 게 어려웠다. 특히 header, usecols, dtype 같은 옵션들의 의미와 사용법이 명확하게 이해되지 않았었다. 옵션들을 하나씩 테스트하면서 각 옵션이 데이터프레임에 어떤 영향을 미치는지 확인해봐야겠다.

정리된 이해#

Pandas 공식문서를 읽으면서 read_excel 함수의 다양한 옵션에 압도되었지만, 핵심은 파일 경로(io)와 읽을 시트 이름(sheet_name)을 정확히 지정하는 것이라는 점을 파악했습니다. 이제는 데이터 프레임 입출력의 기본 원리를 이해하고, 필요에 따라 추가적인 옵션들을 학습해나가면서 좀 더 복잡한 Excel 파일을 다룰 수 있을 것입니다.

import pandas as pd

# Excel 파일 읽기 예시
file_path = "C:\\Ollama-IPEX\\데이터\\example_data.xlsx"
sheet_name = "tips"

# 데이터프레임 생성
df = pd.read_excel(io=file_path, sheet_name=sheet_name)

# 읽어온 데이터 확인
print(df.head())

# 간단한 데이터 내보내기 예시 (이해를 돕기 위한)
df.to_excel("output_tips.xlsx", index=False, sheet_name="OutputSheet")

6. 데이터 분석 기초: 통계, 변수, 역할 구분 완벽 가이드#

무엇을 배웠나#

통계청 자료처럼 이미 요약된 데이터는 분석 목적에 맞게 활용하기 어렵고, 데이터 분석을 위해서는 데이터의 척도와 원천성을 고려해야 한다는 점을 깨달았습니다. 또한, 데이터베이스 관리자와 분석가의 역할이 다르며, 각 역할에 따른 관점이 어떻게 다른지를 이해하게 되었습니다. 이제는 데이터 분석을 위한 데이터 준비 과정의 중요성을 더욱 명확하게 알게 되었습니다.

헷갈렸던 점#

통계청 자료가 바로 분석에 사용할 수 있을 것이라고 생각했고, 변수 척도별로 분석 방법이 어떻게 달라지는지 이해하는 데 어려움이 있었습니다. 또한, SQL 수업에서 DBA와 분석가의 역할 차이를 명확히 구분하지 못해 혼란스러웠습니다.

7. Pandas groupby와 다양한 집계 함수 활용 가이드#

무엇을 배웠나#

Pandas groupby 함수를 사용하여 데이터를 그룹화하고, count, sum, mean과 같은 집계 함수를 적용하는 방법을 익혔습니다. 특히 agg() 함수를 사용하여 여러 집계 함수를 동시에 적용하고, 각 컬럼에 다른 함수를 적용하는 방법을 이해하게 되었습니다. size 컬럼의 경우 단순히 합계를 계산하는 것이 아니라 개수를 세는 것이 중요하다는 점을 깨달았습니다.

헷갈렸던 점#

처음에는 ‘size’ 컬럼을 요일별로 더하는 것이 옳다고 생각했지만, 인원 수를 나타내는 컬럼이므로 개수를 세는 것이 맞다는 것을 깨달았습니다. 또한 agg() 함수를 사용하여 여러 통계값을 동시에 계산하는 방법을 익히는 데 어려움을 겪었습니다. 여러 컬럼에 대해 다른 집계 함수를 적용하는 구문이 복잡하게 느껴졌습니다.

정리된 이해#

Pandas의 groupby는 데이터를 특정 기준으로 묶어 분석할 수 있게 해주며, 집계 함수는 각 그룹에 대해 다양한 통계 값을 계산하는 데 사용됩니다. agg() 함수를 활용하면 여러 집계 함수를 동시에 적용하여 결과를 효율적으로 요약할 수 있다는 점을 명확히 이해했습니다. 특히 size 컬럼과 같은 인원수를 나타내는 컬럼은 sum()이 아닌 count()를 사용해야 한다는 점을 재정의했습니다.

# 요일별 인원 수 세기 (count)
tips.groupby("day")["size"].count()

# 요일별 총 빌링 금액 합산 (sum)
tips.groupby("day")["total_bill"].sum()

# 요일별 평균 빌링 금액 계산 (mean)
tips.groupby("day")["total_bill"].mean()

8. 결측치 처리: 데이터 품질 향상을 위한 정책 및 실습#

무엇을 배웠나#

결측치를 채우는 것은 데이터 해석을 돕는 처리일 뿐, 실제 값을 복원하는 것이 아니라는 점을 깨달았다. NaN 대신 “정보없음"과 같은 명확한 레이블을 사용하여 데이터의 불확실성을 투명하게 드러내는 것이 중요하며, 결측 여부를 별도 컬럼으로 기록하는 방법도 고려해야 한다는 점을 알게 되었다. 데이터 품질 향상을 위해 결측치 처리 정책을 신중하게 결정해야 함을 배웠다.

헷갈렸던 점#

처음에는 알고리즘을 복잡한 공식으로 생각했지만, 실제로는 단순한 규칙의 반복적인 과정이라는 것을 깨달았습니다. 이미지 수치화부터 CAD 검증까지 유사한 구조를 가지는 파이프라인으로 이해하게 되었고, JSON을 활용하여 데이터를 구조화하고 관리하는 것이 중요하다는 점을 알게 되었습니다. 특히, 검증 결과를 피드백 루프로 활용하여 알고리즘을 개선하는 것이 중요하다는 점을 배웠습니다.

헷갈렸던 점#

처음에는 알고리즘을 복잡한 수학 공식처럼 생각해서, 어떻게 적용해야 할지 막막했습니다. 특히 이미지 수치화, JSON 저장, CAD 변환이 어떻게 연결되는지 이해하기 어려웠어요. 알고리즘 개발이라는 것이 단순히 공식을 반복하는 것 이상이라고 생각했지만, 그 ‘이상’이 무엇인지 파악하는 데 시간이 걸렸습니다.

정리된 이해#

알고리즘은 복잡한 공식이 아니라, 입력 데이터를 받아 규칙에 따라 처리하고 저장하며, 그 결과를 바탕으로 반복적인 개선을 거치는 과정이라는 것을 알게 되었습니다. 이미지 수치화, JSON 저장, CAD 변환과 같은 과정들이 유사한 알고리즘 구조를 가진다는 점을 이해하게 되었고, 이를 통해 초보적인 설계 파이프라인을 구축하는 데 도움이 될 것이라고 생각합니다. JSON을 활용하여 데이터를 구조화하고, CAD 도구를 이용하여 설계를 검증하는 전체적인 흐름을 파악하는 것이 중요합니다.

17. 데이터 로드 오류 해결 및 워킹 노트#

무엇을 배웠나#

노트에서 데이터셋 로드 오류의 원인이 코드 실행 순서에 있음을 알게 되었다. 특히 데이터 로드 코드는 항상 노트북에서 가장 먼저 실행해야 변수가 정의되고, 이후 코드들이 정상적으로 작동한다. 데이터셋을 불러오는 단계를 건너뛰면 NameError나 KeyError와 같은 오류가 발생하는 것을 확인했다.

헷갈렸던 점#

코드가 보인다고 해서 바로 실행되는 게 아니고, 데이터 로드 부분부터 제대로 실행해야 한다는 점이 처음에는 이해가 안 되었습니다. 중간 셀부터 실행하면 변수가 정의되지 않아 오류가 발생한다는 것도 몰랐고, 데이터 로드 셀을 가장 먼저 실행해야 한다는 것을 깨달으니 문제 해결의 실마리가 풀렸습니다.

정리된 이해#

노트북에서 코드가 보이는 것만으로는 실행되지 않기 때문에, 데이터 로드 코드를 항상 가장 먼저 실행해야 문제를 해결할 수 있다는 걸 알게 됐어. 데이터셋을 불러오는 단계를 건너뛰고 아래 셀부터 실행하면 변수가 정의되지 않아 오류가 발생할 수 있다는 점을 명심해야겠다.

18. 판다스 실습 문제 해결과 핵심 용어 정리#

무엇을 배웠나#

Pandas를 처음 배우면서 sum()과 count() 함수의 차이, agg()의 활용, transform()과 agg()의 구분, unstack()의 역할 등 여러 부분이 헷갈렸던 경험을 통해 개념을 정리했습니다. loc 사용 오류와 같은 실수를 통해 정확한 인덱스 지정의 중요성을 깨달았고, 데이터프레임과 시리즈의 관계, 그리고 행/열/인덱스/컬럼 등의 기본적인 용어에 대한 이해를 높였습니다. 이 학습 노트를 통해 Pandas 기본 기능을 더욱 명확하게 이해하게 되었습니다.

헷갈렸던 점#

sum()과 count() 함수가 비슷해서 데이터 개수를 세는 방식이 다른지 몰랐고, agg() 함수는 복잡해서 그 유용성을 제대로 파악하지 못했습니다. transform()과 agg()의 차이점도 명확히 이해하지 못했고, loc 사용 시 인덱스 오류가 자주 발생했습니다.

정리된 이해#

Pandas를 사용하면서 sum()과 count()의 차이, agg()의 활용, transform()과 agg()의 구분 등 기본적인 함수 사용법에서 어려움을 겪었습니다. 하지만 DataFrame, Series, loc, iloc 등의 개념과 boolean mask, isin() 함수를 통해 데이터 선택과 조작에 대한 이해도를 높일 수 있었습니다. 앞으로는 꾸준한 실습을 통해 Pandas 사용법을 숙달하고, 데이터 분석 능력을 향상시키도록 노력해야겠습니다.

# sum() vs count() 예시
import pandas as pd

data = {'col1': [1, 2, 3, 2, 1], 'col2': [4, 5, 2, 1, 5]}
df = pd.DataFrame(data)

print(df['col1'].sum())  # 값의 합: 9
print(df['col1'].count()) # 항목의 개수: 5

# agg() 예시
data = {'col1': [1, 2, 3, 2, 1], 'col2': [4, 5, 2, 1, 5]}
df = pd.DataFrame(data)

print(df.agg({'col1': 'sum', 'col2': 'mean'}))

# transform() vs agg() 예시
data = {'col1': [1, 2, 3, 2, 1], 'col2': [4, 5, 2, 1, 5]}
df = pd.DataFrame(data)

df['col1_mean'] = df['col1'].transform(lambda x: x - df['col1'].mean())
print(df)

df['col1_sum'] = df['col1'].agg('sum')
print(df)

# unstack() 예시
import pandas as pd

data = {'A': {'x': 1, 'y': 2}, 'B': {'x': 3, 'y': 4}}
df = pd.DataFrame(data)

print(df.unstack())
