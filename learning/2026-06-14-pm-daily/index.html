1. SQL 윈도우 함수와 그룹 함수 완벽 가이드#

무엇을 배웠나#

SQL 윈도우 함수와 그룹 함수의 차이점을 명확하게 이해하게 되었다. 윈도우 함수는 원본 데이터를 유지하면서 각 행에 대한 계산 결과를 추가하는 반면, 그룹 함수는 데이터를 집계하여 결과를 제공한다는 것을 알게 되었다. 특히 OVER 구문을 활용한 윈도우 함수의 활용법과 ROLLUP을 통한 소계 및 총계 계산 방법을 학습했다.

헷갈렸던 점#

처음에는 윈도우 함수와 그룹 함수가 비슷해서 데이터 집계 방식에 대한 혼동이 많았습니다. 특히 LAST_VALUE() 함수 사용 시 전체 범위를 어떻게 지정해야 할지, 그리고 ROLLUP 결과에서 보이는 NULL 값의 의미를 정확히 파악하는 데 어려움을 겪었습니다.

정리된 이해#

윈도우 함수와 그룹 함수 모두 데이터를 집계하지만, 윈도우 함수는 원본 데이터를 유지하며 각 행에 대한 계산 값을 추가하는 반면, 그룹 함수는 데이터를 그룹화하여 행의 수를 줄입니다. 특히 윈도우 함수는 OVER 구문을 사용하여 범위를 정의해야 하며, 그룹 함수는 GROUP BY나 ROLLUP 등을 사용하여 데이터를 그룹화합니다. 이제는 이 두 함수의 주요 차이점을 명확하게 이해하게 되었습니다.

-- 윈도우 함수 예시: 각 부서별 평균 연봉과 전체 평균 연봉 비교
SELECT
    department,
    salary,
    AVG(salary) OVER (PARTITION BY department) AS department_avg_salary,
    AVG(salary) OVER () AS overall_avg_salary
FROM employees;

-- 그룹 함수와 ROLLUP 예시: 제품 카테고리별 매출 총계 및 소계
SELECT
    category,
    SUM(sales)
FROM products
GROUP BY ROLLUP(category);

-- 그룹 함수와 GROUPING SETS 예시:  다양한 그룹 조합에 대한 집계
SELECT
    category,
    SUM(sales)
FROM products
GROUP BY GROUPING SETS (
    (category),
    (category, region)
);

2. SQL 윈도우 함수와 그룹 함수 완벽 가이드#

무엇을 배웠나#

SQL 윈도우 함수와 그룹 함수를 구분하는 데 어려움이 있었는데, 윈도우 함수는 원본 데이터를 유지하면서 분석을 수행하고, 그룹 함수는 데이터를 요약한다는 점을 명확히 이해하게 되었다. 특히 OVER 구문이 윈도우 함수의 분석 범위를 정의하는 중요한 역할을 한다는 것을, 그리고 순위 함수들의 차이점을 제대로 알게 되었다. 실제 예제를 통해 윈도우 함수를 적용하는 방법을 익히면서 데이터 분석 능력을 향상시킬 수 있을 것이다.

헷갈렸던 점#

처음에는 윈도우 함수와 GROUP BY가 비슷해 보여서 둘의 차이점을 명확히 파악하기 어려웠습니다. 특히 윈도우 함수가 원본 행을 유지하면서 계산값을 추가하는 방식이 직관적으로 이해되지 않았고, OVER 구문이 정확히 어떤 역할을 하는지 헷갈렸습니다. 순위 함수들의 미묘한 차이, 예를 들어 RANK, DENSE_RANK, ROW_NUMBER의 동점 처리 방식이 어떻게 다른지 구별하는 데 어려움을 느꼈습니다.

정리된 이해#

윈도우 함수는 원본 데이터를 유지하며 그룹 내에서 순위나 합계 같은 추가 정보를 제공하고, OVER절을 통해 데이터 분석 범위를 조절할 수 있다는 점을 이해했습니다. 반면, GROUP BY는 데이터를 묶어 요약 정보를 제공하며, 개별 행의 상세 정보는 사라집니다. 이러한 차이점을 명확히 이해하고 활용하면 복잡한 데이터 분석 작업도 효율적으로 수행할 수 있을 것입니다.

-- 월별 판매량 순위 부여 (RANK) 및 전체 판매량 합계 (SUM OVER)
SELECT
    날짜,
    제품명,
    판매량,
    RANK() OVER (PARTITION BY 제품명 ORDER BY 판매량 DESC) AS 판매량_순위,
    SUM(판매량) OVER () AS 총_판매량
FROM 판매
