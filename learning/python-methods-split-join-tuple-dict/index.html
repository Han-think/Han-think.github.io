Python 기초: 함수와 메서드 이해하기 - 튜플과 딕셔너리 기초

초보자를 위한 Python 함수와 메서드 이해 및 튜플, 딕셔너리의 기본 개념 정리
2026년 6월 1일 · 5 min

왜 썼나#

이번 포스팅은 Python 프로그래밍 언어를 처음 배우는 초보자들이 가장 흔히 겪는 혼란들을 다루고자 작성되었습니다. 특히 함수와 메서드의 차이점, 그리고 문자열 처리에 자주 사용되는 split()과 join() 메서드의 활용법, 그리고 기본적인 자료구조인 튜플과 딕셔너리에 대한 이해를 돕기 위해 초안을 작성했습니다. 이러한 개념들은 코딩의 기초를 이루는 핵심 요소들로, 확실한 이해 없이는 후속 학습에 어려움이 따르기 때문입니다.

배운 것#

  • 함수 vs 메서드: 함수는 독립적으로 실행 가능한 코드 블록으로, 호출 시 매개변수를 전달하여 결과를 얻을 수 있습니다. 예를 들어, 문자열 길이를 확인하는 len() 함수는 별도의 객체 없이 호출됩니다. 반면, 메서드는 객체와 연결되어 있으며, . 연산자를 통해 해당 객체의 속성이나 기능을 사용합니다. 예를 들어, 문자열 객체 my_str에서 split() 메서드를 사용하려면 my_str.split(sep=',')와 같이 호출해야 합니다.

헷갈린 것#

  • 메서드 호출: 메서드 호출 시 반드시 필요한 . 연산자의 역할을 이해하는 데 어려움이 있었습니다. 함수 호출과 달리 메서드는 객체의 속성이나 동작을 이용하기 때문에 이 차이를 명확히 이해하는 것이 중요합니다.
  • 문자열 메서드 활용: split()과 join() 메서드의 구체적인 사용 방법과 그 결과 예측이 어려웠습니다. 특히, split()은 문자열을 지정된 구분자로 분리하고, join()은 리스트의 요소들을 지정된 구분자로 합쳐 문자열로 반환하는 기능을 가지고

왜 썼나#

문자열 데이터를 다룰 때 split()과 join() 메서드는 매우 중요한 역할을 합니다. 이 두 메서드를 통해 복잡한 문자열 데이터를 쉽게 분석하고 다시 조합할 수 있어, 다양한 프로그래밍 문제 해결에 활용됩니다. 특히, 텍스트 데이터의 처리나 파싱 작업에서 필수적인 도구로 작용합니다.

배운 것#

  • split(): 주어진 구분자를 기준으로 문자열을 리스트로 분할합니다. 기본 구분자는 공백이지만, 다른 문자나 문자열도 지정할 수 있습니다. 
    sentence = "파이썬 공부 열심히 하자"
words = sentence.split()  # 결과: ['파이썬', '공부', '열심히', '하자']
  • join(): 반대로, 리스트 내의 문자열 요소들을 지정된 구분자로 연결하여 하나의 문자열로 만듭니다. 
    star_words = ["*" + word + "*" for word in words]
result = " ".join(star_words)  # 결과: "*파이썬* *공부* *열심히* *하자*"

헷갈린 것#

  • 함수 사용 방향: 초기에는 split()과 join()을 잘못 이해했습니다. 예를 들어, chars.join(...)처럼 문자열 객체가 직접 리스트를 연결한다고 오해했습니다.
    • 정확한 이해: 실제로는 문자열 객체가 아닌 구분자 문자열이 리스트를 연결하는 역할을 합니다. 올바른 사용법은 "구분자".join([항목1, 항목2, ...]) 형태입니다.

왜 썼나#

코딩을 시작하면서 가장 기본적이면서도 자주 범하는 실수 중 하나가 변수명의 일관성 부족입니다. 특히 문자열 처리에서 변수명을 혼용하면 코드의 가독성을 떨어뜨리고 예상치 못한 오류를 발생시킬 수 있습니다. 이를 통해 더 명확하고 유지보수하기 쉬운 코드를 작성하는 방법을 공유하고자 합니다.

배운 것#

  1. 변수명 일관성: 동일한 데이터 타입을 다루는 변수들은 일관된 네이밍 규칙을 따르는 것이 중요합니다. 예를 들어, 단일 데이터를 다룰 때와 리스트 형태의 데이터를 다룰 때는 명확한 구분을 두어야 합니다.
  2. 예시를 통한 이해: star_word와 star_words와 같은 변수명을 사용할 때, 각각의 용도와 범위를 명확히 구분하는 것이 코드의 정확성을 높입니다.

헷갈릴린 것#

  • 변수명 혼동: star_word와 star_words 같은 변수명을 혼용하면서 코드 실행 중 NameError가 발생하는 경우가 많았습니다. 이는 변수의 존재 여부를 혼동하게 만들고 디버깅 시간을 늘리는 주요 원인이 되었습니다.

  • 단수 변수 예시: 단일 별 문자열을 다룰 때는 star_word와 같은 단수형 변수명을 사용합니다. 
    star_word = "*"*5  # 별이 5개 있는 문자열
print(star_word)  # 출력: *****

왜 썼나?#

이번 학습 세션에서는 Python 프로그래밍 언어의 핵심 요소인 문자열 처리와 다양한 컬렉션 타입에 대해 깊이 이해하는 것이 목표였습니다. 특히, 실무에서 자주 사용되지만 초보자에게는 혼란을 줄 수 있는 개념들을 명확히 정리하고자 했습니다. 이를 통해 코드 작성 시 더욱 효율적이고 명확한 접근 방식을 갖출 수 있을 것으로 기대합니다.

배운 것#

  • 문자열 처리:

    • split() 메서드를 사용하여 문자열을 단어 단위로 나누는 방법을 배웠습니다. 예를 들어, "오늘 날씨 좋네요"라는 문장을 공백을 기준으로 나누면 ["오늘", "날씨", "좋네요"]와 같은 리스트를 얻을 수 있습니다.
    • join() 메서드는 반대로 리스트의 요소들을 하나의 문자열로 결합하는 데 유용합니다. ["오늘", "날씨", "좋네요"]를 "오늘 날씨 좋네요"로 합치는 데 사용됩니다.

  • 컬렉션 타입:

    • 튜플(tuple)은 불변의 순서가 있는 데이터 구조로, 주로 좌표나 고정된 값의 집합을 표현할 때 사용됩니다. 예를 들어, (10, 20)은 x축과 y축 좌표를 나타냅니다.
    • 리스트(list)는 변경 가능한 순서가 있는 데이터 구조로, 항목 추가나 삭제가 용이하여 유연한 데이터 관리에 적합합니다. 예를 들어, [1, 2, 3]은 순서가 있는 변경 가능한 숫자 목록입니다.
    • 딕셔너리(dictionary)는 키-값 쌍으로 구성된 구조로, 데이터를 빠르게 검색하고 관리할 수 있습니다. 학생의 성적을 {"수학": 85, "영어": 90}

무엇이 헷갈렸나?#

학습 과정에서 몇 가지 핵심 개념에 대해 혼란을 느꼈습니다.

  • 딕셔너리 처리 방법: dict.keys(), dict.values(), dict.items() 메서드의 구체적인 차이점과 실제 코딩에서 어떻게 적용할지 이해하는 데 어려움이 있었습니다. 각 메서드가 반환하는 데이터 타입과 사용 목적에 대한 명확한 구분이 필요했습니다.

  • 변수 명명 규칙: 튜플과 리스트의 차이점뿐만 아니라, 변수 이름을 지을 때 단수와 복수를 구분하는 방법에 대해 혼동이 있었습니다. 예를 들어, star_word와 star_words와 같은 명명 규칙이 실제 코드에서 어떻게 적용되어야 하는지 명확히 이해하지 못했습니다.

  • 문자열 처리 메서드: split()과 join() 메서드의 정확한 사용법과 그 방향성에 대한 이해가 부족했습니다. 특히 문자열을 분리하고 다시 결합하는 과정에서 오류가 발생하는 경우가 많았습니다.

정리된 이해#

딕셔너리 메서드의 명확한 이해#

  • dict.keys(): 딕셔너리에서 모든 키를 추출하여 리스트 형태로 반환합니다. 이 메서드는 주로 키에 대한 접근이나 필터링 작업에 사용됩니다. 
    example_dict = {
    "name": "Alice",
    "age": 25,
    "city": "Seoul"
}
keys = example_dict.keys()

왜 썼나#

이번 학습 세션에서는 데이터 분석 및 처리 과정에서 중요한 역할을 하는 키-값 쌍 추출 방법과 다양한 데이터 구조의 이해에 초점을 맞추었습니다. 특히, Python에서 파일 타입별 데이터의 분포를 파악하는 것이 프로젝트 진행에 얼마나 중요한지 실감할 수 있었습니다.

배운 것#

  • 키-값 쌍 추출: 주어진 데이터 소스에서 파일 타입별로 개수를 세는 방법을 익혔습니다. 이는 다양한 파일 포맷을 다루는 데 있어 필수적인 기술입니다. 예를 들어, pdf, ipynb, md 파일의 개수를 세는 코드를 통해 데이터의 다양성을 파악할 수 있었습니다.

    items = source_counts.items()
print("Items:", list(items))  # 출력 예시: Items: [('pdf', 24), ('ipynb', 1), ('md', 3)]

  • 튜플과 리스트의 이해:

    • 리스트: 변경 가능한(mutable) 데이터 구조로, 요소를 추가하거나 제거하는 등의 동적 조작이 가능합니다.
    • 튜플: 불변(immutable) 데이터 구조로, 생성 후에는 내용을 변경할 수 없습니다. 이 특성 덕분에 데이터의 안정성과 성능 향상에 유용합니다. 예를 들어, 특정 데이터 집합을 고정적으로 유지해야 할 때 튜플을 사용하는 것이 효과적입니다.

헷갈릴린 것#

  • 튜플과 리스트의 차이점: 초기에는 튜플과 리스트의 차이를 명확히 구분하지 못했습니다. 특히, 튜플이 변경 불가능하다는 점이 실제 프로그래밍에서 어떤 이점을 제공하는지 이해하는 데 시간이 걸렸습니다. 하지만, 성능 최적화와 데이터 무결성 유지 측면에서 튜플의 중요성을 깨달았습니다.
