1. 함수와 메서드 구분#

왜 이걸 보게 됐나#

함수와 메서드의 개념 차이를 명확히 이해하고, 특히 메서드 호출 시의 문법적 차이와 문자열 처리 메서드의 실제 사용법을 익히는 것이 중요합니다. 이를 통해 코드 작성 시 효율적이고 정확한 선택을 할 수 있습니다.

내가 헷갈린 지점#

초보자들은 함수와 메서드의 구분이 모호하고, 특히 split(), join() 메서드가 어떻게 문자열을 처리하는지 예측하기 어려웠습니다. 또한 튜플과 딕셔너리의 특성과 올바른 사용 방법에 대한 이해 부족이 혼란을 초래했습니다.

시도한 코드 / 예시#

# 함수 예시
def greet(name):
    return f'안녕하세요, {name}님!'

# 메서드 예시
my_str = '안녕'
greeting = greet('초보자')
print(greeting)

# split()과 join() 예시
sentence = '파이썬 공부 열심히 하자'
words = sentence.split(' ')  # 공백을 기준으로 분리
rejoined_sentence = ' '.join(words)  # 다시 결합
print(words)
print(rejoined_sentence)

# 튜플과 딕셔너리 예시
# 튜플
coordinates = (10, 20)
print(coordinates)

# 딕셔너리
grades = {'수학': 85, '영어': 90}
print(grades.items())  # 키-값 쌍 출력
print(grades['수학'])  # 특정 키의 값 접근

결과와 해석#

# 함수 출력
안녕하세요, 초보자님!

# split()과 join() 출력
['파이썬', '공부', '열심히', '하자']
파이썬 공부 열심히 하자

# 튜플 출력
(10, 20)

# 딕셔너리 출력
dict_items 딕셔너리의 키-값 쌍 튜플 리스트 출력: [('수학', 85), ('영어', 90)]
수학 85

정리된 이해#

이 항목들은 함수와 메서드의 구분, 문자열 처리 메서드 split()과 join()의 실제 사용법, 그리고 불변 데이터 구조인 튜플과 키-값 쌍을 다루는 딕셔너리의 기본 개념을 강조합니다. 이를 통해 초보자들은 코드 작성 시 더 명확하고 효과적인 접근법을 배울 수 있습니다.

2. split() 문자열 분리#

왜 이걸 보게 됐나#

문자열을 효과적으로 분리하고 결합하는 방법을 이해하는 것은 데이터 처리에서 매우 중요합니다. 특히 split()과 join() 메서드는 문자열 조작에서 핵심적인 역할을 합니다. 초보자들이 이 개념을 명확히 이해함으로써 더 복잡한 문자열 처리 작업을 수행하는 데 도움이 됩니다.

내가 헷갈린 지점#

초보자들은 split()과 join()의 역할을 혼동하거나, 문자열 객체가 직접 리스트를 결합한다고 오해하는 경우가 많습니다. 또한, 튜플과 리스트의 차이점과 각각의 사용 시나리오를 명확히 구분하는 데 어려움을 겪습니다. 변수 명명 규칙, 특히 단수와 복수를 구분하는 방법에 대한 이해도 부족합니다.

시도한 코드 / 예시#

# split() 예시
sentence = '파이썬 공부 열심히 하자'
words = sentence.split(' ')  # 공백을 기준으로 분리
print(words)  # 출력: ['파이썬', '공부', '열심히', '하자']

# join() 예시
star_words = ['*' + word + '*' for word in words]
result = ' '.join(star_words)
print(result)  # 출력: '*파이썬* 공부* 열심히* 하자*'

# 튜플 예시
coordinates = (10, 20)
print(coordinates)
# 출력: (10, 20)

# 리스트 예시
numbers = [1, 2, 3, 4]
numbers.append(5)
print(numbers)
# 출력: [1, 2, 3, 4, 5]

# 딕셔너리 예시
dict_example = {'이름': '홍길동', '나이': 25}
print(dict_example.items())  # 출력: dict_keys([('이름', '홍길동'), ('나이', 25)])

결과와 해석#

['파이썬', '공부', '열심히', '하자']
*파이썬* 공부* 열심히* 하자*
(10, 20)
[1, 2, 3, 4, 5]
dict_keys([('이름', '홍길동'), ('나이', 25)])

정리된 이해#

이 학습 노트는 split()과 join() 메서드를 통해 문자열을 효과적으로 분리하고 결합하는 방법을 설명하며, 튜플과 리스트의 차이점, 그리고 딕셔너리의 기본적인 메서드 활용법을 다룹니다. 초보자들이 이러한 문자열 처리와 컬렉션 타입의 핵심 개념을 이해함으로써 더 복잡한 프로그래밍 작업을 수행하는 데 필요한 기초를 다질 수 있도록 돕습니다.

3. join() 문자열 합치기#

왜 이걸 보게 됐나#

문자열 조작에서 split()과 join() 메서드의 역할과 사용법을 명확히 이해하는 것은 데이터 처리와 문자열 포맷팅에 필수적입니다. 이를 통해 복잡한 문자열을 효과적으로 다룰 수 있습니다.

내가 헷갈린 지점#

처음에는 split()과 join()이 문자열 객체 자체에서 직접 리스트를 결합한다고 오해했습니다. 특히 구분자 역할을 하는 문자열의 중요성을 간과했습니다. 또한, 변수 명명 규칙과 컬렉션 타입의 차이에 대한 이해 부족으로 인해 코드 오류를 겪었습니다.

시도한 코드 / 예시#

# 문자열 split과 join 예시
sentence = '이것은 문장입니다'
words = sentence.split(' ')  # 공백을 기준으로 분리
rejoined_sentence = ' '.join(words)  # 다시 결합
print(rejoined_sentence)  # 출력: 이것은 문장입니다

# 리스트를 구분자로 연결
fruits = ['사과', '바나나', '체리']
comma_separated_fruits = ', '.join(fruits)
print(comma_separated_fruits)  # 출력: 사과, 바나나, 체리

결과와 해석#

출력:

이것은 문장입니다
사과, 바나나, 체리

정리된 이해#

이 항목들은 split()과 join() 메서드의 실제 사용법을 설명하며, 문자열을 구분자로 분리하고 다시 합치는 과정을 보여줍니다. 또한, 리스트를 문자열로 결합할 때 구분자의 역할과 변수 명명 규칙의 중요성을 강조합니다.
