1. 함수 vs 메서드#

왜 이걸 보게 됐나#

처음 코딩을 배우면서 함수와 메서드의 차이를 명확히 이해하지 못해, 객체 지향 프로그래밍의 기본 원리를 제대로 파악하기 어려웠다. 특히, 메서드는 객체와 밀접하게 연결되어 동작한다는 점을 깨닫지 못해 코드가 어떻게 실행되는지 혼란스러웠다. 이러한 어려움을 해결하기 위해 두 개념의 차이점을 명확히 하고, 메서드를 올바르게 활용할 수 있도록 학습하게 되었다.

내가 헷갈린 지점#

처음에는 메서드가 함수와 완전히 똑같은 것이라고 생각했어요. 메서드가 객체에 종속되는 개념이라는 점을 이해하지 못해서, 왜 객체 이름을 앞에 붙여서 호출해야 하는지 궁금했습니다. 특히 . 연산자가 메서드 호출에 어떤 역할을 하는지 명확하게 이해하지 못했습니다.

시도한 코드 / 예시#

# 함수 예시: len() 함수는 문자열의 길이를 반환합니다.
my_str = "Hello"
length = len(my_str)  # length는 5가 됩니다.
print(length)

# 메서드 예시: my_str.split()는 문자열을 공백으로 분리하여 리스트를 반환합니다.
my_str = "Hello world"
words = my_str.split()  # words는 ['Hello', 'world']가 됩니다.
print(words)

결과와 해석#

함수는 독립적인 코드 블록으로, len() 함수처럼 바로 호출할 수 있어요. 메서드는 객체에 종속되어, my_str.split()처럼 객체 이름 뒤에 점(.)으로 접근해서 사용해야 하죠. 예를 들어, my_str이라는 문자열 변수에 대해 split() 메서드를 사용하면 문자열을 나누는 기능을 수행할 수 있습니다.

정리된 이해#

함수는 독립적으로 실행되는 코드 덩어리이고, 메서드는 객체에 묶여서 객체 이름과 함께 호출되는 함수입니다. 메서드는 객체의 특정 동작을 수행하며, . 연산자를 통해 객체와 연결됩니다. 따라서, 함수는 객체 없이도 실행될 수 있지만, 메서드는 객체가 필요합니다.

2. 문자열 메서드 split()과 join()#

왜 이걸 보게 됐나#

문자열을 다루는 기본적인 작업이 필요할 때 split()과 join() 메서드는 필수적으로 사용됩니다. 텍스트 데이터에서 원하는 정보를 추출하거나, 여러 문자열을 연결하여 새로운 문자열을 만들 때 매우 유용합니다. 이 두 메서드를 익히면 데이터 처리 및 문자열 조작 능력이 향상되어 더욱 복잡한 프로그래밍 작업을 수행할 수 있게 됩니다.

내가 헷갈린 지점#

처음에는 chars.join(...)처럼 생각해서 문자열 객체가 리스트를 결합한다고 생각했어요. split()과 join()이 어떻게 서로 반대되는 역할을 하는지, 그리고 어떤 것을 기준으로 문자열을 나누고 합치는 건지 명확하게 이해하지 못했습니다. 특히 join() 메서드가 리스트를 결합할 때 구분자 역할을 하는 문자열이 필요하다는 점을 파악하는 데 시간이 걸렸습니다.

시도한 코드 / 예시#

sentence = "파이썬 공부 열심히 하자"
words = sentence.split()  # 결과: ['파이썬', '공부', '열심히', '하자']
star_words = ["*" + word + "*" for word in words]
result = " ".join(star_words)  # 결과: "*파이썬* 공부* 열심히* 하자*"

결과와 해석#

문자열을 특정 구분자를 기준으로 나누어 리스트로 만들 때는 split() 메서드를 사용합니다. 예를 들어 “apple,banana,cherry” 문자열을 쉼표로 분리하면 [‘apple’, ‘banana’, ‘cherry’] 리스트가 생성됩니다. 반대로, 리스트의 문자열 요소들을 특정 구분자로 합쳐 하나의 문자열로 만들 때는 join() 메서드를 활용하며, " “.join([‘apple’, ‘banana’, ‘cherry’])은 “apple banana cherry"가 됩니다.

정리된 이해#

split() 메서드는 문자열을 특정 구분자를 기준으로 나누어 리스트로 만들고, join() 메서드는 리스트의 문자열 요소들을 지정된 구분자를 사용하여 하나의 문자열로 합쳐줍니다. split()은 문자열을 쪼개고, join()은 문자열을 이어붙인다고 이해하면 좋습니다. 예를 들어, “Hello World"를 " “로 split하면 [“Hello”, “World”]가 되고, [“a”, “b”, “c”]를 “,“로 join하면 “a,b,c"가 됩니다.

3. 튜플과 딕셔너리#

왜 이걸 보게 됐나#

프로그래밍을 할 때 데이터를 효율적으로 관리하고 표현하기 위해 튜플과 딕셔너리는 필수적인 자료구조이기 때문에 학습하게 됐어. 튜플은 변경 불가능한 데이터를 안전하게 저장하고, 딕셔너리는 키-값 쌍으로 데이터를 연결하여 빠르게 접근할 수 있게 해줘. 이 개념들을 익히면 더 복잡한 프로그램을 만들 때 데이터 관리를 훨씬 수월하게 할 수 있을 거야.

내가 헷갈린 지점#

튜플이 변경 불가능하다는 점이 처음에는 잘 이해가 안 되어서, 리스트처럼 수정할 수 있다고 생각했습니다. 딕셔너리의 경우, 키-값 쌍이 중요하지만 그 역할과 활용법을 명확하게 파악하지 못하고 단순히 자료를 저장하는 곳 정도로만 생각했습니다. 또한, 튜플을 언패킹하는 방법에 익숙하지 않아서, 여러 변수에 튜플의 값을 할당하는 데 어려움을 겪었습니다.

시도한 코드 / 예시#

# 튜플 예시: 좌표 (x, y)
coordinates = (10, 20)
print(coordinates)  # 출력: (10, 20)

# 딕셔너리 예시: 학생 정보
student = {"name": "Alice", "age": 18, "major": "Computer Science"}
print(student)  # 출력: {'name': 'Alice', 'age': 18, 'major': 'Computer Science'}

결과와 해석#

튜플은 데이터를 변경할 수 없는 자료구조로, 예를 들어 점의 좌표(1, 1)처럼 순서가 중요하고 변하지 않는 데이터를 표현할 때 유용하다. 딕셔너리는 키와 값의 쌍으로 이루어진 자료구조로, 학생 이름과 점수를 연결하여 저장할 때 키(이름)를 통해 값을(점수) 빠르게 찾을 수 있다. 딕셔너리를 사용할 때 items() 메서드는 각 키-값 쌍을 튜플 형태로 반환하여 반복문에서 편리하게 사용할 수 있게 해준다.

정리된 이해#

튜플은 생성 후 내용 변경이 불가능한 순서 있는 자료구조로, 데이터의 안정성이 중요할 때 유용하게 사용됩니다. 딕셔너리는 키와 값의 쌍으로 이루어진 자료구조로, 데이터 조회 및 관리에 효율적이며, 키를 통해 특정 값을 빠르게 찾을 수 있습니다.

4. 단수/복수 변수명 혼동#

왜 이걸 보게 됐나#

처음에는 변수명을 대충 짓고 코딩했는데, “NameError"가 자주 발생하면서 변수명에 대한 규칙이 있다는 것을 깨달았어. 특히 단수 변수는 하나의 항목을 나타내고, 복수 변수는 여러 항목의 리스트를 나타낸다는 점을 명확히 이해하지 못해서 혼동이 많이 왔었지. 코드가 제대로 실행되도록 변수명을 일관성 있게 짓는 것이 중요하다는 것을 배우게 됐어.

내가 헷갈린 지점#

처음에는 변수명에 ’s’를 붙이는 것이 복수형을 나타내는 일반적인 규칙이라는 건 알았지만, 어떤 경우에 ’s’를 붙여야 하는지, 그리고 단수 변수와 복수 변수를 어떻게 구분해야 하는지 명확하지 않았습니다. 변수 이름을 지을 때 단수/복수 구분을 제대로 하지 못하고 코드를 작성해서, NameError가 자주 발생했었습니다. 이 때문에 변수 이름 짓는 것 자체에 대해 크게 신경 쓰지 않고 있었던 것 같습니다.

시도한 코드 / 예시#

# 단수 변수 사용 예시
star_word = "*"*5  # 별이 5개 있는 문자열
print(star_word)  # 출력: *****

# 복수 변수 사용 예시
star_words = ["*"*3, "*"*4, "*"*6]  # 각각 별이 다른 개수의 리스트
for words in star_words:
    print(words)  # 출력: ***, ****, *****

결과와 해석#

처음에 star_word 변수를 사용해서 하나의 별 문자열을 다루려고 했는데, 실제로는 여러 개의 별 문자열을 처리해야 해서 star_words 리스트를 사용해야 해서 오류가 발생했어. 변수 이름을 명확하게 구분하지 않아서 발생하는 문제였어. 변수명을 지을 때 단수와 복수를 확실히 구분해야 한다는 것을 알게 됐어.

정리된 이해#

변수 이름을 지을 때, 단수형 변수는 하나의 객체를 가리키고 복수형 변수는 여러 객체를 담은 리스트나 컬렉션을 가리키도록 일관되게 사용해야 오류를 방지할 수 있다는 것을 깨달았습니다. 예를 들어, 하나의 별표 문자열을 다룰 때는 star_word를 사용하고, 여러 개의 별표 문자열 리스트를 다룰 때는 star_words를 사용하는 것이 좋습니다. 변수명은 코드의 가독성과 유지보수성을 높이는 중요한 요소라는 것을 알게 되었습니다.

총평#

오늘 전체에서 배운 것#

파이썬에서 함수와 메서드의 차이를 명확히 이해하고, 문자열을 분리하고 결합하는 split()과 join() 메서드 사용법을 익혔습니다. 또한 튜플과 딕셔너리의 특징과 활용법을 정리하여 자료구조에 대한 이해도를 높였습니다. 변수명 혼동 문제를 해결하여 코드의 가독성을 향상시켰습니다.

다음에 조심할 것#

split()과 join() 사용 시 문자열이 어떻게 처리되는지, 그리고 변수명을 일관되게 사용하는 데 더 신경 써야겠다. dict.items()는 단순히 “아이템"이 아닌 키-값 쌍을 추출하는 기능임을 항상 기억하고 활용해야 할 것 같다.

다음 복습 주제#
