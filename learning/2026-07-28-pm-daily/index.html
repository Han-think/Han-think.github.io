1. CSS 변환과 브라우저 Prefix 완벽 이해하기#

무엇을 배웠나#

CSS transform 속성은 여러 변환을 한 줄로 연결하여 적용하며, 각 변환은 순차적으로 적용되지 않고 마지막 선언이 우선합니다. 브라우저 prefix는 이전 버전의 브라우저와의 호환성을 위해 사용되었으며, 최신 브라우저는 대부분 기본 CSS를 지원합니다. transform 속성과 prefix를 사용하여 요소를 변형하는 방법에 대한 기본적인 이해를 쌓았습니다.

헷갈렸던 점#

transform 속성을 여러 줄로 작성하면 변환이 순차적으로 적용될 거라고 생각했는데, 실제로는 덮어쓰는 방식으로 동작하는 것을 알게 되었다. 또한, 브라우저 Prefix가 왜 필요한지, 그리고 어떻게 사용하는지에 대한 이해가 부족했다.

정리된 이해#

CSS transform 속성은 여러 변환을 한 번에 적용하는 단일 속성이며, 각 변환은 순차적으로 적용되지 않고 마지막 선언이 우선합니다. 브라우저 Prefix는 이전 버전의 브라우저와의 호환성을 위해 사용되었지만, 현재는 최신 브라우저 대부분이 표준 CSS를 지원하므로 필요성이 줄어들고 있습니다.

2. 호버 효과를 부드럽게 만드는 CSS 트랜지션 완벽 가이드#

무엇을 배웠나#

transition 속성을 사용해 CSS 속성 변화를 부드럽게 만들 수 있다는 것을 알게 되었고, hover 가상 선택자와 함께 사용하면 마우스 호버 시 일어나는 변화를 애니메이션처럼 보이게 할 수 있다는 것을 배웠습니다. 특히 transition 단축 속성에서 시간 값의 순서가 duration과 delay로 결정된다는 점을 명확히 이해하게 되었습니다. 또한, transition-delay 문법 오류를 수정하는 과정에서 CSS 문법에 대한 이해도를 높일 수 있었습니다.

헷갈렸던 점#

transition 속성을 사용할 때 가상 선택자와 속성 사이의 띄어쓰기가 필요할지 몰랐고, duration과 delay의 순서가 헷갈렸습니다. 또한, transition-delay의 문법을 잘못 이해하고 있어 수정하는 과정에서 어려움을 겪었습니다.

정리된 이해#

transition 속성을 사용하여 CSS 속성 변화를 부드럽게 만들 수 있으며, hover 가상 선택자와 함께 사용하면 마우스 호버 시 변화를 자연스럽게 표현할 수 있습니다. transition 단축 속성에서 시간 값은 duration이 먼저, delay가 나중에 오는 순서로 적용됩니다. 이 속성들을 올바르게 사용하려면 각 속성의 역할과 순서를 정확히 이해하는 것이 중요합니다.

  .box {
    width: 100px;
    height: 100px;
    background-color: lightblue;
    transition: width 2s ease 0.5s;
  }

  .box:hover {
    width: 200px;
  }

3. UI 애플리케이션 메뉴 및 카드에 트랜지션 효과 적용하기#

무엇을 배웠나#

CSS :hover 효과를 적용할 때, 어떤 요소에 적용할 것인지 선택자가 결정하는 것을 명확히 이해하게 되었다. 카드 내 이미지 확대 효과를 적용할 때, 이미지 밖으로 나가지 않도록 주의해야 한다는 점도 알게 되었다. 실습 예시를 통해 :hover 효과와 transition 속성을 활용하여 메뉴와 카드에 다양한 시각적 효과를 줄 수 있음을 확인했다.

헷갈렸던 점#

처음에는 :hover 효과를 어떤 요소에 적용해야 할지, 그리고 각 요소가 어떻게 반응해야 할지 감이 잘 안 잡혔다. 특히 이미지 확대 효과를 적용할 때 이미지가 영역 밖으로 나가는 문제가 발생해서 어떻게 해결해야 할지 몰랐다. 각 선택자가 어떤 요소를 제어하는지 명확히 이해하는 것이 중요했다.

정리된 이해#

CSS :hover 효과는 적용하는 선택자에 따라 반응 범위가 결정되며, 이미지 확대 시 영역을 벗어나는 문제를 해결하려면 추가적인 스타일 조정이 필요하다. 각 요소에 적절한 트랜지션 시간을 부여하여 부드러운 효과를 만들 수 있다. 이제는 어떤 요소에 :hover 효과를 적용해야 하는지 명확히 구분하고 적용할 수 있게 되었다.

4. CSS 애니메이션과 키프레임 동작 원리 이해하기#

무엇을 배웠나#

CSS 애니메이션과 키프레임의 역할과 작동 방식을 이해하게 되었어요. 특히 alternate 속성을 사용했을 때 애니메이션의 진행 방향과 animation-fill-mode가 애니메이션 종료 후 요소의 상태를 어떻게 결정하는지 명확히 알게 되었죠. 예시 코드를 통해 이 지식들을 직접 적용해 보면서 더욱 확실하게 이해할 수 있었습니다.

헷갈렸던 점#

애니메이션의 alternate 속성이 어떻게 반복되는지, 그리고 애니메이션이 끝나고 요소의 상태가 어떻게 결정되는지 이해하는 데 어려움을 느꼈습니다. 특히 animation-fill-mode 속성이 마지막 키프레임 상태를 유지하는 원리에 대한 명확한 그림이 잡히지 않았습니다.

5. 변환 애니메이션 조합과 시간 속성 이해#

무엇을 배웠나#

CSS 애니메이션에서 @keyframes는 각 단계별 물체의 상태 변화를 정의하고, animation 속성은 애니메이션의 실행 방식을 제어한다는 것을 알게 되었습니다. 특히 animation 속성에서 duration, delay 등의 시간 관련 속성들이 각각 어떤 역할을 하는지 명확히 이해하게 되었습니다. 이제 회전과 확대 애니메이션을 결합할 때, 각 값들이 어떻게 작용하는지 더 명확하게 파악할 수 있을 것 같습니다.

헷갈렸던 점#

@keyframes 안에서 transform 속성에 회전과 크기 조정을 같이 넣을 때, 각 값의 역할이 어떻게 적용되는지 명확히 이해하지 못했습니다. 또한, animation 축약형 속성에서 각 시간 값들이 무엇을 의미하는지 혼동되었습니다. 애니메이션의 각 단계에서의 변화와 실행 방식 제어에 대한 개념이 부족했던 것 같습니다.

정리된 이해#

@keyframes는 애니메이션의 각 단계를 정의하며, transform 속성을 활용하여 회전 각도나 크기 조절과 같은 시각적 변화를 설정할 수 있다. animation 속성은 애니메이션의 실행 방식을 제어하며, duration은 한 사이클의 총 시간, delay는 시작 지연 시간을 의미한다. 이 두 가지 속성을 함께 사용하면 복잡한 회전과 크기 조절을 결합한 애니메이션을 구현할 수 있다.

@keyframes rotation {
    from { transform: rotate(45deg) scale(0.1); }
    to { transform: rotate(-45deg) scale(0.5); }
}

animation: rotation 1500ms linear 500ms infinite alternate none;

6. 반응형 상단 영역 구현을 위한 미디어 쿼리 활용법#

무엇을 배웠나#

미디어쿼리를 별도 블록으로 작성하고, 해당 조건 하에서만 스타일이 덮어쓰는 방식을 이해하게 되었다. 기본 CSS를 유지하면서 화면 크기에 따라 필요한 부분만 수정하는 방법을 학습했고, HTML 구조 내에서 반응형 상단 영역을 만들 수 있게 되었다. 특히 @media 블록의 위치와 스타일 덮어쓰기 개념이 명확해졌다.

헷갈렸던 점#

미디어쿼리를 어디에 넣어야 하는지, 그리고 기본 CSS와 어떻게 충돌하지 않고 특정 스타일만 변경해야 할지 몰랐습니다. 스타일이 덮어씌워지는 방식과 미디어쿼리 조건에 따른 스타일 변경이 직관적으로 이해되지 않았습니다.

정리된 이해#

미디어쿼리는 CSS 파일 내에서 별도의 블록으로 작성하며, 특정 조건에 맞춰 스타일을 덮어써서 기본 스타일을 유지하면서 반응형 디자인을 구현할 수 있다. 미디어쿼리 내의 스타일은 해당 조건이 충족될 때만 적용되어, 기본적인 스타일은 그대로 유지된다.

/* 미디어쿼리 블록 */
@media (min-width: 320px) and (max-width: 800px) {
    #intro h1 {
        width: 100%;
        text-align: center;
        padding: 22px 0 0 0;
    }
    #intro nav {
        width: 100%;
    }
    #intro {
        height: 160px;
    }
    .container {
        width: 640px; /* 예시로 추가한 부분 */
    }
}
