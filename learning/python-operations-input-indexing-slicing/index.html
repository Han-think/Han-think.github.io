Python 연산자 이해하기: 초보자를 위한 가이드 (1부)

초보자로서 Python 연산자의 다양한 사용법과 타입 변환에 대한 혼란을 정리하고 이해하는 과정을 공유합니다.
2026년 5월 30일 · 10 min

왜 썼나#

오늘은 Python 프로그래밍 언어를 처음 배우는 입장에서 가장 기본적이면서도 종종 혼란을 일으키는 연산자들에 대해 깊이 이해해보고자 합니다. 특히, 다양한 데이터 타입 간의 연산자 활용과 타입 변환에 초점을 맞추어 학습 경험을 기록하고 싶었습니다. 이를 통해 비슷한 고민을 하는 초보자들이 조금 더 명확하게 개념을 파악할 수 있기를 바랍니다.

배운 것#

  • 데이터 타입과 연산자의 상호작용: Python에서는 동일한 연산자라도 사용하는 데이터 타입에 따라 결과가 달라질 수 있다는 점을 명확히 이해했습니다. 예를 들어, 정수와 실수를 함께 사용할 때 연산 결과가 항상 실수로 반환되는 이유를 알게 되었습니다. 이는 연산의 기본적인 타입 우선순위와 관련이 있습니다.
  • 나눗셈 연산자의 결과 타입: / 연산자는 항상 실수(float)를 반환한다는 사실을 확인했습니다. 이는 두 숫자를 나눌 때 결과가 항상 실수로 처리되기 때문입니다. 반대로, 정수 나눗셈을 원한다면 // 연산자를 사용해야 함을 배웠습니다. 이 연산자는 몫을 정수로 반환합니다.
  • 나머지 연산자 이해: % 연산자는 나머지를 반환하며, 주로 나눗셈에서의 나머지 값을 계산할 때 사용됩니다. 예를 들어, 10 % 3은 1을 반환합니다.
  • 문자열 연산자: 문자열에서 +는 문자열 연결을 의미하며, 여러 문자열을 이어붙일 때 사용됩니다. 반면, * 연산자는 문자열을 지정된 횟수만큼 반복합니다. 예를 들어, "안녕" * 3은 "안녕안녕안녕"을 생성합니다.

헷갈린 것#

  • 타입 변환의 미묘함: 정수와 실수를 혼합 사용할 때 발생하는 타입 변환의 미묘한 부분이 여전히 명확하지 않습니다. 특히, 의도치 않은 타입 변환이 프로그램의 결과에 어떤 영향을 미칠 수 있는지에 대해 더 깊이 이해할 필요가 있습니다.
  • 연산자 역할의 복잡성: //와 % 연산자의 역할이 비슷해 보일 수 있지만, 실제로는 서로 다른 목적을 가지고 있다는 점이 혼란스럽습니다. 구체적인 사용 사례를 통해 차이점을 명확히 파악해야겠습니다.

정리된 이해#

  • 데이터 타입의 중요성: Python에서 연산자의 결과는 사용하는 변수의 데이터 타입에 크게 영향을 받습니다. 특히, 정수와 실수 연산에서는 결과 타입이 항상 실수로 변환되는 경향이 있으므로 주의가 필요합니다.
  • 연산자의 명확한 역할: /, //, % 연산자는 각각 다른 목적을 가지고 있으며, 이를 정확히 이해하고 사용하는 것이 중요합니다. 특히 문자열 연산자인 +와 *는 문자열 처리 시 매우 유용하지만, 올바른 사용법을 익혀야 합니다.

실습 예시#

  • 정수 나눗셈과 몫 계산:

    # 정수 나눗셈 예시
a = 10
b = 3
print(a / b)  # 결과: 3.3333333333333335 (실수 결과)
print(a // b)  # 결과: 3 (정수 몫)

# 나머지 계산 예시
remainder = a % b
print(remainder)  # 결과: 1

  • 문자열 연산 예시:

    # 문자열 연결
greeting = "안녕하세요"
name = "사용자님"
full_greeting = greeting + ", " + name + "! 환영합니다."
print(full_greeting)  # 결과: "안녕하세요, 사용자님! 환영합니다."

# 문자열 반복
repeated_greeting = greeting * 3
print(repeated_greeting)  # 결과: "안녕하세요안녕하세요안녕하세요"

왜 썼나#

숫자 연산은 프로그래밍의 기초 중 하나로, 알고리즘 구현이나 데이터 처리 과정에서 필수적으로 사용됩니다. 이 글을 통해 제 개인적인 학습 과정을 공유하며, 초보자들이 흔히 겪는 혼란을 해결하고 실제 코드 예시를 통해 이해를 돕고자 합니다.

배운 것#

  • 타입의 영향: Python에서 숫자 연산을 수행할 때 입력 타입(정수 또는 실수)이 결과 타입에 큰 영향을 미칩니다. 특히 문자열 입력을 숫자로 변환해야 하는 상황에서 타입 캐스팅의 중요성을 깨달았습니다.
  • 연산자의 다양성: 사칙연산 외에도 몫, 나머지, 제곱 등 다양한 연산자를 통해 더 복잡한 계산을 수행할 수 있다는 것을 배웠습니다.

헷갈린 것#

  • 타입 캐스팅의 필요성: input() 함수로 받은 입력이 문자열로 처리되기 때문에, 숫자 연산을 시도할 때 타입 오류가 발생할 수 있다는 점이 혼란스러웠습니다. 예를 들어, 숫자를 입력받아 연산해야 하는 상황에서 직접 타입을 변환하지 않으면 오류가 발생합니다. 
    user_input = input("숫자를 입력하세요: ")
result = int(user_input) * 5  # 타입 변환 없이 연산 시 오류 발생
  • 인덱싱과 슬라이싱의 복잡성: 문자열이나 리스트에서 특정 부분을 추출하는 방법에 대한 이해가 아직 완벽하지 않았습니다. 특히 슬라이싱의 시작과 끝 인덱스 설정에 대한 명확한 인식이 필요했습니다. 
    my_list = [10, 20, 30, 40]
# 슬라이싱 예시
part_of_list = my_list[1:3]  # 인덱스 1부터 2까지 (3은 포함되지 않음)

정리된 이해#

  • 숫자 연산:
    • 사칙연산 (+, -, *, /): 정수와 실수를 함께 사용할 경우 결과는 항상 실수 타입으로 반환됩니다.
      • 예시: 
        # 정수 연산
print(3 * 5)      # 출력: 15 (int)
# 실수 연산
print(3.0 * 5.0)  # 출력: 15.0 (float)
print(3 * 5.0)    # 출력: 15.0 (float, 실수 타입으로 변환)
# 나눗셈 결과는 항상 실수
print(10 / 5)     # 출력: 2.0 (float)
      • 추가 연산자:
        • //: 정수 타입으로 몫 반환 
          print(10 // 3)   # 출력: 3 (int)
        • %: 나머지 반환 
          print(10 % 3)    # 출력: 1 (int)
        • **: 제곱 연산 
          print(2 ** 3)    # 출력: 8 (int)

실습 예시#

아래 코드 예시를 통해 위에서 다룬 개념들을 직접 확인해 보세요.

# 타입 캐스팅 예시
user_input = input("정수를 입력하세요: ")
number = int(user_input)  # 문자열을 정수로 타입 캐스팅
result = number * 2       # 정수 연산 결과
print(f"결과: {result}")

# 인덱싱과 슬라이싱 예시
sample_string = "Hello, World!"
print("첫 글자:", sample_string[0])  # 첫 번째 문자
print("슬라이싱 예시:", sample_string[7:12])  # "World" 추출

# 리스트 슬라이싱 예시
numbers = [1, 2, 3, 4, 5]
print("부분 리스트:", numbers[1:4])  # 인덱스 1부터 3까지

### 왜 썼나
이번 학습 세션에서는 Python 프로그래밍 언어의 핵심 개념 중 하나인 타입 캐스팅과 리스트 조작에 집중했습니다. 특히 숫자 처리와 데이터 구조 이해는 프로그래밍에서 매우 기본적이면서도 중요한 기술입니다. 이러한 기초 지식은 복잡한 프로젝트를 진행할 때 효율적인 코드 작성에 큰 도움이 됩니다.

### 배운 것
- **타입 캐스팅**:
  - 사용자 입력이나 외부 데이터가 문자열 형태로 들어올 때, 숫자 연산을 위해 타입을 변환해야 한다는 사실을 깨달았습니다. 이를 통해 `int()`와 `float()` 함수를 적절히 사용하여 데이터 타입을 조정할 수 있습니다.
  - 리스트나 배열에서 특정 요소에 접근하거나 부분 리스트를 추출하는 방법인 **인덱싱**과 **슬라이싱** 기법을 익혔습니다. 특히, Python의 0부터 시작하는 인덱스 시스템과 슬라이싱의 유연성에 놀랐습니다.

### 헷갈린 것
- 타입 캐스팅 시 `int()`와 `float()`의 차이점과 언제 각각을 사용해야 하는지에 대해 잠시 혼란스러웠습니다. 숫자가 정수인지 소수인지 판단하고 적절한 타입 변환을 선택하는 것이 중요하다는 것을 다시 한번 확인했습니다.
- 인덱싱과 슬라이싱에서 `-1`과 같은 음수 인덱스가 마지막 요소를 가리키는 것을 이해하는 데 잠시 시간이 걸렸습니다. 하지만 실제로 적용해보니 이해가 훨씬 쉬워졌습니다.

### 정리된 이해
- **타입 캐스팅**:
  - **문자열을 숫자로 변환**: `input()`으로 받은 문자열을 숫자로 변환하려면 `int()` 또는 `float()`를 사용합니다.
    ```python
    # 문자열을 정수로 변환하여 덧셈
    num1 = input("첫 번째 숫자를 입력하세요: ")
    num2 = input("두 번째 숫자를 입력하세요: ")
    result = int(num1) + int(num2)
    print("합계:", result)
    
    # 한 줄로 타입 변환 및 입력
    num1 = int(input("숫자를 입력하세요: "))
    ```
  - **인덱싱**: 리스트나 문자열에서 특정 위치의 값을 추출합니다. Python은 인덱스가 0부터 시작합니다.
    ```python
    word = "Ready"
    print(word[0])  # 'R' - 첫 번째 문자
    print(word[1])  # 'e' - 두 번째 문자
    print(word[-1]) # 'y' - 마지막 문자
    ```
  - **슬라이싱**: 특정 범위의 요소를 추출합니다.
    ```python
    # 예시 리스트
    numbers = [10, 20, 30, 40, 50]
    # 2번째부터 4번째까지의 요소 추출
    slice_result = numbers[1:4]  # [20, 30, 40]
    ```

왜 썼나#

이번 학습 세션에서는 특히 Python에서 복잡한 데이터 구조를 다루는 방법과 기본 자료형들 간의 미묘한 차이에 초점을 맞추었습니다. 이러한 이해는 프로그램을 작성할 때 예상치 못한 오류를 줄이고 효율적인 코드 작성을 가능하게 합니다. 특히 초보자로서 이러한 개념들을 명확히 파악하는 것은 향후 프로젝트 개발에 큰 도움이 됩니다.

배운 것#

  • 중첩 리스트 활용: 중첩 리스트는 다양한 형태의 데이터를 한 곳에 모아 다룰 수 있게 해줍니다. 이를 통해 복잡한 정보 구조를 쉽게 관리할 수 있습니다.

    • 실습 예시: 
      nested_list = ["주요 프로젝트", ["일일보고", "주간보고"], ["보고서", ["세부내용", "첨부파일"]]]
print(nested_list[1][1])  # 출력: "주간보고"

    이 예시를 통해 리스트 내에 리스트를 포함시켜 계층적인 데이터 구조를 다루는 방법을 배웠습니다.

  • 문자열과 숫자의 동작 차이: Python에서 문자열과 숫자는 기본적으로 다른 방식으로 처리됩니다.

    • 문자열 연산: 문자열은 연결되거나 특정 위치의 문자를 참조하는데 사용됩니다. 
      str1 = "안녕"
str2 = "하세요"
print(" ".join([str1, str2]))  # 출력: "안녕 하세요"
    • 숫자 연산: 숫자는 수학적 연산에 사용됩니다. 
      num1 = 5
num2 = 3
total = num1 + num2  # 값: 8

헷갈린 것#

  • 문자열과 숫자의 혼동: "1"과 1의 차이와 그에 따른 연산 결과의 차이로 인해 초기에는 혼란스러웠습니다. "1" + "2"는 "12"로 문자열 연결이 이루어지지만, 1 + 2는 숫자 연산으로 3이 됩니다.
  • 인덱싱과 슬라이싱의 미묘한 차이: 특히 슬라이싱에서 마지막 인덱스가 포함되지 않는다는 점이 이해하기 어려웠습니다. 예를 들어, list[1:3]은 인덱스 1부터 2까지의 값을 가져옵니다.

정리된 이해#

  • 중첩 리스트의 활용: 중첩 리스트는 복잡한 데이터 구조를 효과적으로 다루는 데 유용합니다. 예제를 통해 깊이 있는 인덱싱 방법을 이해할 수 있었습니다.

    • nested_list = ["주요 프로젝트", ["일일보고", "주간보고"], ["보고서", ["세부내용", "첨부파일"]]]
print(nested_list[1][1])  # 출력: "주간보고"

  • 자료형에 따른 동작 차이: Python에서 자료형에 따라 동일한 연산자라도 다르게 동작합니다. 이 차이를 이해함으로써 더 정확하고 유연한 코드를 작성할 수 있습니다.

    문자열 연결#

    str_list = [“안녕”, “하세요”] print(" “.join(str_list)) # 출력: “안녕 하세요”

    숫자 덧셈#

    num_sum = 5 + 3 # 값: 8

  • 인덱싱과 슬라이싱의 고급 활용 방법 연구

왜 썼나#

이번 글에서는 Python을 처음 배우는 학습자들이 흔히 겪는 혼란스러운 주제들을 다룹니다. 특히 input() 함수를 사용할 때 발생하는 오류와 숫자 변환 과정에서의 어려움, 그리고 리스트나 문자열에서의 인덱싱 및 슬라이싱에 대한 이해 부족을 중심으로 다룹니다. 이러한 내용을 통해 초보자들이 실제 코드 작성 시 더 안정적이고 예측 가능한 프로그래밍 경험을 할 수 있도록 도움을 주고자 합니다.

배운 것#

  • input() 함수의 본질: input() 함수는 사용자로부터 문자열을 입력받는 기본적인 방법입니다. 숫자 입력을 기대할 때는 즉시 형 변환을 해야 합니다. 이를 간과하면 숫자 처리 로직에서 예상치 못한 오류가 발생할 수 있습니다.
  • 형 변환의 중요성: 문자열을 숫자로 변환할 때 int() 또는 float()를 사용해야 하지만, 잘못된 입력이 들어오면 ValueError 예외가 발생합니다. 이를 효과적으로 처리하는 방법을 배웠습니다.
  • 인덱싱과 슬라이싱의 기초: 리스트나 문자열에서 특정 요소를 추출하거나 부분 문자열을 얻기 위한 인덱싱과 슬라이싱의 기본 개념을 확실히 이해하게 되었습니다. 인덱스의 시작이 0이라는 점과 슬라이싱의 범위 설정 방법에 대해 명확히 배웠습니다.

헷갈린 것#

  • input()과 형 변환: 사용자 입력이 무조건 문자열이라는 점을 간과하고 숫자 입력을 기대하면서 즉시 형 변환을 하지 않아 오류가 발생했습니다. 예를 들어, 숫자 입력을 요구하는 상황에서 문자열로 들어온 입력을 그대로 처리하려고 하면 문제가 생깁니다.
  • 예외 처리: 문자열을 숫자로 변환할 때 잘못된 입력이 들어올 경우 예외 처리를 제대로 하지 않아 프로그램이 갑자기 중단되는 경험이 있었습니다. 이를 해결하기 위해 try-except 블록을 적절히 사용하는 방법을 배웠습니다.
  • 인덱싱 오류: 리스트나 문자열에서 인덱싱을 할 때 인덱스 범위를 벗어나는 접근을 하거나, 슬라이싱 범위를 잘못 설정하여 예상치 못한 결과를 얻었습니다. 특히 Python에서 인덱스의 시작이 0이라는 점을 간과한 것이 주요 원인이었습니다.

정리된 이해#

  • input() 함수 활용: 사용자로부터 숫자 입력을 받을 때는 즉시 형 변환을 해야 합니다. 예시 코드는 다음과 같습니다:

    user_input = input("숫자를 입력하세요: ")
try:
    number = int(user_input)  # 또는 float(user_input) 사용 가능
    print(f"입력된 숫자는 {number}입니다.")
except ValueError:
    print("올바른 숫자를 입력해주세요.")

  • 안전한 형 변환: 잘못된 타입 변환 시도로 인한 오류를 방지하기 위해 예외 처리를 반드시 포함시켜야 합니다. 예를 들어:

    try:
    converted_value = int(user_input)
    print(f"변환된 값: {converted_value}")
except ValueError:
    print("유효한 숫자를 입력해주세요.")

  • 인덱싱과 슬라이싱: 리스트나 문자열에서 요소를 안전하게 추출하거나 부분 문자열을 얻기 위해 인덱스와 슬라이싱의 기본을 확실히 이해해야 합니다.

    # 리스트 예시
my_list = [10, 20, 30, 40, 50]
first_element = my_list[0]  # 첫 번째 요소
slice_elements = my_list[1:4]  # 인덱스 1부터 3까지의 요소
print(f"첫 번째 요소: {first_element}, 슬라이스된 요소: {slice_elements}")
# 문자열 예시
my_string = "Hello World"
first_char = my_string[0]  # 첫 번째 문자
substring = my_string[0:5]  # "Hello"
print(f"첫 문자: {first_char}, 부분 문자열: {substring}")

왜 썼나#

파이썬 프로그래밍을 배우면서 데이터 조작의 핵심 기술 중 하나인 인덱싱과 슬라이싱에 대해 깊게 이해하고자 이 글을 작성했습니다. 이 두 기술은 리스트와 문자열을 효율적으로 다룰 수 있게 해주며, 프로그래밍에서 매우 중요한 역할을 합니다. 특히, 실무에서 자주 사용되므로 초보자도 쉽게 익힐 수 있도록 설명하고자 합니다.

배운 것#

  • 인덱싱: 파이썬에서 리스트나 문자열의 요소에 접근하는 방법입니다. 인덱스는 항상 0부터 시작하며, 양수 인덱스는 마지막 요소부터 시작됩니다 (예: my_list[-1]은 마지막 요소를 참조).

    my_list = [10, 20, 30, 40]
print(my_list[0])  # 출력: 10
print(my_list[-1])  # 출력: 40

  • 슬라이싱: 특정 범위의 요소를 추출하거나 수정할 때 사용됩니다. [시작:끝:스텝] 형태로 표현됩니다.

    # 리스트 슬라이싱 예시
slice_list = my_list[1:3]  # 인덱스 1부터 2까지 (3은 포함되지 않음)
print(slice_list)  # 출력: [20, 30]

# 문자열 슬라이싱 예시
my_string = "Python"
slice_string = my_string[1:4]  # 인덱스 1부터 3까지 (4는 포함되지 않음)
print(slice_string)  # 출력: "yth"

헷갈린 것#

슬라이싱에서 가장 헷갈릴 수 있는 부분은 인덱스의 포함 여부입니다. 슬라이싱 범위를 지정할 때 끝 인덱스는 포함되지 않는다는 점을 기억하는 것이 중요합니다. 이를 놓치면 예상치 못한 결과를 얻게 될 수 있습니다.

정리된 이해#

인덱싱은 리스트나 문자열의 특정 위치에 있는 요소를 정확하게 접근하는 데 사용되며, 슬라이싱은 연속된 요소들의 부분 집합을 효율적으로 다룰 수 있게 해줍니다. 이러한 기술들은 코드를 간결하게 만들고, 데이터 처리를 훨씬 유연하게 만드는 데 기여합니다.

실습 예시#

아래는 실제 코드 예시를 통해 인덱싱과 슬라이싱을 적용해보는 예제입니다.

# 리스트 조작 예시
numbers = [5, 15, 25, 35, 45]
print("특정 요소 접근:", numbers[2])  # 출력: 25
print("슬라이싱 예시:", numbers[1:4])  # 출력: [15, 25, 35]

# 문자열 조작 예시
greeting = "Hello, World!"
print("문자열 슬라이싱:", greeting[7:12])  # 출력: "World"

초보자 키워드#

  • 인덱스: 리스트나 문자열의 특정 위치를 가리키는 숫자
  • 슬라이싱: 범위 내의 요소를 추출하는 기법
  • 포함 여부: 슬라이싱 시 끝 인덱스는 포함되지 않음
