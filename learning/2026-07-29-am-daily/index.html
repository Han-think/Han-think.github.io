1. JavaScript 코드 실행과 디버깅 기초#

무엇을 배웠나#

JavaScript 코드가 웹 페이지에 바로 반영되지 않는 이유를 이해하고, <script> 태그와 외부 파일 연결을 통해 코드 실행 위치를 명확히 알게 되었다. 브라우저 개발자 도구의 각 탭(Console, Sources, Elements)의 역할을 구분하고, console 출력 확인과 breakpoint 설정 등 기본적인 디버깅 방법을 익혔다. 이제 HTML 파일을 직접 열고 개발자 도구를 활용하여 코드를 실행하고 오류를 해결할 수 있게 되었다.

헷갈렸던 점#

처음에는 JavaScript 코드를 작성했는데 웹 페이지에 아무런 변화가 없어 제대로 실행되지 않는 것 같아 답답했습니다. 브라우저 개발자 도구의 각 탭이 무엇을 하는 곳인지 헷갈리고, 어떤 탭에서 어떤 정보를 확인해야 하는지 몰라 어려움을 겪었습니다. Live Server를 사용하는 방법과 단순히 HTML 파일을 여는 것의 차이도 명확하게 이해하지 못했습니다.

정리된 이해#

JavaScript 코드는 HTML 파일 내 <script> 태그나 별도의 .js 파일로 연결하여 실행되며, 웹 페이지에 즉시 반영되지 않을 수 있습니다. 브라우저 개발자 도구의 Console은 코드 출력을 확인하고, Sources는 코드 실행 흐름을 따라가며, Elements는 HTML 구조를 보여줍니다. 이러한 이해를 바탕으로 HTML 파일을 직접 열거나 Live Server를 활용하여 코드를 실행하고, 개발자 도구를 통해 문제 해결 및 디버깅을 진행할 수 있습니다.

<script>
   var str1 = "Hello world!";
   console.log(str1); // 콘솔에 출력
   debugger; // 디버깅 지점 표시
</script>

<script src="path/to/your/script.js"></script>

2. JavaScript 변수, 타입, 그리고 데이터 변환 이해하기#

무엇을 배웠나#

JavaScript에서 문자열과 숫자 타입의 구분이 중요하다는 것을 알게 되었다. 특히, + 연산자가 상황에 따라 덧셈과 문자열 연결을 수행하기 때문에 타입에 주의해야 한다는 점을 깨달았다. 또한 JavaScript에는 char 타입이 없으며, 문자열을 숫자로 변환하려면 명시적인 타입 변환 함수를 사용해야 한다는 점을 이해했다.

헷갈렸던 점#

숫자와 문자열을 구분하는 게 어려웠고, + 연산자가 덧셈과 연결 둘 다 하는지 몰라 코드가 예측 불가능하게 느껴졌다. “문자"랑 “문자열” 차이도 헷갈려서 JavaScript에 char 타입이 있는 줄 알았다.

정리된 이해#

JavaScript에서 문자열과 숫자는 명확히 구분되어야 하며, + 연산자는 피연산자의 타입에 따라 덧셈 또는 문자열 연결을 수행한다. 문자열을 숫자로 활용하려면 Number(), parseInt(), parseFloat() 등의 함수를 사용하여 명시적으로 타입 변환을 해주어야 한다. char 타입은 JavaScript에 존재하지 않으며, 문자(character)는 문자열의 일부로 취급된다.

var str = "20";
console.log(typeof str);

console.log(typeof 20);

var textNumber = "20";

3. 함수 활용법: 매개변수, 인자, 반환값 완벽하게 이해하기#

무엇을 배웠나#

함수의 매개변수는 함수 정의 시 입력 값의 위치를 나타내는 이름이고, 인자는 실제 함수 호출 시 전달하는 값이라는 것을 명확히 이해하게 되었다. 또한, 반환값이 없는 함수는 결과가 undefined가 될 수 있다는 점과, JavaScript에서 함수를 변수에 담아 사용하는 방식도 파악했다. 번호표 기계와 저금통 예시를 통해 반환값의 필요성을 더욱 깊이 이해할 수 있었다.

헷갈렸던 점#

함수 매개변수와 실제 인자를 구분하는 게 어려웠고, 반환값이 없는 함수가 어떻게 작동하는지 이해하는 데 꽤 애먹었습니다. 특히 반환값이 없는 저금통 예시에서 결과가 어떻게 보이는지 명확하게 이해되지 않았습니다. JavaScript에서 함수를 변수에 할당하는 방식도 Python 함수 정의 방식과 달라서 약간 혼란스러웠습니다.

정리된 이해#

함수는 특정 작업을 수행하는 코드 묶음이고, 매개변수는 함수를 정의할 때 입력받는 값을 위한 이름이며 인자는 실제 함수 호출 시 전달하는 값이야. 함수는 작업을 완료 후 결과를 반환할 수도 있고, 반환하지 않을 수도 있으며, 반환하지 않으면 undefined가 반환되는 것으로 이해하면 돼. JavaScript에서 함수를 변수에 담아 사용하는 방식과 Python의 def 함수는 다르지만, 기본적인 개념은 동일하다는 것을 알게 되었어.

function 토스트기(빵) {  // '빵'은 매개변수
    return "구워진 " + 빵;  // 실제 인자 '호밀빵'이 전달됨
}
토스트기("호밀빵");  // 인자 전달

var 접시 = 토스트기("호밀빵");  // 인자 '호밀빵' 전달

function 번호표기기() {
    번호++;  // 내부 상태 변경
    return 번호;  // 반환값 지정
}

var 결과 = 저금통(500);  // 명시적 반환값 없음 → undefined

4. JavaScript 실습: 흔한 오류와 핵심 개념 정리#

무엇을 배웠나#

JavaScript 실습 초반에 HTML 구조, 브라우저 설정, 출력 위치, 함수 호출 방식에 대한 기본적인 이해가 부족하여 어려움을 겪었습니다. 코드가 제대로 작동하는지 확인하는 방법을 잘못 알고 있었고, 오타로 인해 오류를 인지하지 못하는 경우도 있었습니다. 하지만 HTML 구조의 역할, console.log()의 활용, 함수 정의와 호출의 중요성 등을 명확히 이해하게 되었습니다.

헷갈렸던 점#

HTML 파일을 직접 열었을 때 빈 화면이 나와 코드가 작동하지 않는 줄 알았고, console.log()가 브라우저 화면에 출력되는 줄 착각해서 어디가 문제인지 파악하기 어려웠습니다. 또한 함수를 정의만 하고 실행하지 않아서 코드의 정상 작동 여부를 제대로 확인하지 못했습니다.

정리된 이해#

HTML 파일을 열었을 때 화면이 비어있는 것이 코드가 작동하지 않는다는 의미는 아니었고, console.log()는 브라우저 콘솔에 결과를 보여주는 것을 확인했습니다. 함수를 정의하고 호출하는 과정과 오타 발생 시 오류 메시지 인식이 중요하다는 점도 깨달았습니다. 이러한 점들을 통해 JavaScript 코드의 실행 과정을 명확히 이해하고 디버깅 능력을 향상시킬 수 있을 것 같습니다.

function 저금통(금액) {
  console.log(`${금액}원 저금 완료!`);
}
저금통(500);

총평#

오늘 오전 전체에서 배운 것#

JavaScript 코드 실행 위치, 변수 타입, 그리고 함수의 매개변수와 반환값 개념을 익혔습니다. 특히, 디버깅 도구를 활용하여 코드 오류를 해결하고, 변수 타입에 주의하며 함수를 정확하게 활용하는 방법을 알게 되었습니다. 실습을 통해 기본적인 JavaScript 실행 과정에서 발생할 수 있는 문제들을 인지하고 해결하는 능력을 키웠습니다.

다음에 조심할 것#

이제 코드를 실행하고 오류를 해결할 수 있게 되었지만, 실습 과정에서 HTML 구조, 브라우저 설정, 출력 위치에 대한 이해가 부족했기에 앞으로는 이 부분들을 더욱 꼼꼼하게 확인해야겠다. 또한 오타로 인한 오류를 놓치지 않도록 코드를 주의 깊게 살펴보고, console.log()를 적극적으로 활용해서 디버깅하는 습관을 들여야겠다.

다음 복습 주제#

JavaScript 타입 변환에 대한 좀 더 다양한 예제를 풀어보고, 함수를 변수에 담아 사용하는 방식이 어떻게 활용될 수 있는지 다른 실습 문제를 통해 복습해볼 필요가 있을 것 같습니다. 그리고 console.log()를 사용하는 것 외에 좀 더 다양한 디버깅 기법을 익혀서 실제 개발 상황에 적용해보고 싶습니다.
