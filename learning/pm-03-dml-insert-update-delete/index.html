1. INSERT 문법#

왜 이걸 보게 됐나#

SQLite 실습을 시작하면서 데이터 테이블에 새로운 정보를 추가하는 가장 기본적인 방법인 INSERT 문법을 익히게 되었어. 처음에 컬럼 순서나 작은따옴표 처리 때문에 어려움을 겪었지만, 기본적인 문법을 이해하고 연습하면서 데이터 추가 작업을 효과적으로 수행할 수 있게 되었어. INSERT 문법은 데이터베이스를 관리하고 활용하는 데 필수적인 요소라는 것을 깨달았어.

내가 헷갈린 지점#

INSERT 문을 쓸 때 컬럼과 값의 순서가 헷갈리는 경우가 많았고, 특히 문자열 안에 작은따옴표를 넣는 방식이 어떻게 해야 하는지 고민했습니다. ‘It’s’처럼 작은따옴표가 포함된 문자열을 입력할 때 작은따옴표를 두 번 사용해야 한다는 점을 깨닫지 못해 삽질했습니다. 컬럼 순서, 값 순서, 그리고 작은따옴표 처리 모두 숙지해야 하는 부분이라는 것을 알게 되었습니다.

시도한 코드 / 예시#

INSERT INTO book (title, category, price, rating, stock)
VALUES ('It''s Only the Himalayas', 'Travel', 45.17, 2, 19);

결과와 해석#

INSERT 문을 사용할 때 컬럼 이름 순서와 값 순서가 일치해야 하고, 문자열 값에 작은따옴표가 필요한데, 작은따옴표 안에 작은따옴표를 넣어서 이스케이프 처리해야 한다는 것을 실습을 통해 알게 되었다. 예를 들어, ‘It’s Only the Himalayas’를 삽입할 때 ‘It’’s’처럼 작성해야 오류 없이 데이터를 넣을 수 있었다.

정리된 이해#

INSERT 문을 사용할 때는 테이블에 정의된 컬럼 순서에 맞춰 값을 입력해야 하고, 문자열 값을 넣을 때 작은따옴표가 필요한데, 작은따옴표 자체를 표현하기 위해서는 작은따옴표를 두 번 사용해야 합니다. 테이블 정의와 정확히 일치하는 컬럼 순서와 값을 넣어주는 것이 중요합니다.

2. UPDATE 연산#

왜 이걸 보게 됐나#

데이터베이스의 재고나 평점 같은 값들을 수정해야 할 때, 단순히 값을 덮어쓰는 것보다 기존 값에 변화를 주는 방식으로 업데이트해야 하는 경우가 많았어. 그래서, UPDATE 문에서 값을 연산해서 적용하는 방법을 배우게 됐어. 예를 들어, 책의 판매량이 늘어났을 때, 재고량을 자동으로 늘리는 기능을 만들 수 있게 됐지.

내가 헷갈린 지점#

UPDATE 문을 쓸 때, 데이터베이스의 특정 필드 값을 변경하는 방법을 처음에는 잘 몰랐어요. 기존 값에 새로운 값을 더하거나 다른 값으로 바꿔 넣는 구문이 어떻게 되는지, 그리고 어떤 조건에 맞는 행을 수정해야 하는지 혼란스러웠습니다. 특히 stock 값을 증가시키는 과정에서 UPDATE 구문이 어떻게 작성되어야 하는지 이해하는 데 시간이 좀 걸렸어요.

시도한 코드 / 예시#

UPDATE book SET stock = stock + 5 WHERE category = 'Poetry';

결과와 해석#

UPDATE 명령에서 SET 절 뒤에 stock = stock + 5와 같이 직접 연산을 수행하여 기존 값에 새로운 값을 더할 수 있다는 것을 알게 되었다. UPDATE 문은 특정 조건을 만족하는 레코드의 값을 변경할 때 매우 유용하며, 데이터베이스의 정보를 업데이트하는 데 핵심적인 역할을 한다. 예를 들어, 특정 카테고리의 책 재고를 늘릴 때 이 방법을 사용했다.

정리된 이해#

UPDATE 문을 사용할 때 SET 뒤에 특정 컬럼의 값을 변경하는 연산을 직접 입력할 수 있어서 기존 값을 기반으로 새로운 값을 계산하여 업데이트할 수 있다는 것을 알게 되었다. 예를 들어, stock 컬럼의 값을 기존 값에 특정 숫자를 더하여 증가시키는 방식으로 활용할 수 있다. WHERE 절과 함께 사용하면 조건에 맞는 레코드의 값만 변경할 수 있다.

3. DELETE 구문#

왜 이걸 보게 됐나#

데이터베이스를 조작하는 실습을 하다가 DELETE 명령어를 잘못 사용해서 데이터가 삭제되는 것을 방지하기 위해 DELETE 구문이 어떻게 작동하는지 자세히 알아야 했습니다. 특히, 조건 없이 테이블의 모든 데이터를 삭제하는 심각한 오류를 막기 위해 WHERE 절의 중요성을 깨닫고 학습하게 되었습니다. 안전하게 데이터베이스를 관리하기 위해 DELETE 구문 사용법을 확실히 익혀야 했습니다.

내가 헷갈린 지점#

처음에는 DELETE 명령을 사용할 때, SET 구문을 사용하는 것처럼 생각해서 DELETE book SET rating = 1; 과 같이 잘못된 쿼리를 작성했었다. 데이터 삭제가 아니라 값을 수정하는 것처럼 착각했던 것 같다. FROM 절과 WHERE 절의 역할이 명확하지 않아서 어려움을 겪었다.

시도한 코드 / 예시#

DELETE FROM book WHERE rating = 1;

결과와 해석#

DELETE 명령은 테이블에서 레코드를 삭제하는 구문인데, DELETE FROM 뒤에 삭제할 테이블 이름을 명시하고, WHERE 절을 통해 삭제 조건을 지정해야 합니다. WHERE 절이 없으면 테이블의 모든 레코드가 삭제되므로 주의해야 하며, 삭제 조건에 맞는 레코드만 선택적으로 삭제할 수 있습니다. 예를 들어, DELETE FROM book WHERE rating = 1;는 rating 값이 1인 모든 책 정보를 삭제합니다.

정리된 이해#

DELETE 문은 테이블에서 행을 삭제하는 명령어인데, 반드시 FROM 절 뒤에 테이블 이름을 명시해야 하고, 실수로 모든 데이터를 삭제하지 않도록 WHERE 절을 사용하여 삭제 조건을 명확하게 지정해야 합니다. WHERE 절을 생략하면 테이블의 모든 데이터가 삭제되므로 주의해야 합니다.

4. WHERE 절#

왜 이걸 보게 됐나#

DELETE 명령어를 사용하다가 테이블의 모든 데이터를 지워버릴 수도 있는 실수에 빠질까 봐 WHERE 절의 중요성을 알게 됐어. 데이터베이스에 있던 내용을 쉽게 날려버릴 수도 있다는 생각에 조심스러워지면서, 특정 조건을 만족하는 데이터만 선택적으로 삭제하는 방법이 필요했어. 그래서 WHERE 절의 개념을 확실히 익혀서 의도치 않은 데이터 손실을 막아야겠다는 생각을 하게 됐지.

내가 헷갈린 지점#

처음에는 DELETE 문에서 WHERE 절이 없어도 되는 줄 알았어요. SET 구문처럼 데이터를 변경하는 거라고 생각했는데, 테이블 전체를 삭제하는 명령어가 아니라는 점을 깨달았어요. WHERE 절이 없으면 테이블의 모든 데이터를 삭제하는 건가 싶어서 조심스러웠습니다.

시도한 코드 / 예시#

DELETE FROM book WHERE rating = 1;

결과와 해석#

WHERE 절은 UPDATE나 DELETE 구문에서 어떤 레코드를 수정하거나 삭제할지 지정하는 아주 중요한 부분이야. UPDATE 구문에서는 특정 조건을 만족하는 레코드만 수정하고, DELETE 구문에서는 특정 조건을 만족하는 레코드만 삭제하게 해줘. 조건이 없으면 테이블의 모든 레코드가 영향을 받으니까 조심해야 해.

정리된 이해#

DELETE 문에서 WHERE 절은 삭제할 데이터를 지정하는 필터 역할을 해, 이 절이 없다면 테이블의 모든 데이터가 삭제되므로 반드시 필요합니다. WHERE 절을 통해 특정 조건을 만족하는 데이터만 선택적으로 삭제할 수 있습니다. 이 절이 누락되면 예상치 못한 데이터 손실이 발생할 수 있습니다.

총평#

오늘 전체에서 배운 것#

SQLite DML 실습을 통해 INSERT 문에서 작은따옴표 처리, UPDATE 문에서 기존 값에 값을 더하는 방식, 그리고 DELETE 문에서 WHERE 절의 필수 사용법을 명확히 이해하게 되었습니다. 특히 WHERE 절이 없는 DELETE 문은 데이터베이스 전체를 삭제하는 명령이 될 수 있다는 점을 인지했습니다. 이제 DML 명령어를 좀 더 자신 있게 사용할 수 있을 것 같습니다.

다음에 조심할 것#

INSERT 할 때 문자열 안에 작은따옴표를 쓸 때, 두 번 써서 이스케이프 해야 한다는 점을 잊지 말아야겠다. UPDATE 할 때 기존 값에 더하거나 빼는 연산을 할 수 있다는 것을 기억하고 활용해야겠고, DELETE 문은 꼭 WHERE 절과 함께 사용해야 테이블 전체가 삭제되지 않도록 주의해야겠다.

다음 복습 주제#

INSERT 문에서 문자열 내 작은따옴표 처리 규칙을 더 확실하게 숙달해야겠다. UPDATE 문에서 다양한 연산(곱셈, 나눗셈 등)을 활용하는 예제를 추가적으로 연습해보고, DELETE 문에서 복합 조건을 사용하는 방법을 살펴볼 필요가 있다.
