1. 모듈화#

왜 이걸 보게 됐나#

모듈화를 이해함으로써 코드의 효율적인 관리와 재사용성을 향상시키는 방법을 배웠습니다. 이를 통해 복잡한 프로젝트를 더 작은, 관리하기 쉬운 부분으로 나눌 수 있게 되었습니다.

내가 헷갈린 지점#

처음에는 모듈화의 실질적인 이점과 import 문 사용 시 주의해야 할 사항들에 대해 명확히 이해하지 못했습니다. 특히, import와 from ... import ...의 선택 기준이 모호했습니다. 또한, Docstring의 중요성과 실제 활용 방법에 대해 더 깊이 이해하고자 했습니다.

시도한 코드 / 예시#

# calculator.py 예시
def add(a, b):
    """두 수를 더하는 함수

    Args:
        a (int): 첫 번째 숫자
        b (int): 두 번째 숫자

    Returns:
        int: 두 수의 합
    """
    return a + b

# string_utils.py 예시
def count_words(text):
    """문자열에서 단어 개수를 세는 함수

    Args:
        text (str): 분석할 문자열

    Returns:
        int: 단어의 개수
    """
    return len(text.split())

결과와 해석#

위 코드 예시에서 calculator.py는 add 함수를 정의하고, string_utils.py는 count_words 함수를 정의합니다. 각 함수는 Docstring을 통해 명확한 설명과 매개변수, 반환 값에 대한 정보를 제공하여 코드의 가독성과 유지보수성을 높입니다.

정리된 이해#

모듈화를 통해 코드를 구조화하고, import 문을 적절히 사용하여 다른 파일의 기능을 재사용할 수 있습니다. if __name__ == '__main__': 조건문은 모듈을 직접 실행할 때만 특정 코드 블록을 실행시켜 다른 스크립트에서의 재사용성을 보장합니다. 또한, Docstring은 함수와 클래스에 대한 상세한 문서화를 제공하여 팀 내 협업과 코드 이해를 돕습니다.

2. 진입점#

왜 이걸 보게 됐나#

진입점은 프로그램의 시작점 역할을 하며, 직접 실행되는 경우에만 특정 코드 블록을 실행시켜 모듈의 재사용성을 향상시킵니다. 이를 이해함으로써 코드의 구조와 실행 흐름을 더 명확하게 파악할 수 있습니다.

내가 헷갈린 지점#

처음에는 if __name__ == '__main__': 구문이 어떤 상황에서 필요한지 정확히 파악하지 못했습니다. 하지만 이제는 이 구문이 모듈을 다른 프로그램에서 import할 때 불필요한 자동 실행을 방지하는 역할을 한다는 것을 이해했습니다.

시도한 코드 / 예시#

def example_function():
    """
    이 함수는 예시로 사용되며,
    간단한 작업을 수행합니다.

    매개변수:
        param1 (int): 첫 번째 정수 입력
        param2 (int): 두 번째 정수 입력

    반환값:
        int: 두 수의 합
    """
    param1 + param2

if __name__ == '__main__':
    example_function()
    print('함수 호출 완료')

결과와 해석#

함수 example_function의 문서 설명이 출력되고, 함수 호출 완료 메시지가 콘솔에 나타납니다.

    이 함수는 예시로 사용되며, 간단한 작업을 수행합니다.

    매개변수:
        param1 (int): 첫 번째 정수 입력
        param2 (int): 두 번째 정수 입력

    반환값:
        int: 두 수의 합

함수 호출 완료

정리된 이해#

진입점은 프로그램의 핵심 실행 부분을 정의하고, 모듈의 독립성을 보장하여 코드의 재사용성을 높입니다. if __name__ == '__main__': 구문을 통해 직접 실행 시만 특정 코드를 실행시켜 다른 프로그램에서의 import 시 자동 실행을 방지합니다. Docstring은 함수나 클래스에 대한 상세한 문서화를 제공하여 코드의 가독성과 유지보수성을 향상시킵니다.

3. Docstring#

왜 이걸 보게 됐나#

Docstring의 구체적인 작성 방법과 그 중요성을 이해하고 싶어합니다. 특히, 어떻게 코드의 가독성과 유지보수를 향상시키는지 알고 싶습니다.

내가 헷갈린 지점#

Docstring이 단순히 주석과 어떻게 다른지, 그리고 왜 Python에서 특별히 강조되는지 명확하게 이해하지 못했습니다. 또한, 다양한 형식의 Docstring (단일 라인, 멀티 라인 등)을 어떻게 구분하고 적용할지 혼란스러웠습니다.

시도한 코드 / 예시#

def add(a, b):
    """
    두 수를 더하는 함수입니다.

    매개변수:
        a (int): 첫 번째 숫자
        b (int): 두 번째 숫자

    반환값:
        int: 두 수의 합
    """
    return a + b

class Calculator:
    """
    간단한 계산기 클래스입니다.

    예제:
        calc = Calculator()
        print(calc.add(5, 3))  # 출력: 8
    """
    def add(self, a, b):
        return self._add(a, b)

    def _add(self, a, b):  # 내부 함수 예시
        return a + b

결과와 해석#

위 코드 예시에서 add 함수와 Calculator 클래스는 각각의 Docstring을 통해 명확한 설명과 매개변수, 반환값 정보를 제공합니다. Calculator 클래스의 Docstring은 클래스의 사용 예시까지 포함하여 사용자가 쉽게 이해하고 적용할 수 있도록 돕습니다.

정리된 이해#

Docstring은 단순 주석을 넘어 함수와 클래스에 대한 구조화된 문서화를 제공하여 코드의 가독성과 유지보수성을 크게 향상시킵니다. 매개변수와 반환값을 명시하고 사용 예시를 포함함으로써 개발자와 사용자 모두에게 명확한 안내를 제공합니다.

4. 함수 import#

왜 이걸 보게 됐나#

함수 import의 다양한 방법을 이해하고 적절하게 사용하기 위해, 각 방법의 장단점과 적용 시나리오를 명확히 파악하고자 합니다. 이를 통해 코드의 가독성과 유지보수성을 향상시키고자 합니다.

내가 헷갈린 지점#

import와 from … import …의 구체적인 차이점과 각각의 사용 사례에 대해 혼란스러웠습니다. 특히, 코드의 구조와 가독성에 어떤 영향을 미치는지 이해하는 것이 어려웠습니다. 또한, Docstring이 단순히 주석인지 아니면 코드 문서화에 필수적인 요소인지 구분하는 데 어려움이 있었습니다.

시도한 코드 / 예시#

# calculator.py 예시
def add(a, b):
    """두 수를 더하는 함수.

    Args:
        a (int): 첫 번째 숫자
        b (int): 두 번째 숫자

    Returns:
        int: 두 수의 합
"""
    return a + b

# string_utils.py 예시
def count_words(text):
    """주어진 문자열에서 단어의 개수를 세는 함수.

    Args:
        text (str): 분석할 문자열

    Returns:
        int: 단어의 개수
"""
    return len(text.split())

결과와 해석#

위 코드 예시에서 calculator.py 모듈은 add 함수를 정의하고, string_utils.py 모듈은 count_words 함수를 정의합니다. 각 함수는 Docstring을 통해 명확한 설명과 인자, 반환값에 대한 정보를 제공하여 문서화를 강화합니다.

정리된 이해#

함수 import를 통해 모듈화된 코드 구조를 이해하고 활용함으로써 코드의 재사용성과 가독성을 높일 수 있습니다. import와 from ... import ...의 적절한 사용은 코드의 구조와 유지보수성에 중요한 역할을 합니다. 또한, Docstring을 통해 함수와 클래스에 대한 명확한 문서화를 수행하면 팀 내 협업과 코드 이해를 크게 향상시킬 수 있습니다.
