1. 모듈화 이해하기#

왜 이걸 보게 됐나#

프로젝트 규모가 커지면서 코드 관리가 어려워져 효율적인 코드 구조에 대해 학습하기 시작했습니다.

내가 헷갈린 지점#

모듈화의 실제 이점과 구조를 명확히 이해하지 못했습니다.

시도한 코드 / 예시#

다음과 같이 간단한 모듈 구조를 직접 만들어 보았습니다.

# calculator.py
def add(a, b):
    return a + b

# string_utils.py
def count_words(text):
    return len(text.split())

def count_chars(text):
    return len(text)

def reverse_string(s):
    return s[::-1]

def is_palindrome(s):
    return s == s[::-1]

# main.py
import calculator
from string_utils import count_words, count_chars, reverse_string, is_palindrome

def main():
    print("계산 결과:", calculator.add(5, 3))
    print("단어 개수:", count_words("안녕하세요"))
    print("문자 개수:", count_chars("안녕하세요"))
    print("뒤집힌 문자열:", reverse_string("python"))
    print("팔진수 확인:", is_palindrome("level"))

if __name__ == "__main__":
    main()

결과와 해석#

코드의 재사용성이 향상되었고, 각 모듈이 독립적으로 관리될 수 있다는 것을 확인할 수 있었습니다. 유지보수와 확장성도 향상되었습니다.

정리된 이해#

모듈화는 코드의 재사용성과 유지보수성을 높이는 효과적인 방법으로, 각 기능을 분리하여 관리하는 것이 핵심입니다.
