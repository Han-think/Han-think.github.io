1. Git 명령어 적용#

왜 이걸 보게 됐나#

Git 명령어를 실제 프로젝트 관리에 어떻게 적용할 수 있는지 이해하고자 합니다.

내가 헷갈린 지점#

특히 mkdir -p, touch, echo, >, >> 명령어의 구체적인 사용 사례와 그 차이점에 대해 명확한 이해가 필요합니다.

시도한 코드 / 예시#

# 중첩 폴더 생성
mkdir -p my_project/docs/tutorials/beginner

# 빈 파일 생성
touch my_notes.md

# 텍스트 파일에 내용 추가
echo "첫 번째 줄" > my_notes.md
echo "두 번째 줄" >> my_notes.md

결과와 해석#

위 명령어 실행 결과:

  • my_project/docs/tutorials/beginner 폴더가 생성됩니다.
  • my_notes.md라는 이름의 빈 파일이 생성됩니다.
  • my_notes.md 파일에 각각 “첫 번째 줄"과 “두 번째 줄"이 추가됩니다.

정리된 이해#

Git Bash에서 mkdir -p 명령어를 사용하여 중첩 폴더 구조를 쉽게 생성하고, touch로 파일을 만들며, echo와 >, >>를 통해 파일 내용을 효율적으로 관리할 수 있음을 확인했습니다.

2. Markdown 기본 문법#

왜 이걸 보게 됐나#

Markdown에서 헤딩을 직접 작성하지 않고 시스템이 자동으로 생성하도록 함으로써 학습자가 핵심 문법에 집중할 수 있도록 합니다.

내가 헷갈린 지점#

학습자가 다양한 도구와 기술의 복잡성으로 인해 혼란을 겪었지만, 각 도구의 기본적인 사용법과 실제 적용 방법을 이해함으로써 혼란을 해소했습니다.

시도한 코드 / 예시#

# 프로젝트 시작 제목

세부 목표#

주요 마일스톤#

# 이 라인은 실행되지 않음
echo "안녕하세요"  # 주석 내에서 변수 사용

name="Hugo"
echo "안녕하세요, $name"  # 출력: 안녕하세요, Hugo

name="Hugo"
echo '안녕하세요, $name'  # 출력: 안녕하세요, $name

# 중첩 폴더 생성 예시
mkdir -p my_project/docs/tutorials/beginner

# 파일 생성 예시
touch my_notes.md

결과와 해석#

학습자는 Markdown의 기본 구조와 Bash 명령어의 실제 적용 방법을 이해하게 되었으며, 특히 mkdir -p 명령어를 통해 중첩 폴더를 쉽게 생성하고, >와 >> 연산자의 차이를 명확히 파악했습니다. 또한, 변수 해석 방식의 차이와 sed를 통한 텍스트 편집에 대한 기본적인 이해를 갖추게 되었습니다.

정리된 이해#

이 노트는 학습자가 Markdown의 기본 문법과 Bash 명령어의 실용적인 사용법을 이해하고 적용하는 과정을 상세히 기록합니다. 특히, 혼란스러웠던 부분을 정리하고 실제 코드 예시를 통해 핵심 개념을 명확히 설명함으로써, 초보자도 쉽게 이해하고 활용할 수 있도록 돕습니다.

3. vi 편집기 단축키#

왜 이걸 보게 됐나#

vi 편집기 단축키를 효과적으로 활용하여 편집 효율성을 높이기 위함입니다.

내가 헷갈린 지점#

처음에는 다양한 단축키의 기능과 조합 방법에 대해 혼란스러웠습니다. 특히, 명령 모드와 삽입 모드 전환 등 기본적인 동작 방식을 이해하는 데 시간이 걸렸습니다.

시도한 코드 / 예시#

# vi 편집기 단축키 예시
# 명령 모드 단축키
:w          # 저장
:q          # 종료
:wq        # 저장 후 종료
:e         # 다른 파일 열기
# 삽입 모드 단축키
i          # 삽입 모드 진입
I          # 줄의 시작에 삽입
a          # 줄의 끝에 삽입
# 이동 단축키
h          # 왼쪽으로 이동
j          # 아래로 이동
k          # 위로 이동
l          # 오른쪽으로 이동
0          # 줄의 처음으로 이동
$          # 줄의 끝으로 이동
G          # 파일의 끝으로 이동
# 편집 단축키
dd         # 줄 삭제
yy         # 줄 선택 복사
p           # 선택한 내용 아래 삽입
u          # 마지막 동작 취소
Ctrl + r   # 여러 줄 되돌리기
# 기타 유용한 단축키
/text      # 텍스트 검색
n          # 다음 검색 결과로 이동
N          # 이전 검색 결과로 이동

결과와 해석#

위 코드는 vi 편집기에서 자주 사용되는 단축키들을 모아놓은 예시입니다. 학습자는 이를 통해 편집 효율성을 높이고, vi 편집기에 대한 이해를 깊게 할 수 있습니다.

정리된 이해#

이 노트는 vi 편집기의 핵심 단축키들을 학습자 중심으로 정리하여, 편집 과정에서의 편의성과 생산성을 향상시키는 데 초점을 맞추고 있습니다. 혼란스러웠던 기본 동작 방식을 이해하고, 실제 편집 작업에서 활용할 수 있는 실용적인 지식을 제공합니다.

4. Hugo 블로그 구조#

왜 이걸 보게 됐나#

Hugo 블로그 구조를 이해하고 효과적으로 활용하기 위한 핵심 개념과 실용적인 적용 방법을 학습자에게 명확히 전달하기 위함입니다.

내가 헷갈린 지점#

학습자들이 Hugo의 복잡한 설정 파일과 테마 구조 사이의 관계를 이해하는 데 어려움을 겪는 경우가 많습니다. 이를 해결하기 위해 구체적인 예시와 단계별 설명이 필요합니다.

시도한 코드 / 예시#

# Hugo 프로젝트 초기화
hugo new site myBlog

# 기본 테마 적용
cd themes
git init
git remote add origin <your-repo-url>
git pull
# 테마 설정 파일 예시
# config.yaml
title: "My Awesome Blog"
theme: "ananke"

# post 예시 파일 생성
hugo new posts/myFirstPost.md

결과와 해석#

학습자는 Hugo 프로젝트를 초기화하고 기본 테마를 적용하는 방법을 이해하게 됩니다. 또한, config.yaml 파일을 통해 블로그의 기본 설정을 조정하는 방법과 새로운 게시물을 생성하는 방법을 익히게 됩니다. 이를 통해 Hugo 블로그의 기본 구조와 파일 관리 방식에 대한 명확한 이해를 얻을 수 있습니다.

정리된 이해#

이 섹션은 Hugo 블로그 구축의 핵심 요소들을 다룹니다. 프로젝트 초기화, 테마 적용 및 설정, 그리고 기본 콘텐츠 생성 과정을 통해 학습자들이 실제 블로그를 구축하는 데 필요한 기술을 습득하도록 안내합니다.
