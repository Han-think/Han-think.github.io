1. SQL 질문 이해#

왜 이걸 보게 됐나#

처음에는 SQL을 단순히 데이터 가져오는 명령어로 생각해서, 원하는 데이터를 효율적으로 추출하는 질문을 구성하는 데 어려움을 겪었습니다. SQL의 질문 구조를 제대로 이해하지 못해 데이터베이스의 잠재력을 최대한 활용하지 못한다는 느낌을 받았고, 그래서 SQL의 본질적인 개념인 ‘질문’에 집중하게 되었습니다.

내가 헷갈린 지점#

처음에는 SQL을 단순히 데이터를 조회하는 명령어로만 생각해서, 어떤 질문을 던져야 원하는 답을 얻을 수 있을지 막막했다. SQL 명령어가 데이터베이스에 던지는 질문이라는 개념이 부족해서, 데이터베이스를 쿼리하는 유연성을 제대로 활용하지 못하고 있었다. 마치 정해진 답만 알고 있는 시험 문제를 푸는 듯한 느낌이었달까.

시도한 코드 / 예시#

SELECT * FROM study_notes; -- study_notes 테이블의 모든 데이터를 요청하는 명령

결과와 해석#

SQL이 단순히 데이터를 가져오는 것이 아니라 데이터베이스에 질문을 던지는 언어라는 점을 깨달았고, SELECT 문을 통해 원하는 정보를 정확하게 요청하는 방식으로 이해가 바뀌었다. CREATE TABLE과 INSERT 문법이 테이블 생성과 데이터 삽입이라는 CRUD 연산을 연결해주는 것을 명확히 파악하게 되었고, 이를 바탕으로 테이블 생성 및 데이터 삽입 실습을 진행했다. 테이블 구조 설계와 데이터 입력 과정을 직접 수행하며 SQL에 대한 이해도를 높일 수 있었다.

정리된 이해#

SQL은 단순히 데이터를 가져오는 것이 아니라, 데이터베이스에 원하는 정보를 묻는 질문을 던지는 언어라는 것을 깨달았다. 이를 통해 SQL문의 유연성과 데이터베이스에 대한 질문 구조를 더 명확하게 이해할 수 있게 되었다.

2. CRUD와 SQL 대응#

왜 이걸 보게 됐나#

처음에는 SQL 문법 자체를 어떻게 적용해야 할지 막막했는데, CRUD 연산과 SQL의 연결 고리를 이해하고 나니 테이블 설계부터 데이터 조작까지 좀 더 명확하게 접근할 수 있게 됐다. 특히 CREATE TABLE 문법과 INSERT 문법이 어떻게 상호작용하는지 알게 되면서, 데이터베이스를 설계하고 관리하는 데 필요한 기본적인 틀을 잡을 수 있게 되었다.

내가 헷갈린 지점#

처음에는 CREATE TABLE 문법이 단순히 테이블을 만드는 과정이라고 생각해서, 그 이후 데이터 입력이 어떻게 연관되는지 감이 잘 안 잡혔어. 특히 CREATE TABLE에서 정의한 컬럼 이름과 INSERT 문법에서 값을 넣는 부분이 어떻게 연결되는지 파악하는 데 시간이 걸렸어. 테이블 구조가 어떻게 영향을 미치는지 명확히 이해하지 못해서 데이터 입력이 추상적으로 느껴졌던 것 같아.

시도한 코드 / 예시#

  - **Create**: `CREATE TABLE`을 사용해 테이블 생성
```sql
    CREATE TABLE IF NOT EXISTS study_notes (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        category TEXT NOT NULL,
        memo TEXT
    );
  • Read: SELECT를 사용해 데이터 조회
    SELECT * FROM study_notes WHERE title = 'SQLite 기본';
  • Update: UPDATE를 사용해 데이터 수정
    UPDATE study_notes SET memo = '테이블 생성과 SELECT 기본 문법 학습 완료' WHERE id = 1;
  • Delete: DELETE를 사용해 데이터 삭제
    DELETE FROM study_notes WHERE category = 'database';


### 결과와 해석
`CREATE TABLE` 문법은 테이블의 구조를 정의하며, `INSERT INTO` 문법은 정의된 구조에 맞춰 데이터를 삽입하는 것을 확인했다. `CREATE TABLE`로 `learning_logs` 테이블을 만들고, `INSERT INTO`로 학습 날짜, 주제, 상세 내용을 기록하는 예시를 통해 테이블 생성과 데이터 삽입이 서로 연관되어 있음을 깨달았다. 이를 통해 테이블 구조 정의와 데이터 입력의 기본 원리를 이해할 수 있었다.

### 정리된 이해
SQL은 데이터베이스에 질문을 던지는 언어이며, CRUD 연산은 SQL 문법을 사용하여 구현됩니다. 테이블 생성은 `CREATE TABLE`, 데이터 조회는 `SELECT`, 수정은 `UPDATE`, 삭제는 `DELETE` 명령어를 통해 이루어집니다. 이 관계를 이해하면 SQL을 사용하여 데이터베이스를 효과적으로 관리할 수 있습니다.

## 3. 테이블 생성

### 왜 이걸 보게 됐나
데이터를 체계적으로 관리하고 싶어서 테이블이라는 구조를 만들 필요성을 느꼈다. SQL을 통해 데이터를 효율적으로 다루기 위해서는 테이블 생성부터 시작해야 했고, 이를 통해 데이터의 구조를 명확히 정의하고 관리할 수 있게 되었다. 테이블 생성은 단순히 데이터를 저장하는 공간을 만드는 것을 넘어, 데이터베이스 설계의 첫걸음이라는 것을 알게 되었다.

### 내가 헷갈린 지점
처음에는 `CREATE TABLE` 명령어가 단순히 테이블을 만드는 행위 자체로 생각해서, 테이블 구조를 정의하는 것 외에 다른 기능이 있을 것이라고는 상상하지 못했다. 테이블 구조 정의 이후 데이터가 어떻게 들어가고, 어떻게 관리되는지에 대한 연결 고리가 부족하다고 느꼈다. 특히 `PRIMARY KEY AUTOINCREMENT` 부분이 어떻게 작동하는지 이해하는 데 시간이 걸렸다.

### 시도한 코드 / 예시
```sql
CREATE TABLE IF NOT EXISTS study_notes (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        category TEXT NOT NULL,
        memo TEXT
    );

결과와 해석#

CREATE TABLE IF NOT EXISTS learning_logs 문법을 통해 학습 기록을 저장할 테이블을 생성했다. IF NOT EXISTS 조건을 통해 이미 테이블이 존재할 경우 오류를 방지하며, log_id, date, topic, details 컬럼을 정의하여 학습 내용을 구조적으로 저장할 수 있도록 설계했다. 이 테이블을 통해 학습 일지 관리의 기반을 마련했다.

정리된 이해#

CREATE TABLE 문법은 데이터베이스에 새로운 테이블을 만들라는 명령어이며, 테이블의 이름과 각 컬럼의 데이터 타입을 정의하는 중요한 단계이다. 이 과정을 통해 데이터를 체계적으로 저장할 수 있는 공간을 확보하게 된다. 테이블 생성은 이후 데이터 입력을 위한 필수적인 준비 작업이라고 이해했다.

4. 데이터 삽입#

왜 이걸 보게 됐나#

데이터를 저장하고 관리하는 시스템을 구축하려면, 테이블에 데이터를 실제로 넣어야 하니까요. 단순히 표를 만드는 것만으로는 정보를 활용할 수 없어서, 기록을 남기고 체계적으로 정리하기 위해 삽입 연산이 필요했습니다. 앞으로 학습 내용을 꾸준히 기록하고 관리하기 위해서 꼭 필요한 과정이라는 것을 알게 되었습니다.

내가 헷갈린 지점#

처음에는 INSERT 문법에서 괄호 안에 들어갈 값들이 테이블 컬럼 순서대로 들어가야 한다는 점이 헷갈렸다. VALUES 뒤에 오는 값들이 컬럼과 연결되는 기준이 명확하지 않아서, 순서가 바뀌면 데이터가 잘못 들어갈까 봐 걱정했다. 그리고 문자열 값은 따옴표로 묶어야 한다는 규칙을 까먹을 때가 많았어서, 항상 주의해야 했다.

시도한 코드 / 예시#

INSERT INTO learning_logs (date, topic, details) VALUES
('2023-06-08', 'SQLite 기본', '테이블 생성 및 SELECT 기본 문법 학습 완료');

결과와 해석#

’learning_logs’ 테이블에 2023년 6월 8일, 학습 주제는 ‘데이터 삽입’, 그리고 추가적인 세부 내용은 아직 입력하지 않은 새로운 로그를 추가했다. INSERT INTO 명령어를 통해 데이터를 삽입하는 방법을 익혔고, 나중에 필요한 경우 SELECT 문으로 다시 불러와 확인할 수 있을 것이다. INSERT 문법을 통해 테이블에 데이터를 채워넣는 기본적인 CRUD 연산을 수행해 보았다.

정리된 이해#

데이터 삽입은 INSERT INTO 명령어를 사용하여 테이블의 특정 컬럼에 값을 채워 넣는 과정이다. 각 컬럼의 데이터 유형에 맞는 값을 지정해야 하며, 괄호 안에 컬럼 이름을 명시하고 VALUES 절에 해당 값을 나열하여 실행한다. 여러 레코드를 한 번에 삽입할 수도 있으며, 이 경우 각 레코드는 괄호로 묶여 VALUES 절에 추가된다.
