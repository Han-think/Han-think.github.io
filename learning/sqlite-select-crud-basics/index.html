1. SELECT 이해하기#

왜 이걸 보게 됐나#

데이터베이스에서 필요한 정보를 효과적으로 추출하는 방법을 이해하고 싶었습니다. 특히 SELECT 명령어의 활용법에 대해 명확히 알고 싶었습니다.

내가 헷갈린 지점#

SELECT가 단순히 데이터를 가져오는 것 이상으로 다양한 조건을 적용하여 데이터를 정밀하게 필터링할 수 있다는 점을 간과하고 있었습니다.

시도한 코드 / 예시#

-- 특정 조건에 맞는 데이터 선택
SELECT * FROM learning_logs WHERE date BETWEEN '2023-06-01' AND '2023-06-30';

결과와 해석#

위 쿼리는 2023년 6월 한 달 동안 기록된 학습 로그 데이터를 성공적으로 반환했습니다. 이를 통해 날짜 범위를 이용한 데이터 필터링이 가능하다는 것을 확인했습니다.

정리된 이해#

SELECT는 데이터베이스에서 특정 조건에 맞는 데이터를 선택적으로 가져오는 강력한 도구입니다. 다양한 조건 연산자를 활용하여 필요한 정보만을 정밀하게 추출할 수 있습니다.

2. CREATE 테이블 생성하기#

왜 이걸 보게 됐나#

데이터베이스 구조를 이해하고 효율적인 데이터 관리 방법을 배우고자 했습니다. 특히 테이블 생성의 중요성을 깨닫고 싶었습니다.

내가 헷갈린 지점#

CREATE TABLE 구문에서 컬럼 타입과 제약 조건을 적절히 설정하는 방법에 대해 혼란이 있었습니다.

시도한 코드 / 예시#

-- 학습 로그 테이블 생성
CREATE TABLE IF NOT EXISTS learning_logs (
    log_id INTEGER PRIMARY KEY AUTOINCREMENT,
    date DATE NOT NULL,
    topic TEXT NOT NULL,
    details TEXT
);
