1. 개발자와 클라우드, 초보자를 위한 진로 이해#

무엇을 배웠나#

강의에서 AWS 시가총액은 단순한 기업 규모가 아니라 클라우드 시장에서의 영향력을 보여주는 지표라는 것을 알게 되었다. Cloudflare와 같은 엣지 네트워크 전문 기업도 있지만, 서버, 데이터베이스, 네트워크 관리 등 종합적인 클라우드 개발 직무에서는 AWS, Azure, GCP가 더 중요하게 활용된다는 것을 이해했다. 또한, 자격증은 기본 학습의 증거일 뿐이며, 실제 프로젝트 경험과 경력이 중요함을 깨달았다.

헷갈렸던 점#

AWS 시가총액이 클라우드 자격증과 어떤 관련이 있는지, 그리고 왜 Cloudflare가 클라우드 기업임에도 불구하고 취업이나 자격증에서 AWS, Azure, GCP가 더 중요한지 이해가 안 갔습니다. 자격증이 실제 실무 능력과 얼마나 연결되는지도 처음에는 명확하게 와닿지 않았습니다.

정리된 이해#

클라우드 자격증은 기본 개념을 익혔음을 보여주는 지표일 뿐, 실제 개발 능력은 프로젝트 경험과 문제 해결 능력에서 나오는 것을 알게 되었다. Cloudflare처럼 특정 분야에 특화된 기업도 있지만, 클라우드 개발 및 운영 직무에서는 AWS, Azure, GCP가 더 중요하게 다뤄지는 이유를 이해하게 되었다. 기존 로컬 환경에서 쌓은 경험을 바탕으로 Pipeline OS를 클라우드 환경에 배포하는 프로젝트를 통해 실질적인 역량을 키워나가야겠다.

2. 파이썬 함수와 메인 구조: 초보자를 위한 핵심 이해#

무엇을 배웠나#

파이썬 함수를 정의할 때 def 키워드를 사용하는 것과 변수에 값을 할당하는 것을 구분해야 한다는 것을 배웠습니다. 또한, 데이터 전처리와 모델 학습을 하나의 함수에 넣는 것보다 각 단계를 독립적인 함수로 분리하는 것이 코드의 가독성과 유지보수성을 높이는 방법임을 알게 되었습니다. main() 함수를 사용하여 프로그램의 흐름을 제어하고, if __name__ == "__main__": 블록을 활용하여 코드의 실행 방식을 명확히 하는 것이 중요합니다.

헷갈렸던 점#

함수 정의와 변수 할당을 헷갈려서 def 키워드를 잘못 사용했고, 데이터 전처리와 모델 학습 분리를 하나의 함수에 넣으려는 시도를 해서 기능 분리의 중요성을 간과했습니다. main() 함수의 역할과 if __name__ == "__main__": 블록의 의미를 명확히 이해하지 못했습니다.

정리된 이해#

함수는 입력, 처리, 반환 값으로 구성되어 특정 작업을 수행하며, main() 함수는 코드 실행의 흐름을 제어하는 중심 역할을 합니다. 함수 정의와 변수 할당을 명확히 구분하고, 각 함수의 역할을 분리하여 독립적으로 구성하는 것이 중요합니다. if __name__ == "__main__": 블록은 프로그램 시작 시 main() 함수만 실행하도록 보장합니다.

무엇을 배웠나#

머신러닝 데이터 전처리는 데이터 로드, 특성과 타겟 분리, 결측치 처리 등 여러 단계로 이루어진다는 것을 깨달았습니다. 특히 Jupyter Notebook 사용 시 라이브러리 import 순서와 코드 실행 여부에 따라 결과가 달라지는 점을 주의해야 하며, pd.get_dummies()와 OneHotEncoder의 차이점을 이해하는 것이 중요했습니다. 앞으로는 이러한 실수를 방지하고 데이터 전처리 과정을 더욱 효과적으로 수행할 수 있도록 노력해야겠습니다.

헷갈렸던 점#

라이브러리 함수를 바로 사용하려고 할 때 import를 잊고 있었고, pd.get_dummies()와 OneHotEncoder의 차이 때문에 어떤 방법을 사용해야 할지 헷갈렸습니다. 특히 Jupyter Notebook에서 코드가 보이는 것과 실제로 실행되는 것의 차이를 명확히 이해하지 못해 변수 인식이 안 되는 문제가 자주 발생했습니다.

정리된 이해#

데이터 전처리는 머신러닝 모델 성능에 큰 영향을 미치는 중요한 과정이며, 데이터 로드부터 결측치 처리, 범주형 변수 인코딩 등 여러 단계를 거칩니다. 특히, 코드 실행 순서와 라이브러리 의존성을 제대로 파악하고, pd.get_dummies()와 같은 함수를 활용하여 데이터 변환을 효율적으로 수행하는 것이 중요합니다. Jupyter Notebook 사용 시 실행 습관을 들이고, 각 코드 셀의 실행 결과가 어떻게 연결되는지 이해하는 것이 필요합니다.
