1. 데이터 전처리 이해하기#

왜 이걸 보게 됐나#

프로젝트 초기 단계에서 데이터의 일관성과 질을 개선하기 위해 데이터 전처리 과정을 이해하고 적용하는 것이 중요하다고 깨달았습니다.

내가 헷갈린 지점#

특히 공백 처리와 빈 문자열 필터링 과정에서 strip() 메서드의 역할과 리스트 컴프리헨션의 효율성을 명확히 파악하는 데 어려움을 겪었습니다.

시도한 코드 / 예시#

# 예시 데이터 리스트
raw_skills = [' Python ', 'Django ', ' React', 'SQL', ' ', 'Docker ', '']

# 공백 제거와 빈 문자열 필터링
cleaned_skills = [s.strip() for s in raw_skills if s.strip()]

# 결과 출력
print(f"원시 데이터: {raw_skills}")
print(f"전처리 결과: {cleaned_skills}")

결과:

# 출력 결과 예시 (실제 실행 결과에 따라 다를 수 있음)
# 원시 데이터: [' Python ', 'Django ', ' React', 'SQL', ' ', 'Docker ', '']
# 전처리 결과: ['Python', 'Django', 'React', 'SQL', 'Docker']

결과와 해석#

위 코드를 실행하면 문자열의 앞뒤 공백이 제거되고 빈 문자열은 필터링되어 필요한 데이터만 남게 됩니다. 리스트 컴프리헨션은 코드의 가독성을 높이면서 간결하게 처리할 수 있는 방법임을 확인했습니다.

정리된 이해#

  • 데이터 전처리는 데이터의 품질을 향상시키는 필수 단계로, 공백 제거와 필터링 등 다양한 기법을 활용합니다.
  • 리스트 컴프리헨션은 복잡한 리스트 생성을 간결하게 처리할 수 있는 강력한 도구입니다.
