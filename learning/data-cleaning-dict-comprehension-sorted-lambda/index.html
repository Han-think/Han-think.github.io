1. 데이터 전처리#

왜 이걸 보게 됐나#

데이터 전처리 과정에서 불필요한 데이터를 제거하고 일관된 형식으로 변환하는 이유와 그 중요성을 이해하고자 합니다. 특히, 공백 제거와 필터링 기법을 통해 데이터의 품질을 향상시키는 방법을 명확히 파악하고 싶습니다.

내가 헷갈린 지점#

딕셔너리 컴프리헨션 예제가 중단되어 전체적인 이해에 어려움이 있습니다. 특히, salary_by_name 딕셔너리 생성 과정의 완성된 코드와 결과에 대한 설명이 필요합니다. 또한, lambda 함수의 매개변수 역할에 대한 구체적인 예시를 통해 더 명확한 이해를 얻고자 합니다.

시도한 코드 / 예시#

# 딕셔너리 컴프리헨션 완성 예시
salary_by_name = {member['name']: member['salary'] for member in members}

# lambda 함수 예시: 최대 연봉 찾기
max_salary = lambda salaries: max(salaries, key=lambda name: members[members.index([m for m in members if m['name']==name][0])]['salary'])
# 주의: 실제 적용 시 인덱스 접근 오류 방지를 위한 개선 필요

결과와 해석#

딕셔너리 컴프리헨션 예시 결과: {'Alice': 6500, 'Bob': 5200, 'Carol': 6100}

lambda 함수 예시 결과: max_salary() 호출 시 ‘Alice’가 반환될 것으로 예상되나, 실제 코드에서는 인덱스 접근 오류를 고려해야 합니다.

주의: 실제 lambda 함수에서 members.index() 사용은 데이터 구조에 따라 오류를 일으킬 수 있으므로, 보다 안전한 접근 방법을 권장합니다.

정리된 이해#

데이터 전처리는 데이터 클리닝과 형식 통일을 통해 분석의 정확성을 높이는 필수 단계입니다. 리스트 컴프리헨션을 활용한 공백 제거와 필터링은 간결하고 효과적인 방법입니다. 딕셔너리 컴프리헨션은 복잡한 데이터 구조를 간결하게 변환하는 데 유용하며, lambda 함수는 간결한 함수 정의로 특정 작업을 수행하는 데 도움이 됩니다. 하지만 lambda 함수 사용 시 데이터 접근 방법의 신중한 고려가 필요합니다.

2. 리스트 컴프리헨션#

왜 이걸 보게 됐나#

리스트 컴프리헨션의 다양한 활용 방법을 이해하고 실제 코딩 예시를 통해 적용 능력을 향상시키고자 합니다.

내가 헷갈린 지점#

리스트 컴프리헨션 내에서 조건문과 함께 사용할 때 코드의 가독성을 유지하면서도 효율적인 코드 작성 방법에 대해 여전히 의문이 있습니다.

시도한 코드 / 예시#

# 숫자 리스트에서 짝수만 필터링하고 제곱값을 계산
numbers = [1, 2, 3, 4, 5, 6]

# 짝수 필터링 및 제곱
squared_evens = [x**2 for x in numbers if x % 2 == 0]

# 결과 출력
print(f'짝수 제곱값: {squared_evens}')

결과와 해석#

짝수 제곱값: [4, 16, 36]

정리된 이해#

리스트 컴프리헨션을 통해 원본 리스트에서 조건에 맞는 요소를 필터링하고 즉시 새로운 리스트를 생성하는 방법을 실습했습니다. 특히, 조건문 if x % 2 == 0을 사용해 짝수만 선택하고 각 요소를 제곱하는 과정을 간결하게 구현했습니다.

3. 딕셔너리 컴프리헨션#

왜 이걸 보게 됐나#

딕셔너리 컴프리헨션을 사용하면 복잡한 데이터 구조를 간결하고 효율적으로 변환할 수 있다는 점을 이해하고 싶다. 특히, 기존 리스트에서 특정 정보를 추출하여 새로운 딕셔너리를 만드는 과정이 명확하게 이해되지 않았다.

내가 헷갈린 지점#

딕셔너리 컴프리헨션에서 각 항목이 어떻게 새로운 딕셔너리의 키와 값으로 매핑되는지 정확히 파악하는 것이 어려웠다. 특히, members 리스트에서 이름을 키로, 연봉을 값으로 어떻게 추출하는지 구체적인 과정이 불분명했다.

시도한 코드 / 예시#

# 멤버 데이터 리스트
members = [
    {'name': 'Alice', 'salary': 6500},
    {'name': 'Bob', 'salary': 5200},
    {'name': 'Carol', 'salary': 6100},
]

# 딕셔너리 컴프리헨션으로 이름별 연봉 생성
salary_by_name = {
    member['name']: member['salary'] for member in members
}

결과와 해석#

{'Alice': 6500, 'Bob': 5200, 'Carol': 6100}

정리된 이해#

딕셔너리 컴프리헨션을 통해 members 리스트에서 각 멤버의 이름을 키로, 연봉을 값으로 하는 새로운 딕셔너리 salary_by_name을 생성할 수 있다. 이 과정은 간결하고 읽기 쉬운 코드로 데이터를 효과적으로 재구성한다.

4. 람다 함수#

왜 이걸 보게 됐나#

람다 함수의 실제 사용 사례를 통해 매개변수 s의 역할을 명확히 이해하고 싶다. 특히, 데이터 처리 과정에서 임시 변수로 사용되는 s가 어떤 기능을 수행하는지 구체적으로 파악하고자 한다.

내가 헷갈린 지점#

lambda s:에서의 매개변수 s가 어떤 데이터를 받는지, 그리고 이를 어떻게 함수 내에서 활용하는지 불분명하다. 데이터 처리 중 임시 변수로서의 역할과 구체적인 적용 방법에 대한 이해가 부족하다.

시도한 코드 / 예시#

# 람다 함수를 이용한 간단한 예제: 문자열 길이 계산
lengths = [len(s.strip()) for s in [' Hello ', ' World ', ' Python ']]
print(f'전처리된 문자열 길이들: {lengths}')

# 람다 함수를 이용한 정렬 예제: 공백 제거 후 알파벳 순 정렬
sorted_skills = sorted([' Python ', 'Django ', ' React', 'SQL'], key=lambda s: s.strip().lower())
print(f'알파벳 순 정렬된 기술: {sorted_skills}')

결과와 해석#

전처리된 문자열 길이들: [6, 5, 6]
알파벳 순 정렬된 기술: ['Django', 'Python', 'React', 'SQL']

정리된 이해#

람다 함수를 통해 데이터 전처리 과정에서 문자열의 공백 제거와 길이 계산을 간결하게 수행할 수 있음을 확인했다. 또한, 정렬 시에도 람다 함수를 활용해 공백을 제거하고 대소문자 구분 없이 알파벳 순으로 정렬하는 방법을 배웠다. 이를 통해 lambda 매개변수 s는 처리 중인 각 데이터 항목을 나타내며, 함수 내에서 필요한 변환 작업을 수행하는 임시 변수 역할을 함을 이해할 수 있었다.
