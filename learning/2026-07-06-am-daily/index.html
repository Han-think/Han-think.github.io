1. EDA와 도메인 지식을 활용한 파생변수 설계 가이드#

무엇을 배웠나#

EDA는 단순히 데이터를 보여주는 것 이상으로, 모델 학습 방향을 설정하는 중요한 단계라는 것을 깨달았습니다. 도메인 지식을 활용해 파생변수를 설계하는 것이 모델 성능에 실제로 영향을 미치며, 데이터 분석 과정에서 인간의 직관과 AI의 반복적인 학습을 적절히 분담하는 것이 중요하다는 것을 알게 되었습니다. 이어폰 제어 시스템 예시를 통해, 실제 데이터 분석에서 이러한 개념들이 어떻게 적용될 수 있는지 이해하게 되었습니다.

헷갈렸던 점#

데이터 분석이 단순히 시각화하는 과정인 줄 알았고, 파생변수를 만들 때 모델 성능에 어떤 영향을 주는지 명확히 이해하지 못했다. 누가 데이터 분석의 어떤 단계를 수행해야 하는지 역할 분담에 대한 개념도 불분명했다.

정리된 이해#

EDA는 단순히 데이터를 시각화하는 것이 아니라, 데이터의 특성을 파악하고 모델 학습 방향을 설정하는 중요한 단계라는 것을 깨달았다. 특히 도메인 지식을 활용하여 파생변수를 설계하는 과정은 모델 성능 향상에 직접적으로 기여하며, 인간은 데이터 해석과 결과 검증을, AI는 모델 테스트와 반복 학습을 담당하는 역할을 분담해야 한다는 것을 알게 되었다. 이 과정을 통해 데이터 분석 프로젝트를 보다 효과적으로 진행할 수 있을 것 같다.

# 예시: SNR 계산 (간략화된 버전)
def calculate_snr(signal_strength, noise_strength):
  """신호 대 잡음비(SNR)를 계산합니다."""
  if noise_strength == 0:
    return float('inf')  # 잡음이 없는 경우
  return signal_strength / noise_strength

# 예시: 밀폐도 점수 계산 (가정적인 계산식)
def calculate_sealing_score(pressure_difference, temperature_difference):
  """밀폐도 점수를 계산합니다."""
  # 실제 계산식은 도메인 지식에 따라 달라짐
  sealing_score = pressure_difference - 0.5 * temperature_difference
  return sealing_score

4. 벡터 공간, 일차 독립성, 그리고 랭크 이해하기#

무엇을 배웠나#

벡터 공간, 부분공간, 일차독립/종속 개념을 복습하고, 실제 데이터 분석에서의 의미를 좀 더 명확하게 이해하게 되었어. 특히 키(cm)와 키(m)와 같은 중복 변수의 의미와 랭크, 다중공선성 개념을 연결하며, 데이터 분석에서 변수 선택의 중요성을 깨달았어. 앞으로는 이러한 개념들을 바탕으로 데이터 분석 문제를 더 효과적으로 해결할 수 있을 것 같아.

헷갈렸던 점#

벡터 공간이나 부분공간의 정의는 대충 이해했지만, 이 개념들이 실제 데이터 분석 상황에서 어떻게 활용되는지 감이 잘 안 잡혔어. 특히 일차독립과 일차종속이 뭔지 겉으로만 아는 느낌이었고, 변수가 중복될 때 어떤 의미인지 파악하기 어려웠어. 결국 선형대수학 개념이 데이터 분석에 연결되는 지점이 명확하지 않았어.

5. 선형변환, Rank, 그리고 다중공선성 이해하기#

무엇을 배웠나#

선형 변환과 Rank 개념을 공부하며, Rank가 행렬 내 독립적인 정보의 개수를 의미하고 변수 간 유사성(다중공선성)이 Rank 감소에 영향을 미친다는 것을 이해하게 되었어. Rank가 낮아지면 회귀 분석 결과가 불안정해질 수 있다는 점도 알게 됐고, 관련 키워드들을 정리해서 앞으로 학습에 활용해야겠다는 생각을 했어. 이제 이 내용을 바탕으로 실제 데이터에 적용해보면서 더 깊이 이해해야겠어.

헷갈렸던 점#

처음에는 Rank가 단순히 행렬의 크기를 나타내는 줄 알았는데, 독립적인 정보의 개수를 의미한다는 점이 이해가 안 됐습니다. 특히 다중공선성 상황에서 Rank가 어떻게 낮아지는지, 그리고 이것이 회귀 분석에 어떤 영향을 미치는지 구체적으로 설명하는 부분이 잘 와닿지 않았습니다. 변수 간의 관계가 Rank에 어떤 영향을 주는지 감이 잘 잡히지 않았습니다.

정리된 이해#

행렬의 Rank는 변수들 간의 독립적인 정보의 개수를 나타내며, 변수 간 유사성으로 인해 Rank가 낮아지면 회귀 분석 결과가 불안정해질 수 있습니다. 다중공선성은 Rank 감소의 원인이 되며, 이는 계수 추정의 어려움을 야기합니다. 이러한 개념들을 이해하고 실습을 통해 복습하여 실제 분석에 적용할 수 있도록 해야겠습니다.

# 예시 데이터셋 (Python, NumPy)
import numpy as np

# X3 = 2*X1 + 0.5*X2  관계 설정
X1 = np.array([1, 2, 3, 4, 5])
X2 = np.array([2, 2.5, 3, 3.5, 4])
X3 = 2 * X1 + 0.5 * X2

# 데이터 프레임 생성 (선택 사항, 시각화를 위해)
import pandas as pd
data = pd.DataFrame({'X1': X1, 'X2': X2, 'X3': X3})
print(data)

# 행렬 생성
X = np.array([X1, X2, X3]).T  # 각 변수를 컬럼으로 하는 행렬 생성

# Rank 계산
rank = np.linalg.matrix_rank(X)
print(f"행렬 X의 Rank: {rank}")

6. 전통적 시계열 분석과 ML·딥러닝 시계열 분석 비교#

무엇을 배웠나#

시계열 분석을 처음 공부할 때 모든 분석이 날짜 컬럼만 있으면 똑같은 것이라고 생각했지만, 전통적 시계열과 ML·딥러닝 시계열 분석은 데이터 크기나 모델 이름의 문제가 아니라, 분석 대상과 방법에 차이가 있다는 것을 알게 되었다. 전통적 시계열은 과거 데이터의 패턴을 분석하는 데 집중하는 반면, ML·딥러닝 시계열은 외부 변수를 함께 고려하여 더욱 복잡한 관계를 학습할 수 있다는 점을 이해하게 되었다. 데이터 예시를 통해 이러한 차이점을 명확히 파악할 수 있었다.

헷갈렸던 점#

시계열 분석은 날짜 컬럼만 있으면 다 같은 거라고 생각했고, 데이터 크기 5천 개를 기준으로 전통적 방법과 머신러닝/딥러닝 방법을 구분하는 기준이 명확하지 않았어. 전통적인 시계열 분석과 다변량 시계열 분석의 차이를 모델 이름의 차이로만 생각했던 것도 실수였어.

정리된 이해#

전통적인 시계열 분석은 주로 시간 순서대로 나열된 단일 데이터의 패턴을 분석하는 반면, ML·딥러닝 시계열 분석은 다양한 외부 변수들을 함께 고려하여 더 복잡한 관계를 학습합니다. 데이터 포인트의 개수보다는 분석 대상 변수의 유무가 전통적 시계열과 ML·딥러닝 시계열을 구분하는 중요한 기준이 됩니다. 이를 통해 외부 요인들이 시계열 데이터에 미치는 영향을 파악하고 예측 정확도를 높일 수 있습니다.

7. 고윳값, SVD, 그리고 데이터 분석 활용법#

무엇을 배웠나#

고윳값과 고유벡터가 행렬 변환에서 핵심 축과 그 축의 스케일 변화를 나타내는 역할, 그리고 이를 통해 복잡한 행렬을 다루기 쉽게 만들 수 있다는 것을 알게 되었다. 특히 특이값 분해(SVD)를 통해 어떤 행렬이든 중요한 정보와 노이즈를 분리하고, 이를 다양한 응용 분야에서 활용할 수 있다는 점을 이해하게 되었다. 이미지 압축 예시를 통해 SVD의 실용적인 사용법을 익혔다.

헷갈렸던 점#

처음에는 고윳값과 고유벡터가 단순히 수식 조작을 위한 개념인 줄 알았는데, 데이터의 주요 경향성을 나타내는 핵심 축이라는 설명을 듣고 아하! 하고 이해가 됐다. SVD는 행렬을 분해하는 기법이라는 것 자체는 알았지만, 왜 이 분해가 유용한지, 그리고 큰/작은 특이값이 의미하는 바를 정확히 파악하지 못했다.

정리된 이해#

고윳값은 변환 후에도 방향이 변하지 않는 축의 스케일 변화를 나타내고, SVD는 어떤 행렬이든 핵심 정보 패턴을 순서대로 분해하여 데이터의 중요한 특징을 추출하는 강력한 도구이다. SVD를 통해 큰 특이값은 중요한 정보, 작은 특이값은 노이즈를 나타내는 패턴으로 해석할 수 있으며, 이미지 압축, 추천 시스템 등 다양한 분야에 활용될 수 있다.

8. 시간 변화 패턴 분석: 계절성 이해와 활용#

무엇을 배웠나#

계절성이 단순히 날씨와 관련된 주기적 변화만을 의미하는 것이 아니라, 요일, 시간대, 월, 분기 등 다양한 주기로 반복되는 모든 패턴을 포괄한다는 것을 알게 되었습니다. 추세와 계절성을 구분하는 것이 어렵게 느껴졌지만, 순환과의 차이를 이해하면서 이를 명확히 구분할 수 있게 되었습니다. 또한, 실제 데이터를 활용하여 계절성을 모델링하는 실습을 통해 이론적 이해를 더욱 깊게 할 수 있었습니다.

헷갈렸던 점#

처음에는 계절성이 계절이나 날씨 변화와 관련된 것만 의미한다고 생각했는데, 다양한 주기적 패턴을 모두 포함한다는 것을 알게 되어 범위에 대한 이해가 부족했다는 것을 깨달았습니다. 추세와 계절성이 함께 나타날 때 무엇을 먼저 분석해야 할지 판단하기 어려웠습니다.

정리된 이해#

계절성은 단순히 날씨 변화와 같은 특정 시기뿐 아니라, 일정한 주기로 반복되는 모든 패턴을 포괄하는 개념이라는 것을 알게 되었다. 추세와 계절성이 함께 나타날 때는 반복적인 패턴을 먼저 파악하는 것이 중요하며, 주기가 불규칙한 장기적인 변동은 순환으로 구분된다. 이러한 이해를 바탕으로 데이터 분석 실습을 통해 계절성을 모델링해 보았다.

import pandas as pd
import numpy as np

# 가상의 일별 매출 데이터 생성
dates = pd.date_range(start='2023-01-01', periods=365, freq='D')
sales = np.random.normal(loc=100, scale=20, size=365)
# 계절성 추가 (예: 매월 말 매출 증가)
for i in range(365, 370):  # 매월 말 5일간
    sales[i-5:i] += np.random.normal(loc=20, scale=5, size=5)
data = pd.DataFrame({'date': dates, 'sales': sales})
data.set_index('date', inplace=True)

9. 시계열 예측 프로세스 및 베이스라인 모델 이해#

무엇을 배웠나#

시계열 예측 프로세스에서 베이스라인 모델의 중요성을 알게 되었고, 단순한 모델들이 때로는 유용한 예측 결과를 제공할 수 있다는 것을 깨달았습니다. 특히 수평 예측선이 나타나는 이유와 베이스라인 모델이 복잡한 모델의 성능을 평가하는 기준이 된다는 점을 이해하게 되었습니다. 또한 시계열 데이터 활용 범위에 대한 오해를 풀고, 전통적인 시계열 분석과 고급 분석의 차이점을 명확히 했습니다.

헷갈렸던 점#

예측선이 모두 수평으로 나오는 이유가 모델 오류인 줄 알았고, 단순한 베이스라인 모델들을 여러 개 비교해야 하는 이유가 이해가 안 갔었어. 또, 시계열만 활용한다는 게 외부 변수를 전혀 사용하지 않는다는 의미로 착각했었어.

정리된 이해#

시계열 예측에서는 단순한 베이스라인 모델들을 먼저 구축하여 복잡한 모델의 성능을 비교할 기준점을 마련해야 하며, 베이스라인 모델들은 데이터의 기본적인 패턴을 파악하는 데 도움을 줍니다. 특히 수평 예측선은 평균 기반 모델의 특징을 보여주며, MAPE와 같은 평가 지표를 통해 모델의 성능을 객관적으로 판단할 수 있습니다. 시계열 분석은 전통적으로 단변량 데이터를 활용하지만, 필요에 따라 외부 변수를 추가할 수도 있습니다.

# 예시: 간단한 전체 평균 베이스라인 모델
def baseline_mean(data):
  """
  전체 평균을 사용하여 시계열 데이터를 예측합니다.

  Args:
    data: 시계열 데이터 리스트.

  Returns:
    예측값 리스트.
  """
  mean_value = sum(data) / len(data)
  return [mean_value] * len(data)

10. 시계열 데이터의 자기상관 이해하기#

무엇을 배웠나#

자기상관은 단순히 날짜 간의 관계가 아니라, 동일 시계열 데이터의 서로 다른 시점 간의 상관관계를 나타내는 개념이라는 것을 명확히 이해하게 되었어요. 양수, 음수, 약한 자기상관과 같은 종류를 구별하고, 데이터의 스케일 변경이 자기상관 계수에 미치는 영향에 대해서도 감을 잡을 수 있게 되었죠. 특히, “Autocorrelation"을 자동화와 관련된 용어로 착각했던 오해를 풀 수 있어서 다행입니다.

헷갈렸던 점#

자기상관을 날짜 사이의 관계라고 생각해서 혼동스러웠고, 값의 변화와 자기상관의 관계가 명확하지 않았어요. 또, Autocorrelation이라는 단어를 자동화된 구조로 착각해서 의미를 제대로 파악하지 못했습니다.

정리된 이해#

자기상관은 동일한 시계열 데이터에서 시간 순서에 따라 떨어진 시점 간의 상관관계를 나타내는 개념으로, 날짜 자체보다는 과거 값과 현재 값의 관계를 분석하는 것입니다. 양의, 음의, 약한 자기상관과 같이 다양한 형태로 나타나며, 데이터의 스케일 변경은 자기상관 계수에 큰 영향을 주지 않지만, 관찰 기간이나 Lag 값 등은 결과에 영향을 줄 수 있습니다. 간단히 말해, 과거 데이터가 현재 데이터에 어떤 영향을 미치는지를 파악하는 것이 자기상관 이해의 핵심입니다.

11. 정상성 검정과 차분, 확률보행 이해하기#

무엇을 배웠나#

정상성 시계열 데이터는 평평한 그래프가 아니라 평균과 분산이 안정적인 상태를 의미한다는 것을 깨달았습니다. ADF 검정은 정상성을 판단하는 도구이고, ACF는 자기상관성을 확인하는 도구라는 것을 구분해야 하며, p-value 해석은 검정 가설에 따라 달라진다는 점을 알게 되었습니다. 또한, 원본 시계열의 정상성 여부와 상관없이 차분 후의 시계열을 분석하여 확률보행 여부를 판단해야 한다는 것을 명확히 이해했습니다.

헷갈렸던 점#

정상성 시계열 데이터가 항상 평평한 그래프를 그린다고 생각했고, ADF 검정과 ACF를 혼동했습니다. p-value 해석도 잘못 이해하고 있었고, 원본 시계열이 정상적이라고 해서 바로 확률보행이라고 단정짓는 실수를 할까 봐 걱정했습니다.

정리된 이해#

정상성은 시계열 데이터의 평균, 분산, 자기상관 구조가 시간에 따라 변하지 않는 상태를 의미하며, ADF 검정은 이 정상성을 검증하는 통계적인 방법입니다. ADF 검정의 p-value 해석은 귀무가설과 대립가설에 따라 달라지고, 원본 시계열이 정상적이라도 확률보행으로 단정짓기 위해서는 차분 후의 정상성을 확인해야 합니다. 자기상관함수(ACF)는 시계열 데이터의 자기상관성을 파악하는 데 사용되며, ADF 검정과는 별개의 역할을 합니다.

# ADF 검정 결과 해석 예시 (가상)
# p-value가 유의수준(예: 0.05)보다 작으면 귀무가설(단위근 존재)을 기각하고, 정상이라고 판단
# p-value가 유의수준보다 크면 귀무가설을 채택하고, 정상성을 판단할 수 없음
from statsmodels.tsa.stattools import adfuller
import numpy as np

# 가상 데이터 (예시)
data = np.random.randn(100)

# ADF 검정 수행
result = adfuller(data)
print(f"ADF Statistic: {result[0]}")
print(f"p-value: {result[1]}")

# p-value에 따른 해석
if result[1] < 0.05:
    print("귀무가설 기각: 시계열은 정상입니다.")
else:
    print("귀무가설 채택: 시계열의 정상성 판단 불가")

12. 선형대수 학습, 초보자의 어려움과 핵심 개념#

무엇을 배웠나#

Rank가 행렬의 독립적인 정보 개수를 나타낸다는 것을 알게 되었고, 다중공선성이 Rank를 낮춰 회귀 분석의 안정성을 저해할 수 있다는 점을 이해하게 되었다. 또한, 다중공선성 문제를 해결하기 위해 변수를 제거하거나 차원 축소 기법을 사용하는 것이 중요하다는 것을 확인했다. 예시 코드를 통해 Rank 계산 및 다중공선성의 영향을 직접 확인하면서 개념 이해도를 높일 수 있었다.

헷갈렸던 점#

선형 변환이 행렬 곱셈으로 표현되는 방식이 추상적으로 느껴져서, 실제 데이터 변환 과정과 연결하기 어려웠습니다. 또한, Rank가 낮아지면 어떤 문제가 발생하는지, 그리고 다중공선성이 모델에 어떤 부정적인 영향을 미치는지 구체적인 사례를 통해 이해하지 못했습니다. 핵공간이라는 개념도 그 의미를 파악하기 어려웠고, Rank와 어떤 관련이 있는지 혼란스러웠습니다.

정리된 이해#

행렬의 Rank는 행렬이 가진 독립적인 정보의 양을 나타내며, 변수 간 선형 종속 관계가 존재할수록 Rank는 낮아집니다. Rank가 낮아지면 회귀 분석과 같은 데이터 분석 작업에서 불안정성이 발생할 수 있으므로, 다중공선성 문제를 해결하기 위해 변수 제거 또는 차원 축소 기법을 활용하는 것이 중요합니다. Rank는 행렬이 변환하는 공간의 차원을 결정하며, 데이터의 불필요한 중복을 줄여 모델의 안정성을 높이는 데 기여합니다.

import numpy as np

# 예시 행렬
A = np.array([[1, 2, 3],
              [4, 8, 12],  # 두 번째 행은 첫 번째 행의 2배
              [7, 14, 21]]) # 세 번째 행은 첫 번째 행의 7배

# Rank 계산
rank_A = np.linalg.matrix_rank(A)
print(f"행렬 A의 Rank: {rank_A}")
