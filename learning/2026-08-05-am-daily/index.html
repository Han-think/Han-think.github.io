1. ES6 Spread 문법과 객체 프로퍼티 축약 이해하기#

무엇을 배웠나#

ES6 Spread 문법이 단순히 배열을 합치는 것이 아니라, 배열, 문자열, 객체 내부의 값을 펼쳐서 새로운 구조에 배치하는 기능을 한다는 것을 이해하게 되었다. 특히 객체 Spread 문법을 사용할 때, 객체 자체를 속성으로 넣는 것과 속성을 펼치는 것의 차이를 명확히 구분해야 함을 배웠다. 이 내용을 바탕으로 더욱 유연하고 간결한 코드를 작성할 수 있을 것 같다.

헷갈렸던 점#

스프레드 문법이 배열을 합치는 기능이라고 막연하게 생각해서, 객체에서 속성들을 펼쳐서 사용하는 것과 객체를 그대로 넣는 것의 차이를 제대로 이해하지 못했다. 객체를 넣으면 내부 구조 그대로 들어가고, 스프레드 문법을 쓰면 속성들이 펼쳐져서 추가되는 개념이 명확하지 않았다. 그래서 실제 사용 시 어떤 경우에 어떤 방식을 사용해야 할지 혼란스러웠다.

정리된 이해#

스프레드 문법은 기존 데이터를 흩뿌려 새로운 구조를 만들 때 사용하며, 단순히 합치는 것이 아니라 요소들을 펼쳐서 배치하는 역할을 한다. 객체를 펼칠 때 주의해야 할 점은, 객체 자체를 속성으로 넣는 것과 속성을 펼쳐서 넣는 것의 차이를 명확히 이해하는 것이다. 이 개념을 확실히 다지면 코드의 의도를 명확하게 표현하고 유연한 데이터 구조를 만들 수 있을 것이다.

const doubled = [...numbers].map(num => num * 2);

2. 고차함수와 클릭 이벤트: 함수 연결과 실행 시점 이해#

무엇을 배웠나#

고차함수의 개념과 클릭 이벤트 핸들러를 연결하는 데 어려움을 겪었지만, repeat() 함수와 addEventListener()의 공통점을 찾으면서 이해가 명확해졌어. 특히, 함수를 인자로 받는다는 점과, 실행 시점의 차이를 이해하는 것이 중요했어. 이제는 버튼 클릭 시 특정 함수를 실행하도록 하는 코드를 작성할 수 있게 되었어.

헷갈렸던 점#

고차함수 개념을 막 익혔을 때, 이벤트 핸들러 코드가 갑자기 등장해서 두 개념이 전혀 관련 없어 보였고, 버튼 클릭 시 어떤 코드를 추가해야 하는지 감이 잘 안 잡혔습니다. 특히 주석만으로는 구현 방법을 파악하기 어려웠고, 고차함수와 이벤트 핸들러의 연결고리를 찾는데 어려움을 겪었습니다.

정리된 이해#

고차함수와 이벤트 핸들러는 결국 함수를 인자로 받는다는 점에서 유사하며, repeat() 함수가 반복문 내에서 즉시 함수를 실행하는 것과 달리 addEventListener()는 특정 이벤트 발생 시 함수를 실행한다는 점이 핵심적인 차이입니다. 버튼 클릭과 같은 이벤트 발생 시 특정 함수를 실행하도록 연결하는 방법을 이해함으로써, 더욱 능동적인 웹 인터랙션을 구현할 수 있게 되었습니다. 이제는 주석과 코드를 연결하여 실제 동작을 예측하고, 필요한 코드를 추가할 수 있다는 자신감이 생겼습니다.

function repeat(n, action) {
    for (let i = 0; i < n; i++) {
        action(i); // 각 반복에서 action 함수 호출
    }
}
repeat(3, n => console.log(`hello - ${n}`));

document
    .querySelector('button')
    .addEventListener('click', () => console.log('버튼 클릭'));

const handleClick = () => {
    console.log('버튼이 클릭되었습니다!');
    // 추가적인 동작 구현 가능 (예: 데이터 전송, UI 업데이트 등)
};

document
    .querySelector('button')
    .addEventListener('click', handleClick);

3. 배열 메서드 활용: map, filter, reduce 완벽 가이드#

무엇을 배웠나#

배열 메서드 map, filter, reduce의 역할을 명확히 구분하고, 각 함수의 사용법을 예시를 통해 이해하게 되었다. 특히 filter() 함수의 조건식 작성과 비교 연산자의 올바른 사용법을 숙지하고, 코드 작성 시 변수 이름 오타와 같은 사소한 실수를 놓치지 않도록 주의해야 함을 깨달았다. 이번 학습을 통해 배열 메서드를 활용한 코드 작성에 대한 자신감이 조금이나마 붙은 것 같다.

헷갈렸던 점#

배열 메서드 map, filter, reduce의 역할이 비슷해 보여서 언제 어떤 메서드를 사용해야 할지 헷갈렸다. 특히 filter 함수 내의 조건식을 어떻게 작성해야 할지, 그리고 reduce 함수에서 변수 이름을 정확하게 써야 하는지 어려움을 느꼈다. 오타로 인해 코드가 제대로 동작하지 않는 경우도 발생하여 주의가 필요하다는 것을 깨달았다.

정리된 이해#

map은 배열의 각 요소를 변환해서 새로운 배열을 만들고, filter는 조건을 만족하는 요소만 골라서 새로운 배열을 만드네. 그리고 reduce는 배열의 모든 요소를 하나의 값으로 줄여주는 역할을 하는 것 같아. 앞으로는 조건식 작성할 때 비교 연산자를 제대로 쓰고, 변수 이름 오타도 꼼꼼히 확인해야겠다.

let students = info_list.map(item => {
    item.name += ' 학생';
    return item;
});

let supple = students.filter(info => info.grade === 'C');

4. 웹 페이지의 창과 문서 객체 이해#

무엇을 배웠나#

window는 브라우저 창 자체를 나타내고 크기나 새 창 열기와 같은 창 관리 기능을 담당하며, document는 현재 로드된 HTML 문서를 나타내고 DOM 요소 조작과 같은 문서 관련 기능을 수행한다는 것을 알게 되었다. window와 document가 서로 다른 역할을 한다는 것을 이해하고 예시 코드를 통해 각각의 기능을 직접 확인하면서 혼란스러웠던 점이 조금이나마 명확해졌다. 앞으로는 웹 개발을 하면서 이 두 개념을 구분하여 사용해야겠다.

헷갈렸던 점#

window와 document가 모두 웹 페이지를 다루는 것처럼 보여서 정확히 어떤 역할을 하는지 헷갈렸습니다. 특히 window.open()의 옵션 설정에 따라 창이나 탭으로 열리는 방식이 브라우저에 따라 달라지는 점이 이해하기 어려웠습니다. 이 둘이 어떻게 상호작용하는지 명확하게 구분하지 못했던 점도 문제였습니다.

정리된 이해#

window는 브라우저 창 자체를 관리하는 객체이고, document는 현재 보여지는 HTML 문서를 나타내는 객체입니다. window는 창의 크기나 새 창 열기와 같은 기능에 사용되고, document는 HTML 요소의 조작과 내용 변경과 같은 작업에 사용됩니다. 따라서 window는 ‘화면’을, document는 ‘내용’을 다룬다고 생각하면 이해하기 쉬울 것 같습니다.

// 현재 브라우저 창의 너비와 높이 확인
console.log(window.innerWidth); // 화면 너비
console.log(window.innerHeight); // 화면 높이

// 새 창 열기
let win;
function openNewWindow() {
    win = window.open('https://www.example.com', '_blank', 'width=600,height=400');
}
function closeWindow() {
    if (win) {
        win.close();
    }
}

// 현재 문서의 URL과 제목 확인
console.log(document.URL); // 현재 페이지 URL
console.log(document.title); // 페이지 제목

// DOM 요소 선택 및 생성
let buttonElement = document.querySelector('button'); // 특정 버튼 요소 선택
let newDiv = document.createElement('div'); // 새로운 div 요소 생성
newDiv.innerHTML = '새로운 콘텐츠'; // div에 콘텐츠 추가
document.body.appendChild(newDiv); // body에 추가

5. 숫자와 Math 객체 활용하기#

무엇을 배웠나#

toFixed() 메서드는 숫자를 문자열로 반환한다는 것을 알게 되었고, 소수점 아래 숫자를 다시 숫자로 사용하려면 parseFloat()를 사용해야 한다는 것을 배웠다. 또한 Math 객체의 ceil, floor, round 메서드의 차이점을 명확히 이해하게 되었다. 앞으로는 이 점들을 기억하고 숫자와 Math 객체를 다룰 때 활용해야겠다.

헷갈렸던 점#

숫자 값을 다루는 과정에서 toFixed()가 문자열을 반환한다는 점을 처음엔 몰라서 당황했고, Math 객체 안에 있는 다양한 메서드들이 무엇을 하는 건지 한꺼번에 이해하기가 어려웠다. 특히 ceil, floor, round의 차이점을 바로 파악하지 못해서 헷갈렸다.

정리된 이해#

toFixed() 메서드는 숫자를 지정된 소수점 자리수로 반올림한 후 문자열로 변환한다는 것을 알게 되었고, 이 결과는 다시 숫자로 사용하려면 parseFloat() 등으로 변환해야 한다는 점을 기억해야겠다. 또한 Math 객체의 ceil, floor, round 메서드는 각각 올림, 내림, 반올림을 수행하며, 이들의 차이를 명확히 이해하고 활용해야겠다.

let num = 314.56789;
console.log(num.toFixed(2));

let numStr = num.toFixed(2);
let numNum = parseFloat(numStr);
