1. 배열 인덱싱, 정렬, 역순 처리: 초보자를 위한 정리#

무엇을 배웠나#

배열 인덱스가 0부터 시작하며, 인덱스를 잘못 이해하면 원하는 값을 가져오지 못한다는 것을 알게 되었습니다. 단순히 reverse()가 아닌 상황에 따라 sort().reverse()를 사용해야 한다는 점, 그리고 정렬 및 역순 처리 시 원본 배열이 변경될 수 있으므로 slice()를 사용하여 복사본을 만들어서 처리해야 한다는 점을 배웠습니다. 이제 배열 인덱싱과 정렬, 역순 처리 개념을 좀 더 명확하게 이해할 수 있게 되었습니다.

헷갈렸던 점#

배열 인덱스가 0부터 시작한다는 건 알았지만, 실제 코딩하다가 2번째 요소가 a[2]가 아니라 a[1]이라는 사실에 당황했어요. “역순”이라는 단어가 배열의 순서를 뒤집는 것인지, 아니면 다른 의미로 사용되는 건지 명확히 구분되지 않았고, 원본 배열이 변경된다는 점을 잊고 코드를 작성해서 데이터 손실이 발생할까 봐 걱정됐습니다.

정리된 이해#

배열 인덱스는 0부터 시작하며, 각 요소는 인덱스가 1씩 증가합니다. 배열을 정렬할 때는 sort()를, 순서를 뒤집을 때는 reverse()를 사용하며, 원본 배열을 변경하지 않도록 slice()를 활용할 수 있습니다. 문제에서 요구하는 “역순"의 의미를 명확히 파악하는 것이 중요합니다.

let fruits = ["banana", "apple", "cherry"];
fruits.sort(); // ["apple", "banana", "cherry"]

let reversedFruits = fruits.slice().reverse();

2. 객체 접근, 변수, 비교 연산자: 초보자를 위한 핵심 개념#

무엇을 배웠나#

객체 속성에 접근할 때는 점 표기법(.)을 사용해서 객체 내부의 값에 직접 접근할 수 있다는 것을 알게 되었다. var, let, const의 차이를 다시 한번 확인하고, 비교 연산자 ==와 ===가 다른 동작을 한다는 점을 숙지해야겠다. 특히 함수 매개변수로 받은 객체의 내부 값에 접근하는 방식에 대한 이해가 깊어졌다.

헷갈렸던 점#

객체를 받았을 때 그 안에 담긴 값을 어떻게 가져와야 할지 몰랐고, 함수 매개변수로 전달된 객체의 내부 데이터에 접근하는 방식이 헷갈렸다. 문자열을 연결할 때 띄어쓰기나 포맷팅이 결과에 영향을 줄 수 있다는 점을 제대로 인지하지 못했고, var, let, const의 차이점을 명확히 이해하지 못했다. ==와 ===가 같은 방식으로 동작한다고 생각했던 것도 잘못이었다.

정리된 이해#

객체를 다룰 때 점 표기법(.)을 사용해 속성에 접근해야 한다는 것을 이해했고, 함수 매개변수로 받은 객체 내부의 값을 바로 사용할 수 있다는 것도 명확해졌다. var, let, const의 차이를 다시 한번 학습하고, ==와 ===의 차이점을 제대로 파악하여 비교 연산을 정확하게 수행해야겠다.

function makeTotalPrice(product) {
    return product.quantity1 * product.price1
         + product.quantity2 * product.price2;
}

3. 배열 메서드와 자료구조 활용법#

무엇을 배웠나#

배열 메서드 사용 시 unshift()가 뒤가 아닌 앞쪽에 요소를 추가한다는 점을 명확히 이해하게 되었고, shift()와 unshift()의 역할 차이도 파악했다. Stack, Queue, Deque 구조가 배열 메서드와 어떻게 연결되는지, 그리고 각 구조의 특징과 활용법을 정리하며 자료구조에 대한 이해를 높였다. 특히 Deque의 개념과 활용법을 제대로 알게 되어 앞으로 자료구조 관련 문제를 해결하는 데 도움이 될 것 같다.

헷갈렸던 점#

배열 메서드 이름이 비슷해서, 특히 unshift()를 뒤쪽 메서드로 착각하고 shift()와 unshift()의 차이점을 명확히 이해하지 못했다. 또한, 자료구조인 Stack, Queue, Deque가 배열 메서드와 어떻게 연결되는지, 그리고 실제 프로그래밍에서 어떻게 활용되는지 파악하는 데 어려움을 느꼈다.

정리된 이해#

배열 메서드 사용 시 unshift()와 shift()가 배열 앞쪽을 조작하는 메서드라는 점을 기억하고, push/pop은 뒤쪽, unshift/shift는 앞쪽에서 동작한다는 방향성을 명확히 이해해야겠다. Stack, Queue, Deque는 배열 메서드를 활용하여 구현 가능하며, 각 자료구조의 특징과 실제 활용 상황을 연결하여 학습해야겠다.

// Stack 예시 (push & pop)
let stack = [];
stack.push(1);
stack.push(2);
let lastIn = stack.pop(); // lastIn은 2
console.log(stack); // [1]

// Queue 예시 (push & shift)
let queue = [];
queue.push(1);
queue.push(2);
let firstOut = queue.shift(); // firstOut은 1
console.log(queue); // [2]

// Deque 예시 (push, pop, unshift, shift)
let deque = [];
deque.push(1);      // 오른쪽 끝에 1 추가
deque.unshift(2);  // 왼쪽 끝에 2 추가
let removedRight = deque.pop();  // removedRight는 1
let removedLeft = deque.shift(); // removedLeft는 2
console.log(deque); // []

4. 반복문과 조건문으로 짝수 판별과 소수 합 구하기#

무엇을 배웠나#

배열을 순회하며 짝수나 소수를 판별하는 코드를 작성하는 과정에서 연산자와 조건문 사용에 어려움이 있었지만, 짝수 판별에는 % 연산자를 사용하고, 소수 판별에는 중첩 반복문과 break문을 활용하여 코드를 작성하는 방법을 익혔습니다. 특히, 소수를 판별할 때 초기값을 true로 설정하고 나누어떨어지는 수가 발견되면 false로 변경하는 로직을 이해하게 되었습니다. 또한, 문제 해결 방식에 따라 합계를 저장할지 배열을 생성할지 결정하는 부분도 명확해졌습니다.

헷갈렸던 점#

처음에는 배열 안의 숫자 하나하나를 어떻게 짝수나 소수인지 판별할지를 코드로 옮겨야 할지 몰랐다. 나눗셈과 나머지 연산의 차이도 헷갈려서 코드를 작성할 때 계속 오류가 발생했고, 조건문 안에서 괄호 위치를 제대로 사용하지 못했다. 소수 판별을 위한 중첩 반복문과 break문의 역할도 이해하기 어려웠다.

정리된 이해#

배열 내 숫자들의 짝수 여부와 소수 여부를 판별하는 코드를 작성하는 과정에서 연산자 혼동, 조건문 구조 오류, 결과 타입 결정 등 여러 부분에서 어려움을 겪었지만, 짝수 판별은 number % 2 === 0으로, 소수 판별은 초기 가정 후 나누어떨어지는 수가 있는지 확인하는 방식으로 코드를 작성할 수 있음을 이해했습니다. 특히 소수 판별 시 break문을 적절히 활용하여 불필요한 연산을 줄일 수 있다는 점을 깨달았습니다.

function sumOfPrimes(limit) {
    let sum = 0;
    for (let i = 2; i <= limit; i++) {
        let isPrime = true;
        for (let j = 2; j < i; j++) {
            if (i % j === 0) {
                isPrime = false;
                break;
            }
        }
        if (isPrime) {
            sum += i;
        }
    }
    return sum;
}

5. 숫자 변환과 문자열 연결: JavaScript 활용법#

무엇을 배웠나#

숫자를 문자열로 변환하고 배열로 나누는 과정에서 toString() 사용 시 쉼표가 포함될 수 있다는 점을 깨달았고, join() 함수를 활용하면 배열 요소를 원하는 형태로 연결할 수 있다는 것을 알게 되었다. 또한 반복문 변수의 이름은 자유롭게 설정할 수 있으며, 다양한 형 변환 도구(String, Number, parseInt, toString)의 활용법을 정리했다. 이러한 과정을 통해 숫자와 문자열 변환 및 배열 조작에 대한 이해도를 높였다.

헷갈렸던 점#

숫자를 문자열로 변환하는 과정에서 toString() 함수 사용 시 쉼표가 포함될 거라고 생각 못 했고, 머릿속으로 떠올린 로직을 코드로 옮기는 데 어려움을 겪었다. 반복문 변수가 꼭 필요한 건지, 그리고 숫자-문자열 변환 과정이 너무 복잡하게 느껴졌던 점도 처음에는 헷갈렸다.

정리된 이해#

숫자를 문자열로 변환하고 배열로 만들 때, toString()을 사용할 때 쉼표가 포함된다는 점을 인지하고, join() 메서드를 사용하여 배열 요소를 연결하는 방법을 익혔어. 반복문 변수는 배열의 인덱스를 나타내는 데 사용되며, 대소문자를 정확히 구분하여 함수를 호출해야 한다는 것도 명심해야겠어.

function 숫자To배열(num) {
    let text = String(num);
    let result = [];
    for (let i = 0; i < text.length; i++) {
        result.push(Number(text[i]));
    }
    return result;
}
