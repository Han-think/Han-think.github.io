3. CatBoost 래퍼와 Stacking: 복제 호환성 및 성능 향상을 위한 이해#

무엇을 배웠나#

CatBoost 모델을 sklearn 파이프라인과 함께 사용하기 위한 래퍼의 목적이 단순히 데이터 누수 방지가 아니라, 모델 복제 호환성을 확보하는 데 있다는 것을 알게 되었다. Stacking은 다양한 모델을 활용하여 서로 다른 오류 패턴을 보완하는 방식으로 성능 향상을 기대할 수 있지만, 반드시 성능이 보장되는 것은 아니라는 점을 이해했다. CatBoost 래퍼 클래스를 직접 정의해보면서, 래퍼의 역할과 중요성을 좀 더 명확하게 파악할 수 있었다.

헷갈렸던 점#

래퍼의 역할이 데이터 누수 방지라고 생각했는데, 실제로는 CatBoost 모델을 sklearn 환경에서 복제해서 사용할 수 있도록 호환성을 맞춰주는 것이 중요하다는 것을 알게 되었다. 단순히 여러 모델을 쌓는다고 해서 무조건 성능이 향상되는 것이 아니고, 모델들의 다양성이 성능 향상에 중요한 역할을 한다는 점도 명확히 이해했다. 래퍼 클래스를 직접 정의해보니, CatBoost를 sklearn과 함께 사용하는 방법을 체감할 수 있었다.

정리된 이해#

CatBoost 모델을 sklearn 파이프라인과 함께 사용하기 위해 CloneSafeCatBoost 래퍼는 단순히 데이터 누수 방지 기능 외에도 모델의 복제 기능을 가능하게 하는 데 중요한 역할을 합니다. Stacking을 사용할 때 성능 향상은 모델들의 다양성에 달려있으며, 비슷한 유형의 모델들을 섞는다고 해서 무조건 성능이 좋아지는 것은 아닙니다. 다양한 알고리즘을 활용하여 서로 다른 오류 패턴을 가진 모델들을 결합하는 것이 중요합니다.

from sklearn.base import BaseEstimator, ClassifierMixin
from catboost import CatBoostClassifier

class CloneSafeCatBoost(BaseEstimator, ClassifierMixin):
    def __init__(self, params):
        self.params = params
        self.model = None

    def fit(self, X, y):
        self.model = CatBoostClassifier(**self.params)
        self.model.fit(X, y)
        return self

    def predict(self, X):
        return self.model.predict(X)

    def predict_proba(self, X):
        return self.model.predict_proba(X)

4. SHAP 해석과 핵심 변수 파악: 초보자를 위한 가이드#

무엇을 배웠나#

SHAP 그래프 해석 시, 세로축은 중요도, 가로축은 예측 결과 방향, 색상은 변수 값의 크기를 나타냄을 이해했다. 단순히 SHAP 요약 상위 변수를 핵심 변수로 단정짓기보다는, 다양한 검증 방법을 통해 판단해야 함을 알게 되었다. 특히 연속형 변수의 경우, 빨간색은 값이 증가할수록 예측이 증가하고, 파란색은 감소하는 것을 의미하는 것을 명확히 파악했다.

헷갈렸던 점#

SHAP 그래프에서 색깔과 위치를 보고 변수의 의미를 바로 파악하기 어려웠습니다. 특히 성별이나 나이와 같은 연속형 변수가 빨간색인지 파란색인지, 그리고 어떤 값을 의미하는지 혼란스러웠습니다. 또한 SHAP 요약에서 상위 변수들을 무조건 핵심 변수로 판단할 수 있는지, 다른 검증 과정이 필요한지 명확하지 않았습니다.

정리된 이해#

SHAP 요약 그래프에서는 세로축이 변수의 중요도를 나타내고, 가로축은 변수 값 변화에 따른 예측 변화 방향을 보여줍니다. 색상은 변수 값의 크기를 나타내며, 빨간색은 값이 클수록 예측을 증가시키는 방향으로, 파란색은 감소시키는 방향으로 해석할 수 있습니다. 단순히 SHAP 요약 상위 변수만 핵심 변수로 단정짓기보다는, 다양한 검증을 통해 결론을 내려야 합니다.

- age: 빨강 = 나이가 많음 → 예측 증가, 파랑 = 나이가 적음 → 예측 감소
- fare: 빨강 = 요금 높음 → 예측 증가, 파랑 = 요금 낮음 → 예측 감소

정리된 이해#

7. SARIMA 모델의 계절 시계열 구조 이해#

무엇을 배웠나#

SARIMA 모델에서 소문자 매개변수는 일반적인 과거 패턴을, 대문자 매개변수는 계절성 패턴을 반영한다는 것을 명확히 이해하게 되었어. 특히, ‘p’와 ‘P’, ‘q’와 ‘Q’의 차이를 구분하는 것이 중요했고, 이를 통해 계절성 시계열 데이터 분석에 대한 이해도를 높일 수 있을 것 같아. 앞으로는 이 지식을 바탕으로 실제 데이터 분석에 적용해 보려고 해.

헷갈렸던 점#

SARIMA 모델에서 소문자 p, d, q와 대문자 P, D, Q의 차이를 명확히 구분하지 못해서, 특히 p와 P, q와 Q가 비슷해 보여서 어떤 게 과거의 일반적인 패턴을 반영하고, 어떤 게 계절성 패턴을 반영하는지 헷갈렸습니다. 계절 차분(D)과 일반 차분(d)의 개념도 연결해서 이해해야 한다는 점이 불분명했습니다.

정리된 이해#

처음에는 train_test_split()으로 이미 데이터를 나눴는데, 왜 K-Fold 교차 검증을 해야 하는지 이해가 안 갔어요. 그리고 Ridge, Lasso, ElasticNet 같은 정규화 회귀 방법들이 왜 서로 다른지, 각각 어떤 기준으로 계수를 조정하는지 명확하게 파악하기 어려웠습니다. L1, L2 정규화의 개념과 그 영향에 대한 이해가 부족했습니다.

정리된 이해#

K-Fold 교차 검증은 데이터를 여러 조각으로 나누어 학습과 검증을 반복함으로써 모델의 성능을 더 안정적으로 평가하는 방법입니다. train_test_split()으로 데이터를 나눈 후에도, K-Fold 교차 검증을 통해 모델이 다양한 데이터 조합에 얼마나 잘 일반화되는지 확인할 수 있습니다. 정규화 회귀는 과적합을 방지하기 위해 모델의 복잡도를 줄이는 방법이며, 각 정규화 방법(Ridge, Lasso, ElasticNet)은 L1 또는 L2 규제 항을 사용하여 모델의 계수를 조정하는 방식이 다릅니다.

from sklearn.model_selection import KFold

kfold = KFold(n_splits=5)

15. 회귀 모델 평가 지표 완벽 분석: RSS, MAE, MSE, R2#

무엇을 배웠나#

회귀 모델 평가 지표인 RSS, MAE, MSE, R2를 학습하면서 각 지표가 오차를 측정하는 방식의 차이와 R2 값 해석에 대해 명확히 이해하지 못했던 점이 있었다. RSS는 오차 제곱합으로, 데이터 크기에 민감하며 비교가 어렵고, MAE는 오차의 절대값 평균으로 직관적인 이해가 가능하다는 것을 알게 되었다. 또한 R2 값이 음수가 되는 경우도 고려해야 함을 학습했다.

헷갈렸던 점#

회귀 모델 평가 지표들을 보면서, 각 지표가 어떻게 오차를 계산하는지, 그리고 어떤 상황에서 어떤 지표를 사용하는 것이 적절한지 파악하는 데 어려움을 느꼈습니다. 특히 R2 값의 의미를 완벽하게 이해하지 못해서, 값이 높다고 해서 무조건 좋은 것인지, 아니면 다른 상황들도 고려해야 하는지 헷갈렸습니다.

정리된 이해#

회귀 모델 평가 지표인 RSS, MAE, MSE, R2를 학습하면서 오차 계산 방식의 차이와 R2 값 해석에 어려움을 겪었지만, 각 지표의 정의와 특징을 명확히 이해하게 되었다. RSS는 오차 제곱합, MAE는 절대 오차의 평균, MSE는 MSE는 오차 제곱의 평균이며, R2는 모델의 설명력을 나타내는 지표임을 알게 되었다. 특히 R2 값이 0에 가까울 때는 모델이 데이터를 설명하는 데 실패했고, 음수일 때는 예측이 실제 값보다 더 나쁘다는 의미임을 이해하게 되었다.

def return_RSS(test_y, predicted):
    RSS = sum((test_y[i] - predicted[i]) ** 2 for i in range(len(test_y)))
    return RSS

from sklearn.metrics import mean_absolute_error
MAE = mean_absolute_error(test_y, predicted)

분류 모델 파이프라인 구축, 모델 선택 시 다양한 요소를 고려하는 방법, 그리고 SARIMA 모델을 포함한 시계열 분석까지 폭넓게 학습했습니다. 데이터 불균형 문제 해결, 의사결정나무 모델링, 선형 회귀 모델 구현, 교차 검증, 회귀 모델 평가 지표까지 꼼꼼하게 학습하며 실무 적용 가능성을 높였습니다. 앞으로는 학습한 내용을 바탕으로 실전 데이터 분석 프로젝트에 적용하며 더욱 깊이 있는 이해를 해나가겠습니다.
