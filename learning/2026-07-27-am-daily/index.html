1. HTML 기본 구조와 태그 이해하기#

무엇을 배웠나#

HTML 기본 구조와 태그를 배우면서, 태그의 중첩 관계를 트리 형태로 이해하는 것이 중요함을 알게 되었다. 단순히 태그를 나열하는 것이 아니라, 부모-자식 관계를 고려해야 하는 점이 헷갈렸지만, 예제를 통해 조금씩 감을 잡았다. 또한, 태그와 요소를 명확히 구분하고 속성을 이해하는 것이 HTML 문서를 만드는 데 필수적임을 깨달았다.

헷갈렸던 점#

처음에는 HTML 태그들이 어떻게 연결되는지, 어떤 태그가 어떤 태그 안에 들어가야 하는지 감을 잡기가 어려웠다. 특히 링크 안에 이미지를 넣는 것처럼 복잡한 구조를 이해하는 데 시간이 걸렸다. 태그와 요소를 구분하는 개념도 처음에는 헷갈렸던 것 같다.

정리된 이해#

HTML은 태그들이 트리 구조로 얽혀있으며, 태그와 속성을 명확히 구분해야 합니다. 단순히 태그를 나열하는 것이 아니라 중첩 구조를 이해하고 부모-자식 관계를 파악하는 것이 중요합니다. 실습 과정에서 오류가 발생하지 않도록 주의하며 꾸준히 연습해야 합니다.

<header>
  <nav>...</nav>
</header>

2. CSS 적용 방식: 인라인 스타일과 Internal Style Sheet#

무엇을 배웠나#

CSS 스타일 적용 방식에 대한 혼동을 풀고, HTML 태그 내 inline style과 <style> 태그를 사용한 internal style sheet의 차이를 이해하게 되었다. internal style sheet는 선택자, 속성, 값, 선언으로 구성되며, HTML 문서 내 <head> 섹션에 스타일 규칙을 정의한다는 점을 명확히 알게 되었다. 강의에서 다루는 내용과 현업에서의 실제 사용 방식 간의 차이에 대한 고민도 정리할 수 있었다.

헷갈렸던 점#

HTML 태그 내의 style 속성과 <style> 태그로 CSS를 적용하는 방식이 비슷해 보여서 어떤 차이가 있는지 명확히 이해하지 못했고, 수업에서 배우는 내용이 HTML 구조에 대한 것인지, 아니면 디자인 적용에 대한 것인지 헷갈렸다. 또한, 강사님이 현업에서는 External Style Sheet를 주로 사용한다고 말씀하셔서, 지금 배우는 Internal Style Sheet가 우선순위인지 확신이 서지 않았다.

정리된 이해#

HTML 태그 내 직접 스타일을 적용하는 인라인 방식과 <style> 태그 내에 CSS 규칙을 정의하는 Internal Style Sheet 방식의 차이를 이해하게 되었고, 선택자, 속성, 값, 선언 등의 CSS 기본 개념을 익혔다. 현재 수업에서는 Internal Style Sheet을 배우는 것이 우선이고, 현업에서는 External Style Sheet을 주로 사용한다는 점을 기억해야겠다. 앞으로는 이 지식을 바탕으로 더 복잡한 스타일링을 해봐야겠다.

<p style="font-size: 16px; color: green;">글꼴 크기와 색상 설정</p>

<head>
  <style>
    p {
      font-size: 16px;
      color: green;
    }
  </style>
</head>

3. CSS 선택자와 구체적 지시 우선순위 완벽 이해#

무엇을 배웠나#

CSS 선택자 표기법과 우선순위 판단 기준에 대한 이해가 부족했던 부분을 명확히 정리할 수 있었다. 특히 복합 선택자의 의미와 구체성 비교 규칙을 통해 어떤 스타일 규칙이 적용될지 예측하는 능력을 키웠다. id 선택자의 고유성이라는 중요한 개념을 다시 한번 확인하고 실습 예제를 통해 이해도를 높였다.

헷갈렸던 점#

처음에는 복합 선택자에서 띄어쓰기가 의미하는 바를 정확히 이해하지 못해서, 어떤 선택자가 어떤 요소를 타겟으로 하는지 혼동되었어요. 특히, ID, 클래스, 태그 선택자의 우선순위를 시각적으로 파악하기 어려워서, 코드의 실제 적용 결과를 예측하는 데 어려움이 있었습니다. 마지막으로, 실습 예제에서 ID 중복 사용은 혼란을 가중시켰습니다.

정리된 이해#

CSS 선택자의 종류와 복합 선택자의 의미를 명확히 이해하고, 선택자 우선순위를 판단하는 기준을 구체적으로 정리했다. 특히, 구체성 비교와 스타일 규칙 작성 순서가 우선순위에 미치는 영향을 고려하여 실제 코드에 적용할 수 있도록 연습했다. 이제는 좀 더 복잡한 스타일 규칙에서도 어떤 스타일이 적용될지 예측할 수 있을 것 같다.

<style>
  h1 {
    color: blue;
  }

  .codes {
    color: red;
  }

  #coding {
    color: green;
  }

  h1.codes {
    color: orange;
  }

  h1 .codes {
    color: purple;
  }
</style>

<h1>코딩 제목</h1>
<h1 class="codes">코딩 제목 (클래스 적용)</h1>
<div id="coding">
  <h1 class="codes">코딩 제목 (클래스 적용) - div 내부</h1>
  <p class="codes">단락 (클래스 적용)</p>
</div>

4. CSS 상속과 자식 선택자: 개념과 차이점 이해#

무엇을 배웠나#

CSS 상속은 부모 요소의 스타일이 자식 요소로 전달되는 것이고, 공백은 선택자를 표현하는 문법이라는 것을 명확히 구분하게 되었다. 특히 header p와 header > p의 차이를 이해하기 위해 중간 요소를 활용해야 한다는 점을 깨달았다. 또한 상속된 속성과 직접 지정된 속성의 우선순위 관계도 좀 더 명확하게 이해하게 되었다.

헷갈렸던 점#

CSS 상속과 선택자 구분이 명확하지 않아서, 부모 요소와 자식 요소 사이의 간격이 상속 현상과 동일하다고 착각했어. 특히 header p와 header > p가 같은 결과를 보여서 자식 선택자의 의미를 제대로 이해하지 못했고, 상속된 속성과 직접 지정된 속성 중 어떤 것이 우선 적용되는지 판단하는 데 어려움이 있었어.

정리된 이해#

CSS 상속은 부모 요소의 스타일이 자식 요소에 전달되는 현상이고, 선택자는 어떤 요소를 스타일링할지 지정하는 문법이라는 것을 구분해야 했다. header p와 header > p의 차이를 명확히 이해하기 위해 중간 요소를 활용하여 테스트해야 한다는 것을 알게 되었다. 상속된 속성과 직접 지정된 속성의 우선순위는 직접 지정된 속성이 더 높은 우선순위를 가진다는 점을 기억해야겠다.

header {
  color: red;
}

header p {
  color: blue;
}
