초보자를 위한 Python 반복문 이해: 혼동 포인트와 정리

Python에서 반복문을 이해하는 과정에서 겪은 혼동 포인트와 그에 대한 정리된 이해를 공유합니다.
2026년 6월 1일 · 6 min

왜 썼나#

Python을 배우며 반복문, 특히 for 루프와 range() 함수에 대해 깊이 이해하는 것이 프로그래밍의 기본이 되는 부분이었습니다. 특히 초보자로서 이 개념들에 대한 명확한 이해가 코드 작성 능력 향상에 큰 도움이 되었습니다.

배운 것#

  1. for 루프의 작동 원리: 리스트나 범위 내의 각 요소를 순차적으로 접근하고 처리하는 방법을 배웠습니다. 이는 데이터 처리나 반복적인 작업 수행에 필수적입니다.

  2. range() 함수의 활용: 특정 범위 내의 숫자 생성을 통해 반복 횟수를 제어하는 방법을 이해하였습니다. 이는 반복문의 효율적인 사용에 중요한 역할을 합니다.

헷갈린 것#

1. for 루프 내 변수 i의 역할#

초기 학습 단계에서 for 루프 내의 변수 i가 어떻게 동작하는지 정확히 파악하는 데 어려움이 있었습니다. 각 반복 단계에서 i의 값 변화와 그에 따른 처리 과정을 명확히 이해하는 데 시간이 필요했습니다.

2. range() 함수의 범위 이해#

range() 함수의 동작 방식, 특히 시작과 끝 숫자가 어떻게 처리되는지에 대한 이해가 부족했습니다. 특히, 끝 숫자가 포함되는지 여부에 대한 명확한 인식이 필요했습니다.

3. 누적 변수의 필요성#

누적 변수를 사용해 합계를 구하는 방법을 이해하는 데 어려움이 있었습니다. 왜 특정 변수를 선언하고 값을 누적시켜야 하는지, 그리고 이를 어떻게 구현할지에 대한 구체적인 이해가 필요했습니다.

혼란 요소 해결#

1. 용어의 혼동

  • 원소/값/항목/요소 (item/element):

    • 개념 정리: 리스트나 배열 내에서 개별 항목을 지칭할 때 사용되는 용어입니다. 정확한 사용은 맥락에 따라 다릅니다.
      • 예시: my_list = [10, 20, 30]에서 10, 20, 30 각각은 리스트 my_list의 요소 (element) 또는 **항목 (item)**입니다.
      • 초보자 키워드: “리스트 내 각 개별 값은 요소 또는 항목으로 불린다.”

  • 길이/길이 계산/길이 구하기/카운트 (length/len/count):

    • 개념 정리: 리스트나 배열의 크기를 나타내는 데 사용됩니다. 주로 Python에서 len() 함수를 통해 얻을 수 있습니다.
      • 예시: 
        my_list = [10, 20, 30]
list_length = len(my_list)  # 길이 구하기
print(list_length)  # 결과: 3
      • 헷갈리는 이유: count() 메소드와 len() 함수의 혼동이 있을 수 있습니다. count()는 특정 요소의 발생 횟수를 세는 데 사용됩니다.
      • 초보자 키워드: “len()으로 리스트의 총 개수를 확인하고, list.count(x)로 특정 값의 개수를 파악하라.”

배운 것#

  • 반복문의 중요성: 반복문은 프로그래밍에서 데이터를 여러 번 처리해야 할 때 필수적인 구조입니다. 특히, 동일한 작업을 여러 항목에 대해 반복할 때 매우 유용합니다.

핵심 개념 정리: 합계와 평균 계산#

핵심 개념 정리:

  • 합계와 평균 계산 방법:
    • 초기화 단계: total = 0으로 합계 변수를 초기화합니다. 이는 합계를 누적할 수 있는 공간을 마련하는 단계입니다.
    • 누적 합산: total = total + score 또는 더 간결한 형태인 total += score를 사용해 리스트 내 각 점수를 차례대로 누적하여 총합을 구합니다.
    • 평균 계산: 리스트의 길이(len(scores))를 이용해 평균을 계산합니다. 평균은 average = total / len(scores)로 구합니다.
    • 실습 예시: 
      scores = [85, 90, 78, 92]
total = 0  # 합계 초기화
for score in scores:
    total += score  # 각 점수를 누적
average = total / len(scores)  # 평균 계산
print("합계:", total)  # 출력 예시: 합계: 325
print("평균:", average)  # 출력 예시: 평균: 81.25

누적 변수 이해하기: 반복 과정에서의 값 누적 기법#

왜 썼나#

누적 변수는 프로그래밍에서 특정 작업을 반복하면서 연속적인 결과를 누적하여 최종 값을 얻는 데 필수적인 개념입니다. 특히 데이터 처리, 합계 계산, 혹은 일련의 연속적인 연산 결과를 추적해야 할 때 유용합니다. 이러한 기법은 단순한 계산을 넘어 복잡한 알고리즘 이해에도 큰 도움이 됩니다.

배운 것#

  • 반복문의 중요성: for 문을 통해 특정 범위나 컬렉션을 순환하며 각 단계에서의 값을 처리할 수 있다는 점을 다시 한번 확인했습니다.
  • 변수 업데이트: 각 반복 단계마다 누적 변수의 값을 업데이트하는 과정이 핵심임을 이해했습니다. 이는 단순한 값 추가뿐 아니라 여러 연산을 포함할 수도 있습니다.

헷갈린 것#

누적 변수를 처음 접할 때, 변수가 계속 업데이트되면서 어떻게 최종 결과에 도달하는지 예측하는 것이 쉽지 않았습니다. 특히 복잡한 조건문이 포함된 경우, 각 반복 단계에서의 변수 상태를 정확히 추적하는 것이 헷갈렸습니다.

정리된 이해#

누적 변수는 반복 작업 중에 지속적으로 값을 더해나가는 변수입니다. 주요 특징은 다음과 같습니다:

  • 초기화: 작업 시작 전에 변수를 초기 값으로 설정합니다 (예: total_sum = 0).
  • 반복 업데이트: 각 반복마다 현재 값을 누적 변수에 더합니다 (예: total_sum += number).
  • 결과 출력: 필요에 따라 중간 결과나 최종 결과를 출력합니다.
