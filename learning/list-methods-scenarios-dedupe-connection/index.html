1. 리스트 추가 (append)#

왜 이걸 보게 됐나#

리스트에 새로운 요소를 추가할 때 각 메서드의 역할과 차이점을 명확히 이해하고자 함. 특히, append(), extend(), insert() 등의 메서드가 어떻게 다른지 파악하고 실제 코딩에서 어떻게 적용할지 배우고자 함.

내가 헷갈린 지점#

append()와 extend()의 차이점과 사용 시기를 정확히 구분하지 못했으며, insert() 메서드가 리스트 내 요소 배치에 미치는 영향을 구체적으로 이해하는 데 어려움이 있었음. 또한, 중복 요소 제거와 관련된 dedupe 기능과 remove() 메서드의 역할을 명확히 구분하지 못했음.

시도한 코드 / 예시#

# append() 예시
my_list = ['사과', '바나나']
my_list.append('체리')
print(my_list)  # 출력: ['사과', '바나나', '체리']

# extend() 예시
fruits = ['사과', '바나나']
more_fruits = ['체리', '포도']
fruits.extend(more_fruits)
print(fruits)  # 출력: ['사과', '바나나', '체리', '포도']

# insert() 예시
numbers = [1, 2, 3]
numbers.insert(1, 1.5)
print(numbers)  # 출력: [1, 1.5, 2, 3]

결과와 해석#

위 코드 실행 결과:

  • append() 후 my_list: ['사과', '바나나', '체리']
  • extend() 후 fruits: ['사과', '바나나', '체리', '포도']
  • insert() 후 numbers: [1, 1.5, 2, 3]

정리된 이해#

리스트 조작 메서드 이해를 통해 append()로 리스트 끝에 요소 추가, extend()로 여러 요소 한 번에 추가, insert()로 특정 위치에 요소 삽입하는 방법을 익혔다. 각 메서드의 특징과 사용 시기를 파악함으로써 리스트 관리 능력 향상에 도움이 되었다.

2. 특정 위치 삽입 (insert)#

왜 이걸 보게 됐나#

특정 위치에 값을 삽입해야 하는 상황에서 정확한 메서드 사용법을 이해하고 적용하기 위해

내가 헷갈린 지점#

언제 insert() 메서드를 사용해야 하는지, 그리고 삽입이 기존 요소에 어떤 영향을 미치는지 명확히 파악하지 못했던 경험

시도한 코드 / 예시#

fruits = ['사과', '바나나']
# 인덱스 1 위치에 '체리' 삽입
fruits.insert(1, '체리')
print(fruits)
# 결과: ['사과', '체리', '바나나']

결과와 해석#

인덱스 1 위치에 ‘체리’가 삽입되어 리스트가 [‘사과’, ‘체리’, ‘바나나’]로 변경됨

정리된 이해#

리스트의 insert() 메서드는 특정 위치에 요소를 삽입하여 리스트의 구조를 조정하는데 사용되며, 이 과정에서 삽입된 요소는 기존 요소들을 뒤로 밀어냅니다.

3. 요소 제거 (remove)#

왜 이걸 보게 됐나#

리스트 조작에서 요소 제거의 핵심 이해와 실제 적용 방법을 명확히 하여, 학습자가 코드 작성 시 혼란을 줄일 수 있도록 함.

내가 헷갈린 지점#

학습자들이 remove() 메서드가 리스트에서 어떤 요소를 정확히 제거하는지, 특히 중복 요소 처리 시 어떤 동작을 하는지에 대해 명확한 이해가 부족함을 인식하고 해결 방안을 제시함.

시도한 코드 / 예시#

fruits = ['사과', '바나나', '체리', '사과']
# 첫 번째로 발견되는 '사과' 제거
fruits.remove('사과')
print(fruits)  # 결과: ['바나나', '체리', '사과']

# 중복 요소 제거를 위한 예시
unique_fruits = []
for fruit in fruits:  # 중복 제거를 위해 별도 리스트 사용
    if fruit not in unique_fruits:
        unique_fruits.append(fruit)
print(unique_fruits)  # 결과: ['바나나', '체리', '사과']

결과와 해석#

코드 실행 결과는 첫 번째로 발견되는 ‘사과’가 제거되고, 중복 요소를 수동으로 제거한 결과 리스트가 출력됨. 이는 remove() 메서드의 동작 방식과 중복 요소 제거를 위한 대체 방법을 보여줌.

['바나나', '체리', '사과']
['바나나', '체리', '사과']

정리된 이해#

학습자들은 remove() 메서드가 리스트에서 첫 번째로 나타나는 특정 요소를 제거함을 이해하게 되며, 중복 요소를 제거할 때는 remove() 대신 수동 반복문을 활용하거나 다른 중복 제거 기법을 적용해야 함을 깨닫게 됩니다. 이를 통해 실제 프로젝트에서의 리스트 조작 능력 향상에 도움이 됩니다.

4. 중복 제거 (dedupe)#

왜 이걸 보게 됐나#

중복 요소를 제거하는 dedupe 기능의 실제 적용 방법과 그 중요성을 이해하고자 합니다. 특히, 리스트 내 중복 요소를 효과적으로 제거하는 방법과 이를 프로젝트, 특히 데이터 처리 파이프라인에서 어떻게 활용할 수 있는지 구체적인 예시를 원합니다.

내가 헷갈린 지점#

중복 요소 제거 시, 어떤 기준으로 중복을 판단해야 하는지 명확하지 않습니다. 예를 들어, 문자열 리스트에서 부분 문자열의 중복을 어떻게 처리할지에 대한 구체적인 방법이 필요합니다. 또한, dedupe와 remove() 메서드의 차이점과 각각의 적절한 사용 사례에 대한 이해가 부족합니다.

시도한 코드 / 예시#

def remove_duplicates(lst):  # 중복 요소 제거 함수
    return list(dict.fromkeys(lst))  # dict를 이용해 중복 제거 후 다시 리스트로 변환

# 예시 리스트
items = ['사과', '바나나', '사과', '체리', '바나나']

# 중복 제거 적용
unique_items = remove_duplicates(items)
print(unique_items)  # 출력: ['사과', '바나나', '체리']

결과와 해석#

[‘사과’, ‘바나나’, ‘체리’]

정리된 이해#

중복 요소를 제거하는 dedupe 기법은 dict.fromkeys()를 활용하여 리스트 내 중복 항목을 효과적으로 제거할 수 있습니다. 이 방법은 원본 리스트의 순서를 유지하면서 중복을 제거하므로, 데이터 처리 파이프라인에서 중복 데이터를 제거하는 데 유용합니다. remove()와 달리 dedupe는 전체 리스트를 스캔하여 모든 중복을 일괄적으로 처리할 수 있다는 점에서 차이가 있습니다.

총평#

오늘 전체에서 배운 것#

리스트 조작 메서드 (append, insert, remove, dedupe)의 정확한 사용법과 적용 시나리오를 이해했습니다. 특히, 각 메서드의 구체적인 동작 방식과 예시를 통해 혼란스러웠던 부분을 명확히 파악했습니다.

다음에 조심할 것#

remove() 함수는 첫 번째 일치 요소만 제거하므로, 특정 값의 모든 발생을 제거하려면 루프를 사용해야 합니다. 또한, dedupe는 일반적으로 외부 라이브러리나 함수를 통해 구현되므로, 기본 리스트 메서드로는 완벽한 중복 제거가 어려울 수 있습니다.

다음 복습 주제#

반복문 내에서 append()를 활용한 순차적 데이터 추가와 insert()를 통한 특정 위치 삽입의 중요성을 깨달았습니다. 리스트 관리의 핵심은 데이터의 효율적인 추가, 수정, 제거에 있으며, 이는 실제 프로젝트에서 데이터 처리와 관리에 필수적입니다.
