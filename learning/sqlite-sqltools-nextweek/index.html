1. VS Code 작업 공간#

왜 이걸 보게 됐나#

처음에는 제가 익숙한 다른 편집기를 주로 사용해 왔기 때문에, 교육 환경에서 VS Code를 사용해야 한다는 점이 낯설었습니다. 하지만 모든 학생이 동일한 환경에서 작업하도록 강제하기 위해 VS Code가 표준 작업 공간으로 지정되었고, 이를 통해 강의 내용 이해와 문제 해결 과정에서 혼란을 줄이고자 합니다. VS Code를 활용하면 선생님과 제가 동일한 환경에서 동일한 도구를 사용하며 학습할 수 있게 됩니다.

내가 헷갈린 지점#

처음에는 VS Code를 단순히 코드 편집기로만 생각해서, 교육용으로 강제해야 하는 이유를 잘 이해하지 못했습니다. 다른 편집기처럼 개인적인 설정을 자유롭게 할 수 없을까 봐 약간의 불편함을 느꼈고, 모든 학생이 동일한 환경을 사용해야 한다는 점이 낯설게 느껴졌습니다. 마치 정해진 틀 안에서 작업해야 하는 듯한 느낌을 받았습니다.

시도한 코드 / 예시#

# 명령 프롬프트 또는 터미널에서 SQLite 실행
sqlite3 example.db  # 'example.db' 파일 생성

결과와 해석#

VS Code는 강의에서 모든 학생이 동일한 환경에서 작업하도록 강제하는, 일종의 표준 작업 공간이라는 것을 알게 되었다. SQLTools 확장팩과 SQLite 드라이버를 설치하여, SQLite 데이터베이스 파일(example.db)을 VS Code 내에서 열어 쿼리를 실행하는 방식으로 환경을 구성했다. 이제 VS Code는 제약이 아닌, 협업을 위한 도구로 받아들일 수 있게 되었다.

정리된 이해#

VS Code는 모든 학생이 동일한 개발 환경을 사용하도록 돕는 강의용 작업 공간입니다. 이 공간 안에서 SQLTools 확장팩과 SQLite 드라이버를 사용하면 파일 기반의 가벼운 데이터베이스인 SQLite에 쉽게 연결하여 쿼리를 실행할 수 있습니다. 이제 VS Code를 교육용 도구로 활용하여 데이터베이스 작업을 수행할 수 있음을 알게 되었습니다.

2. SQLite 데이터베이스#

왜 이걸 보게 됐나#

이전에는 복잡한 서버 기반 데이터베이스 시스템에만 익숙했는데, 가볍게 로컬 환경에서 데이터를 다룰 수 있는 데이터베이스가 있다는 것을 알게 되었습니다. 특히 교육 환경에서 통일된 개발 환경을 구축하기 위해 SQLite를 사용한다고 하니, 학습 과정을 원활하게 진행하기 위해 배우게 되었습니다. 앞으로는 간단한 데이터 관리를 위해 SQLite를 활용할 수 있을 것입니다.

내가 헷갈린 지점#

SQLite가 정확히 어떤 존재인지, 그리고 그 이름이 어떻게 발음되는지가 처음에는 명확하게 떠오르지 않았습니다. 파일 기반 데이터베이스라는 설명은 이해했지만, 실제로 어떻게 사용되는지에 대한 구체적인 그림이 부족했습니다. 강의 환경에서 사용해야 하는 도구라는 생각에 처음에는 약간의 거부감이 있었던 것도 사실입니다.

시도한 코드 / 예시#

# 명령 프롬프트 또는 터미널에서 SQLite 실행
sqlite3 example.db  # 'example.db' 파일 생성

결과와 해석#

터미널에서 sqlite3 example.db 명령어를 실행하면, example.db라는 이름의 SQLite 데이터베이스 파일이 생성되었고, 이 파일을 VS Code의 SQLTools에서 열어 간단한 SQL 쿼리를 실행하여 데이터베이스를 조작할 수 있었다. 이는 SQLite가 별도의 서버 없이 파일 형태로 작동하는 간단한 데이터베이스임을 보여주었고, SQLTools 확장팩을 통해 VS Code에서 쉽게 접근할 수 있음을 확인시켜주었다.

정리된 이해#

SQLite는 파일 기반으로 작동하는 가벼운 데이터베이스 시스템으로, 별도의 서버 설치 없이 로컬 환경에서 쉽게 데이터 관리가 가능합니다. VS Code의 SQLTools 확장팩과 SQLite 드라이버를 함께 사용하면 SQLite 데이터베이스에 연결하여 쿼리를 실행하는 과정을 간편하게 할 수 있습니다. 이를 통해 교육 환경에서 강사 및 학생 모두가 동일한 개발 환경을 유지하며 학습할 수 있습니다.

3. SQLTools 확장팩#

왜 이걸 보게 됐나#

교육 환경에서 모든 학생이 동일한 개발 환경을 사용해야 해서 VS Code와 SQLTools를 사용하게 되었어. SQLite 데이터베이스를 VS Code에서 편리하게 사용하기 위해 SQLTools 확장팩과 SQLite 드라이버를 설치해야 했고, 이를 통해 데이터베이스 연결 및 쿼리 실행을 쉽게 할 수 있게 되었어. 이렇게 하면 강의 내용에 집중하고 개인적인 환경 설정 문제로 시간을 낭비하는 것을 줄일 수 있어.

내가 헷갈린 지점#

처음에는 SQLTools가 단순히 SQLite를 실행하는 도구인 줄 알았는데, VS Code 상에서 SQLite 데이터베이스에 연결하고 쿼리를 실행할 수 있게 해주는 확장팩이라는 것을 이해하는 데 시간이 걸렸습니다. 또한, SQLTools 자체만 설치하면 되는 줄 알았는데, 별도로 SQLite 드라이버까지 설치해야 한다는 점이 헷갈렸습니다. 이 두 가지 구성 요소가 함께 작동해야 SQLite 데이터베이스를 제대로 사용할 수 있다는 것을 깨닫고 설치 과정을 다시 확인했습니다.

시도한 코드 / 예시#

# 명령 프롬프트 또는 터미널에서 SQLite 실행
sqlite3 example.db  # 'example.db' 파일 생성

결과와 해석#

SQLTools 확장팩을 설치하고 SQLite 드라이버까지 추가하니 VS Code에서 SQLite 데이터베이스 파일(example.db)을 열어 간단한 SQL 쿼리를 실행할 수 있게 되었다. 명령어 프롬프트에서 sqlite3 example.db 명령을 통해 데이터베이스 파일을 생성하고, SQLTools를 통해 연결하여 데이터를 조회하거나 수정할 수 있게 되었다. 이제 VS Code 환경에서 SQLite 데이터베이스를 다루는 것이 익숙해질 것 같다.

정리된 이해#

SQLTools 확장팩은 VS Code에서 SQLite와 같은 데이터베이스에 연결하여 쿼리를 실행할 수 있게 해주는 매우 유용한 도구입니다. VS Code에서 데이터베이스 작업을 쉽고 편리하게 할 수 있도록 도와주며, SQLite 드라이버와 함께 설치해야 제대로 작동합니다.

4. SQLite 드라이버#

왜 이걸 보게 됐나#

SQLite를 VS Code에서 사용하려면 SQLTools라는 확장팩이 필요한데, 이 확장팩은 SQLite 데이터베이스와 연결하기 위한 드라이버를 필요로 합니다. 강의에서 제시된 환경을 그대로 구축하기 위해, 그리고 SQLite 데이터베이스에 제대로 연결하여 쿼리를 실행할 수 있도록 하기 위해 이 드라이버를 배우게 되었습니다. 이 드라이버 설치가 없으면 데이터베이스 연결 자체가 불가능하기 때문입니다.

내가 헷갈린 지점#

처음에는 SQLite 드라이버가 SQLite 데이터베이스 자체인 줄 알았어요. SQLTools 확장팩을 설치한다고 해서 데이터베이스가 자동으로 생성되는 게 아니라, 데이터베이스에 연결할 수 있게 해주는 별도의 프로그램이라는 점을 이해하는 데 시간이 걸렸습니다. 그냥 이름만 보고는 데이터베이스 파일 자체라고 생각했던 것 같아요.

시도한 코드 / 예시#

# 명령 프롬프트 또는 터미널에서 SQLite 실행
sqlite3 example.db  # 'example.db' 파일 생성

결과와 해석#

SQLTools 확장팩을 사용하려면 SQLite와 통신할 수 있는 드라이버를 설치해야 하는데, VS Code에서 SQLTools 확장 프로그램을 설치한 후, SQLTools 내에서 별도로 ‘SQLite’ 드라이버를 찾아 설치하면 됩니다. 드라이버 설치 후에는 VS Code 내에서 SQLite 데이터베이스 파일(.db)을 열어 쿼리를 실행할 수 있어 데이터베이스 작업이 가능해졌습니다. 드라이버 설치 과정은 꽤 간단하며, 이후 데이터베이스 연결 및 쿼리 실행 시 필수적입니다.

정리된 이해#

SQLite 드라이버는 VS Code의 SQLTools 확장팩이 SQLite 데이터베이스와 연결될 수 있도록 해주는 필수적인 구성 요소입니다. 쉽게 말해, SQLTools가 SQLite 데이터베이스를 인식하고 쿼리를 실행할 수 있도록 연결해주는 다리 역할을 합니다. 이 드라이버가 없으면 SQLTools는 SQLite 데이터베이스와 통신할 수 없습니다.

총평#

오늘 전체에서 배운 것#

오늘 VS Code를 교육용 공통 작업 공간으로 활용하는 방법을 익혔고, 파일 기반의 가벼운 데이터베이스인 SQLite를 사용하고, VS Code에서 SQLite와 연결하여 쿼리를 실행하기 위한 SQLTools 확장팩과 SQLite 드라이버를 설치하는 방법을 배웠습니다. 이제 교육 환경에서 필요한 기본적인 데이터베이스 개발 환경을 구축할 수 있게 되었습니다.

다음에 조심할 것#

VS Code가 강제되는 환경에 대한 불만을 떨쳐내고, 앞으로는 교육용 표준 환경으로 받아들이도록 노력해야겠다. SQLTools 설치 시 SQLite 드라이버를 잊지 않도록 주의하고, 데이터베이스 연결 시 정확한 파일 경로를 확인해야 한다.

다음 복습 주제#

SQLTools 확장팩의 다양한 기능(예: 데이터베이스 관리, 테이블 생성 등)과 SQLite 데이터베이스의 고급 기능들을 더 자세히 알아보고 싶다. 데이터베이스 연결 시 발생할 수 있는 에러 해결 방법도 숙지해야겠다.
