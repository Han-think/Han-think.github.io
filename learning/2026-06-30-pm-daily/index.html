1. R^n 벡터 공간과 벡터 연산: 고객 분석 활용 이해#

무엇을 배웠나#

R^n 벡터 공간이 단순히 숫자 리스트가 아니라, 고객의 다양한 특성을 숫자로 표현하여 분석하는 데 활용될 수 있다는 것을 이해하게 되었어. 벡터 덧셈을 통해 여러 행동 데이터를 통합하고, 스칼라 곱을 통해 데이터의 중요도에 따라 크기를 조절할 수 있다는 것도 알게 되었어. 이제 R^n 공간을 고객 분석에 적용하는 아이디어를 좀 더 구체적으로 떠올릴 수 있을 것 같아.

헷갈렸던 점#

벡터 공간이 단순히 숫자 리스트로 느껴져서 실제 고객 분석에 어떻게 활용되는지 감이 잘 안 잡혔다. 스칼라 곱이 단순히 숫자를 곱하는 것 이상으로 벡터의 방향성과 크기를 조절한다는 설명이 이해하기 어려웠다. 특히, ‘방향성 유지와 규모 확대’라는 표현이 어떤 의미인지 명확히 와닿지 않았다.

정리된 이해#

R^n 벡터 공간은 고객의 다양한 특성을 숫자화하여 표현하고, 이를 통해 고객의 상태를 나타내는 공간이라는 것을 이해하게 되었습니다. 벡터 덧셈은 서로 다른 행동 데이터를 통합하여 더 풍부한 프로필을 만들 수 있고, 스칼라 곱은 벡터의 크기를 조절하여 특정 행동의 중요도를 반영할 수 있다는 것을 알게 되었습니다. 이제 벡터 공간을 통해 고객 데이터를 분석하고 활용하는 방법을 좀 더 명확하게 생각할 수 있을 것 같습니다.

online_behavior = np.array([4, 2])  # 온라인 구매 횟수, 체류 시간
offline_behavior = np.array([1, 4])  # 오프라인 구매 횟수, 방문 횟수
integrated_v = online_behavior + offline_behavior  # 벡터 덧셈

2. 내적, Norm, 코사인 유사도: 방향성과 크기 이해#

무엇을 배웠나#

벡터의 내적은 항상 스칼라 값을 결과로 내놓고, 2차원 직관과는 달리 3차원 이상에서는 벡터의 비율 구조를 고려해야 한다는 것을 깨달았습니다. 또한 벡터의 크기(Norm)를 계산하는 방법과 코사인 유사도를 통해 두 벡터의 방향 유사성을 측정하는 방법을 익혔습니다. 앞으로는 내적 결과를 스칼라 값으로 해석하고, 3차원 벡터의 방향성 이해에 더 주의해야겠습니다.

헷갈렸던 점#

벡터의 기울기가 같다고 해서 방향이 같다는 직관이 3차원 이상에서는 통하지 않음을 인지하지 못했고, 내적의 결과가 벡터인지 스칼라 값인지 혼동했었다. 특히 내적 결과가 스칼라 값이라는 점을 명확하게 이해하지 못해, 그 의미를 제대로 해석하지 못했다.

정리된 이해#

내적은 두 벡터의 각 성분별 곱을 모두 더한 스칼라 값이며, 벡터의 크기(Norm)는 벡터의 길이를 나타낸다. 코사인 유사도는 두 벡터의 절대적인 크기를 고려하지 않고 방향의 유사성을 측정하는 지표이며, 내적과 각 벡터의 크기를 이용하여 계산한다.

import numpy as np

# 벡터 크기 계산 예시
customer_A = np.array([1, 2, 1])
norm_A = np.linalg.norm(customer_A)
print(f"고객 A의 취향 벡터 크기: {norm_A}")

# 코사인 유사도 계산 예시
v1 = np.array([1, 0, 6])
v2 = np.array([0, 1, 6])

dot_product = np.dot(v1, v2)
norm_v1 = np.linalg.norm(v1)
norm_v2 = np.linalg.norm(v2)

cosine_similarity = dot_product / (norm_v1 * norm_v2)
print(f"v1과 v2의 코사인 유사도: {cosine_similarity}")

4. Gauss 소거법과 비즈니스 모델링을 통한 제약 조건 해결#

무엇을 배웠나#

np.linalg.solve 함수를 사용하여 연립방정식을 풀 때, 각 행렬과 벡터가 어떤 의미를 가지는지 명확하게 이해하게 되었습니다. 특히, 제약 조건 모델링은 실제 비즈니스 문제에서 변수, 계수, 상수항을 어떻게 정의하고 활용하는지를 보여주는 실용적인 방법론임을 깨달았습니다. 이 지식을 통해 광고 예산 배분과 같은 문제에 더 효과적으로 접근할 수 있을 것 같습니다.

헷갈렸던 점#

처음에는 제약조건 모델링이 실제 문제 해결에 어떻게 적용되는지 감이 잡히지 않았고, np.linalg.solve 함수가 어떻게 작동하는지, 각 행렬과 벡터의 역할을 명확히 이해하기 어려웠습니다. 특히 변수, 계수, 상수항이 각각 무엇을 의미하는지, 그리고 이들이 비즈니스 문제 해결에 어떻게 연결되는지 파악하는 데 어려움을 겪었습니다.

정리된 이해#

np.linalg.solve(A, b)는 변수들 간의 관계와 제약조건을 행렬과 벡터로 표현하여 최적의 해를 찾아주는 도구입니다. 비즈니스 문제에서는 변수를 조절 가능한 선택사항으로, 계수를 변수의 자원 소비량으로, 상수항을 총 자원으로 해석하여 문제를 해결할 수 있습니다. 이 함수를 사용하면 제약조건을 모두 만족하는 최적의 배분값을 구할 수 있습니다.

import numpy as np

print(x)
