1. PyTorch 생태계와 장치 설정 가이드#

무엇을 배웠나#

PyTorch를 사용하면서 GPU 자동 인식 문제와 다양한 모듈의 역할을 명확히 구분하는 데 어려움을 겪었지만, 각 모듈의 역할과 실행 장치 설정을 이해하게 되었습니다. torch, torch.nn, torch.optim 등의 역할 차이를 정리하고, .to(device) 메서드를 사용하여 모델과 데이터를 GPU로 옮기는 방법을 알게 되었습니다. 이제 PyTorch 생태계를 좀 더 자신 있게 활용할 수 있을 것 같습니다.

헷갈렸던 점#

GPU가 설치되어 있음에도 PyTorch가 자동으로 GPU를 사용하지 않는 이유가 명확하지 않았고, torch, torch.nn, torch.optim 등 PyTorch 관련 모듈들의 역할 차이점을 정확히 이해하지 못했습니다. 데이터와 모델을 GPU로 옮겨야 하는 방법도 헷갈렸습니다.

정리된 이해#

PyTorch 생태계는 텐서 연산, 신경망 모델 정의, 최적화 알고리즘, 가중치 초기화 등 다양한 역할을 분담하여 수행하며, torch는 기본적인 계산 엔진 역할을 합니다. GPU를 사용하려면 PyTorch 설치 상태, 드라이버, CUDA 호환성 등 환경 설정이 중요하고, 모델과 데이터를 GPU로 옮기기 위해 .to(device) 메서드를 활용해야 합니다. 이러한 이해를 바탕으로 PyTorch 환경을 정확히 설정하고 모델을 학습시킬 수 있습니다.

# PyTorch 모듈 임포트

2. FashionMNIST 이미지 전처리 및 정규화 상세 이해#

무엇을 배웠나#

FashionMNIST 이미지 전처리 과정에서 ToTensor()는 픽셀 값을 0~1 사이로 변환하고, Normalize()는 평균과 표준편차를 이용하여 데이터를 재조정하는 것을 알게 되었다. 특히, 이미지 정규화와 Batch Normalization은 서로 다른 역할을 수행하며, 정규화는 데이터 스케일링을 통해 학습 효율을 높이는 역할을 한다는 점을 명확히 이해했다. 이제 FashionMNIST 데이터셋을 전처리할 때 이 지식을 바탕으로 정확한 단계를 적용할 수 있을 것이다.

헷갈렸던 점#

이미지 전처리 과정에서 데이터 스케일링을 224로 나누는 이유를 이해하는 데 어려움이 있었고, 데이터 정규화와 Batch Normalization이 같은 개념인지 착각했습니다. 흑백 이미지의 픽셀 범위가 0~255인데 224라는 숫자가 등장하는 부분이 특히 헷갈렸습니다.

정리된 이해#

ToTensor()는 이미지 픽셀 값을 텐서로 변환하고 0~1 사이로 조정하며, Normalize()는 평균과 표준편차를 이용하여 데이터를 특정 범위로 재조정하는 역할을 합니다. 이미지 전처리는 데이터 스케일링을 통해 모델 학습을 안정화하고 속도를 높이는 데 도움을 주며, Batch Normalization은 신경망 레이어 뒤에 위치하여 각 배치에 대한 평균과 표준편차를 사용하여 데이터 분포를 정규화하는 방식입니다. 따라서, 전처리 단계에서 이미지 데이터의 스케일링을 진행하고, Batch Normalization은 신경망 내부에서 학습되는 파라미터를 통해 데이터를 정규화하는 것이 핵심입니다.

import torchvision.transforms as transforms
from torchvision import datasets

# 데이터 로더 설정
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,))
])

# FashionMNIST 데이터셋 로드
train_dataset = datasets.FashionMNIST(root='./data', train=True, download=True, transform=transform)

3. FashionMNIST를 활용한 미니배치 학습과 데이터 로더 이해#

무엇을 배웠나#

미니배치 학습은 전체 데이터셋을 작은 묶음으로 나누어 순차적으로 학습하는 방식이며, 세탁기 비유로 이해하는 것이 도움이 되었다. Dataset은 데이터와 접근 규칙을, DataLoader는 배치 구성, 셔플링, 반복 공급을 관리한다는 것을 명확히 알게 되었다. 이제 FashionMNIST 데이터를 활용한 딥러닝 모델 학습을 위한 기반을 다질 수 있을 것 같다.

헷갈렸던 점#

처음에는 미니배치 학습이 데이터 일부만 선택해서 학습하는 줄 알았고, Dataset과 DataLoader의 역할이 명확히 구분되지 않았습니다. 데이터가 어떻게 처리되고 접근되는지에 대한 혼동이 있었던 거죠. 전체 데이터셋을 작은 묶음으로 나누어 순차적으로 학습한다는 개념과 Dataset이 데이터 자체를 관리하고, DataLoader가 배치를 묶고 관리한다는 점을 제대로 이해하지 못했습니다.

정리된 이해#

전체 데이터셋을 작은 묶음인 미니배치로 나누어 순차적으로 학습하는 방식이며, 각 미니배치는 지정된 크기(batch_size)를 가집니다. Dataset은 데이터와 접근 규칙을 정의하고, DataLoader는 이 데이터를 배치 크기에 맞게 묶어 셔플링하고 반복적으로 모델에 공급하는 역할을 합니다. 이 둘을 잘 이해하면 효율적인 딥러닝 모델 학습이 가능합니다.

train_dataset = torchvision.datasets.FashionMNIST(
    root='./data',
    train=True,
    download=True,
    transform=transform
)

test_dataset = torchvision.datasets.FashionMNIST(
    root='./data',
    train=False,
    download=True,
    transform=transform

4. 데이터 시각화와 신경망 구조 이해: 초보자 워킹 노트#

무엇을 배웠나#

데이터 시각화의 중요성을 깨닫고, DataLoader에서 데이터를 가져와서 이미지와 라벨을 직접 확인하는 과정을 통해 데이터의 형태와 일관성을 점검하는 것이 필수적임을 알게 되었다. squeeze() 함수의 사용법에 대한 이해가 부족했던 점을 인지하고, NN-SVG를 활용하여 신경망 구조를 시각적으로 검토하는 것의 필요성을 배웠다. CNN과 MLP의 기본적인 작동 방식에 대한 이해를 바탕으로, 실제 데이터와 모델 구조를 연결하는 과정을 학습했다.

헷갈렸던 점#

데이터 시각화가 학습 과정의 필수적인 부분이라는 것을 제대로 이해하지 못했고, squeeze() 함수를 사용할 때 배치 차원 제거가 잘못될 수 있다는 점이 헷갈렸습니다. 또한 NN-SVG를 단순히 신경망 구조를 보여주는 도구로만 생각하고, 코드 구조를 분석하고 검토하는 데 활용하는 데에는 미흡했습니다.

정리된 이해#

데이터 시각화는 모델 학습 전에 데이터의 형태와 일관성을 확인하는 필수적인 과정이며, squeeze() 함수는 불필요한 차원을 제거하는 데 사용되지만 잘못 사용하면 데이터를 손상시킬 수 있습니다. NN-SVG는 단순히 신경망 구조를 보여주는 도구가 아니라, 코드의 구조를 파악하고 개선점을 찾는 데 중요한 역할을 한다는 것을 알게 되었습니다. 이제는 데이터 점검 순서와 CNN, MLP의 기본적인 구조를 이해하고 이미지 데이터를 신경망에 적용하는 과정을 좀 더 명확하게 수행할 수 있을 것 같습니다.
