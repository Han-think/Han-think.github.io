1. 옵티마이저와 기울기 흐름: 기본 개념 및 주요 비교#

무엇을 배웠나#

옵티마이저와 손실 함수의 역할을 명확히 구분하고, 주요 옵티마이저들의 특징을 비교하며 이해하게 되었다. Adam 옵티마이저가 항상 최선은 아니라는 점을 깨닫고, 문제와 모델 구조에 따라 다른 옵티마이저를 선택해야 함을 알게 되었다. PyTorch 코드를 통해 옵티마이저 적용 과정을 간략하게나마 경험해 볼 수 있었다.

헷갈렸던 점#

가중치 변화가 실제 코드로 어떻게 구현되는지 감이 잘 안 잡혔고, Adam 옵티마이저가 만능이라고 생각했지만 상황에 따라 다른 옵티마이저가 더 좋을 수 있다는 점이 헷갈렸다. 손실 함수와 옵티마이저의 역할이 명확하게 구분되지 않아 학습 과정 전체를 이해하는 데 어려움을 겪었다.

정리된 이해#

손실 함수는 예측과 실제 값의 오차를 측정하고, 옵티마이저는 이 오차를 줄이기 위해 가중치를 어떻게 조정할지 결정하는 역할을 한다는 것을 명확히 이해하게 되었다. Adam 옵티마이저가 항상 최고는 아니며, 문제와 모델 구조에 따라 SGD 계열 옵티마이저가 더 적합할 수 있다는 점도 알게 되었다. 이제는 다양한 옵티마이저의 특징을 비교하고 상황에 맞는 최적의 옵티마이저를 선택할 수 있을 것 같다.

import torch
import torch.nn as nn
import torch.optim as optim

# 모델 정의
model = nn.Linear(10, 1)  # 예시 모델
criterion = nn.MSELoss()  # 손실 함수

# 데이터 생성 (예시)
inputs = torch.randn(5, 10)  # 입력 데이터
targets = torch.randn(5, 1)

2. 활성화 함수, 초기화, 기울기 소실 완벽 이해하기#

무엇을 배웠나#

시그모이드 함수의 기울기 소실 문제를 제대로 이해하게 되었고, 입력 값에 따라 기울기가 변한다는 것을 알게 되었다. 또한 활성화 함수와 가중치 초기화 방법의 역할을 명확히 구분하게 되었으며, ReLU의 Dying ReLU 문제와 시그모이드의 기울기 소실 문제를 해결하기 위한 가중치 초기화 방법(Xavier, He)의 필요성을 깨달았다. 이제 이러한 지식을 바탕으로 신경망 학습 시 더 효과적인 설정을 할 수 있을 것 같다.

헷갈렸던 점#

Sigmoid 함수의 기울기가 항상 0이라고 생각했고, 다양한 활성화 함수와 초기화 방법들이 비슷하게 작동한다고 생각했습니다. 특히 ReLU와 Xavier, He 초기화의 차이점을 명확하게 이해하지 못하고 있었습니다.

정리된 이해#

활성화 함수, 특히 Sigmoid는 입력 값에 따라 기울기가 변하고, 극단적인 입력 값에서는 기울기가 작아져 기울기 소실을 일으킬 수 있다는 것을 알게 되었습니다. 또한, 활성화 함수 종류에 따라 적절한 가중치 초기화 방법(Xavier, He)을 선택해야 역전파 과정에서 발생하는 문제를 완화할 수 있다는 것을 이해했습니다. 이제는 활성화 함수와 가중치 초기화의 역할을 명확히 구분하여 신경망 학습에 적용할 수 있을 것 같습니다.

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-5, 5, 100)
y_sigmoid = 1 / (1 + np.exp(-x))
plt.plot(x, y_sigmoid, label='Sigmoid')
plt.title('Sigmoid Function')

3. 과적합 방지 및 값 정규화 기법: 정규화 vs. 정규화#

무엇을 배웠나#

과적합 방지를 위한 정규화 기법(Regularization)과 값의 분포를 안정화시키는 정규화 기법(Normalization)을 명확히 구분하는 방법을 알게 되었습니다. 특히 Batch Normalization은 학습 안정화와 속도 향상을 위한 도구이며, 정규화 기법들을 완전히 대체하지는 않는다는 것을 깨달았습니다. L2 정규화 예시 코드를 통해 실제 구현 방식도 이해하게 되었습니다.

헷갈렸던 점#

정규화(Regularization)와 값의 분포를 안정화하는 정규화(Normalization)를 명확히 구분하지 못했고, Batch Normalization이 과적합 방지를 위한 핵심 기법이라고 잘못 생각했습니다. 또한, 정규화 기법들이 서로 완전히 대체 가능한 관계라고 생각했습니다.

정리된 이해#

정규화는 과적합 방지를 위한 기법(Regularization)과 학습 안정화 및 속도 향상을 위한 기법(Normalization)으로 나뉘어, 용어는 같지만 목적과 방식이 다릅니다. Batch Normalization은 학습 과정에서 활성화 값의 분포를 안정화시키는 역할을 하며, 과적합 방지를 위한 핵심 기법이라기보다는 부가적인 효과를 제공합니다. L1, L2 정규화, Dropout과 같은 기법들은 모델 자체의 복잡도를 줄이는 데 초점을 맞추는 반면, Batch Normalization은 신경망 내부의 데이터 분포를 조정합니다.

import torch.nn as nn

model = nn.Sequential(
    nn.Linear(10, 50),
    nn.ReLU(),
    nn.Linear(50, 1),

4. 실험과 프로젝트 적용을 위한 초보 가이드#

무엇을 배웠나#

머신러닝과 딥러닝에서는 모델 이름을 암기하는 것보다 다양한 시도를 통해 문제 해결 능력을 키우는 것이 중요하다는 것을 깨달았습니다. 특히 프로젝트를 진행할 때, 데이터 유형에 따른 전처리 방식과 배치 크기 설정 등 기본적인 과정을 명확히 이해하고 적용하는 것이 필요합니다. 앞으로는 제시된 실험 절차를 바탕으로 프로젝트에 적용하며 실력 향상을 위해 노력해야겠습니다.

헷갈렸던 점#

프로젝트를 시작할 때 막연하게 모델 구조나 알고리즘을 이해하는 것만으로 결과가 나올 거라고 생각했는데, 실제로는 데이터 전처리부터 하이퍼파라미터 튜닝까지 다양한 실험이 필요하다는 것을 깨달았습니다. 특히 데이터 유형에 따른 전처리 방법이 다양해서, 어떤 방법을 선택해야 할지 처음에는 감이 잘 안 잡혔습니다.

정리된 이해#

머신러닝 프로젝트를 시작할 때, 모델 이름이나 이론을 암기하는 것보다 다양한 가설을 세우고 실험하며 결과를 분석하는 능력이 더 중요하다는 것을 깨달았다. 데이터 유형에 따라 적절한 전처리 방식을 적용하고, 배치 크기, 손실 함수, 옵티마이저 등을 설정하는 과정을 체계적으로 따라가는 것이 프로젝트 성공의 핵심이다.

이 노트에는 코드 예시가 포함되어 있지 않습니다. 따라서 코드를 출력할 수 없습니다.

5. PyTorch 학습 파이프라인 핵심 구성 요소#

무엇을 배웠나#

PyTorch 학습 파이프라인의 핵심 구성 요소인 Dataset, DataLoader, torch.nn 모듈, 손실 함수, 그리고 모델 학습 과정을 이해하게 되었어요. 특히 데이터 처리 라이브러리들을 이미지, 음성, 추천 시스템으로 구분하여 사용하는 방법을 알게 되었습니다. Tensor의 기본 속성(shape, dtype, device)도 간단하게나마 숙지했습니다.

헷갈렸던 점#

처음에는 Dataset과 DataLoader의 역할을 명확히 구분하지 못해서 Dataset이 단순히 데이터를 저장하는 역할만 한다고 생각했다. 또한, 손실 함수의 종류와 그 선택 기준을 제대로 이해하지 못해서, 어떤 손실 함수를 사용해야 하는지 막연하게 느껴졌다. PyTorch Tensor의 device 속성을 간과하고 CPU에서만 작업하다가 GPU 사용의 중요성을 뒤늦게 알게 되었다.

정리된 이해#

PyTorch 학습 파이프라인은 Dataset으로 데이터를 준비하고, DataLoader로 미니 배치 단위로 로딩하며, torch.nn으로 신경망 레이어를 층층이 쌓아 모델을 구축하는 과정을 포함합니다. 모델은 손실 함수를 통해 예측 값과 실제 값의 차이를 최소화하도록 학습되고, 이 과정에서 역전파와 Optimizer를 활용하여 모델 가중치를 업데이트합니다. 또한 이미지, 음성, 텍스트 데이터 처리를 위한 별도 라이브러리들이 존재하여 각 데이터 유형에 맞춰 학습 파이프라인을 구성할 수 있습니다.

# 예시: 간단한 데이터 로딩 및 확인
import torch
from torch.utils.data import Dataset, DataLoader

class MyDataset(Dataset):
    def __init__(self, data, labels):
        self.data = torch.tensor(data)
        self.labels = torch.tensor(labels)

    def __len__(self):
        return len(self.data)

    def __getitem__(self, idx):
        return self.data[idx], self.labels[idx]

data = [[1, 2], [3, 1]]
labels = [0, 2]
my_dataset = MyDataset(data, labels)
dataloader = DataLoader(my_dataset, batch_size=1)

for batch_idx, (data, label) in enumerate(dataloader):
    print(f"Batch {batch_idx}:")
    print(f"  Data shape: {data.shape}")
    print(f"  Label: {label}")

6. MNIST 실습으로 배우는 MLP, Softmax, CNN 이해#

무엇을 배웠나#

MNIST 데이터셋을 이용한 MLP 실습 과정에서 흔히 발생하는 코드 오류들을 겪으며, 데이터 전처리, 레이어 구성, 활성화 함수, 손실 함수 등의 개념을 정리했습니다. 특히 오류 메시지를 통해 구체적인 문제점을 파악하고 해결하는 경험을 통해 딥러닝 코드 디버깅 능력을 향상시켰으며, MLP와 CNN의 구조적 차이와 각 모델이 적합한 상황을 이해하게 되었습니다. 또한, 흔히 발생하는 오류에 대한 키워드 및 검색어를 기록하여 앞으로 유사한 문제 발생 시 빠르게 해결할 수 있도록 했습니다.

헷갈렸던 점#

처음에는 딥러닝 코드를 실행하면서 오류의 원인을 딥러닝 개념 문제인지 문법 오류인지 구분하기 어려웠습니다. 특히, 오류 메시지가 직관적이지 않아 디버깅 과정이 꽤 힘들었습니다. 라이브러리 누락이나 오타로 인해 발생하는 오류도 예상치 못하게 발생해서 주의가 필요했습니다.

정리된 이해#

MNIST 이미지 데이터를 활용한 MLP 실습 과정에서 데이터 정규화, 레이어 구성(Flatten, 은닉층, Softmax 출력), 손실 함수 선택 등의 기본 사항을 익혔습니다. 특히 딥러닝 코드 오류 발생 시, 문법 오류인지 개념 오류인지 구분하고, AttributeError, TypeError, NameError 등의 오류 메시지를 통해 문제 해결 방법을 학습했습니다. MLP는 단순 데이터에 적합하지만, CNN은 복잡한 이미지와 특징 추출에 더 효과적이라는 것을 알게 되었습니다.
