배열 순회와 조건문의 핵심: 시작·종료·증감 조립하기 학습 정리

1. 반복문#

왜 이걸 보게 됐나#

나는 데이터 처리 과정에서 단순히 값을 나열하는 것을 넘어, 배열의 구조를 정확히 파악하고 제어해야 할 필요성을 느꼈다. 특히 ‘순서’가 정렬된 것인지 원래 위치인지 구별하지 못해 혼란을 겪으며, 반복문이 단순한 출력이 아니라 인덱스를 조작해 배열을 탐색하는 도구임을 깨닫게 되었다. 따라서 length - 1과 같은 공식이 왜 필요한지 이해하고, 시작점과 종료 조건, 증감 방향을 직접 설정하여 원하는 대로 데이터를 처리할 수 있는 능력을 기르고자 한다.

내가 헷갈린 지점#

처음에는 ‘순서’가 데이터의 크기 순인지 배열에 저장된 원래 위치 순인지 구별하지 못해 혼란스러웠습니다. 특히 역순 문제를 마주했을 때 length - 1 공식이 왜 필요한지 바로 머릿속에 그려지지 않아 답답함을 느꼈습니다. 반복문의 종료 조건에 대한 감이 없어 “왜 굳이 length에서 1을 빼야 하지?“라는 의문이 들었습니다.

시도한 코드 / 예시#

// 정방향 순회 (0부터 시작하여 length 미만까지)
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]);
}

// 역순 순회 (length - 1부터 0까지 감소)
for (let i = arr.length - 1; i >= 0; i--) {
  console.log(arr[i]);
}

결과와 해석#

반복문은 배열의 각 요소에 접근하기 위해 시작점, 종료 조건, 증감 방향을 조립하는 도구입니다. 정방향 순회는 0부터 length 미만까지 1씩 증가시키며 진행하고, 역순 순회는 length에서 1을 뺀 값부터 0 이상까지 1씩 감소시킵니다. 이 구조를 이해하면 배열의 앞뒤로 자유롭게 접근하여 데이터를 처리할 수 있습니다.

정리된 이해#

반복문은 배열을 순회하는 도구이며, 시작 위치와 종료 조건, 증감 방향을 직접 조립해야 한다. for문은 저장된 순서를 읽고, sort는 값의 위치를 재배치하는 서로 다른 개념으로 구분해야 한다. 핵심은 ‘시작점, 끝나는 기준, 방향’ 세 가지 뼈대를 스스로 구성할 수 있는 능력에 있다.

2. 조건문#

왜 이걸 보게 됐나#

처음에는 ‘순서’가 데이터의 크기 순인지 배열의 위치 순인지 구별하지 못해 혼란스러웠습니다. 특히 역순 문제를 마주했을 때 length - 1 공식이 왜 필요한지 바로 머릿속에 그려지지 않아 답답함을 느꼈습니다.

반복문과 정렬이라는 두 개념을 확실히 분리해서 생각하게 된 계기가 되었습니다. 반복문은 배열의 저장 순서를 읽어오는 도구이며, 시작 위치와 종료 조건, 증감 방향을 직접 조립해야 한다는 점이 핵심입니다.

내가 헷갈린 지점#

처음에는 ‘순서’라는 단어가 배열에 저장된 위치 순서를 뜻하는지, 데이터 크기 순으로 정렬된 것인지 구분하지 못해 혼란스러웠습니다. 특히 역순 문제에서 length - 1 공식이 왜 필요한지 바로 머릿속에 그려지지 않아 반복문 종료 조건에 대한 감이 없었습니다. 결국 반복문의 ‘시작 위치, 종료 조건, 증감 방향’이라는 세 가지 뼈대를 직접 세워야 한다는 점을 깨닫고 나니 정방향과 역방향을 명확히 구별할 수 있게 되었습니다.

시도한 코드 / 예시#

// 정방향 순회 (0부터 시작, 길이 미만일 동안)
// i = 0, arr[0] = '사과'
// i = 1, arr[1] = '바나나'
// i = 2, arr[2] = '체리'
const fruits = ['사과', '바나나', '체리'];
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

// 역순 순회 (length - 1부터 시작, 0 이상일 동안)
// i = 2, arr[2] = '체리'
// i = 1, arr[1] = '바나나'
// i = 0, arr[0] = '사과'
for (let i = fruits.length - 1; i >= 0; i--) {
  console.log(fruits[i]);
}

// 조건부 출력 (짝수만 출력)
// i = 0, arr[0] = '사과' (출력)
// i = 1, arr[1] = '바나나' (건너뜀)
// i = 2, arr[2] = '체리' (출력)
for (let i = 0; i < fruits.length; i++) {
  if (i % 2 === 0) {
    console.log(fruits[i]);
  }
}

결과와 해석#

반복문의 종료 조건은 배열의 마지막 인덱스(length - 1)를 기준으로 설정해야 합니다. 이는 배열의 인덱스가 0부터 시작하기 때문에, 실제 마지막 요소의 번호가 길이에서 1을 뺀 값과 같기 때문입니다. 이 공식 없이 반복문을 작성하면 정의되지 않은 인덱스에 접근하여 오류가 발생하거나 의도치 않은 결과가 나올 수 있습니다.

정리된 이해#

반복문은 배열의 저장 순서를 읽는 도구이며, 시작 위치와 종료 조건, 증감 방향을 직접 조립해야 한다. sort는 값의 위치를 재배치하는 별도 개념이므로 반복문과 혼동해서는 안 된다. 핵심은 ‘시작점, 끝나는 기준, 방향’ 세 가지만 정확히 설정하면 된다는 점이다.

3. for문#

왜 이걸 보게 됐나#

처음에는 ‘순서’가 데이터의 크기 순인지 배열의 위치 순인지 구별하지 못해 혼란스러웠습니다. 특히 역순 문제를 마주했을 때 length - 1 공식이 왜 필요한지 바로 머릿속에 그려지지 않아 답답함을 느꼈습니다. 반복문의 종료 조건에 대한 감이 없어 공식의 의미를 바로 파악할 수 없었기 때문입니다.

내가 헷갈린 지점#

처음에는 ‘순서’가 데이터의 크기 순으로 정렬된 것인지, 배열에 저장된 원래 위치 순서인지 구별하지 못해 혼란이 컸습니다. 특히 역순 문제를 마주했을 때 length - 1 공식이 왜 필요한지 바로 머릿속에 그려지지 않아 답답함을 느꼈습니다. 반복문의 종료 조건에 대한 감이 없어 “왜 굳이 length에서 1을 빼야 하지?“라는 의문이 들었던 것이 가장 큰 어려움이었습니다.

시도한 코드 / 예시#

// 정방향 순회 (0부터 시작, length 미만까지)
// 예시: arr = [10, 20, 30]
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]); // 출력 결과: 10, 20, 30
}

// 역순 순회 (length - 1부터 시작, 0 이상까지)
// 예시: arr = [10, 20, 30]
for (let i = arr.length - 1; i >= 0; i--) {
  console.log(arr[i]); // 출력 결과: 30, 20, 10
}

// 조건부 출력
// 예시: arr = [1, 2, 3, 4, 5], 조건: 짝수만
for (let i = 0; i < arr.length; i++) {
  if (arr[i] % 2 === 0) {
    console.log(arr[i]); // 출력 결과: 2, 4
  }
}

결과와 해석#

for문은 배열의 저장 순서를 읽어오는 반복 구조입니다. 시작점을 0으로 설정하고, 종료 조건을 length 미만이 될 때까지 반복하도록 작성합니다. 증감 연산자(++)를 사용하여 다음 인덱스로 이동하며 데이터를 처리합니다.

정리된 이해#

for문은 배열의 저장 순서를 읽어오는 도구로, 시작 위치와 종료 조건, 증감 방향을 직접 조립해야 한다. 정방향은 0부터 length까지, 역순은 length-1부터 0까지 내려가는 식으로 반복 횟수와 방향을 설정하는 것이 핵심이다. 단순히 코드를 외우는 것보다 이 세 가지 뼈대를 스스로 세울 수 있어야 실제 문제에서 유연하게 대처할 수 있다.

4. while문#

왜 이걸 보게 됐나#

while문을 배우게 된 것은, 배열을 거꾸로 읽거나 특정 조건이 만족될 때까지 반복해야 할 때 for문의 고정된 시작점과 종료 조건이 제약이 되어서입니다. i++ 대신 직접 카운트를 조절하거나, 데이터의 끝나는 시점을 정확히 모를 때 무한 루프를 방지하기 위해 반복 횟수를 스스로 관리할 수 있기 때문입니다.

내가 헷갈린 지점#

while문은 ‘조건이 참일 동안 계속 실행된다’는 점이 가장 핵심적이었습니다. 처음에는 무한 루프에 빠질까 봐 종료 조건을 설정하는 것이 막연하게 느껴졌습니다. 특히 i--와 같은 감소식이나 특정 지점에서 멈추는 break문의 작동 원리를 이해하는 데 시간이 걸렸습니다. 결국 반복 횟수가 정해져 있지 않아도 논리적으로 ‘그만둬야 할 시점’을 정확히 짚어내는 것이 while문의 핵심이라고 느꼈습니다.

시도한 코드 / 예시#

// while문: 조건이 참인 동안 반복 실행
let i = 0;
while (i < arr.length) {
  console.log(arr[i]); // 예시 출력: arr[0] = '사과'
  i++;
}

결과와 해석#

while문은 조건이 참일 동안 반복해서 실행되는 제어문입니다. for문과 달리 초기값 설정, 종료 조건, 증감이 모두 코드 안에 명시되지 않고 자유롭게 구성할 수 있다는 점이 가장 큰 차이점입니다. 주로 배열의 특정 요소를 검색하거나 무한 루프가 필요한 상황에서 유용하게 사용됩니다.

정리된 이해#

while문은 반복 횟수가 불확실하거나 특정 조건이 충족될 때까지 실행해야 할 때 사용합니다. 무한 루프를 방지하기 위해 반드시 반복을 멈추는 조건(break 또는 while문의 종료 조건)을 설정해야 합니다. 변수 값을 변경하며 점진적으로 목표 상태에 도달하도록 제어하는 것이 핵심입니다.

총평#

오늘 전체에서 배운 것#

반복문의 시작점, 종료 조건, 증감 방향 세 가지를 조립하여 배열을 제어하는 것이 핵심입니다. 특히 역순 순회는 length - 1부터 0까지 감소하며 내려가는 패턴을 정확히 이해해야 합니다.

다음에 조심할 것#

반복문의 시작점, 종료 조건, 증감 방향을 외우는 것이 아니라 직접 조립하는 연습을 해야 합니다.

특히 length - 1 공식은 역순 순회 시 배열의 마지막 인덱스를 정확히 가리키기 위한 필수 계산임을 기억해야 합니다.

다음 복습 주제#

반복문의 종료 조건(i < arr.length vs i >= 0)을 외우는 것보다, 배열의 인덱스가 0부터 시작한다는 전제 하에 ‘마지막 요소의 번호’가 length - 1이라는 관계를 직접 계산하는 연습을 해야 합니다.

특히 for...of문은 인덱스 값을 자동으로 제공하지 않으므로, 특정 위치의 요소를 제어하거나 역순으로 출력해야 할 때는 전통적인 for문을 사용하는 습관을 들여야 합니다.
