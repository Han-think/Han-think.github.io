1. 결측치 처리 전략: 초보자를 위한 완벽 가이드#

무엇을 배웠나#

결측치 처리 전략을 처음에는 단순히 삭제하는 것만 생각했지만, 데이터의 특성과 결측치 비율에 따라 다양한 방법이 필요하다는 점을 알게 되었다. drop()과 dropna() 함수의 차이와 inplace=True 옵션의 원본 데이터 변경 방식에 대한 이해도 높였다. 이제 결측치 처리 시 상황에 맞는 전략을 선택하여 데이터 분석의 정확도를 높일 수 있을 것 같다.

헷갈렸던 점#

결측치를 그냥 dropna()로 간단히 지우면 된다고 생각했는데, 데이터 손실이 커서 좋지 않은 방법일 수 있다는 점이 처음에는 이해가 안 됐어. drop()과 dropna() 함수의 차이도 헷갈렸고, 특히 inplace=True 옵션이 원본 데이터를 어떻게 수정하는지 명확히 알지 못해서 주의해야 할 점이 많다고 느껴졌어.

정리된 이해#

결측치 처리할 때 무조건 삭제하는 게 정답은 아니고, 데이터 특성과 결측치 비율에 따라 삭제, 대체 등 다양한 전략을 선택해야 해. drop() 함수는 특정 행/열을 삭제하고, dropna()는 결측치가 있는 행/열을 삭제하며, fillna()는 결측치를 특정 값으로 채우는 역할을 한다는 것을 명확히 이해해야겠어. 특히 inplace=True 옵션 사용 시 원본 데이터 변경 여부를 항상 고려해야겠다.

2. 중앙값 대체와 시각화를 통한 데이터 이해#

무엇을 배웠나#

평균과 중앙값의 차이와 중앙값으로 결측치를 대체했을 때 히스토그램 변화의 의미를 명확히 이해하게 되었어. 중앙값 대체 후 데이터 분포가 왜곡될 수 있다는 점을 인지하고, 데이터프레임 간 중앙값 차이가 데이터 처리 과정의 영향임을 알게 되었어. 이제 결측치 대체 시 중앙값 사용의 장단점을 고려하고, 데이터 처리 과정을 꼼꼼히 확인해야겠다는 생각이 들어.

헷갈렸던 점#

평균과 중앙값을 헷갈려서 중앙값이 평균처럼 전체 데이터의 특징을 나타낸다고 생각했고, 결측치를 중앙값으로 대체한 후 그래프가 왜 바뀌는지 이해가 안 갔어요. 또, 동일한 데이터에 대해 다른 데이터프레임에서 중앙값을 계산했는데 결과가 달라서 당황스러웠습니다.

정리된 이해#

평균과 달리 중앙값은 데이터의 중간값을 나타내므로 이상치에 덜 민감하며, 결측치를 중앙값으로 대체하면 히스토그램에서 중앙값 주변 빈도가 증가하는 것은 자연스러운 현상이다. 데이터프레임 간 중앙값 차이는 데이터 전처리 과정에서의 데이터셋 변화로 인해 발생할 수 있다. 이러한 점들을 이해하고 데이터 분석에 활용하면 더 정확하고 신뢰성 있는 결과를 얻을 수 있을 것이다.

3. 이상치 처리: IQR, Boxplot, Winsorizing 이해#

무엇을 배웠나#

이상치 처리 과정에서 outliers DataFrame이 필터링된 결과가 아니라 후보군을 모아놓은 것이라는 점을 명확히 알게 되었다. 또한, 논리 연산자 |와 &의 사용법을 혼동했던 부분을 해결하고, Boxplot에서 동그라미 표시가 IQR 기준을 벗어난 이상치 후보를 나타냄을 이해했다. 마지막으로, Winsorizing이 이상치를 삭제하는 대신 값을 조정하는 기법이라는 것을 깨달았다.

헷갈렸던 점#

처음에는 outliers DataFrame이 이상치가 완전히 삭제된 결과인 줄 알았는데, 필터링된 후보군이라는 것을 이해하는 데 시간이 걸렸다. 논리 연산자 |와 &의 사용법을 헷갈려서 조건문 작성에 어려움을 겪었고, Boxplot에서 동그라미 표시의 의미를 단순한 장식으로 여겨 정확한 해석을 놓쳤었다. Winsorizing을 이상치 삭제 방식으로 착각하여 데이터 보존의 개념을 제대로 이해하지 못했다.

정리된 이해#

IQR 기반 이상치 탐지는 데이터의 1사분위수(Q1)와 3사분위수(Q3)를 이용하여 이상치 후보를 찾는 방법인데, outliers DataFrame은 단순히 이상치 후보를 모아 놓은 결과물이다. 논리 연산자 |는 “또는"의 의미로, 정상 범위를 판단할 때 & (AND)와 함께 사용하는 것을 기억해야 하며, Boxplot에서 동그라미는 IQR 범위를 벗어난 이상치 후보를 의미한다. Winsorizing은 이상치를 삭제하는 것이 아니라, 값을 특정 경계값으로 조정하여 데이터의 가치를 보존하는 기법이다.

# 예시: IQR 기반 이상치 탐지
# Q1, Q3, IQR 계산 (실제 코드에서는 데이터에 따라 달라짐)
Q1 = data['column'].quantile(0.25)
Q3 = data['column'].quantile(0.75)
IQR = Q3 - Q1

lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

# 이상치 후보 필터링
outliers = data[(data['column'] < lower_bound) | (data['column'] > upper_bound)]

헷갈렸던 점#

정리된 이해#

헷갈렸던 점#

데이터 분석만으로 좋은 결과를 얻을 수 있다고 생각했지만, 분석 결과를 실제 문제 해결로 연결하는 액션 플랜이 훨씬 중요하다는 것을 몰랐습니다. 데이터 탐색, 전처리, 모델링 과정은 비슷하게 느껴져서, 분석 이후 해석과 실행 가능한 액션 플랜을 어떻게 구성해야 할지 막막했습니다.
