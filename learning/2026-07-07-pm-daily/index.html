2. 샘플링 기법 비교: 데이터 불균형 문제 해결 가이드#

무엇을 배웠나#

언더샘플링과 오버샘플링 기법을 선택할 때 정답은 없으며 데이터의 특성, 모델 종류, 평가 지표, 비즈니스 목표를 종합적으로 고려해야 한다는 것을 알게 되었습니다. 특히 CNN은 데이터 효율성이 중요하므로, 데이터 양이 적더라도 핵심 데이터 포인트만 활용하면 효과적인 분류가 가능할 수 있다는 점을 이해했습니다. ‘저녁은?’ 프로젝트에서 다양한 샘플링 기법을 직접 시도해보면서, 데이터 불균형 문제 해결에 도움을 받을 수 있을 것으로 기대됩니다.

헷갈렸던 점#

언더샘플링과 오버샘플링을 적용하면 항상 모델 성능이 좋아질 거라고 생각했지만, 데이터 특성, 모델 종류, 평가 지표에 따라 결과가 달라질 수 있다는 점이 처음에는 이해가 안 갔어요. 특히 CNN에서 데이터 양이 적은 상태에서도 F1 점수가 높게 나오는 경우 직관과 맞지 않아 혼란스러웠고, 어떤 샘플링 기법이 항상 최선인지 판단하기 어려웠어요. 데이터 크기가 많다고 무조건 좋은 것도 아니고, 어떤 샘플링 기법이 항상 정답인 것도 아니라는 점을 깨달았습니다.

정리된 이해#

샘플링 기법은 데이터의 특성, 모델 종류, 평가 지표, 그리고 비즈니스 목표에 따라 달라지기 때문에 절대적인 정답이 없다. CNN 모델은 데이터 효율성이 중요한 경우가 많아 적은 데이터로도 효과적인 분류가 가능할 수 있으며, 다양한 샘플링 방법을 시도하며 데이터와 모델에 가장 적합한 방법을 찾아야 한다.

3. 데이터 전처리 파이프라인: 결측치 처리와 스케일링 이해#

무엇을 배웠나#

결측치 처리와 데이터 스케일링을 위한 SimpleImputer와 StandardScaler의 역할과 사용법을 명확히 이해하게 되었다. fit, transform, fit_transform의 의미를 구분하고, 훈련 데이터에서 기준을 학습한 후 테스트 데이터에 적용하는 중요성을 깨달았다. 파이프라인 중심 전처리를 위한 기초적인 이해가 조금 더 깊어졌다고 생각한다.

헷갈렸던 점#

결측치 처리 순서가 전체 데이터에서 먼저 해도 되는지, 그리고 Imputer와 Scaler의 역할이 구체적으로 어떻게 다른지 감이 잘 안 잡혔다. fit, transform, fit_transform의 차이점도 혼동되어 어떤 단계를 언제 적용해야 할지 헷갈렸다.

정리된 이해#

결측치 처리와 스케일링 과정에서 Imputer는 결측치를 채울 기준을, Scaler는 데이터의 스케일을 학습하고, 이 기준을 fit과 transform 메서드를 사용하여 훈련 및 테스트 데이터에 적용한다. fit은 학습, transform은 적용을 의미하며, fit_transform은 이 둘을 결합한 것이다. 데이터 누수 문제를 방지하기 위해 훈련 데이터로 학습한 기준은 테스트 데이터에 그대로 적용해야 한다.

5. 지니 불순도, 엔트로피, 의사결정나무 특성 중요도 이해#

무엇을 배웠나#

지니 엔트로피와 엔트로피를 이용한 불순도 계산이 의사결정나무에서 데이터를 분할할 최적의 기준점을 찾는 데 사용된다는 것을 알게 되었다. 또한 특성 중요도는 단순히 트리에서 사용 빈도가 높은 특성을 의미하는 것이 아니라, 실제 데이터 분할에 얼마나 기여했는지 종합적으로 평가하는 지표라는 점을 명확히 이해하게 되었다. 이 과정을 통해 의사결정나무의 핵심 원리를 더 깊이 있게 파악할 수 있었다.

헷갈렸던 점#

지니 엔트로피와 불순도 계산 과정을 거친 후, 그 결과가 실제 의사결정나무의 분할 조건 결정에 어떻게 연결되는지 감이 잘 안 잡혔어. 노드들이 데이터 분할에 어떤 역할을 하는지 혼동했고, 특성 중요도가 단순히 트리에서 많이 나온 특성인지, 아니면 성능에 얼마나 기여하는지 정확히 이해하지 못했어.

정리된 이해#

의사결정나무에서 지니 불순물과 엔트로피는 데이터의 순도를 평가하는 지표이며, 분할 전후의 불순도 감소량을 통해 최적의 분할 기준을 찾습니다. 특성 중요도는 단순히 특성이 많이 사용된 횟수가 아니라, 데이터 분할에 얼마나 기여했는지, 그리고 영향을 받은 데이터의 비율을 고려하여 계산됩니다. 이를 통해 트리 학습 시 어떤 특성이 중요한지 파악할 수 있습니다.

# 예시: 파이썬으로 지니 불순도 계산 함수
def gini_impurity(labels):
    """
    주어진 레이블 목록에 대한 지니 불순도를 계산합니다.
    """
    counts = {}
    for label in labels:
        counts[label] = counts.get(label, 0) + 1

    impurity = 1
    total_count = len(labels)
    for label in counts:
        probability = counts[label] / total_count
        impurity -= probability**2
    return impurity

무엇을 배웠나#

특성 엔지니어링을 통해 데이터를 모델이 더 잘 이해하도록 만들고, 의사결정나무의 max_depth를 조절하여 모델의 복잡도를 제어하는 방법을 배웠습니다. max_depth는 과소적합과 과적합 사이의 균형을 맞춰주며, None 값은 교차검증을 통해 최적의 깊이를 찾아야 함을 알게 되었습니다. 특히, 교차검증을 이용해 다양한 max_depth 값을 테스트하여 모델의 성능을 최적화하는 것이 중요하다는 것을 깨달았습니다.

헷갈렸던 점#

트리 깊이가 깊어질수록 항상 성능이 좋아지는 줄 알았고, max_depth가 None이면 트리가 무조건 깊어진다고 생각했습니다. 과소적합과 과적합의 관계도 명확하게 이해하지 못해서, 모델 복잡도를 어떻게 조절해야 할지 막막했습니다.

정리된 이해#

특성 엔지니어링은 데이터의 의미를 명확히 하고 모델이 패턴을 더 잘 파악하도록 돕는 과정이며, 의사결정나무의 복잡도를 조절하는 max_depth는 과소적합과 과적합 사이의 균형을 맞추는 중요한 요소이다. max_depth를 None으로 두면 트리가 최대한 깊어지지만, 최적의 깊이는 교차검증을 통해 찾아야 하며, 이를 통해 모델의 일반화 성능을 높일 수 있다.

무엇을 배웠나#

헷갈렸던 점#

통계분석과 머신러닝을 완전히 별개의 영역으로 생각하고, 특히 로지스틱 회귀가 두 분야 모두에서 사용될 수 있다는 점이 이해가 안 됐다. 어떤 기준으로 어떤 질문을 던지는지에 따라 해석이 달라지는 점을 명확히 파악하지 못했다. 변수 선택 과정에서 통계적 의미와 예측 성능 사이의 관계를 어떻게 조율해야 할지 막막했다.
