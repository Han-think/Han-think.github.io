1. 함수의 본질#

왜 이걸 보게 됐나#

코드의 효율적 관리와 재사용성을 높이기 위해 함수의 중요성을 인지하고, 이를 실무에 어떻게 적용할지 이해하고자 했습니다.

내가 헷갈린 지점#

함수와 클래스 간의 관계, 그리고 테스트 가능한 코드 작성 방법에 대한 명확한 구분이 어려웠습니다.

시도한 코드 / 예시#

사칙연산을 처리하는 클래스 Arithmetic을 작성했습니다.

class Arithmetic:
    def __init__(self, a, b):
        self.a = a
        self.b = b

    def add(self):
        return self.a + self.b

    def subtract(self):
        return self.a - self.b

    def multiply(self):
        return self.a * self.b

    def divide(self):
        if self.b == 0:
            raise ValueError("0으로 나눌 수 없습니다.")
        return self.a / self.b

결과와 해석#

코드를 함수 단위로 분리하여 각 연산이 독립적으로 작동함을 확인할 수 있었습니다. 특히 예외 처리를 통해 코드의 안정성이 향상되었습니다.

정리된 이해#

함수는 코드의 모듈화와 재사용성을 증가시키는 핵심 요소입니다. 클래스 내 메서드도 함수로 볼 수 있으며, 이를 통해 복잡한 로직을 관리하기 쉬워집니다.
