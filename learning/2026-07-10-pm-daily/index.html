1. PCA와 t-SNE, 차원 축소 시각화 완벽 이해#

무엇을 배웠나#

PCA와 t-SNE가 모두 차원 축소에 사용되지만, PCA는 선형 방식이고 데이터의 분산을 보존하는 반면, t-SNE는 비선형 방식으로 데이터의 국소적인 구조를 시각화하는 데 중점을 둡니다. t-SNE는 군집화를 수행하는 알고리즘이 아니며, 시각화 결과에 사용된 색상은 단순히 라벨이나 추가 정보에 따른 것입니다. 이제 PCA는 재사용성이 높고, t-SNE는 시각화에 더 적합하다는 점을 이해하게 되었습니다.

헷갈렸던 점#

PCA와 t-SNE가 모두 차원 축소 기법이라고 막연하게 생각했고, t-SNE가 데이터 군집을 알아서 찾아준다고 믿었습니다. t-SNE 시각화에서 색깔이 실제 군집을 나타낸다고 생각해서 해석에 어려움을 겪었습니다.

정리된 이해#

PCA는 데이터를 선형적으로 축소하며 분산을 최대한 유지하는 반면, t-SNE는 비선형적인 방식으로 데이터의 국소적인 구조를 시각화하는 데 초점을 맞추는 차원 축소 기법입니다. t-SNE는 시각화 도구일 뿐 군집화를 수행하는 것이 아니며, 산점도에 색깔이 적용된 경우에도 이는 실제 군집 결과를 나타내는 것이 아니라 추가적인 정보를 반영한 것입니다. 따라서 PCA는 재사용성이 높고, t-SNE는 시각화에 더 적합하다고 이해했습니다.

2. K-Means 클러스터링과 평가 지표 완벽 이해#

무엇을 배웠나#

K-Means 알고리즘의 비용 함수는 지도 학습 손실 함수와 달리 데이터 포인트와 클러스터 중심 사이의 거리를 최소화하는 것을 목표로 한다는 것을 명확히 알게 되었고, Elbow Method는 시각적인 변이 감소 지점을 찾는 방법이며 경사하강법과 직접적인 관련이 없다는 것을 이해했습니다. 또한 실루엣 점수와 같은 클러스터링 지표는 정확도와는 다른 의미를 가지며, 군집의 응집도와 분리도를 나타내는 중요한 지표라는 것을 배웠습니다. 다양한 클러스터링 평가 지표의 의미를 제대로 파악하고 해석하는 것이 중요함을 알게 되었습니다.

헷갈렸던 점#

K-Means의 비용 함수가 지도 학습의 오차율과 같은 개념이라고 생각해서 헷갈렸고, Elbow Method가 경사하강법처럼 작동한다고 오해했었어. 실루엣 점수를 정확도처럼 해석하려다가 잘못된 부분이 있었고, 클러스터링 지표들의 의미를 제대로 파악하지 못했던 것 같아.

정리된 이해#

K-Means의 비용 함수는 데이터 포인트와 클러스터 중심 사이의 거리를 최소화하는 값이며, Elbow Method는 시각적으로 최적의 클러스터 수를 찾는 방법이고, 실루엣 점수나 Dunn Index는 군집의 품질을 평가하는 지표라는 것을 명확히 이해하게 되었다. 특히, 이러한 지표들이 정확도와 같은 지도 학습 지표와 직접적인 연관이 없다는 점을 기억해야겠다. 앞으로는 이러한 개념들을 바탕으로 클러스터링 결과를 더 정확하게 분석하고 해석할 수 있을 것이다.

3. GMM과 EM 알고리즘: 초보자를 위한 이해 및 활용#

무엇을 배웠나#

GMM의 혼합비율은 전체 성분의 가중치를, 소속 확률은 각 데이터 포인트가 특정 군집에 속할 확률을 나타낸다는 점을 명확히 이해하게 되었다. 또한 Soft Clustering의 개념과 EM 알고리즘의 역할, 그리고 predict()와 predict_proba() 함수의 차이를 제대로 구분할 수 있게 되었다. 이러한 이해를 바탕으로 실제 프로젝트에 GMM을 적용하여 다양한 범주에 대한 확률적 소속을 활용하는 시스템을 구축할 수 있을 것 같다.

헷갈렸던 점#

혼합비율과 데이터 포인트의 소속 확률을 동일한 개념으로 생각해서 당황했고, 군집 영역이 단순히 교집합으로만 존재한다고 생각했습니다. predict() 함수가 GMM에서만 사용되는 줄 알았어서 다른 클러스터링 알고리즘에서도 활용될 수 있다는 점이 신기했습니다.

정리된 이해#

GMM의 혼합비율은 각 성분이 전체 데이터에서 차지하는 가중치를 나타내고, predict_proba()는 각 데이터 포인트가 특정 군집에 속할 확률을 보여주므로 이 둘을 혼동하지 않도록 주의해야 합니다. 겹치는 군집 영역은 단순한 교집합이 아닌, 여러 군집의 확률이 높아지는 복잡한 영역이며, 이는 데이터 포인트가 여러 군집에 속할 가능성이 있음을 의미합니다. EM 알고리즘은 이러한 GMM 모델의 파라미터를 반복적으로 학습하여 최적화하는 과정입니다.

4. 실제 데이터 분석, 초보자의 시행착오와 깨달음#

무엇을 배웠나#

강의 데이터와 실제 데이터의 차이점을 명확히 이해하게 되었고, 실제 데이터는 훨씬 더 복잡하고 다양한 문제를 내포한다는 것을 알게 되었다. 이상치 제거보다는 집단 간 이질성 고려의 중요성을 깨달았고, ‘재현율’과 ‘재현성’의 의미를 정확히 구분하는 방법을 배웠다. 앞으로 실제 데이터 분석에서는 이러한 점들을 염두에 두고 접근해야겠다.

헷갈렸던 점#

데이터 준비 과정에서 강의 데이터처럼 쉽게 정리될 거라고 생각했지만, 실제 데이터는 결측치, 중복, 단위 불일치 등 다양한 문제로 훨씬 복잡했습니다. 나이만으로 그룹화할 때 이상치와 집단 간 차이를 어떻게 해석해야 할지 감이 잡히지 않았고, ‘재현율’과 ‘재현성’ 용어를 헷갈려 사용했습니다.

정리된 이해#

강의 데이터와 실제 데이터를 비교하며, 실제 데이터는 결측치, 중복, 단위 불일치 등 다양한 문제로 훨씬 복잡하다는 것을 알게 되었습니다. 이상치는 무조건 제거하는 것이 아니라, 데이터의 특징을 반영하는 중요한 정보일 수 있으므로 신중하게 판단해야 하며, ‘재현율’과 ‘재현성’은 서로 다른 개념이라는 것도 명확히 구분하게 되었습니다. 앞으로는 실제 데이터 분석 시 이러한 점들을 고려하여 더욱 신중하게 접근해야겠습니다.

무엇을 배웠나#

군집화 수식 구현 시 데이터 타입 변환의 필요성과 K-Means 관성 계산의 효율성 차이를 이해하게 되었고, 실루엣 계수 계산 시 예외 처리에 대한 고민을 했습니다. CSV 파일 퀵 스캔 함수를 통해 데이터 탐색의 순서와 목적을 파악하고, 이상치(outlier)를 단순히 제거하는 것이 아니라 데이터의 건전성을 확인하는 지표로 활용해야 함을 알았습니다. 데이터 탐색 자동화 도구가 모델 선택보다 우선순위가 될 수 있다는 점을 깨달았습니다.

헷갈렸던 점#

데이터 분석 공식이 실제 코드로 어떻게 구현되는지 이해하는 데 어려움을 겪었습니다. CSV 파일을 처음 불러왔을 때 어떤 부분을 먼저 살펴봐야 할지 막막했고, IQR을 이용한 이상치 검출 결과를 어떻게 처리해야 할지 고민했습니다.

# 유클리드 거리 계산 예시 (np.asarray, dtype=float 설명)
import numpy as np

def euclidean_distance(point1, point2):
  """두 점 사이의 유클리드 거리를 계산합니다."""
  point1 = np.asarray(point1, dtype=float) # 데이터 타입을 float로 명시적으로 변환하여 수치 연산의 정확성을 보장합니다.
  point2 = np.asarray(point2, dtype=float)
  return np.sqrt(np.sum((point1 - point2)**2))

# 실루엣 계수 구현 예시 (max(a, b) 사용, denominator == 0 예외 처리)
def silhouette_coefficient(a, b, denominator):
  """실루엣 계수를 계산합니다."""
  if denominator == 0:
    return 0  # 예외 처리: 분모가 0인 경우 0을 반환
  return max(a, b) / denominator

7. AI와 인간의 협업: 데이터 분석 워크플로우 이해#

무엇을 배웠나#

AI 보조 데이터 분석에서 AI는 반복적인 코드 작성과 실험에 강점을 보이지만, 인간은 명확한 목표 설정과 결과 해석, 최종 승인 과정이 중요하다는 점을 알게 되었다. 특히, AI가 생성한 코드와 군집화 결과는 반드시 검증하고, 현재 사용 중인 도구들의 한계를 파악하여 적절한 도구 선택과 통합 전략이 필요하다는 것을 배웠다. 이러한 과정을 통해 도구 활용 능력과 한계 이해가 중요하다는 것을 확인했다.

헷갈렸던 점#

AI가 코드를 작성해주면 내가 얼마나 알아야 하는지, 그리고 자동화된 군집 결과의 정확성을 어떻게 보장해야 할지 처음에는 헷갈렸다. 현재 사용하고 있는 도구들이 완벽하게 제 요구사항을 충족하지 못하는 이유도 명확하게 파악하기 어려웠다. 하지만 결국 AI는 도구일 뿐이고, 최종적인 판단과 해석은 인간의 몫이라는 것을 깨달았다.

정리된 이해#

AI는 반복적인 코드 작성 및 실험에 유용하지만, 명확한 목표 설정과 결과 해석은 여전히 인간의 역할이다. AI를 활용하여 분석 결과를 요약하고 다음 실험 조건을 제안하는 것은 효율적이지만, 자동화된 프로세스가 오류를 발생시킬 수 있으므로 주의해야 한다. 중요한 것은 AI 도구의 사용법과 한계를 정확히 이해하고 적절하게 활용하는 능력이다.

# 예시: 데이터 정제 코드 (Python)
# 실제 코드는 데이터 구조 및 분석 목표에 따라 달라짐

# 1. 라이브러리 불러오기
import pandas as pd

# 2. 데이터 불러오기
df = pd.read_csv("your_data.csv")

# 3. 결측치 처리
df = df.fillna(df.mean())

# 4. 이상치 제거 (예: IQR 사용)
Q1 = df.quantile(0.25)
Q3 = df.quantile(0.75)
df = df[(df >= Q1) & (df <= Q3)]

# 5. 특정 컬럼 변환 (예: 문자열 -> 숫자)
df['column_name'] = pd.to_numeric(df['column_name'], errors='coerce')
df = df.dropna(subset=['column_name']) # NaN 값 제거

# 6. 결과 저장
df.to_csv("cleaned_data.csv", index=False)
