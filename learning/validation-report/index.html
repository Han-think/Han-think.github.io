초보자 워킹 노트: 라이브러리 생태계 선택부터 프로젝트 연동까지 (6월 4일)#

## 1. 라이브러리 선택의 중요성 이해하기#

### 왜 이걸 보게 됐나#

오늘의 학습은 복잡한 라이브러리 생태계 속에서 프로젝트에 가장 적합한 도구를 선택하는 방법을 알아보기 위함이었습니다. 다양한 라이브러리와 프레임워크가 제공하는 기능들 사이에서 혼란스러움을 겪었습니다.

### 내가 헷갈린 지점#

라이브러리와 프레임워크의 차이점과 각각의 장단점을 명확히 구분하는 것이 어려웠습니다. 또한, 특정 상황에서 어떤 도구를 선택해야 하는지 구체적인 가이드라인이 부족하여 방향성을 잡는 데 애를 먹었습니다.

### 시도한 코드 / 예시#

# 가상 환경 생성 예시
python -m venv my_project_env

# 가상 환경 활성화 예시 (Windows)
my_project_env\Scripts\activate
# 가상 환경 활성화 예시 (Linux/Mac)
source my_project_env/bin/activate

# requirements.txt 파일 생성 예시
# 필요한 패키지 목록을 추가합니다.
# 예: pandas==1.4.3, matplotlib==3.5.1
pip freeze > requirements.txt

### 결과와 해석#

가상 환경을 설정하고 requirements.txt 파일을 생성하는 과정을 통해 프로젝트의 의존성 관리가 훨씬 명확해졌습니다. 각 프로젝트마다 독립적인 환경을 유지함으로써 라이브러리 간 충돌을 피하고 코드의 재현성을 높일 수 있음을 확인했습니다.

### 정리된 이해#

  • 라이브러리 선택 기준: 프로젝트의 목표와 요구사항에 따라 적합한 라이브러리를 선택해야 합니다. 예를 들어, 데이터 분석은 Pandas와 Matplotlib를, 웹 애플리케이션 개발은 Flask나 Django를 고려할 수 있습니다.
