1. 베이즈 정리: 조건부 확률과 사전/사후 확률 업데이트#

무엇을 배웠나#

베이즈 정리 학습을 하면서 조건부 확률의 방향이 바뀌면 의미가 완전히 달라진다는 것을 깨달았습니다. 또한, 사전확률, 우도, 사후확률의 관계를 이해하고, 주어진 정보를 바탕으로 확률을 계산하는 과정을 명확히 할 수 있게 되었습니다. 이제는 베이즈 정리가 새로운 증거를 통해 기존 믿음을 업데이트하는 유용한 도구라는 것을 알게 되었습니다.

헷갈렸던 점#

처음에는 조건부 확률의 방향이 바뀌면 확률값이 달라지는 점이 명확하게 이해되지 않았고, 베이즈 정리 계산식 자체가 어떻게 적용되는지 감이 잘 잡히지 않았습니다. 특히 유방암 검사 예시처럼 복잡한 계산 과정이 들어가면 더욱더 어려웠습니다.

정리된 이해#

베이즈 정리는 기존의 믿음을 새로운 정보와 결합하여 업데이트하는 강력한 도구이며, 조건부 확률의 방향에 따라 의미가 완전히 달라진다는 것을 알게 되었다. 멧돼지 경보나 유방암 검사 예시처럼 실제 상황에 적용해 보면서 사전확률, 우도, 사후확률의 관계를 명확히 이해하는 것이 중요하다고 생각한다. 앞으로는 다양한 예시를 통해 베이즈 정리를 더 깊이 있게 익혀나가야겠다.

P(멧돼지 | 경보) = (P(경보 | 멧돼지) × P(멧돼지)) / P(경보)
                      = (0.90 × 0.01) / 0.10
                      = 0.09 (9%)

2. 손실 함수 최적화를 위한 미분, 테일러 급수, 경사하강법#

무엇을 배웠나#

손실함수의 기울기(도함수)는 파라미터를 업데이트하여 손실을 줄이는 방향을 알려주고, 학습률은 파라미터 업데이트의 보폭을 결정한다는 것을 명확히 이해하게 되었습니다. 테일러 급수와 경사하강법의 관계를 통해 손실함수를 근사하고 최적화하는 과정을 더욱 깊이 있게 이해할 수 있었습니다. 특히 학습률의 중요성을 깨닫고, 적절한 학습률 설정이 최적화 과정에 미치는 영향을 고려해야 함을 알게 되었습니다.

헷갈렸던 점#

처음에는 학습률이 어떤 값을 의미하는지, 그리고 손실 함수를 줄이는 것이 항상 좋은 방향으로 이어지는지 의문이었습니다. 특히 학습률이 너무 큰 경우, 손실이 계속 줄어들지 않고 오히려 발산하는 상황이 발생할 수 있다는 점이 헷갈렸습니다. 도함수, 테일러 급수, 그리고 경사하강법의 관계가 명확하게 연결되지 않아 어려움을 느꼈습니다.

정리된 이해#

손실함수의 기울기(도함수)는 현재 위치에서의 변화 방향을 알려주며, 경사하강법은 이 기울기를 따라 파라미터를 업데이트하여 손실을 줄여나가는 방식이야. 학습률은 이 때 파라미터 업데이트의 보폭을 결정하는 중요한 값인데, 너무 크면 최소점을 지나치고, 너무 작으면 학습이 느려질 수 있어. 테일러 급수는 복잡한 손실함수를 단순화하여 경사하강법을 이해하는 데 도움을 주는 도구라고 생각하고 있어.

3. 모델 학습 과정 핵심 지표 및 체크포인트 관리#

무엇을 배웠나#

epoch을 무작정 늘리는 것이 모델 성능 향상으로 이어지지 않고, 오히려 과적합을 유발할 수 있다는 것을 알게 되었습니다. 훈련 손실 감소가 생성 품질 향상과 반드시 연결되지 않으며, 검증 손실을 통해 모델의 실제 성능을 파악해야 한다는 점도 중요하게 배웠습니다. 마지막으로, 학습 과정 중간중간 모델 상태를 저장하는 checkpoint를 통해 최적의 모델을 선택하는 것이 효과적이라는 것을 이해했습니다.

헷갈렸던 점#

처음에는 epoch 수를 늘리면 모델 성능이 무조건 좋아질 거라 생각했고, 훈련 손실이 낮아지면 생성 품질도 향상될 거라고 단순하게 생각했습니다. 하지만 epoch가 너무 많아지면 과적합이 일어날 수 있고, 손실이 낮아도 생성 품질이 떨어질 수 있다는 점을 깨닫고 개념을 재정립해야 했습니다.

정리된 이해#

Epoch은 데이터셋을 모델이 한 번 학습하는 주기로, 너무 많이 반복하면 과적합이 발생할 수 있습니다. 손실 값 감소가 항상 생성 품질 향상을 의미하는 것은 아니며, 검증 손실 추이를 통해 모델의 과적합 여부를 판단해야 합니다. 학습 중간에 저장하는 체크포인트를 통해 최적의 성능을 보이는 모델을 선택하는 것이 중요합니다.

4. 선형대수 실습: 내적과 Null Space 이해#

무엇을 배웠나#

이번 실습을 통해 벡터 내적의 의미를 좀 더 명확하게 이해하게 되었고, 특히 파이썬 코드에서 : 연산자의 역할을 제대로 파악할 수 있었다. null space는 행렬 변환 과정에서 특정 방향의 정보를 유지하며 해를 확장하는 역할을 한다는 것을 알게 되었고, 이를 활용한 예시 코드를 통해 개념적 이해를 높일 수 있었다. 앞으로는 이러한 개념들을 활용하여 선형대수 문제를 더 효과적으로 해결할 수 있을 것 같다.

헷갈렸던 점#

내적 연산에서 : 표기법이 전체 축을 의미한다는 것을 파악하는 데 어려움을 겪었고, null space 벡터를 기존 해에 더하는 개념이 직관적으로 이해되지 않았다. null space가 단순히 해를 다양하게 만드는 것이 아니라, 행렬 변환에 영향을 주지 않는 특수한 방향을 나타낸다는 핵심을 놓치고 있었던 것 같다.

정리된 이해#

내적은 벡터가 특정 방향으로 얼마나 성분을 갖는지 알려주는 방식으로, 벡터의 각 축에 대한 투영 값을 구할 때 활용된다. 널 스페이스는 행렬 변환 후 결과가 변하지 않는 특별한 방향을 나타내며, 기존 해에 널 스페이스 벡터를 더하는 것은 이 방향을 고려하여 해의 자유도를 높이는 것을 의미한다. 행렬 변환으로 인해 사라지지 않는 벡터들을 활용하여 다양한 해를 찾아낼 수 있다는 점이 핵심이다.

import numpy as np
from scipy.linalg import null_space
A = np.array([[1, 2], [3, 6]])  # 랭크가 낮은 예시 행렬
ns = null_space(A)  # null space 벡터
x1 = np.array([[1], [0]])
x2 = x1 + ns  # 기존 해에 null space 벡터

5. 정규분포 실습: 샘플 값의 변동성과 중심극한정리#

무엇을 배웠나#

정규분포 실습을 통해 모집단의 이론적 평균과 표준편차는 샘플링을 통해 얻은 값과 정확히 일치하지 않을 수 있다는 점을 이해하게 되었습니다. 샘플링 과정의 난수성으로 인해 값은 이론값 근처에 위치하며, 이는 중심극한정리의 결과로 해석될 수 있습니다. 코드를 실행해보니 샘플 평균과 표준편차가 예상 범위 내에 있다는 것을 확인했습니다.

헷갈렸던 점#

샘플링을 할 때마다 평균과 표준편차가 이론적으로 설정된 값과 조금씩 달라서 왜 그런지 몰랐어요. 여러 번 샘플링을 해도 항상 똑같은 값이 나오지 않는다는 점이 처음에는 이해가 안 되었습니다. 중심극한정리가 어떻게 샘플 값의 변동성을 설명하는지 궁금했습니다.

정리된 이해#

정규분포 실습을 하면서 샘플 평균과 표준편차가 이론적 값과 정확히 일치하지 않는 점이 처음에는 헷갈렸는데, 이는 샘플링 과정에서 발생하는 자연스러운 변동 때문이라는 것을 알게 되었습니다. 중심극한정리에 따라 샘플 크기가 클수록 샘플 평균은 모집단 평균에 가까워지지만, 항상 완벽하게 일치하지는 않습니다. 따라서 샘플링 시 난수 생성 시드를 설정하여 재현성을 확보하는 것이 중요하다고 생각합니다.

import numpy as np
import matplotlib.pyplot as plt

# 난수 생성 시드 설정 (재현성을 위해)
np.random.seed(0)

# 모집단 파라미터 설정
mean = 2
std = 1

# 샘플링
n_samples = np.random.normal(mean, std, 1000)

# 샘플 평균과 표준편차 계산
samples_mean = np.mean(n_samples)
samples_std = np.std(n_samples)

# 결과 출력
print(f"샘플 평균: {samples_mean:.2f}")
print(f"샘플 표준편차: {samples_std:.2f}")
