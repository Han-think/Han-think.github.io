1. 비지도학습과 클러스터링: 핵심 개념 및 실습 이해#

무엇을 배웠나#

비지도 학습, 특히 클러스터링에서 군집 내 유사성과 군집 간 차이가 회귀분석의 다중공선성과는 별개의 개념이라는 점을 명확히 이해하게 되었다. K-Fold 교차 검증과 K-means 알고리즘에서 사용되는 K의 의미가 다르다는 것도 구분할 수 있게 되었고, 간단한 K-means 클러스터링 실습을 통해 개념을 더 확실히 다질 수 있었다. 앞으로는 이 점들을 기억하며 클러스터링을 적용해나가야겠다.

헷갈렸던 점#

처음에는 클러스터링에서 군집 내 데이터의 유사성과 군집 간의 차이 관계를 회귀분석의 독립변수 간 관계와 비슷하게 생각해서 혼란스러웠다. K-Fold와 K-means에서 K가 의미하는 바가 달라서 구분이 잘 안 되었고, 클러스터링에서 다중공선성의 개념이 적용되는 것인지 궁금했다.

정리된 이해#

클러스터링은 데이터의 유사성을 기반으로 그룹을 나누는 과정이며, 회귀분석에서 독립변수 간의 중복 정보인 다중공선성과는 별개의 개념이다. K-Fold는 데이터 분할 기법이고, K-means는 데이터를 K개의 군집으로 나누는 알고리즘이며, 이 둘에서 ‘K’는 서로 다른 의미를 가진다. 앞으로는 이 개념들을 명확히 구분하여 클러스터링을 이해하고 적용해야겠다.

from sklearn.cluster import KMeans
import numpy as np

2. Raw 데이터 전처리부터 모델 입력 행렬 생성까지#

무엇을 배웠나#

Raw Data에서 모델 입력 행렬을 만들기 위한 전처리 과정과 NumPy 배열 인덱싱 방식에 대한 이해가 부족했던 점을 파악하고, 데이터 구조 확인부터 스케일링까지 전처리 단계를 체계적으로 정리했습니다. 특히 One-Hot Encoding의 필요성과 NumPy 배열의 행, 열 인덱싱 방식에 대한 이해도를 높였습니다. 펭귄 데이터를 활용한 실습 예시를 통해 실제 데이터 전처리 과정을 경험했습니다.

헷갈렸던 점#

Raw Data에서 모델 입력 행렬을 만드는 과정에서 array, ndarray 같은 기본 용어와 행/열의 의미가 헷갈렸고, One-Hot Encoding을 단순히 기계적인 변환으로만 생각해서 범주형 데이터의 순서와 거리에 대한 의미를 제대로 파악하지 못했습니다. 또한, 데이터 전처리 과정을 단계별로 정리하고 이해하는 데 어려움을 느꼈습니다.

정리된 이해#

Raw 데이터를 모델 입력 행렬로 변환하는 과정은 데이터 구조 이해, 결측치 처리, 범주형 데이터 인코딩, 스케일링 등의 전처리 단계를 거쳐 이루어진다. NumPy 배열은 행과 열 인덱싱을 통해 특정 데이터에 접근할 수 있으며, One-Hot Encoding은 범주형 데이터의 순서에 따른 문제를 해결하기 위한 중요한 과정이다. 이러한 이해를 바탕으로 데이터 전처리 과정을 체계적으로 수행할 수 있다.

import pandas as pd
import numpy as np
from sklearn.preprocessing import StandardScaler

# 가상 데이터프레임 생성
df_penguins = pd.DataFrame({
    'Species': ['Gentoo', 'Adelie', 'Chinstrap', 'Gentoo'],
    'Bill_length_mm': [47.1, 39.1, 36.7, 47.8],

    'Flipper_length_mm': [195.8, 181.7, 173.4, 200.0]
})

# 데이터프레임을 NumPy 배열로 변환
X = df_penguins.drop('Species', axis=1).values

# 데이터 스케일링 예시
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

3. 차원 축소, PCA와 t-SNE 완벽 가이드#

무엇을 배웠나#

PCA와 t-SNE의 차원 축소 개념을 명확하게 이해하게 되었고, 특히 PCA가 데이터의 분산을 최대한 유지하며 데이터를 투영하는 과정과 t-SNE가 비선형적인 관계를 포착하여 시각화에 적합하다는 점을 알게 되었다. 차원 축소를 통해 데이터의 복잡성을 줄이고 효율성을 높이는 목적과 각 방법이 갖는 역할 차이를 제대로 파악할 수 있게 되었다. 앞으로는 이 지식을 바탕으로 데이터 분석 및 시각화 프로젝트에 적절한 방법을 선택하고 활용할 수 있을 것이다.

헷갈렸던 점#

고차원 데이터를 2차원이나 3차원으로 줄이는 과정에서 정보 손실을 얼마나 감수해야 하는지, 그리고 PCA와 t-SNE가 정확히 어떤 상황에 적합한지 혼란스러웠습니다. PCA가 단순히 데이터를 평평한 그림으로 옮겨 놓는 것이라고 생각했고, PCA와 t-SNE의 역할과 사용 목적에 대한 명확한 차이점을 파악하는 데 어려움을 겪었습니다.

정리된 이해#

차원 축소는 데이터의 복잡성을 줄여 분석 및 시각화를 용이하게 하는 중요한 과정이며, PCA는 데이터의 분산을 최대한 보존하면서 선형적인 방식으로 차원을 줄이는 반면, t-SNE는 비선형적인 관계를 고려하여 데이터 시각화에 특화되어 있습니다. 따라서 PCA는 데이터의 주요 특징을 유지하면서 차원을 축소할 때, t-SNE는 데이터 간의 복잡한 관계를 시각적으로 표현하고자 할 때 적합합니다.

from sklearn.decomposition import PCA
import numpy as np

# 예시 데이터 (4개의 특성을 가진 10개의 데이터 포인트)
data = np.random.rand(10, 4)

# PCA 모델 생성
pca = PCA(n_components=2)

# 데이터에 PCA 적용
principal_components = pca.fit_transform(data)

# 결과 확인 (2개의 주성분)
print(principal_components)

4. PCA 설명분산 비율과 scikit-learn 속성 이해#

무엇을 배웠나#

PCA에서 주성분 분석 결과, 각 주성분이 전체 분산에서 얼마나 많은 정보를 담고 있는지 나타내는 설명 분산 비율과 이를 누적한 누적 설명 분산 비율을 이해하게 되었습니다. explained_variance_ratio_ 와 같은 속성 뒤에 붙는 _ 기호가 속성값을 의미한다는 점도 알게 되었습니다. 마지막으로 n_components 매개변수의 역할을 명확히 파악하여 PCA 모델을 더욱 효과적으로 사용할 수 있을 것 같습니다.

헷갈렸던 점#

처음에는 PCA에서 설명 분산 비율과 누적 설명 분산 비율이 정확히 무엇을 의미하는지, 그리고 어떻게 해석해야 하는지 헷갈렸습니다. _ 기호가 붙은 속성이 왜 그런 형태인지도 궁금했고요. n_components 파라미터를 생략하면 어떤 일이 벌어지는 건지 파악하는 데 어려움을 느꼈습니다.

정리된 이해#

PCA에서 설명 분산 비율은 각 주성분이 데이터의 분산을 얼마나 설명하는지 보여주는 값이고, 누적 설명 분산은 여러 주성분을 합쳐서 얼마나 설명하는지를 보여주어, 몇 개의 주성분으로 데이터를 잘 표현할 수 있는지 판단하는 데 도움을 줍니다. scikit-learn 속성 뒤에 붙는 _ 기호는 해당 속성이 배열이나 리스트를 반환하는 것을 나타내고, n_components 매개변수를 생략하면 모든 주성분을 계산한다는 것을 알게 되었습니다.

pca_full = PCA(random_state=RANDOM_STATE)

ev_ratio = pca_full.explained_variance_ratio_

5. 비지도 학습과 설계 과정 연결하기#

무엇을 배웠나#

비지도학습은 데이터에서 숨겨진 패턴을 찾고, 이를 인간의 해석과 함께 초기 라벨을 만들어내는 데 유용하다는 것을 알게 되었다. 이렇게 만들어진 초기 라벨을 바탕으로 지도학습을 적용하면 모델 성능을 더 향상시킬 수 있다는 점을 이해했다. 앞으로는 프로젝트에 어떤 학습 방법을 적용할지 결정할 때, 비지도학습으로 초기 패턴을 발견하고 지도학습으로 성능을 높이는 전략을 고려해야겠다.

헷갈렸던 점#

지도학습과 비지도학습을 명확히 구분하는 기준이 잘 안 잡혀서, 어떤 방법을 선택해야 할지 혼란스러웠다. 특히 회귀분석인지 분류인지 판단 기준이 불명확해서, 목표 설정부터가 어려웠다. 비지도학습 후 약한 라벨링 과정을 거쳐 지도학습에 적용하는 전체적인 설계 흐름이 어떻게 진행되는지 파악하기 어려웠다.

정리된 이해#

비지도학습은 데이터 자체의 숨겨진 구조와 패턴을 찾아내고, 이를 바탕으로 초기 라벨링을 수행하는 방식으로, 이후 인간이 해석하여 의미를 부여하는 과정을 거칩니다. 초기 라벨링된 데이터를 활용하여 지도학습 모델을 훈련시켜 성능을 향상시키는 방식으로 연결될 수 있습니다. 이러한 과정을 통해 데이터의 특징을 더 정확하게 파악하고 예측 모델의 성능을 개선할 수 있습니다.

무엇을 배웠나#

헷갈렸던 점#

로지스틱 회귀가 회귀라는 이름인데 왜 분류 문제에 사용되는지, 그리고 사이킷런에서 데이터를 입력할 때 1차원 배열이 아닌 2차원 배열로 바꿔야 하는 이유가 처음에는 잘 이해가 되지 않았습니다. 특히, 특성이 하나일 때도 (100,)이 아닌 (100, 1) 형태로 만들어야 한다는 점이 헷갈렸습니다.

정리된 이해#

로지스틱 회귀는 이름과는 달리 분류 모델이며, 입력값을 확률 값으로 변환하여 클래스를 예측합니다. 사이킷런에서 데이터를 입력할 때 X는 (데이터 개수, 특성 개수) 형태의 2차원 배열이어야 하고, 단일 특성 데이터도 (100, 1)처럼 변환해야 모델이 정상적으로 작동합니다. 최신 NumPy에서는 데이터 타입을 float으로 변환하는 것이 안정적입니다.

7. SVM 분류 모델 학습 및 활용: 초보자를 위한 워킹 노트#

무엇을 배웠나#

SVM 분류 모델을 사용할 때 axis=1이 열(column)을 삭제하는 역할을 한다는 것을 명확히 이해하게 되었고, 학습 데이터(fit())와 예측 데이터(predict())를 분리해서 사용해야 한다는 점을 알게 되었다. 또한 예측 결과를 평가할 때는 실제 정답 레이블과 비교하여 정확도를 계산해야 한다는 것을 실습을 통해 확인했다. 이제 SVM 모델을 좀 더 자신 있게 사용할 수 있을 것 같다.

헷갈렸던 점#

axis=1이 행을 제거하는 것인지 열을 제거하는 것인지 명확하지 않았고, fit() 메서드에 테스트 데이터를 넣어도 되는지, 그리고 예측 결과를 평가할 때 정답 데이터와 함께 사용해야 하는지 궁금했습니다. 학습 데이터와 테스트 데이터를 어떻게 구분해서 사용해야 하는지 혼동스러웠습니다.

정리된 이해#

axis=1은 Pandas DataFrame에서 열을 선택하거나 제거할 때 사용하며, data.drop("Class", axis=1)은 ‘Class’ 열을 삭제하고 나머지 열들을 입력 데이터로 사용한다는 것을 알게 되었다. fit() 메서드는 학습 데이터를 사용하여 모델을 훈련시키고, predict() 메서드는 학습된 모델을 사용하여 새로운 데이터에 대한 예측을 수행하며, 예측 결과는 실제 정답과 비교하여 모델의 성능을 평가할 수 있다.

8. 베이즈 정리로 스팸 메일 확인 키워드 확률 계산하기#

무엇을 배웠나#

베이즈 정리를 활용하여 조건부 확률의 방향성을 명확히 이해하게 되었고, 특히 P(A | B)에서 B가 조건이라는 점을 확실히 알게 되었다. 스팸 메일 확인 키워드 확률을 계산할 때 조건부 확률의 의미를 정확히 파악하는 것이 중요하며, 베이즈 정리를 통해 이를 명확하게 이해할 수 있었다. 앞으로 스팸 필터링 모델을 개발하거나 분석할 때 이 지식을 활용할 수 있을 것이다.

헷갈렸던 점#

확인이라는 단어가 스팸 메일과 정상 메일에서 얼마나 자주 등장하는지, 그리고 그것이 어떤 의미를 가지는지 정확히 파악하는 데 어려움이 있었습니다. P(확인 | 스팸)과 P(스팸 | 확인)의 방향성을 혼동하여, 조건부 확률의 의미를 제대로 이해하지 못했습니다. 특히, 조건부 확률의 세로줄 기호(|)가 나타내는 의미를 정확히 이해하는 데 어려움을 겪었습니다.

정리된 이해#

베이즈 정리를 통해 조건부 확률의 방향성을 명확히 이해하게 되었고, 특히 P(A|B)에서 B가 조건임을 깨달았습니다. ‘확인’이라는 단어가 포함된 메일이 스팸일 확률(P(스팸 | 확인))은 스팸 메일에서 ‘확인’ 단어가 나올 확률(P(확인 | 스팸))과 전체 스팸 메일의 비율(P(스팸))에 따라 결정되며, 이를 통해 스팸 메일 분류 정확도를 높일 수 있습니다. 이제는 조건부 확률의 의미를 헷갈리지 않고, 문제 상황에 맞게 적용할 수 있을 것 같습니다.

9. GaussianNB 핵심 개념과 와인 데이터 분류 실습#

무엇을 배웠나#

GaussianNB가 각 클래스의 특성값을 정규분포를 따른다고 가정하는 나이브 베이즈 모델임을 이해하게 되었고, random_state 옵션이 데이터 분할의 재현성을 보장하는 역할을 한다는 것을 알게 되었다. 특히, random_state가 모델 학습 자체에 영향을 주지 않는다는 점을 명확히 파악하게 되었다. 이를 통해 나이브 베이즈 모델의 다양한 변형을 이해하고, 실험의 재현성을 확보하는 방법을 배우었다.

헷갈렸던 점#

GaussianNB가 일반적인 나이브 베이즈와 어떻게 다른지, 그리고 왜 정규분포를 가정하는지 잘 이해하지 못했습니다. 또한 random_state 옵션이 모델 학습에 영향을 주는 것인지, 아니면 데이터 분할 과정에 영향을 주는 것인지 혼동스러웠습니다. 이 옵션이 실험 결과의 재현성을 어떻게 보장하는지 명확하게 파악하지 못했습니다.

정리된 이해#

GaussianNB는 각 클래스별 특성값이 정규분포를 따른다고 가정하는 나이브 베이즈 모델이며, random_state는 데이터 분할 과정의 재현성을 보장하는 설정값입니다. random_state를 설정하면 데이터 분할 과정이 항상 동일하게 진행되어 실험 결과를 다시 확인해도 동일한 결과를 얻을 수 있습니다. 이 덕분에 모델 학습 자체는 영향을 받지 않으면서도 결과의 일관성을 유지할 수 있습니다.

10. 다중 클래스 혼동행렬 및 정규화 시각화 완전 정복#

무엇을 배웠나#

혼동행렬 계산 시 실제 값과 예측 값의 순서가 중요하며, 행은 실제 클래스, 열은 예측 클래스를 나타낸다는 것을 명확히 알게 되었다. 특히 정규화된 혼동행렬은 각 행의 합이 1이 되는 방식으로, 각 실제 클래스가 어떤 예측 클래스로 잘못 분류되는 비율을 보여주는 것을 이해했다. 이 내용을 바탕으로 혼동행렬 시각화에 대한 이해도를 높일 수 있을 것이다.

헷갈렸던 점#

혼동행렬의 입력 값 순서와 행/열의 의미를 헷갈렸고, 정규화된 혼동행렬에서 어떤 값이 1이 되는지 명확하게 이해하지 못했습니다. 실제 레이블이 첫 번째 인자로 와야 하고, 행은 실제 클래스, 열은 예측 클래스를 나타낸다는 것을 알게 되었으며, 정규화는 각 행의 합을 기준으로 이루어진다는 것을 확인했습니다.

정리된 이해#

다중 클래스 혼동행렬에서 행은 실제 클래스, 열은 예측 클래스를 나타내며, 대각선은 정확하게 분류된 데이터 수를 보여줍니다. 정규화된 혼동행렬은 각 실제 클래스에 대한 예측 비율을 보여주기 위해 각 행을 해당 행의 합으로 나누어 정규화하며, 이로 인해 각 행의 합은 1이 됩니다. 이 지식들을 바탕으로 모델 성능을 보다 정확하게 분석할 수 있습니다.
