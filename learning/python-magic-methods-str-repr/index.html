1. str 메서드#

왜 이걸 보게 됐나#

객체 출력 시 메모리 주소 대신 객체의 핵심 정보를 직관적으로 보여주기 위해 __str__ 메서드의 중요성을 이해하고자 했습니다. 이를 통해 개발자와 사용자 모두가 객체의 상태를 쉽게 파악할 수 있도록 하는 방법을 학습했습니다.

내가 헷갈린 지점#

처음에는 객체 출력 결과가 메모리 주소만 표시되어 객체의 실제 정보를 얻는 데 어려움을 겪었습니다. 이로 인해 객체의 상태를 직관적으로 이해하는 데 어려움이 있었습니다.

시도한 코드 / 예시#

class TeamMember:
    def __init__(self, name, role, salary):
        self.name = name
        self.role = role
        self.salary = salary

    def __str__(self):
        return f'{self.role} {self.name}'

    def __repr__(self):
        return f'TeamMember(name="{self.name}", role="{self.role}", salary={self.salary})'

# 객체 생성 및 출력
alice = TeamMember(name="Alice", role="시니어 개발자", salary=6000)
print(str(alice))  # 출력: 시니어 개발자 Alice
print(repr(alice))  # 출력: TeamMember(name='Alice', role='시니어 개발자', salary=6000)```

결과와 해석#

출력 예시:

  • str(alice): 시니어 개발자 Alice
  • repr(alice): TeamMember(name=‘Alice’, role=‘시니어 개발자’, salary=6000)

정리된 이해#

이 학습을 통해 __str__ 메서드는 객체의 주요 정보를 사용자 친화적인 형식으로 출력하는 데 중점을 둔다는 것을 깨달았습니다. 반면 __repr__ 메서드는 객체의 정확한 상태를 개발자에게 제공하는 데 초점을 맞추고 있음을 확인했습니다.

4. 개발자 정보 출력#

왜 이걸 보게 됐나#

개발자로서 객체의 상태를 직관적으로 이해하고 싶었지만, 기본 출력이 메모리 주소만 보여주어 정보 파악이 어려웠습니다. 이를 해결하기 위해 사용자 친화적인 정보 출력과 상세한 객체 상태 확인을 위한 메서드를 이해하고 적용하고자 했습니다.

내가 헷갈린 지점#

처음에는 __str__과 __repr__의 차이점을 명확히 이해하지 못해 객체 출력 결과가 왜 그렇게 나오는지 혼란스러웠습니다. 특히, 메모리 주소만 출력되는 이유를 파악하는 데 어려움이 있었습니다.

시도한 코드 / 예시#

class DeveloperInfo:
    def __init__(self, name, role, experience_years)
        self.name = name
        self.role = role
        self.experience_years = experience_years

    def __str__(self):
        return f'이름: {self.name}, 역할: {self.role}, 경력: {self.experience_years}년'

    def __repr__(self):
        return f'DeveloperInfo(name="{self.name}", role="{self.role}", experience_years={self.experience_years})'

# 예시 객체 생성
john = DeveloperInfo(name="John", role="프론트엔드 개발자", experience_years=5)

# 출력 테스트
print(str(john))  # 출력: 이름: John, 역할: 프론트엔드 개발자, 경력: 5년
print(repr(john))  # 출력: DeveloperInfo(name='John', role='프론트엔드 개발자', experience_years=5)

결과와 해석#

위 코드를 실행하면, str(john)은 사용자 친화적인 정보를 출력하고 (이름: John, 역할: 프론트엔드 개발자, 경력: 5년), repr(john)은 객체의 상세 정보를 포함한 공식적인 문자열 표현을 제공합니다 (DeveloperInfo(name='John', role='프론트엔드 개발자', experience_years=5)).

정리된 이해#

이 개념을 이해함으로써, 개발자 정보를 출력할 때 사용자 친화적인 __str__ 메서드와 상세한 상태 확인을 위한 __repr__ 메서드를 적절히 활용할 수 있게 되었습니다. 이를 통해 코드 가독성과 디버깅 효율성이 향상되었습니다.

총평#

오늘 전체에서 배운 것#

str 메서드는 사용자 친화적인 객체 정보 출력을 위해, repr 메서드는 개발자에게 객체의 상세 상태를 보여주기 위해 각각 사용됨을 이해했습니다.
