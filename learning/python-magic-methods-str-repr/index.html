1. __str__ 메서드#

왜 이걸 보게 됐나#

처음 객체를 출력했을 때 메모리 주소만 보여줘서 객체의 실제 정보가 무엇인지 알 수 없어 답답함을 느꼈다. 그래서 객체를 좀 더 직관적으로 표현할 수 있도록, 그리고 디버깅 시 객체의 상태를 정확하게 파악할 수 있도록 __str__와 __repr__ 메서드를 배우게 되었다. 이 두 메서드를 통해 객체를 좀 더 유용하게 다룰 수 있게 되었다.

내가 헷갈린 지점#

처음에는 객체를 출력했을 때 메모리 주소가 나타나는 게 너무 당황스러웠다. 객체의 정보가 아니라 주소만 보여주는 게 무슨 의미가 있을까 싶었고, 왜 이렇게 복잡하게 출력되는 건지 이해가 안 갔었다. 단순히 객체의 정보를 쉽게 볼 수 있으면 좋겠다고 생각했었다.

시도한 코드 / 예시#

class TeamMember:
    def __str__(self):
        return f"{self.role} {self.name}"

alice = TeamMember(name="Alice", role="시니어 개발자", salary=6000)
print(str(alice))  # 출력: 시니어 개발자 Alice

결과와 해석#

__str__ 메서드는 객체를 사람이 읽기 쉬운 형태로 보여주는 역할을 합니다. TeamMember 클래스에 __str__을 정의해서 객체의 역할과 이름을 출력하도록 했더니, print() 함수를 통해 보기 좋게 정보를 확인할 수 있게 되었어요. 덕분에 객체의 상태를 더 직관적으로 이해할 수 있습니다.

정리된 이해#

__str__ 메서드는 객체를 화면에 출력할 때 사용자에게 친숙하고 읽기 쉬운 문자열 표현을 제공하는 역할을 합니다. 이 메서드를 통해 객체의 정보를 좀 더 의미있게 보여줄 수 있으며, print() 함수와 함께 사용될 때 유용합니다. 나는 이 메서드를 활용하여 객체의 핵심 정보만 보여주도록 정의했다.

2. __repr__ 메서드#

왜 이걸 보게 됐나#

객체를 출력했을 때 메모리 주소만 보이는게 아니라, 객체의 실제 정보를 확인할 수 있는 방법이 있을 것 같아서 __repr__ 메서드를 찾아보게 됐어. 디버깅이나 객체의 상태를 정확하게 파악할 때 유용할 것 같아서 배우게 됐고, 앞으로는 객체의 상태를 좀 더 명확하게 표현할 수 있게 될 것 같아.

내가 헷갈린 지점#

처음에는 __repr__가 __str__와 비슷하게 보여서, 개발자용으로 특별히 필요한 것일까 의문이었어. 객체의 상태를 정확히 표현하는 것이 왜 중요하고, 어디에 쓰이는 걸까 이해가 부족했지. 코드 재현을 위한 정보라니, 그 의미를 명확하게 파악하지 못했던 것 같아.

시도한 코드 / 예시#

class TeamMember:
    def __repr__(self):
        return f"TeamMember(name='{self.name}', role='{self.role}', salary={self.salary})"

alice = TeamMember(name="Alice", role="시니어 개발자", salary=6000)
print(repr(alice))  # 출력: TeamMember(name='Alice', role='시니어 개발자', salary=6000)

결과와 해석#

__repr__ 메서드는 객체의 정확한 상태를 파악할 수 있도록, 객체를 생성할 때 사용될 수 있는 표현을 문자열로 반환하는 역할을 한다. TeamMember 클래스에 정의했을 때, 객체의 속성값들을 포함한 문자열이 출력되어 객체의 상세 정보를 확인할 수 있게 되었다. 이 정보는 디버깅이나 객체 복제 등에 유용하게 활용될 수 있을 것 같다.

정리된 이해#

__repr__ 메서드는 객체의 정확한 상태를 개발자가 확인하기 위한 상세한 문자열 표현을 제공하는 역할을 합니다. 이 메서드를 통해 객체의 속성 값들을 그대로 출력하여 객체를 다시 생성하거나 디버깅할 때 유용하게 활용할 수 있습니다. 기본적으로 __str__보다 더 많은 정보를 담고 있으며, 코드 재현에 필요한 정보를 포함하는 것을 목표로 합니다.

3. 사용자 친화적 표현#

왜 이걸 보게 됐나#

객체를 출력했을 때 메모리 주소만 보여주는 방식으로는 어떤 정보가 담겨 있는지 제대로 파악하기 어려웠어요. 그래서 객체의 정보를 좀 더 직관적으로 보여주는 __str__ 메서드를 배우게 되었고, 디버깅이나 개발 과정에서 객체의 정확한 상태를 파악할 수 있도록 __repr__ 메서드도 익히게 되었습니다.

내가 헷갈린 지점#

처음에는 ‘사용자 친화적 표현’이라는 말이 ‘모든 사용자’를 만족시키는 이상적인 표현을 의미한다고 생각했어요. 그래서 객체를 출력했을 때 보기 좋은 형태가 항상 정답이라고 생각했지만, __repr__의 존재를 통해 개발자를 위한 정보 제공이라는 또 다른 목적이 있다는 것을 알게 됐습니다. 결국 ‘사용자 친화적’은 ‘사람이 읽기 쉬운 형태’라는 의미로 이해했습니다.

시도한 코드 / 예시#

class TeamMember:
    def __str__(self):
        return f"{self.role} {self.name}"

alice = TeamMember(name="Alice", role="시니어 개발자", salary=6000)
print(str(alice))  # 출력: 시니어 개발자 Alice

결과와 해석#

__str__ 메서드는 print() 함수로 객체를 출력할 때 보여지는 문자열을 정의하여 사용자에게 친숙한 형태의 정보를 제공한다. 예를 들어, TeamMember 객체의 경우 역할과 이름을 합쳐서 보기 좋게 출력하도록 만들었을 때, 시니어 개발자 Alice와 같은 읽기 쉬운 정보가 사용자에게 전달된다. 이는 객체의 중요한 속성들을 간결하게 보여주어 이해를 돕는다.

정리된 이해#

__str__ 메서드는 객체를 출력할 때 사람이 이해하기 쉬운 형태의 문자열을 보여주는 역할을 해서, 마치 객체를 설명하는 친절한 안내말처럼 느껴져. __repr__은 좀 더 공식적인 표현으로, 객체의 상태를 재현할 수 있을 정도의 자세한 정보를 담고 있어서, 디버깅이나 객체의 정확한 표현을 필요할 때 사용하면 편리해.

4. 공식적 표현#

왜 이걸 보게 됐나#

객체를 출력할 때, 단순히 메모리 주소가 나오는 게 아니라, 객체의 정보가 직관적으로 보이도록 하고 싶었어. 특히 디버깅할 때, 객체의 상태를 명확하게 파악하려면 좀 더 자세한 정보가 필요하다는 것을 깨달았지. 그래서 객체의 상태를 정확하고 재현 가능한 형태로 보여주는 __repr__를 이해하게 됐어.

내가 헷갈린 지점#

처음에는 __repr__가 ‘공식적 표현’이라는 이름에 걸맞게 객체를 평가해서 값으로 반환하는 줄 알았습니다. 그래서 객체의 문자열 표현을 ‘공식적으로’ 생성한다고 생각했지만, 실제로 __repr__는 객체의 상태를 코드에서 재현할 수 있도록 상세한 문자열을 반환하는 역할임을 알게 되었습니다. 단순히 ‘공식적인’이라는 단어 때문에 헷갈렸던 부분입니다.

시도한 코드 / 예시#

    class TeamMember:
        def __repr__(self):
            return f"TeamMember(name='{self.name}', role='{self.role}', salary={self.salary})"

결과와 해석#

__repr__ 메서드는 TeamMember 객체를 TeamMember(name='Alice', role='시니어 개발자', salary=6000) 와 같이 정확하게 재현할 수 있는 문자열로 표현하는데, 이는 객체의 속성과 값을 명확하게 보여주어 디버깅이나 객체 상태 확인에 유용하다. 이 표현은 마치 객체를 다시 생성하는 데 필요한 정보를 담고 있다고 생각하면 이해하기 쉽다. 디버깅 시 객체의 속성 값을 빠르게 파악할 수 있어서 개발 효율성을 높여준다.

정리된 이해#

__repr__은 객체를 코드에서 다시 생성할 수 있을 정도로 상세한 정보를 담은 공식적인 문자열 표현을 제공하며, 객체의 정확한 상태를 개발자가 확인하는 데 유용합니다. 반면 __str__은 사람이 읽기 쉽도록 객체를 단순화하여 표현하는 사용자 친화적인 문자열 표현을 제공합니다. 즉, __repr__은 개발자를 위한 것이고 __str__은 사용자를 위한 것이라고 이해하면 쉽습니다.

총평#

오늘 전체에서 배운 것#

__str__은 사람이 읽기 쉬운 문자열 표현을, __repr__은 개발자를 위한 상세한 정보 표현을 제공한다는 것을 알게 되었다. 두 메서드를 통해 객체를 출력할 때 어떤 정보가 나타나는지를 제어할 수 있으며, 이를 통해 디버깅 및 객체 활용에 도움을 받을 수 있다.

다음에 조심할 것#

__str__과 __repr__ 메서드를 정의할 때, 사용자 친화성과 개발 편의성 간의 균형을 잘 고려해야겠다. __repr__은 디버깅 및 객체 재현에 매우 유용하지만, 너무 자세한 정보는 오히려 혼란을 야기할 수 있다는 점을 기억해야겠다.

다음 복습 주제#

__str__과 __repr__ 메서드의 차이점을 실제 프로젝트에서 어떻게 활용할 수 있는지, 그리고 두 메서드를 모두 정의하지 않았을 때 기본적으로 호출되는 표현 방식에 대해 좀 더 자세히 알아봐야겠다. 특히 __repr__를 사용하여 디버깅을 얼마나 효율적으로 할 수 있는지 실습을 통해 확인하고 싶다.
