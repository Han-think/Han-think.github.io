1. 클래스 변수 이해하기#

왜 이걸 보게 됐나#

팀 프로젝트에서 팀원들의 정보를 클래스로 관리하려고 했지만, total_members 변수의 동작이 예상과 다르게 작동하여 혼란이 생겼습니다. 특히 변수 이름의 일관성 문제로 인해 오류가 발생했음을 깨닫게 되었습니다.

내가 헷갈린 지점#

  • 클래스 내에서 total_members와 유사한 이름의 변수들이 존재했는데, 이들이 어떻게 구분되고 공유되는지 명확하지 않았습니다. 특히 TeamMembers와 같은 이름이 있었음에도 불구하고 코드가 제대로 동작하지 않는 것을 보고, 이름 유사성만으로 변수가 동일하게 인식되는 것으로 오해했습니다.

시도한 코드 / 예시#

class TeamMember:
    # 클래스 변수: 모든 팀원이 공유하는 정보
    company_name = "앨리스 회사"  # 클래스 변수 예시
    total_members = 0  # 전체 팀원 수 카운트

    def __init__(self, name, role, salary):
        # 각 인스턴스의 고유 데이터
        self.name = name  # 인스턴스 변수 예시
        self.role = role
        self.salary = salary
        # 클래스 변수 업데이트
        TeamMember.total_members += 1  # 클래스 변수 직접 참조

    def introduce(self):
        print(f"[{self.company_name}] {self.role} {self.name} (연봉: {self.salary}만원)")

# 인스턴스 생성
alice = TeamMember("Alice", "시니어 개발자", 6000)
bob = TeamMember("Bob", "주니어 기획자", 3800)

# 인스턴스 메소드 호출
alice.introduce()
bob.introduce()

# 클래스 변수 출력
print(f"현재 총 팀원 수: {TeamMember.total_members}명")  # 클래스 변수 출력

결과와 해석#

코드를 실행했을 때, 각 팀원 객체가 생성될 때마다 total_members 값이 올바르게 증가하는 것을 확인했습니다. 이는 클래스 변수가 모든 인스턴스에서 공유되고 수정될 수 있음을
