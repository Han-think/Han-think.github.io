왜 썼나 오늘은 Python 프로그래밍 언어를 처음 배우는 입장에서 가장 기본적이면서도 종종 혼란을 일으키는 연산자들에 대해 깊이 이해해보고자 합니다. 특히, 다양한 데이터 타입 간의 연산자 활용과 타입 변환에 초점을 맞추어 학습 경험을 기록하고 싶었습니다. 이를 통해 비슷한 고민을 하는 초보자들이 조금 더 명확하게 개념을 파악할 수 있기를 바랍니다. 배운 것 데이터 타입과 연산자의 상호작용: Python에서는 동일한 연산자라도 사용하는 데이터 타입에 따라 결과가 달라질 수 있다는 점을 명확히 이해했습니다. 예를 들어, 정수와 실수를 함께 사용할 때 연산 결과가 항상 실수로 반환되는 이유를 알게 되었습니다. 이는 연산의 기본적인 타입 우선순위와 관련이 있습니다. 나눗셈 연산자의 결과 타입: / 연산자는 항상 실수(float)를 반환한다는 사실을 확인했습니다. 이는 두 숫자를 나눌 때 결과가 항상 실수로 처리되기 때문입니다. 반대로, 정수 나눗셈을 원한다면 // 연산자를 사용해야 함을 배웠습니다. 이 연산자는 몫을 정수로 반환합니다. 나머지 연산자 이해: % 연산자는 나머지를 반환하며, 주로 나눗셈에서의 나머지 값을 계산할 때 사용됩니다. 예를 들어, 10 % 3은 1을 반환합니다. 문자열 연산자: 문자열에서 +는 문자열 연결을 의미하며, 여러 문자열을 이어붙일 때 사용됩니다. 반면, * 연산자는 문자열을 지정된 횟수만큼 반복합니다. 예를 들어, "안녕" * 3은 "안녕안녕안녕"을 생성합니다. 헷갈린 것 타입 변환의 미묘함: 정수와 실수를 혼합 사용할 때 발생하는 타입 변환의 미묘한 부분이 여전히 명확하지 않습니다. 특히, 의도치 않은 타입 변환이 프로그램의 결과에 어떤 영향을 미칠 수 있는지에 대해 더 깊이 이해할 필요가 있습니다. 연산자 역할의 복잡성: //와 % 연산자의 역할이 비슷해 보일 수 있지만, 실제로는 서로 다른 목적을 가지고 있다는 점이 혼란스럽습니다. 구체적인 사용 사례를 통해 차이점을 명확히 파악해야겠습니다. 정리된 이해 데이터 타입의 중요성: Python에서 연산자의 결과는 사용하는 변수의 데이터 타입에 크게 영향을 받습니다. 특히, 정수와 실수 연산에서는 결과 타입이 항상 실수로 변환되는 경향이 있으므로 주의가 필요합니다. 연산자의 명확한 역할: /, //, % 연산자는 각각 다른 목적을 가지고 있으며, 이를 정확히 이해하고 사용하는 것이 중요합니다. 특히 문자열 연산자인 +와 *는 문자열 처리 시 매우 유용하지만, 올바른 사용법을 익혀야 합니다. 실습 예시 정수 나눗셈과 몫 계산: ...
