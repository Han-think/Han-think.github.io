1. 단층 퍼셉트론과 XOR 문제: 선형 분리의 한계#

무엇을 배웠나#

단층 퍼셉트론으로는 XOR 문제를 학습 횟수를 늘려도 해결할 수 없다는 점을 깨달았다. 이는 모델의 구조적 한계, 즉 선형 결정 경계만 생성할 수 있다는 점 때문이며, 단순히 학습 부족이 아닌 표현력 부족 문제가 핵심임을 알게 되었다. 앞으로는 모델의 구조를 변경하여 비선형 문제를 해결할 수 있음을 인지하고 학습해야겠다.

헷갈렸던 점#

XOR 문제를 해결하려고 학습 횟수를 계속 늘려야 한다는 생각에 갇혀서 모델의 구조적인 한계를 제대로 생각하지 못했어요. 손실이 줄어들지 않는 이유를 단순히 학습 관련 문제로만 생각하고, 모델 자체가 해결할 수 없는 문제인지 파악하지 못했습니다. 처음에는 단순히 데이터가 부족해서 그런가 싶어서 계속 노력했지만, 결국 모델의 한계를 깨닫게 됐습니다.

정리된 이해#

단층 퍼셉트론은 선형적인 분리 경계만 생성할 수 있어서 XOR과 같은 비선형 문제를 해결할 수 없다는 것을 깨달았습니다. 학습 횟수를 아무리 늘려도, 모델의 구조적인 한계 때문에 문제를 해결할 수 없고, 이를 위해 모델의 구조를 바꿔야 한다는 점을 이해했습니다. XOR 문제는 단층 퍼셉트론의 표현력 부족을 보여주는 대표적인 예시입니다.

import numpy as np
from sklearn.linear_model import LogisticRegression

# XOR 데이터셋
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
y = np.array([0, 1, 1, 0])

# 단층 모델 시도 (로지스틱 회귀로 대체)
model = LogisticRegression()
model.fit(X, y)
predictions = model.predict(X)
print("Predictions:", predictions)

2. TensorFlow 텐서 기초: 상수, 변수, 연산 이해#

무엇을 배웠나#

TensorFlow에서 텐서를 다루는 기본적인 개념을 익혔고, 특히 tf.constant와 tf.Variable의 차이점을 명확히 이해하게 되었다. 또한 요소별 곱셈과 행렬곱의 구분을 확실히 할 수 있게 되었으며, TensorFlow의 텐서 연산이 일반적인 Python 변수나 NumPy 배열과 어떻게 다른지 감을 잡을 수 있게 되었다. 이제 TensorFlow를 사용하여 모델을 구축하고 훈련하는 데 필요한 기본적인 지식을 갖추게 되었다.

헷갈렸던 점#

tf.constant와 tf.Variable의 차이, 그리고 요소별 곱셈과 행렬곱을 구분하는 것이 처음에는 매우 헷갈렸습니다. 텐서 연산이 TensorFlow 내부에서 어떻게 처리되는지, 특히 Python 변수나 NumPy 배열과의 차이가 명확하게 와닿지 않았습니다.

정리된 이해#

TensorFlow에서 텐서는 다차원 배열을 의미하며, tf.constant는 불변하는 값을, tf.Variable은 학습 과정에서 변하는 값을 저장합니다. 요소별 곱셈은 배열의 같은 위치에 있는 값들을 곱하는 반면, 행렬곱은 행렬의 차원을 고려하여 곱셈을 수행합니다. 이러한 차이점을 명확히 이해하는 것이 TensorFlow를 효과적으로 활용하는 데 중요합니다.

a = tf.constant([[1.0, 2.0], [3.0, 4.0]])

tensor_f = tf.Variable(initial_value=[0.1, -0.2, 0.3], dtype=tf.float32, name="weights")
tensor_f.assign([1.0, 2.0, 3.0])

c = a + b

3. 순전파와 Dense 층 완벽 이해: 입력 차원 설정의 비밀#

무엇을 배웠나#

Dense 층의 input_dim 옵션은 입력 특성의 개수를 지정하는 것이며, 입력층이라고 부르는 것은 첫 번째 Dense 층일 때 사용될 수 있다는 것을 알게 되었다. 순전파 과정에서 Wx + b는 아핀 변환을 나타내는 핵심적인 계산임을 명확히 이해하게 되었고, 예시 코드를 통해 실제 계산 과정을 확인할 수 있었다. 이제 Dense 층의 역할과 구조에 대한 혼란이 줄어들었고, 텐서플로우 코드를 작성할 때 input_dim 옵션을 올바르게 사용할 수 있을 것 같다.

헷갈렸던 점#

처음에는 input_dim 옵션이 입력층을 정의하는 것인지, 아니면 첫 번째 은닉층의 초기 설정을 의미하는 것인지 명확하게 이해하지 못했다. Dense 층의 역할과 구조, 특히 input_dim 옵션의 정확한 의미를 제대로 파악하고 싶었는데, 자료마다 설명이 달라서 혼란스러웠다.

정리된 이해#

Dense 층에서 input_dim은 입력 데이터의 특성 개수를 나타내는 값이며, 입력층이 아닌 첫 번째 은닉층의 초기 설정을 의미한다. input_dim을 통해 Dense 층은 입력 데이터의 형태를 파악하고, 가중치 행렬 W와 편향 b를 초기화하는 데 필요한 정보를 얻는다. 순전파 과정에서는 입력 데이터와 가중치 행렬의 곱에 편향을 더하는 아핀 변환을 수행하여 다음 층으로 데이터를 전달한다.

import tensorflow as tf

# 가중치와 편향 초기화
W = tf.Variable([[1.0, -1.0]], dtype=tf.float32)  # 가중치 행렬
b = tf.Variable([0.5], dtype=tf.float32)          # 편향 벡터
x = tf.constant([[1.0], [0.0]], dtype=tf.float32)  # 입력 데이터

# 순전파 계산
y = tf.matmul(W, x) + b  # 선형변환 + 편향 덧셈
print(y.numpy())

4. 다층 퍼셉트론의 은닉층과 활성화 함수 이해하기#

무엇을 배웠나#

처음에는 레이어를 단순히 연결선으로 생각하고, 은닉층의 개수로 딥러닝을 판단했지만, 레이어는 동일 계산 단계를 나타내는 면이고, 딥러닝은 네트워크의 깊이를 의미한다는 것을 깨달았습니다. nn.Linear 함수의 역할과 레이어의 폭(width) 개념도 명확하게 이해하게 되었습니다. 간단한 MLP 모델을 코드로 직접 작성하며 레이어와 노드 개념을 더 깊이 이해할 수 있었습니다.

헷갈렸던 점#

처음에는 레이어를 추가할 때 단순히 연결선을 더 그리는 것으로 생각했고, 은닉층이 몇 개 이상이면 딥러닝이라고 고정된 기준이 있다고 오해했습니다. 레이어와 노드의 개념이 명확하지 않아, 가중치 설정 부분도 제대로 이해하지 못했습니다.

정리된 이해#

레이어는 뉴런들의 계산 단계를 나타내는 면으로 이해하고, 딥러닝은 은닉층의 개수보다는 네트워크의 깊이가 중요하다는 것을 알게 되었다. nn.Linear 함수는 입력 노드와 출력 노드 사이의 가중치를 설정하는 역할을 하며, 레이어와 노드의 개념을 명확히 이해해야 네트워크 구조를 설계할 수 있다는 점을 깨달았다. 이제는 은닉층을 단순히 연결선을 더하는 것이 아니라, 면을 쌓아 올리는 개념으로 파악할 수 있게 되었다.

import torch

# 간단한 MLP 모델 정의

        x = self.activation(self.fc1(x))  # 은닉층 1

5. Keras 모델 학습, 초보자를 위한 핵심 가이드#

무엇을 배웠나#

Keras 모델 학습 시 TensorFlow와 PyTorch의 문법 차이 때문에 어려움을 겪었는데, Sequential 모델을 사용한 모델 정의 방식과 각 층의 파라미터 계산 방법을 명확히 이해하게 되었다. 특히 model.summary()를 통해 모델 구조를 확인하고, 각 Dense 층의 파라미터 수를 직접 계산하는 연습을 통해 모델 구성에 대한 이해도를 높일 수 있었다. 이제는 Keras 모델 학습 파이프라인을 좀 더 자신 있게 다룰 수 있게 되었다.

헷갈렸던 점#

모델을 만들 때 Sequential 모델을 사용하는 방법과 add() 메서드를 사용하는 방법이 어떻게 다른지 명확히 이해하지 못했다. 각 층의 파라미터 계산 방식도 처음에는 어떻게 계산해야 하는지 헷갈렸고, model.summary()가 어떤 정보를 제공하는지 파악하는 데 시간이 걸렸다.

정리된 이해#

Keras 모델을 만들 때 Sequential 모델을 사용하고 층을 쌓는 방식으로 구조를 정의할 수 있다는 것을 알게 되었다. model.summary()를 통해 모델의 구조와 각 층의 파라미터 수를 확인할 수 있으며, 각 Dense 층의 파라미터 수는 입력과 출력 노드 수를 기반으로 계산된다는 점을 명확히 이해했다. 이제 Keras 모델 학습 과정에 대한 기본적인 이해가 확립되었다고 생각한다.

model = tf.keras.models.Sequential([
    tf.keras.layers.Dense(10, activation="sigmoid", input_shape=(2,)),
    tf.keras.layers.Dense(10, activation="sigmoid"),
    tf.keras.layers.Dense(1, activation="sigmoid")
])

model = tf.keras.models.Sequential()
model.add(tf.keras.layers.Dense(10, activation="sigmoid", input_shape=(2,)))
model.add(tf.keras.layers.Dense(10, activation="sigmoid"))
model.add(tf.keras.layers.Dense(1, activation="sigmoid"))

model.summary()

6. 손실 지형과 초기값: 신경망 학습의 이해와 전략#

무엇을 배웠나#

신경망 학습이 단순히 전역 최솟값에 도달하는 것이 아니라, 기울기가 작아져 멈추는 상태일 수 있다는 것을 알게 되었습니다. 손실 지형의 복잡성, 초기값의 중요성, 그리고 초기화 방법이 학습 결과에 큰 영향을 미친다는 점도 이해하게 되었습니다. 앞으로는 손실 지형을 고려하여 학습 전략을 세우고, 초기값을 신중하게 설정해야겠다는 생각이 듭니다.

헷갈렸던 점#

처음에는 신경망 학습이 멈추면 전역 최솟값에 도달한 거라고 생각했는데, 기울기가 작아져서 멈춘 것일 수도 있다는 점을 몰랐어요. 조기 종료가 모델 파라미터 최적화를 의미한다고 생각했지만, 실제로는 검증 데이터셋 성능 개선이 멈추는 시점을 기준으로 학습을 중단하는 전략이라는 것을 제대로 이해하지 못했습니다. 손실 지형이 복잡해서 전역 최솟값을 찾는 것보다 지역 최솟값이나 안장점에 빠질 수도 있다는 점을 인지하지 못했습니다.

정리된 이해#

신경망 학습은 손실 함수를 최소화하는 과정을 거치지만, 손실 공간의 복잡성 때문에 항상 전역 최솟값에 도달하는 것은 아니며, 학습이 멈추는 것은 기울기가 작아진 결과일 수 있습니다. 학습 시작 시 초기 가중치 설정과 활성화 함수에 적합한 초기화 방법 선택이 학습 결과에 큰 영향을 미치며, 조기 종료는 검증 데이터셋 성능 개선이 멈추었을 때 사용하는 전략입니다. 손실 지형의 다양한 특징을 이해하는 것이 효과적인 학습을 위한 첫걸음입니다.

import torch
torch.manual_seed(42)  # 재현성을 위한 시드 설정

7. 역전파와 자동 미분: 계산 그래프를 활용한 손실 기반 가중치 조정#

무엇을 배웠나#

처음에는 계산 그래프를 단순한 로그로 생각하고 역전파를 오류 검출 과정으로 오해했지만, 이번에 계산 그래프는 연산 의존성을 나타내고 역전파는 손실에 대한 가중치 기여도를 분석하는 과정임을 이해하게 되었다. 특히 역전파는 모델의 오류 위치를 찾는 것이 아니라, 가중치 조정을 위한 방향을 제시하는 중요한 과정이라는 것을 명확히 알게 되었다. 이 내용을 바탕으로 프로젝트 내 실행 의존성을 계산 그래프와 연결하여 이해해 볼 수 있을 것 같다.

헷갈렸던 점#

처음에는 계산 그래프를 단순히 프로그램 실행 과정의 로그로 생각했고, 역전파를 모델 내 오류를 찾아주는 검출 메커니즘이라고 잘못 이해했습니다. 이러한 오해 때문에 역전파의 핵심 역할과 자동 미분과의 연관성이 잘 파악되지 않았습니다.

정리된 이해#

계산 그래프는 신경망 연산의 의존성을 나타내는 구조이며, 역전파는 이 그래프를 이용하여 각 가중치에 대한 손실의 기울기를 계산하는 과정입니다. 역전파는 오류를 찾는 것이 아니라, 손실을 줄이기 위한 가중치 조정 방향을 알려주는 중요한 단계입니다. 이 과정을 통해 모델은 데이터에 더 잘 적합하도록 학습할 수 있습니다.

# 예시: PyTorch 자동 미분
import torch

# 간단한 신경망 정의

11. 모델 훈련 및 실험 관리 기초#

무엇을 배웠나#

처음에는 역전파를 학습 과정 전체를 관장하는 것처럼 생각했지만, 실제로는 가중치 업데이트를 담당하는 한 단계라는 것을 알게 되었다. 또한, 훈련 손실 감소 외에도 검증 손실을 통해 모델의 일반화 성능을 평가하고, 이를 바탕으로 최적의 하이퍼파라미터를 탐색해야 한다는 점을 깨달았다. 이제는 학습 엔진과 제어 타워를 구분하여 모델 관리를 더욱 체계적으로 할 수 있게 되었다.

헷갈렸던 점#

역전파를 처음 배울 때는 단순히 손실 함수를 줄이는 전체 과정을 담당하는 함수라고 생각했고, 검수 로그만으로 좋은 모델을 판단할 수 있다고 믿었습니다. 훈련 손실만 감소하면 모델이 좋아지는 거라고 생각했던 저의 착각을 바로잡을 수 있었습니다.

정리된 이해#

역전파는 한 번의 학습 단계에서 가중치를 업데이트하는 역할을 하며, 전체적인 학습 과정은 엔진과 실험 관리를 담당하는 제어 타워로 구분해서 이해해야 합니다. 훈련 손실 감소 외에도 검증 손실을 통해 모델의 일반화 성능을 평가하고, 하이퍼파라미터 탐색을 통해 최적의 설정을 찾아야 좋은 모델을 선택할 수 있습니다. 이를 통해 과적합을 방지하고 모델의 성능을 향상시킬 수 있습니다.
