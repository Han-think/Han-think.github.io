1. 스코프 이해#

왜 이걸 보게 됐나#

초보 학습자로서 전역 변수의 수정 방법과 스코프 이해 부족으로 인해 UnboundLocalError 오류를 경험하며 혼란을 겪었습니다. 이를 통해 변수의 스코프와 global 키워드의 중요성을 깊이 이해하게 되었습니다.

내가 헷갈린 지점#

전역 변수 count를 함수 내에서 직접 수정하려고 했을 때 발생한 UnboundLocalError 오류 메시지와 그 원인을 이해하는 데 어려움을 겪었습니다. 특히 함수 내에서 변수를 수정할 때 global 키워드의 필요성을 깨달았습니다.

시도한 코드 / 예시#

count = 0  # 전역 변수

def increase():
    global count  # 전역 변수 수정 선언
    count += 1

increase()
print(count)  # 출력: 1

결과와 해석#

함수 increase를 호출한 후 전역 변수 count의 값이 1로 업데이트되어 출력됩니다.

정리된 이해#

스코프 이해를 통해 전역 변수와 지역 변수의 차이를 파악하고, 함수 내에서 전역 변수를 수정하려면 global 키워드를 사용해야 함을 배웠습니다. 또한 변수 이름 겹침으로 인한 shadowing 현상과 이를 피하는 방법에 대해서도 학습했습니다.

2. Shadowing#

왜 이걸 보게 됐나#

초보 학습자로서 전역 변수의 수정 방법을 이해하는 데 어려움을 겪었으며, 특히 UnboundLocalError 오류 메시지를 해석하는 데 혼란을 느꼈습니다. 이를 통해 스코프와 변수의 사용에 대한 깊은 이해가 필요함을 깨달았습니다.

내가 헷갈린 지점#

전역 변수 count가 함수 내에서 직접 수정될 수 있다고 생각했으나, 파이썬의 문법 규칙에 따라 global 키워드 없이는 오류가 발생한다는 점이 혼란스러웠습니다. 또한 매개변수와 전역 변수 간의 차이를 명확히 구분하는 데 시간이 걸렸습니다.

시도한 코드 / 예시#

count = 0  # 전역 변수

def increase():
    global count  # 전역 변수 수정을 명시
    count += 1

increase()
print(count)

결과와 해석#

출력: 1

함수 호출 후 전역 변수 count의 값이 1로 업데이트되었습니다.

정리된 이해#

변수의 스코프 이해와 global 키워드의 중요성을 깨달았습니다. 전역 변수를 함수 내에서 수정하려면 global 키워드를 사용해야 하며, 이를 통해 변수 덮어쓰기(Shadowing) 현상을 이해하고 안전한 코딩 방법을 배웠습니다.

3. global 키워드#

왜 이걸 보게 됐나#

초보자로서 전역 변수와 함수 내 변수의 상호작용에 대한 이해 부족으로 인해 UnboundLocalError를 경험하며, 전역 변수 수정 방법을 학습하게 되었습니다.

내가 헷갈린 지점#

전역 변수 count가 함수 내에서 자연스럽게 업데이트될 것으로 예상했으나, UnboundLocalError로 인해 파이썬의 스코프 규칙에 대한 혼란을 겪었습니다. 특히 global 키워드의 필요성과 shadowing 현상에 대해 명확히 이해하는 데 시간이 걸렸습니다.

시도한 코드 / 예시#

count = 0  # 전역 변수

def increase():
    global count  # 전역 변수 수정을 명시
    count += 1

increase()
print(count)

결과와 해석#

출력: 1

추가 호출 시 출력: 2

정리된 이해#

전역 변수 수정을 위해 global 키워드를 사용하는 방법을 배웠습니다. 함수 내에서 동일한 이름의 변수가 지역 변수로 shadowing 되어 전역 변수 접근 시 오류가 발생할 수 있다는 점을 이해했습니다. 이를 통해 변수 스코프 관리와 안전한 코딩 관행의 중요성을 깨달았습니다.

4. 지역 변수#

왜 이걸 보게 됐나#

지역 변수와 전역 변수의 차이를 이해하고, 함수 내에서 전역 변수를 수정하려면 global 키워드를 적절히 사용해야 하는 이유를 파악하고자 합니다. 또한 shadowing 현상이 어떻게 변수의 스코프에 영향을 미치는지 알아보고자 합니다.

내가 헷갈린 지점#

처음에는 함수 내에서 전역 변수를 직접 수정하려다 UnboundLocalError가 발생해 혼란스러웠습니다. 전역 변수와 함수 내 매개변수 간의 차이를 명확히 이해하지 못해 코드의 동작 예측이 어려웠습니다.

시도한 코드 / 예시#

# 전역 변수 초기화
global_count = 10

def modify_global():
    global global_count  # 전역 변수 수정을 명시
    global_count += 5

modify_global()
print(f'전역 변수 수정 후 값: {global_count}')  # 출력: 전역 변수 수정 후 값: 15

# shadowing 예시
global_var = 20

def shadow_example(local_var):
    local_var += 10  # 지역 변수 수정
    print(f'함수 내 local_var: {local_var}')  # 출력: 함수 내 local_var: 30
    print(f'전역 변수 global_var: {global_var}')  # 출력: 전역 변수 global_var: 20

shadow_example(global_var)

결과와 해석#

첫 번째 코드 예시에서 modify_global 함수를 호출한 후 global_count의 값이 15로 성공적으로 업데이트되었습니다. 두 번째 코드 예시에서는 함수 내에서 매개변수 local_var를 사용하여 전역 변수 global_var와 이름이 겹치지만, 전역 변수는 수정되지 않고 shadowing 현상으로 인해 함수 내에서만 local_var가 변경되었습니다.

  • 첫 번째 코드 출력: 전역 변수 수정 후 값: 15
  • 두 번째 코드 출력:
    함수 내 local_var: 30
전역 변수 global_var: 20

정리된 이해#

지역 변수와 전역 변수의 스코프 차이를 이해하고, 함수 내에서 전역 변수를 수정하려면 global 키워드를 사용해야 함을 배웠습니다. shadowing 현상으로 인해 함수 내에서 매개변수 이름이 전역 변수와 겹치면 전역 변수가 숨겨지고 지역 변수만 참조되는 것을 확인했습니다. 이러한 지식은 안전하고 예측 가능한 코드 작성에 필수적입니다.

다음에 조심할 것#

함수 내에서 전역 변수를 수정하려면 반드시 global 키워드를 사용해야 하며, 이를 무시하면 UnboundLocalError가 발생할 수 있다는 점에 주의해야 합니다. 또한, 변수 이름 겹침으로 인한 shadowing 현상은 의도치 않은 코드 동작을 초래할 수 있습니다.
