1. 터미널 명령어 기초#

왜 이걸 보게 됐나#

터미널 명령어와 편집기 사용법을 이해하여 시스템 관리와 문서 작성 효율성을 높이기 위함

내가 헷갈린 지점#

> 와 >> 의 정확한 차이와 vi 편집 모드 전환 방법에 대한 혼란

시도한 코드 / 예시#

# 폴더 생성 예시
mkdir -p my_folder/sub_folder

# 파일 생성 및 내용 추가
touch new_file.txt
echo "첫 번째 내용" > new_file.txt
echo "두 번째 내용" >> new_file.txt
cat new_file.txt

# vi 편집기 사용 예시
vi new_file.txt
# 삽입 모드 진입: i
# 변경 후 저장 및 종료: ESC → :wq → Enter

결과와 해석#

폴더 my_folder 내에 sub_folder가 생성되고, new_file.txt 파일에는 첫 번째 내용이 새로 쓰이고, 두 번째 내용이 이어붙여진다. vi 편집기에서는 파일 내용을 수정하고 저장 후 종료한다.

정리된 이해#

이 섹션은 Git Bash를 통해 Linux CLI 기초를 배우고, Markdown 파일 작성 시 >와 >>의 차이를 이해하며, vi 편집기의 기본 사용법을 익혀 터미널 환경에서 효율적으로 작업하는 방법을 다룬다.

2. Markdown 문법#

왜 이걸 보게 됐나#

마크다운 문법을 통해 터미널 명령어와 텍스트 편집기 사용법을 학습자 친화적으로 설명하고 이해를 돕기 위해 실제 사용 사례와 비유를 활용한다.

내가 헷갈린 지점#

학습자들이 흔히 혼동하는 마크다운 기호와 vi 편집기의 모드 사용법에 초점을 맞추어 명확한 예시와 해결 방법을 제공한다.

시도한 코드 / 예시#

# 폴더 구조 만들기
mkdir -p test/docs/linux

# 파일 만들고 내용 쓰기
touch memo.md
echo "첫 번째 줄" > memo.md
echo "두 번째 줄" >> memo.md
cat memo.md

# vi로 파일 열기 및 저장 후 종료
vi memo.md
# i로 삽입 모드 진입 후 내용 입력
# ESC로 일반 모드로 이동
:wq

결과와 해석#

학습자는 마크다운의 >와 >> 차이와 #의 문맥별 의미를 이해하고, vi 편집기의 기본적인 사용법을 익혀 터미널 작업 효율성을 높일 수 있다. 또한, 실제 명령어 실행 예시를 통해 이론을 실무에 적용하는 방법을 배운다.

정리된 이해#

이 노트는 Git Bash와 Linux CLI 기초, 마크다운 문법, vi 편집기 사용법, 그리고 Hugo를 활용한 블로그 구축 과정을 학습자 중심으로 다룬다. 특히 혼동하기 쉬운 마크다운 기호와 vi 모드 사용법에 대한 명확한 설명과 실제 명령어 예시를 통해 실용적인 이해를 돕는다.

3. vi 편집 모드#

왜 이걸 보게 됐나#

이해를 돕기 위해 vi 편집 모드와 관련된 핵심 개념과 실제 사용 사례를 설명하고자 함.

내가 헷갈린 지점#

초보자들이 vi 편집 모드에서 탈출하는 방법과 파일을 다루는 기본 명령어에 대해 혼란스러워하는 것을 반영하고자 함.

시도한 코드 / 예시#

# vi 편집 모드 예시
vi memo.md
# 삽입 모드 진입
i
# 텍스트 입력 후
ESC
# 일반 모드로 전환
:wq
# 파일 저장 후 종료

결과와 해석#

사용자는 vi 편집기를 통해 memo.md 파일을 열고 텍스트를 입력한 후, ESC 키를 눌러 일반 모드로 전환하고 :wq 명령어를 통해 변경 사항을 저장하고 편집기를 종료할 수 있게 됨.

정리된 이해#

이 섹션은 vi 편집 모드의 기본 사용법을 강조하며, 특히 초보자들이 INSERT 모드로 진입하고, 파일을 편집한 후 안전하게 종료하는 방법을 학습하도록 돕는다. 코드 예시는 실제 터미널에서 실행 가능한 명령어를 제공하여 실용적인 이해를 돕는다.

4. Hugo 블로그 구축#

왜 이걸 보게 됐나#

오늘의 학습은 Hugo 블로그를 구축하기 위한 기초 기술들을 익혔다. Git Bash를 통해 터미널 환경에 익숙해지고, Markdown과 vi 편집기를 활용해 콘텐츠를 작성하는 방법을 배웠으며, 이를 통해 개인 학습 로그를 효과적으로 관리하고 공개할 수 있는 Hugo 블로그 구조를 이해하게 되었다.

내가 헷갈린 지점#

처음에는 >와 >>의 차이와 #의 문맥에 따른 의미 차이로 인해 혼란이 있었으나, 실제 사용 예시를 통해 개념을 명확히 이해할 수 있었다. 또한, vi 편집기에서의 탈출 방법과 문자열 인용 부호의 차이도 처음에는 어려웠으나, 연습을 통해 익숙해질 수 있었다.

시도한 코드 / 예시#

# 폴더 구조 생성
mkdir -p myblog/docs

# 빈 파일 생성 및 내용 추가
touch post.md
echo "첫 번째 포스트" > post.md
echo "두 번째 포스트" >> post.md

cat post.md

# vi 편집기로 파일 열기 및 저장 후 종료
vi post.md
# 삽입 모드 진입: i
# 내용 수정 후
ESC
:wq

결과와 해석#

위 코드를 실행하면 post.md 파일이 생성되고 첫 번째 줄과 두 번째 줄이 추가된 내용을 확인할 수 있다. 또한, vi 편집기를 통해 파일을 열고 내용을 수정한 후 저장 없이 종료하거나 저장하고 종료하는 방법을 실습할 수 있다.

정리된 이해#

오늘의 학습은 Hugo 블로그 구축을 위한 핵심 기술들을 다루었다. Git Bash를 통해 터미널 환경에 익숙해지고, Markdown을 활용한 콘텐츠 작성과 vi 편집기를 통한 파일 관리 방법을 익혔다. 이러한 기술들은 개인 학습 로그를 효과적으로 관리하고 공개하는 Hugo 블로그 구축에 필수적이다. 혼란스러웠던 개념들은 실제 사용 예시를 통해 명확히 이해할 수 있었으며, 이를 통해 블로그 구축의 첫걸음을 내딛을 수 있는 기반이 마련되었다.
