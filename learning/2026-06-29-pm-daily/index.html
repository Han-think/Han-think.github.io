1. Seaborn 시각화: regplot, countplot, jointplot 활용 가이드#

무엇을 배웠나#

Seaborn 시각화를 처음 배울 때 함수 이름과 인자 역할을 제대로 이해하지 못했던 점을 파악하고, 기본적인 Seaborn 함수(regplot, countplot, jointplot)들의 기능과 사용법을 정리했습니다. 특히 데이터 준비 순서가 중요하다는 점과 각 인자(data, x, y, hue)가 그래프에 어떤 영향을 미치는지 명확히 이해하게 되었습니다. 이제 Seaborn을 사용하여 데이터 시각화하는 과정이 훨씬 수월해질 것 같습니다.

헷갈렸던 점#

Seaborn 함수를 사용할 때 어떤 인자가 어떤 역할을 하는지 명확히 이해하지 못해서, 그래프가 제대로 나오지 않을 때 무엇을 잘못했는지 파악하기 어려웠습니다. 또한 데이터프레임 준비 단계를 놓치거나 순서를 바꾸면 에러가 나서, 데이터 준비가 얼마나 중요한지 깨닫지 못했습니다.

정리된 이해#

Seaborn은 데이터 시각화를 위한 라이브러리인데, 함수와 인자를 제대로 이해해야 원하는 그래프를 그릴 수 있다. 데이터프레임을 먼저 준비하고, sns 함수 내에서 data, x, y, hue 등의 인자를 올바르게 지정하는 것이 중요하다. 다양한 예제를 통해 인자들이 실제 그래프에 어떤 영향을 미치는지 확인하며 실력을 키워야겠다.

import seaborn as sns
import matplotlib.pyplot as plt

# 회귀선과 산점도 그리기
sns.regplot(data=tips, x="total_bill", y="tip")
plt.show()

# 범주별 카운트 막대그래프
sns.countplot(data=titanic, x="class", hue="survived")
plt.show()

# 두 변수의 관계와 분포 시각화
sns.jointplot(data=tips, x="total_bill", y="tip", kind="reg")
plt.show()

2. 데이터 탐색: 상관관계 시각화와 회귀 분석 가정 점검#

무엇을 배웠나#

데이터 분석 전에 EDA를 통해 데이터를 자세히 살펴봐야 한다는 것을 깨달았습니다. 회귀선은 데이터 패턴을 설명하는 데 유용하지만, 항상 정확한 정보를 제공하는 것은 아니며, 회귀분석의 여러 가정들을 충족해야 신뢰할 수 있는 분석 결과를 얻을 수 있다는 점을 알게 되었습니다. 특히 데이터 시각화 결과만으로 성급하게 결론을 내리기보다는 데이터의 특징을 면밀히 파악하는 것이 중요하다는 것을 배웠습니다.

헷갈렸던 점#

산점도와 회귀선만 보고 바로 분석 결과를 믿음직하게 받아들이기 어려웠고, 회귀선이 항상 데이터 패턴을 완벽하게 반영하는 것은 아니라는 점이 헷갈렸습니다. 특히 데이터가 곡선 형태를 띄거나 비선형적인 관계를 보일 때 회귀선이 제대로 의미하는 바가 있을지 의문이었습니다. 강의에서 언급된 회귀분석 가정들이 왜 중요한지, 그리고 어떻게 확인해야 하는지 명확하게 이해하지 못했습니다.

정리된 이해#

EDA는 모델링 전에 데이터를 파악하는 중요한 과정이며, 시각화된 회귀선은 데이터 패턴을 완벽하게 반영하지 못할 수 있다는 점을 인지해야 합니다. 선형 회귀 분석은 몇 가지 중요한 가정을 기반으로 하므로, 이 가정들이 충족되지 않으면 분석 결과의 신뢰도가 떨어질 수 있습니다. 따라서 데이터 분석 시 시각화 결과에만 의존하지 않고, 데이터의 특성을 면밀히 검토해야 합니다.

# 예시: 산점도 및 회귀선 시각화 (matplotlib 사용)
import matplotlib.pyplot as plt
import numpy as np
from scipy import stats

# 간단한 예시 데이터 생성
age = np.array([20, 25, 30, 35, 40, 22, 28, 24])
survival_rate = np.array([1, 0, 1, 0, 1, 1, 0, 0])

# 산점도 그리기
plt.scatter(age, survival_rate)

# 최소제곱법으로 회귀선 계산
slope, intercept, r_value, p_value, std_err = stats.linregress(age, survival_rate)
line = slope*age + intercept

# 회귀선 그리기
plt.plot(age, line)

plt.xlabel("Age")
plt.ylabel("Survival Rate")
plt.title("Age vs. Survival Rate")
plt.show()

4. 로지스틱 회귀 해석: p-value와 오즈비 완전 정복#

무엇을 배웠나#

로지스틱 회귀 분석 시 p-value를 변수의 통계적 유의미성을 판단하는 지표로 해석해야 하지만, 유의성이 있다고 해서 반드시 실제 영향력이 크다는 의미는 아니라는 점을 알게 되었다. 또한 로지스틱 회귀 계수는 확률을 직접적으로 나타내지 않고 로그 오즈를 기반으로 하므로, 오즈비로 변환하여 해석해야 함을 이해하게 되었다. 앞으로는 통계적 유의성과 실제 효과 간의 차이를 고려하여 로지스틱 회귀 결과를 분석할 계획이다.

헷갈렸던 점#

처음 로지스틱 회귀 분석을 할 때 p-value를 단순히 0.05 넘으면 변수가 중요하지 않다고 생각해서 해석에 어려움을 겪었습니다. 계수 값 자체를 확률 변화량으로 직관적으로 해석하려고 시도하다 보니 모델의 기본 구조를 제대로 이해하지 못하고 있었습니다. 이러한 이해 부족으로 인해 결과 해석에 오류가 발생할까 봐 걱정했습니다.

정리된 이해#

로지스틱 회귀 분석 시 p-value가 0.05보다 작다고 해서 반드시 변수가 큰 영향을 미친다고 단정할 수 없으며, p-value는 단순히 통계적 유의성이 부족함을 의미할 수 있습니다. 로지스틱 회귀 계수는 직접적인 확률 변화량을 나타내지 않고 log-odds를 나타내므로, 오즈비(Odds Ratio)를 계산하여 변수가 결과에 미치는 영향을 해석해야 합니다. 이러한 이해를 바탕으로 모델 해석의 정확도를 높일 수 있습니다.

무엇을 배웠나#

학습된 모델을 새로운 데이터에 적용하여 예측값을 얻고, 이 예측값과 실제 정답을 비교하여 모델의 성능을 평가하는 과정을 이해했습니다. 정확도 외에도 다양한 평가 지표들을 활용하여 데이터의 특성을 고려한 균형 잡힌 성능 판단이 중요하다는 점을 알게 되었습니다. 특히 불균형 데이터셋에서는 정밀도, 재현율, F1-score 등이 정확도보다 유용한 지표가 될 수 있습니다.
