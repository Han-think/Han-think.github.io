1. 함수 구조#

왜 이걸 보게 됐나#

함수를 제대로 이해해야 코드를 좀 더 효율적이고 재사용 가능하게 만들 수 있다는 것을 알게 되었어. 처음에는 단순히 코드를 실행시키는 것만 중요하다고 생각했지만, 함수를 사용하면 반복되는 코드를 줄이고, 더 복잡한 문제도 해결할 수 있다는 것을 깨달았어. 함수를 제대로 다루는 건 프로그래밍 실력을 키우는 데 필수적이라고 생각해서 학습하게 되었어.

내가 헷갈린 지점#

처음에는 print() 함수를 사용하면 결과가 바로 보이니까 return이 필요 없는 줄 알았습니다. 함수의 역할이 단순히 화면에 보여주는 것인 줄 착각해서 return을 빼먹고 코드를 작성했었죠. 매개변수와 인자를 구분하는 것 역시 익숙하지 않아서, 함수를 만들 때나 호출할 때 어떤 것을 변수 이름으로 쓰고 어떤 것을 실제 값으로 써야 하는지 헷갈렸습니다.

시도한 코드 / 예시#

def calculate_area(length, width):
    """사각형의 넓이 계산 함수"""
    area = length * width
    return area  # 결과 반환

결과와 해석#

calculate_area 함수는 길이와 너비를 매개변수로 받아 사각형의 넓이를 계산하여 반환하는 역할을 한다. 함수를 호출하면서 side_length와 side_width를 인자로 전달하면, 이 값들이 함수의 length와 width 매개변수에 각각 할당된다. 최종적으로 함수는 계산된 넓이 15를 return하고, 이 결과는 result 변수에 저장되어 화면에 출력된다.

정리된 이해#

함수는 def 키워드로 정의되며, 매개변수를 통해 외부에서 값을 받아 처리하고, return 키워드를 통해 결과를 반환한다. return이 없으면 None이 반환되며, print()는 화면에 결과를 출력하는 역할로 return과는 구별된다. 이 이해를 바탕으로 함수를 사용하면 코드의 재사용성을 높이고, 복잡한 작업을 효율적으로 처리할 수 있다.

2. print() 함수#

왜 이걸 보게 됐나#

처음 프로그래밍을 배우면서 화면에 결과가 어떻게 보여지는지, 그리고 함수가 어떻게 작동하는지 이해하기 위해 print() 함수를 접하게 됐어. 함수를 만들고 그 결과를 확인하는 가장 기본적인 방법이기도 했고, 이후 return과 함께 사용하면서 함수 내부의 연산 결과가 어떻게 활용되는지 파악하는 데 중요한 역할을 했지. print() 함수를 통해 결과값을 보면서 코드가 제대로 작동하는지 검증하고, 디버깅 과정에서도 유용하게 사용하고 있어.

내가 헷갈린 지점#

처음에는 print() 함수를 사용하면 화면에 바로 결과가 보여서, 함수가 끝난 후에도 뭔가 계속 남는 것처럼 느껴졌어. 그래서 return 값이 필요 없는 단순한 결과 출력에는 print()만으로도 충분하다고 생각했지. 하지만 함수 결과를 다른 곳에서 사용하려면 print()만으로는 안 된다는 걸 깨닫고 return의 필요성을 알게 되었어.

시도한 코드 / 예시#

def greet(name):
    greeting = f"안녕하세요, {name}님!"
    print(greeting)  # 안녕하세요, 영희님!
    return greeting

결과와 해석#

print() 함수는 함수 내부에서 계산된 결과를 화면에 바로 보여주는 역할을 합니다. 예를 들어, print(2 + 0)을 실행하면 화면에 2가 출력됩니다. 이 함수를 사용하면 중간 계산 결과를 확인하기 용이하며, 디버깅 과정에서 유용하게 활용할 수 있습니다.

정리된 이해#

print() 함수는 함수 내부에서 계산된 결과를 즉시 화면에 보여주어 개발자가 과정을 확인하는 데 도움을 주는 도구입니다. 이 함수를 사용하면 함수의 진행 상황이나 중간 결과 값을 바로 확인할 수 있어 디버깅 과정에서 유용합니다. 하지만 print()는 단순히 화면에 결과를 출력하는 역할만 수행하며, 함수 호출 결과를 외부로 전달하는 기능은 없습니다.

3. return 문#

왜 이걸 보게 됐나#

처음에는 함수 안에서 print()만 사용해서 결과를 화면에 띄우는 데 집중했더니, 함수가 실제로 어떤 값을 내놓는지, 그 값을 다른 곳에서 활용하려면 어떻게 해야 하는지 막막했어요. 그래서 함수가 계산한 결과를 외부로 전달하는 return 문을 배우게 됐고, 이제 함수를 좀 더 유연하게 활용할 수 있게 됐죠.

내가 헷갈린 지점#

처음에는 return 문이 단순히 함수 내에서 값을 저장하는 것인 줄 알았습니다. 그래서 return을 사용하지 않아도 함수가 정상적으로 실행될 거라는 잘못된 생각을 했습니다. 또, return이 있으면 함수가 그 시점에서 종료된다고 생각해서, 복잡한 로직을 return을 통해 중간중간 끊어 처리해야 하는 줄 오해했습니다.

시도한 코드 / 예시#

def calculate_area(length, width):
    """사각형의 넓이 계산 함수"""
    area = length * width
    return area  # 결과 반환

결과와 해석#

함수 내에서 return 5 코드를 실행하면, 함수는 5라는 값을 반환하고 프로그램은 다음 줄로 진행합니다. 반환된 값은 변수에 할당하거나, 다른 함수의 인자로 사용하거나, 출력할 수 있습니다. return 문이 없으면 함수는 None을 반환하므로, 결과 활용에 주의해야 합니다.

정리된 이해#

return 문은 함수 내부에서 계산된 결과를 함수를 호출한 곳으로 다시 보내주는 역할을 합니다. 이 덕분에 함수가 처리한 결과를 변수에 저장하거나 다른 함수의 인자로 넘겨서 활용할 수 있습니다. return 문이 없다면 함수는 아무런 결과를 남기지 않고 None 값을 반환하게 됩니다.

4. 매개변수 (Parameter)#

왜 이걸 보게 됐나#

함수를 만들고 사용할 때, 어떤 값을 받아서 어떻게 처리할지 정의해야 했는데, 이 때 변수 이름들이 필요했어. 마치 레시피에서 재료 이름과 양을 적는 것처럼, 함수도 입력값을 받기 위한 이름(매개변수)을 지정해야 했지. 처음에는 그냥 변수라고 생각했지만, 함수를 만들 때만 쓰이는 특별한 변수라는 것을 알게 됐어.

내가 헷갈린 지점#

처음에 매개변수가 함수를 정의할 때 그냥 변수 이름이라고 생각했는데, 함수를 사용할 때는 이 변수에 실제 값을 넣어줘야 한다는 점이 헷갈렸습니다. 마치 집을 짓기 전에 설계도에 변수 이름이 적혀있는 것처럼, 함수를 정의할 때 매개변수는 그 자리에 어떤 값을 넣을지 미리 약속하는 것 같았습니다. 그런데 실제 집을 짓기 위해서는 설계도에 적힌 변수 이름 대신 구체적인 재료를 넣어줘야 하는 것처럼, 함수를 호출할 때는 이 매개변수에 실제 값을 전달해야 한다는 점이 처음에는 이해가 잘 안 되었습니다.

시도한 코드 / 예시#

def greet(name):
    """인사를 하는 함수"""
    print(f"안녕하세요, {name}!")

greet("Alice") # 매개변수 'name'에 인자 'Alice' 전달

결과와 해석#

함수 정의 시 괄호 안에 나열되는 변수들이 매개변수인데, def calculate_sum(x, y):에서 x와 y가 바로 매개변수야. 함수를 호출할 때, calculate_sum(10, 5)처럼 실제 값을 넣어주는데 이 실제 값들이 인자에 해당해. 인자들을 매개변수에 맞게 전달해야 함수가 제대로 동작하고 결과를 계산할 수 있어.

정리된 이해#

함수는 특정 작업을 수행하는 코드 묶음이고, 매개변수는 함수가 수행하는 작업을 위해 필요한 입력값을 받는 변수 이름이라고 이해했습니다. 함수를 만들 때 정의하는 변수가 매개변수이며, 함수를 실제로 사용할 때 전달하는 값을 인자라고 부릅니다. 매개변수는 함수의 기능 구현에 필수적인 정보를 담고 있습니다.

총평#

오늘 전체에서 배운 것#

함수 내 print()는 화면 출력용이고 return은 함수 결과를 외부로 전달하는 역할을 한다는 것을 확실히 이해하게 되었어. 매개변수와 인자가 어떻게 연결되는지, 그리고 함수 호출 시 정확한 개수와 순서가 중요하다는 것도 명확해졌어. 오늘 배운 내용을 바탕으로 더 복잡한 함수를 만들어볼 수 있을 것 같아.

다음에 조심할 것#

print()와 return의 역할을 헷갈리지 않도록 주의하고, 함수 호출 시 매개변수의 개수와 인자의 정확한 일치를 확인해야겠다. 특히, 함수 내에서 처리된 결과를 재사용하거나 다음 단계로 넘겨줄 때는 return을 확실히 사용해야 한다.

다음 복습 주제#

함수 내에서 다른 함수를 호출하는 연쇄 호출 방식에 대한 좀 더 다양한 예제와 함께 이해도를 높여야겠다. 또한, 가독성이 좋은 코드를 만들기 위해 함수의 이름 짓는 규칙이나 스타일 가이드를 학습하고 실천해야겠다.
