Python 함수 이해하기: 초보자를 위한 가이드

Python 함수의 기본 개념과 `print()`, `return`의 차이를 이해하는 데 초점을 맞춘 초보자 가이드.
2026년 6월 1일 · 6 min

본문#

왜 썼나?#

함수는 프로그래밍에서 핵심적인 구성 요소로, 코드의 재사용성과 가독성을 크게 향상시킵니다. 특히 초보자에게는 함수를 통해 복잡한 로직을 단순화하고 이해하는 데 큰 도움이 됩니다. 이번 글에서는 Python 함수의 기본 구조와 특히 print()와 return 키워드의 차이점을 탐구해 보겠습니다.

배운 것#

  • 함수 정의: Python에서 함수는 def 키워드로 시작하며, 이름을 지정하고 매개변수를 정의합니다. 예를 들어, def formula_with_return(x, y):와 같이 작성할 수 있습니다.
  • 매개변수와 인자: 함수 호출 시 전달되는 값들이 매개변수이고, 실제 함수 호출 시 사용되는 값들이 인자입니다. 예를 들어, formula_with_return(3, 5)에서 3과 5는 인자입니다.
  • print()의 역할: print()는 함수 내부에서 결과를 화면에 출력하는 데 사용됩니다. 그러나 이 출력은 함수 외부로 전달되지 않습니다.
  • return의 중요성: return 키워드는 함수가 처리한 결과를 외부로 반환합니다. 이를 통해 함수의 결과를 변수에 저장하거나 다른 함수에 전달할 수 있습니다. 예를 들어, return x + y와 같이 사용하면 함수 호출 시 결과를 받을 수 있습니다.

헷갈리는 것#

  • print()와 return의 혼동: 가장 큰 혼란은 함수 내부에서 print()를 사용하면 결과가 즉시 출력되지만, return 없이는 함수 외부에서 그 결과를 직접 사용할 수 없다는 점입니다. 위에서 언급한 예제 코드는 이를 명확히 보여줍니다:

    def formula_with_return(x,

왜 썼나#

이 글을 작성한 이유는 프로그래밍 초보자들이 흔히 겪는 개념적 혼란을 해소하고, 함수의 핵심 구성 요소인 매개변수와 반환값에 대한 명확한 이해를 돕기 위함입니다. 특히 Python에서 이러한 개념을 어떻게 적용하는지 실제 예시를 통해 설명함으로써 실무에서의 적용 능력을 향상시키는 데 중점을 두었습니다.

배운 것#

  • 함수의 구조: 함수 정의와 호출의 기본적인 구조를 복습하였습니다. 특히, 함수 내에서 어떤 역할을 수행하는 매개변수와 반환값의 중요성을 깨달았습니다.
  • 매개변수와 인자의 차이: 함수 정의 시 사용되는 매개변수와 함수 호출 시 전달되는 인자의 구분을 명확히 이해하였습니다. 이는 코드의 가독성과 유지보수성을 크게 향상시킵니다.
  • print()와 return의 역할: 함수 내에서 결과를 출력하는 print()와 함수 결과를 외부로 반환하는 return의 차이점을 구체적으로 파악하였습니다.

헷갈릴린 것#

학습 과정에서 가장 혼란스러웠던 부분은 다음과 같습니다:

  • print()와 return의 역할 혼동: 함수 내에서 계산된 값을 출력하는 것과 반환하는 것 사이의 구분이 명확하지 않았습니다. 특히, return 문을 사용하지 않으면 함수 외부로 결과가 전달되지 않는다는 점에서 혼란이 있었습니다.
  • 매개변수와 인자의 혼동: 함수 정의 시 사용되는 용어와 함수 호출 시 실제로 전달되는 값 사이의 차이를 명확히 이해하는 데 어려움이 있었습니다.

  • 매개변수 불일치 오류 처리: 함수 호출 시 필요한 매개변수 개수와 타입을 정확히 맞추는 것이 중요합니다. 잘못된 인자 개수나 타입은 오류를 발생시킵니다.

왜 썼나#

함수를 효과적으로 사용하기 위해서는 그 안에서 작용하는 기본 구성 요소들에 대한 명확한 이해가 필수적입니다. 특히 매개변수와 인자는 함수의 동작 방식을 결정하는 중요한 요소들입니다. 이들 개념을 정확히 파악함으로써 코드의 가독성을 높이고 문제 해결 능력을 향상시킬 수 있습니다.

배운 것#

  • 매개변수(Parameters): 함수 정의 시점에 함수의 입력 변수들을 정의하는 역할을 합니다. 예를 들어, def greet(name):에서 name은 함수 정의 시 사용되는 매개변수입니다. 매개변수는 함수가 호출될 때 값을 대입할 수 있는 플레이스홀더 역할을 합니다.

  • 인자(Arguments): 함수를 호출할 때 실제 값들이 매개변수에 대입되는 순간을 지칭합니다. 예를 들어, greet("김철수")에서 "김철수"가 name 매개변수에 대입되는 값이 바로 인자입니다. 인자는 함수 실행 시 구체적인 데이터를 제공하여 함수가 실제 작업을 수행할 수 있게 합니다.

헷갈릴린 것#

  • 매개변수와 인자의 혼동: 가장 흔한 오해 중 하나는 매개변수와 인자를 혼동하는 것입니다. 쉽게 말해, 함수를 정의할 때 설정되는 변수 이름(매개변수)과 실제 호출 시 값을 넣어주는 데이터(인자)의 차이를 명확히 구분하는 것이 중요합니다. 예를 들어, 다음 코드를 보면 이해가 쉬울 것입니다: 
    def calculate_area(length, width):  # 매개변수
    area = length * width
    return area

print(result)  # 출력: 50
