1. 개념: enumerate() 함수의 이해#

왜 이걸 보게 됐나#

프로그래밍에서 데이터의 순서를 나타내는 인덱스를 함께 다루는 경우가 많습니다. enumerate() 함수는 이러한 상황에서 코드를 간결하고 읽기 쉽게 만드는 데 유용하다고 느껴서 학습하게 되었습니다.

내가 헷갈린 지점#

  • season 리스트를 사용할 때 season 변수를 반복하면서 전체 seasons 리스트를 출력하는 오류를 겪었습니다. 리스트 이름과 요소의 혼동으로 인해 발생한 문제였습니다.
  • idx + 1과 enumerate(..., start=1)을 사용했을 때 인덱스 시작점이 어떻게 달라지는지 명확히 이해하지 못했습니다.

시도한 코드 / 예시#

seasons = ['봄', '여름', '가을', '겨울']

# 오류 예시: seasons 리스트 자체를 출력하려고 함
for season in seasons:
    print(season)  # 예상대로 작동하지만, 인덱스를 함께 출력하려는 의도와 맞지 않음

# 수정된 예시: enumerate() 함수를 사용하여 인덱스와 값 함께 출력
# 기본 시작 인덱스 0
for idx, season in enumerate(seasons):
    print(f"  [{idx}] {season}")

# 출력 예시:
#   [0] 봄
#   [1] 여름
#   [2] 가을
#   [3] 겨울

# 시작 인덱스 1로 설정
for idx, season in enumerate(seasons, start=1):
    print(f"  {idx}번 계절: {season}")

# 출력 예시:
#   1번 계절: 봄
#   2번 계절: 여름
#   3번 계절: 가을
#   4번 계절: 겨울
