1. enumerate() 함수#

왜 이걸 보게 됐나#

리스트를 순회하면서 각 요소의 위치를 함께 알아야 할 때, 인덱스를 직접 관리하는 코드를 작성하는 게 번거로웠어요. enumerate() 함수를 배우게 된 건, 이러한 번거로움을 해결하고 코드를 더 간결하게 만들어 줄 수 있는 유용한 도구라는 이야기를 듣고, 실제로 사용해 보면서 얼마나 효율적인지 체감하기 위해서였습니다.

내가 헷갈린 지점#

처음에는 enumerate()를 사용할 때 리스트 이름과 리스트 안의 요소들을 구분하는 데 어려움을 느껴서, season이라고 변수를 선언했는데 seasons 전체 리스트를 반복하려고 실수했어. 또, 인덱스를 1부터 시작하는 방법을 idx + 1로 할지, start=1로 할지 고민했는데, 둘의 차이점을 명확하게 이해하지 못해서 헷갈렸어.

시도한 코드 / 예시#

teams = ['개발팀', '기획팀', '영업팀', '분석팀']

# 1부터 시작
for idx, team in enumerate(teams, start=1):
    print(f"  {idx}번 팀: {team}")

결과와 해석#

enumerate() 함수는 리스트의 각 요소와 함께 해당 요소의 인덱스를 쉽게 가져오도록 해줘서 반복문에서 유용하게 쓰일 수 있어. 시작 인덱스를 0이 아닌 다른 숫자로 설정할 수 있다는 점도 이해했어. 코드를 통해 인덱스와 값을 함께 출력하고, 이를 활용해서 성적 순위표 같은 결과물을 만들 수 있다는 것을 알게 되었어.

정리된 이해#

enumerate() 함수는 반복문에서 요소의 인덱스와 값을 동시에 얻어와서 사용할 수 있게 해주는 함수야. 기본적으로 인덱스는 0부터 시작하지만 start 매개변수를 사용하면 원하는 숫자부터 시작하도록 조정할 수 있어. idx + 1을 사용하는 방법과 start=1을 사용하는 방법 모두 동일한 결과를 낼 수 있어.

2. 인덱스 조정#

왜 이걸 보게 됐나#

처음에는 enumerate() 함수를 사용하면서 리스트 이름과 요소 이름을 헷갈려버려서 코드가 제대로 작동하지 않았어. 특히 인덱스를 1부터 시작하도록 만들 때 idx + 1를 사용하는 방법과 start=1을 사용하는 방법이 뭐가 다른지 명확히 이해하지 못하고 답답했어. 그래서 이 개념을 배우게 된 거야.

내가 헷갈린 지점#

처음에 enumerate를 사용할 때, 리스트 이름과 리스트 내 요소들을 구분하는 게 헷갈렸어요. season이라고 적었는데 왜 seasons 리스트 전체를 출력하려는지 이해가 안 돼서요. 그리고 인덱스를 1부터 시작하는 방법을 idx + 1과 start=1으로 표현할 수 있다는 건 알았지만, 두 방식의 차이를 명확히 파악하지 못해서 언제 어떤 방법을 써야 할지 헷갈렸습니다.

시도한 코드 / 예시#

# 1부터 시작
teams = ['개발팀', '기획팀', '영업팀', '분석팀']
for idx, team in enumerate(teams, start=1):
    print(f"  {idx}번 팀: {team}")
# 출력 예시:
#  1번 팀: 개발팀
#  2번 팀: 기획팀
#  3번 팀: 영업팀
#  4번 팀: 분석팀

결과와 해석#

enumerate() 함수를 사용하면서 인덱스가 0부터 시작하는 점이 헷갈렸는데, start=1 옵션을 사용하면 인덱스를 1부터 시작하도록 쉽게 조정할 수 있어서 편리하네요. idx + 1을 사용하는 방법도 가능하지만, start=1이 더 간결하고 가독성이 좋아서 앞으로는 이걸로 사용하는 게 좋겠어요.

정리된 이해#

enumerate() 함수를 사용할 때 start 매개변수를 활용하거나 인덱스에 1을 더하면 반복문의 시작 인덱스를 0이 아닌 다른 숫자로 설정할 수 있습니다. 두 방법 모두 결과는 동일하지만, start 매개변수를 사용하는 것이 코드를 더 간결하고 명확하게 만들어 줍니다.

3. 리스트 이름 구분#

왜 이걸 보게 됐나#

코딩 연습을 하다가 리스트 변수 이름과 리스트 안의 요소 이름이 헷갈려서 오류가 계속 발생했어. 특히 반복문에서 season과 seasons을 혼동해서 코드가 제대로 작동하지 않았던 경험 때문에, 리스트 이름과 요소 구분을 확실히 해야겠다는 생각을 하게 됐어.

내가 헷갈린 지점#

처음에는 리스트 자체의 이름과 리스트 안에 있는 요소들을 헷갈렸어. season이라고 적어야 할지, seasons라고 적어야 할지 계속 혼동해서 코드 실행 시 오류가 발생했었지. 특히 반복문에서 리스트 이름을 잘못 사용해서 전체 리스트를 출력하려는 실수를 저질렀어.

시도한 코드 / 예시#

seasons = ["봄", "여름", "가을", "겨울"]

for season in seasons:
    print(season)

결과와 해석#

리스트 이름을 변수명으로 사용하는 과정에서 season과 seasons를 혼동하여, 반복문에서 season이라는 변수를 사용하면서 전체 리스트 seasons를 참조하려는 실수를 저질렀습니다. seasons 리스트를 제대로 사용하려면 변수 이름을 정확히 일치시켜야 한다는 점을 깨달았습니다.

정리된 이해#

리스트를 사용할 때 리스트 자체의 이름과 리스트 안에 있는 요소들을 헷갈리지 않도록 주의해야 한다. 예를 들어, 리스트의 이름이 seasons라면, season이라고 해서 리스트의 요소를 직접 사용하는 것이 아니라 seasons라는 리스트 전체를 활용해야 한다. 이 점을 명확히 구분해야 예상치 못한 오류를 방지할 수 있다.

4. 순위표 생성#

왜 이걸 보게 됐나#

이번에 배운 순위표 생성은 데이터가 여러 개 있을 때, 그 중요도나 성과를 한눈에 파악할 수 있도록 정렬하는 방법을 익히기 위해서야. 단순히 점수를 나열하는 것보다 순위를 매겨서 시각적으로 보여주면, 데이터의 의미를 더 명확하게 전달할 수 있다고 생각했어. 이런 기능을 활용하면 다양한 상황에서 데이터를 분석하고 효과적으로 활용할 수 있을 것 같아.

내가 헷갈린 지점#

처음에 students 리스트 안에 딕셔너리들이 있다는 사실을 간과해서, enumerate()를 사용했을 때 딕셔너리 전체가 출력되는 오류가 발생했어. 단순히 이름만 순서대로 출력하는 줄 알고, 각 딕셔너리 안의 값을 가져오는 방법을 몰라서 답답했지. 딕셔너리 안의 값을 꺼내는 방법과 순위를 매기는 로직을 어떻게 적용할지가 처음에는 잘 생각나지 않았어.

시도한 코드 / 예시#

students = [
    {"name": "민수", "korean": 88, "math": 95, "english": 78},
    {"name": "지혜", "korean": 92, "math": 85, "english": 90},
    {"name": "현우", "korean": 78, "math": 92, "english": 95}
]

total_scores = []
for student in students:
    total_scores.append(student['korean'] + student['math'] + student['english'])

ranked_students = sorted(zip(total_scores, students), reverse=True)

print("성적 순위표:")
for rank, (score, student) in enumerate(ranked_students, start=1):
    print(f"{rank}등: {student['name']} ({score}점)")

결과와 해석#

성적을 담은 딕셔너리 리스트를 enumerate()를 사용해 순위를 매겼는데, start=1을 적용해서 1위부터 순번이 표시되도록 했습니다. 리스트의 순서대로 순위를 결정짓기 때문에, 학생들의 성적이 동일할 경우 리스트에 있던 순서대로 묶여서 같은 순위를 갖게 됩니다.

정리된 이해#

성적을 기준으로 순위를 매겨 순위표를 만들 수 있는데, enumerate()를 활용하면 각 학생의 이름과 순위를 쉽게 함께 출력할 수 있다. start=1 옵션을 사용하거나 인덱스에 1을 더하면 순위가 1부터 시작하는 순위표를 만들 수 있다.

총평#

오늘 전체에서 배운 것#

enumerate() 함수를 사용하면 반복문에서 인덱스와 값을 동시에 사용할 수 있고, start 매개변수를 통해 인덱스 시작값을 조정할 수 있다는 것을 배웠어. 특히 리스트 이름과 요소 이름의 구분을 명확히 하는 것이 중요했고, 이를 활용해 간단한 순위표를 만들 수 있음을 확인했어.

다음에 조심할 것#

리스트 이름과 실제 요소 구분을 확실히 해야 하고, enumerate() 사용 시 start 옵션과 인덱스 조정 방식의 차이를 다시 한번 확인해야겠다. 특히 실제 코딩 상황에서 에러 메시지를 통해 어떤 부분이 잘못되었는지 정확히 파악하는 연습이 필요하다.

다음 복습 주제#

리스트 내포를 활용하여 순위를 매기는 방식을 알아보고, 실제 데이터에 적용하여 다양한 순위표를 만들어보고 싶다. 복잡한 조건으로 순위를 매기는 경우, enumerate()를 어떻게 활용할 수 있는지 추가적으로 연구해봐야겠다.
