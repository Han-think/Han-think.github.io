무엇을 배웠나#

헷갈렸던 점#

ADF 검정에서 귀무 가설이 “시계열이 비정상적"이라는 점이 처음에는 이해가 잘 안 돼서 헷갈렸고, 차분 적용 횟수를 결정하는 과정에서 원본 데이터와 차분된 데이터의 관계가 명확하지 않아서 어려움을 겪었어. 차분을 너무 많이 적용하면 중요한 정보가 손실될 수 있다는 점도 인지하지 못하고 있었어.

정리된 이해#

ADF 검정에서는 귀무가설이 시계열이 비정상이라는 점을 기억하고, p-value가 유의수준보다 작으면 정상성을 인정해야 합니다. 차분을 적용할 때, 원래 데이터에 차분을 하는 것과 이미 차분된 데이터에 다시 차분을 하는 것의 의미를 정확히 이해하고, 과도한 차분으로 정보 손실이 발생하지 않도록 주의해야 합니다. 시계열 분석에서는 추세, 계절성, 잔차를 파악하고, 적절한 차분 횟수를 통해 정상성을 확보하는 것이 중요합니다.

2. ARMA·ARIMA 모델 선택 및 잔차 진단 가이드#

무엇을 배웠나#

ARIMA 모델 선택 시 ACF와 PACF 그래프를 통해 바로 파라미터를 결정하기 어렵다는 것을 깨달았고, 이 그래프들은 모델 후보 범위를 좁히는 진단 도구라는 점을 이해했습니다. AIC 값을 최소화하는 모델을 선택하되, 잔차 진단을 통해 모델의 적합성을 검증해야 한다는 점도 명확하게 알게 되었습니다.

헷갈렸던 점#

ACF와 PACF 그래프를 보고 AR과 MA의 파라미터를 바로 알 수 있다고 생각했지만, 실제 데이터에서는 패턴이 불분명해서 어려움을 겪었습니다. 모델 선택 결과로 얻는 AIC 값을 어떻게 DataFrame으로 정리되는지 이해하는 데도 막혔습니다. 모델 선택 기준이 AIC 값뿐이 아니고 잔차 진단도 중요하다는 것을 뒤늦게 알았습니다.

정리된 이해#

ARMA/ARIMA 모델 선택 시 ACF와 PACF는 모델 파라미터의 후보 범위를 좁히는 데 도움을 주는 진단 도구이며, AIC 값이 가장 낮다고 해서 무조건 좋은 모델이 되는 것이 아니라 잔차 진단을 통해 유의성을 확인해야 합니다. 잔차 진단을 통해 잔차에 자기상관이 없는지 검증하고, Ljung–Box 검정의 p-value를 활용하여 모델의 적합성을 판단해야 합니다.

4. 손실 함수, 경사하강법, 체크포인트 핵심 개념 이해#

무엇을 배웠나#

회귀 기울기와 경사하강법의 기울기가 혼동되었던 점을 명확히 이해했고, 둘은 서로 다른 개념이라는 것을 알게 되었다. 손실함수는 예측과 실제 값의 차이를 수치화하고, 경사하강법은 이 손실을 줄이기 위해 모델 가중치를 조정하는 과정이라는 점을 다시 확인했다. 손실값이 낮다고 해서 모델 성능이 항상 좋은 것은 아니며, 다양한 요인을 고려해야 한다는 점도 배웠다.

헷갈렸던 점#

회귀 기울기와 경사하강법의 기울기가 똑같은 개념인 줄 알았는데, 회귀는 입력 변수의 변화율을, 경사하강법은 모델 가중치 조정에 필요한 손실함수 변화량을 의미한다는 것을 명확히 알지 못했다. 손실 값이 낮다고 해서 모델 성능이 항상 좋은 것도 아니고, 손실 값만으로 모델을 판단할 수 없다는 점도 처음에는 이해가 잘 안 갔다.

정리된 이해#

손실함수는 예측값과 실제값의 차이를 수치화해서 모델이 학습의 목표를 달성하도록 돕는 역할을 하고, 경사하강법은 이 손실함수를 가장 낮게 만드는 방향으로 모델의 가중치를 조금씩 조정하는 알고리즘이야. 단순히 손실값이 낮다고 모델이 좋은지 판단할 수 없고, 학습률이라는 중요한 파라미터를 잘 조절해야 경사하강법이 제대로 작동해.

# 경사하강법 예시 (간단한 선형 회귀)
import numpy as np

# 간단한 데이터 생성
X = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 5, 4, 5])

# 모델 초기화
theta = 0  # 기울기
learning_rate = 0.01
epochs = 100

# 경사하강법 반복
for epoch in range(epochs):
  # 예측값 계산
  y_predicted = theta * X

  # 손실 계산 (MSE)
  loss = np.mean((y_predicted - y) ** 2)

  # 기울기 계산
  gradient = 2 * np.mean((theta * X - y) * X)

  # 가중치 업데이트
  theta = theta - learning_rate * gradient

  if epoch % 10 == 0:
    print(f"Epoch {epoch}: theta = {theta}, Loss = {loss}")

5. 다중 및 다항 회귀: 개념 이해 및 정리#

무엇을 배웠나#

다중 선형 회귀는 종속변수가 여러 개가 아니라 독립변수가 여러 개인 모델이라는 점을 명확히 이해하게 되었다. 또한, 다항 회귀는 비선형 관계를 표현하기 위한 도구이며, 단순히 곡선을 그리는 것이 아니라 경사하강법을 통해 최적의 파라미터를 찾는 과정임을 알게 되었다. 특히, 기울기의 변화가 위치에 따라 달라지는 다항 회귀의 개념이 기존의 선형 회귀 모델과의 차이점을 이해하는데 중요한 역할을 했다.

헷갈렸던 점#

다중 선형 회귀는 종속변수가 여러 개인 문제인 줄 알았고, 다항 회귀에서 각도와 기울기 개념이 직관적으로 이해되지 않았다. 특히 다항 회귀의 기울기가 위치에 따라 변한다는 점과 경사하강법의 gradient 개념이 얽혀서 어려움을 느꼈다. 독립변수의 비선형 관계를 표현하는 다항 회귀의 핵심을 파악하는 데 집중해야겠다는 생각을 했다.

정리된 이해#

다중 선형 회귀는 여러 독립변수를 활용하여 하나의 종속변수를 예측하는 모델이고, 다항 회귀는 독립변수와 종속변수 간의 관계가 직선이 아닐 때 고차항을 사용하여 곡선 관계를 표현하는 방법이다. 다항 회귀는 독립변수의 비선형 관계를 모델링하는 데 유용하며, 경사하강법을 통해 회귀 계수를 선형적으로 최적화한다. 이제 ‘다중’이라는 단어 때문에 종속변수가 여러 개인 문제로 착각하지 않고, 다항 회귀가 위치에 따라 기울기가 변하는 곡선을 그릴 수 있다는 점을 명확히 이해하게 되었다.

# 다중 선형 회귀 예시 (scikit-learn 사용)
import numpy as np
from sklearn.linear_model import LinearRegression

# 샘플 데이터
X = np.array([[1, 1], [1, 2], [2, 2], [2, 3]])  # 독립변수
y = np.array([1, 2, 1, 2])  # 종속변수

# 모델 생성 및 학습
model = LinearRegression()
model.fit(X, y)

# 예측
print(model.predict([[3, 3]]))

7. L1·L2·Elastic Net 정규화 완벽 이해하기#

무엇을 배웠나#

정규화가 단순히 데이터를 지우는 것이 아니라 모델의 계수에 제약을 가하여 과적합을 방지하는 방식이라는 점을 이해하게 되었습니다. L1(Lasso)은 변수 선택을 통해 중요하지 않은 변수를 제거하고, L2(Ridge)는 계수를 안정화시키는 역할을 한다는 것도 명확해졌습니다. Elastic Net은 이 두 가지 효과를 결합하여 더 복합적인 정규화가 가능하다는 점도 알게 되었습니다.

헷갈렸던 점#

처음에는 정규화가 데이터 자체를 없애는 줄 알았고, Ridge 정규화는 모든 계수를 똑같이 줄이는 줄 착각했습니다. L1과 L2 정규화의 차이점과 각각의 역할에 대한 이해가 부족해서 어떤 상황에 어떤 정규화를 사용해야 할지 막막했습니다. Elastic Net이 L1과 L2의 조합이라는 사실은 알고 있었지만, 구체적으로 어떤 장점이 있는지 명확하게 이해하지 못했습니다.

정리된 이해#

정규화는 모델의 복잡도를 줄여 과적합을 막고, 계수 폭주 현상을 방지하여 일반화 성능을 높이는 기법입니다. L1(Lasso)은 일부 계수를 0으로 만들어 변수를 선택하고, L2(Ridge)는 계수의 크기를 안정화시키며, Elastic Net은 이 두 가지 방법을 결합하여 더 유연하게 모델을 조정할 수 있습니다. 특히 L2 정규화는 상관관계가 높은 변수들 간의 균형을 맞춰주는 역할을 합니다.
