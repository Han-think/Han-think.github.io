개념 1: 강화학습(RLHF) 이해#

왜 이걸 보게 됐나#

강화학습 기반의 인간 피드백 모델(RLHF)이 어떻게 작동하는지 명확히 이해하고자 했습니다. 특히 좋은 응답과 나쁜 응답의 차이점에 대해 깊이 파고들고 싶었습니다.

내가 헷갈린 지점#

초기에는 강화학습(RLHF)과 LoRA(Low-Rank Adaptation)를 혼동하여, RLHF가 단순히 모델 조정 기법으로 이해했습니다.

시도한 코드 / 예시#

  • 예시 프롬프트 및 응답 생성: 
    프롬프트: "오늘 날씨가 어때?"
응답 1: "오늘은 맑고 따뜻합니다."
응답 2: "날씨는 보통이고 비가 오지 않습니다."
응답 3: "날씨에 대한 정보는 제공하지 않습니다."

결과와 해석#

응답들을 평가한 결과, 응답 1이 가장 적합하고 유용한 정보를 제공하는 것으로 나타났습니다. 반면 응답 3은 맥락에 맞지 않고 사용자에게 실질적인 도움을 주지 못했습니다.

정리된 이해#

  • 강화학습(RLHF)의 핵심: 사용자 피드백을 통해 모델의 응답을 지속적으로 최적화합니다. 이는 단순한 학습 방식을 넘어 사용자 선호도에 맞춘 답변을 생성하는 과정입니다.
  • LoRA와의 차이점: LoRA는 기존 모델을 미세 조정하는 기법으로, RLHF의 학습 프로세스와는 별개의 기술적 접근법입니다.
