1. init 메서드#

왜 이걸 보게 됐나#

__init__ 메서드는 객체가 생성될 때 자동으로 실행되어 인스턴스 변수를 초기화하는 핵심 역할을 합니다. 이를 이해하지 못하면 객체 속성 설정 과정에서 오류가 발생할 수 있습니다.

내가 헷갈린 지점#

처음에는 self 키워드의 역할과 인스턴스 속성 정의 방법에 대한 명확한 이해가 부족하여 self.name 대신 단순히 name만 사용하는 오류를 범했습니다. 이로 인해 속성이 로컬 변수로만 취급되어 인스턴스 전체에서 접근할 수 없게 되었습니다.

시도한 코드 / 예시#

class TeamMember:
    def __init__(self, name, role, salary):
        self.name = name  # self를 사용하여 인스턴스 속성 초기화
        self.role = role   # self를 사용하여 인스턴스 속성 초기화
        self.salary = salary

결과와 해석#

위 코드는 TeamMember 클래스의 인스턴스를 생성할 때 name, role, salary 속성을 올바르게 초기화합니다. 예를 들어, alice = TeamMember('Alice', '시니어 개발자', 6000)를 호출하면 alice 객체는 각각의 속성에 해당하는 값을 갖게 됩니다.

정리된 이해#

__init__ 메서드를 통해 클래스의 인스턴스 변수를 정의하고 초기화하는 것이 중요합니다. self 키워드는 클래스 내에서 현재 객체 인스턴스를 참조하는 데 사용되며, 이를 통해 각 객체의 독립적인 상태를 관리할 수 있습니다. 이를 통해 객체 지향 프로그래밍에서 필요한 데이터 초기화와 접근을 효과적으로 수행할 수 있습니다.

3. 인스턴스 속성#

왜 이걸 보게 됐나#

인스턴스 속성은 각 객체 인스턴스가 독립적인 데이터를 저장할 수 있게 해주어 클래스의 유연성과 재사용성을 높입니다. 이를 이해함으로써 객체 지향 프로그래밍의 핵심 개념을 더 잘 파악할 수 있습니다.

내가 헷갈린 지점#

처음에는 name과 self.name의 차이를 명확히 이해하지 못해 인스턴스 속성 정의에 어려움을 겪었습니다. 오타로 인한 AttributeError 또한 코드 디버깅 능력 향상에 도움이 되었습니다.

시도한 코드 / 예시#

class Employee:
    def __init__(self, employee_name, job_title, monthly_salary):
        self.employee_name = employee_name  # 인스턴스 속성 정의
        self.job_title = job_title          # 인스턴스 속성 정의
        self.monthly_salary = monthly_salary

# 객체 생성 및 속성 출력 예시
john = Employee('John Doe', '매니저', 5000)
print(f'이름: {john.employee_name}, 직책: {john.job_title}, 연봉: {john.monthly_salary}만원')

결과와 해석#

이름: John Doe, 직책: 매니저, 연봉: 5000만원

정리된 이해#

인스턴스 속성은 self 키워드를 사용하여 객체 내에서 데이터를 저장하고 접근하며, 각 객체가 독립적인 상태를 유지할 수 있게 합니다. 예시 코드를 통해 Employee 클래스의 인스턴스 속성을 정의하고 사용하는 방법을 보여줍니다.

4. Docstring#

왜 이걸 보게 됐나#

Docstring은 코드의 가독성을 향상시키고, 다른 개발자들이 코드를 이해하고 사용하는 데 도움을 주는 중요한 문서화 도구입니다. 이를 통해 클래스와 함수의 역할, 매개변수, 반환값 등을 명확하게 설명할 수 있습니다.

내가 헷갈린 지점#

처음에는 Docstring이 단순히 주석과 어떻게 다른지 이해하는 데 어려움을 겪었습니다. 특히, 코드 실행 중 자동 문서화 도구나 help() 함수와의 연계성을 완전히 이해하는 데 시간이 걸렸습니다.

시도한 코드 / 예시#

class TeamMember:
    """
    IT 회사 팀원을 표현하는 클래스입니다.

    속성:
        name (str): 팀원의 이름
        role (str): 팀원의 직책
        salary (int): 팀원의 연봉 (단위: 만원)

    초기화 매개변수:
        name (str): 팀원 이름
        role (str): 직책
        salary (int): 연봉 (만원 단위)
    """
    def __init__(self, name, role, salary):
        self.name = name
        self.role = role
        self.salary = salary

# 객체 생성 예시
alice = TeamMember('Alice', '시니어 개발자', 6000)
print(alice.__dict__)

결과와 해석#

출력:

{'name': 'Alice', 'role': '시니어 개발자', 'salary': 6000}

정리된 이해#

이 예시는 TeamMember 클래스를 정의하고, 각 속성을 초기화하는 __init__ 메서드를 포함합니다. 특히, 클래스 정의 위에 상세한 Docstring을 작성하여 클래스의 목적, 속성, 초기화 매개변수를 명확하게 설명합니다. 이를 통해 코드의 이해와 유지보수를 용이하게 합니다.
