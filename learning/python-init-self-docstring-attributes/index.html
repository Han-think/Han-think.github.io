1. init 메서드#

왜 이걸 보게 됐나#

이 항목들은 __init__ 메서드를 이해하고 효과적으로 사용하는 데 필요한 핵심 개념들을 학습자에게 명확히 설명하기 위함입니다. 특히 초보자들이 자주 겪는 혼동과 오류를 다루어 실용적인 지식을 제공합니다.

내가 헷갈린 지점#

학습자들은 __init__ 메서드와 self 키워드의 역할, 인스턴스 속성의 정의 방법, 그리고 Docstring 작성의 중요성에 대해 혼란스러워할 수 있습니다. 이를 통해 구체적인 예시와 오류 해결 방법을 통해 이해를 돕고자 합니다.

시도한 코드 / 예시#

class Employee:
    def __init__(self, employee_id, name, position):
        self.employee_id = employee_id  # 인스턴스 속성 초기화
        self.name = name                 # 인스턴스 속성 초기화
        self.position = position         # 인스턴스 속성 초기화

    def display_info(self):
        print(f'Employee ID: {self.employee_id}, Name: {self.name}, Position: {self.position}')

# 객체 생성 및 정보 출력
employee1 = Employee(1, 'John Doe', 'Manager')
employee1.display_info()  # 출력: Employee ID: 1, Name: John Doe, Position: Manager

결과와 해석#

출력 결과는 다음과 같습니다:

Employee ID: 1, Name: John Doe, Position: Manager

정리된 이해#

이 항목들은 __init__ 메서드를 통해 클래스 인스턴스를 초기화하는 방법, self 키워드의 사용, 인스턴스 속성의 정의와 접근, 그리고 클래스 문서화를 위한 Docstring 작성의 중요성을 다룹니다. 초보자들이 코드 작성 중 흔히 겪는 오류와 그 해결 방법을 포함하여 실용적인 학습 경험을 제공합니다.

2. self 키워드#

왜 이걸 보게 됐나#

자기 자신을 참조하여 클래스 인스턴스의 속성과 메서드에 접근하는 방법을 이해하는 것이 중요합니다. 이를 통해 객체 지향 프로그래밍에서의 데이터 관리와 코드 재사용성이 향상됩니다.

내가 헷갈린 지점#

특히 self 키워드와 __init__ 메서드의 역할을 명확히 구분하지 못하고, 오타로 인한 AttributeError 발생 시 원인 파악에 어려움을 겪었습니다. 또한, Docstring 작성의 중요성과 효과적인 사용법을 완전히 이해하는 데 시간이 필요했습니다.

시도한 코드 / 예시#

class Employee:
    def __init__(self, name, position, salary):
        self.name = name  # 자기 자신을 참조하여 인스턴스 속성 초기화
        self.position = position
        self.salary = salary

    def display_info(self):
        """직원 정보 출력 메소드
        :param self: 현재 인스턴스
        """
        print(f'이름: {self.name}, 직책: {self.position}, 연봉: {self.salary}만원')

# 예시 사용
alice = Employee('Alice', '매니저', 5000)
alice.display_info()

결과와 해석#

이름: Alice, 직책: 매니저, 연봉: 5000만원

정리된 이해#

이 예제는 self 키워드를 사용해 클래스 Employee의 인스턴스 속성을 초기화하고, 해당 속성을 참조하는 방법을 보여줍니다. 또한, 클래스 메소드 내에서 self를 사용해 인스턴스 정보를 출력하는 display_info 메소드를 정의하여 객체의 상태를 효과적으로 관리하고 출력하는 방법을 설명합니다.

3. 인스턴스 속성#

왜 이걸 보게 됐나#

인스턴스 속성은 각 객체 인스턴스가 독립적인 데이터를 저장할 수 있게 해주어 클래스의 유연성과 재사용성을 높입니다. 이를 이해하고 올바르게 사용하면 객체 지향 프로그래밍에서 핵심적인 역할을 수행할 수 있습니다.

내가 헷갈린 지점#

초보자들은 self 키워드의 필요성과 name과 self.name의 차이를 명확히 이해하는 데 어려움을 겪습니다. 특히 오타로 인한 AttributeError는 코드 디버깅 과정에서 중요한 학습 포인트가 됩니다.

시도한 코드 / 예시#

class Employee:
    def __init__(self, employee_id, name, position):
        self.employee_id = employee_id  # 인스턴스 속성 정의
        self.name = name                 # 인스턴스 속성 정의
        self.position = position         # 인스턴스 속성 정의

# 객체 생성 예시
employee1 = Employee(1, 'John Doe', 'Software Engineer')

# 속성 접근 예시
print(f'Employee ID: {employee1.employee_id}')
print(f'Name: {employee1.name}')
print(f'Position: {employee1.position}')

결과와 해석#

Employee ID: 1
Name: John Doe
Position: Software Engineer

정리된 이해#

인스턴스 속성은 self를 통해 각 객체 인스턴스에 고유한 데이터를 할당하며, 이를 통해 Employee 클래스의 각 객체는 독립적인 정보를 보유할 수 있습니다. 예제 코드는 Employee 클래스를 정의하고 객체를 생성하여 속성을 올바르게 초기화하고 접근하는 방법을 보여줍니다.

4. Docstring#

왜 이걸 보게 됐나#

Docstring은 코드의 가독성을 높이고 유지보수를 용이하게 하며, 자동 문서화 도구와 함께 사용될 때 개발자들이 클래스와 함수의 역할을 쉽게 이해할 수 있도록 돕습니다. 이를 통해 팀 내 협업과 코드의 명확한 설명이 가능해집니다.

내가 헷갈린 지점#

처음에는 Docstring이 단순히 주석과 어떻게 다른지 명확히 이해하지 못했습니다. 주석과 달리, Docstring이 코드 분석 도구에서 어떻게 활용되는지에 대한 이해가 부족했습니다.

시도한 코드 / 예시#

class TeamMember:
    """
    IT 회사 팀원을 표현하는 클래스입니다.

    속성:
        name (str): 팀원의 이름
        role (str): 팀원의 직책
        salary (int): 팀원의 연봉 (단위: 만원)

    초기화 매개변수:
        name (str): 팀원 이름
        role (str): 직책
        salary (int): 연봉 (만원 단위)
    """
    def __init__(self, name, role, salary):
        self.name = name
        self.role = role
        self.salary = salary

결과와 해석#

위 코드는 TeamMember 클래스를 정의하며, 클래스 정의 바로 위에 멀티라인 Docstring을 사용하여 클래스의 목적, 속성, 그리고 초기화 매개변수에 대한 상세 설명을 제공합니다. 이를 통해 다른 개발자들이 코드를 이해하거나 자동 문서화 도구를 활용할 때 명확한 정보를 얻을 수 있습니다. 예상 출력 주석: None (Docstring 자체는 출력되지 않지만, 코드 문서화에 활용됩니다.)

정리된 이해#

Docstring은 클래스와 함수에 대한 상세 설명을 제공하여 코드의 가독성을 향상시키고, 팀 내 협업과 자동 문서화 도구 활용을 용이하게 합니다. 예제에서는 TeamMember 클래스의 속성과 초기화 매개변수를 명확하게 설명함으로써 이러한 이점을 보여줍니다.

총평#

오늘 전체에서 배운 것#

init 메서드는 객체 생성 시 초기화를 담당하고, self 키워드는 클래스 내에서 현재 인스턴스를 참조하며, 인스턴스 속성은 각 객체마다 독립적인 값을 저장하며, Docstring은 코드 문서화에 필수적임을 이해했습니다.
