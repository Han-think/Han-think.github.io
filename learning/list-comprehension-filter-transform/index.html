1. 리스트 컴프리헨션#

왜 이걸 보게 됐나#

리스트 컴프리헨션은 코드를 간결하게 만들고 반복 작업을 효율적으로 처리할 수 있는 강력한 도구라는 말을 듣고, 파이썬 코드의 가독성과 생산성을 높이는 데 도움이 될 것 같아서 배우기 시작했습니다. 특히 기존의 반복문 코드를 더 짧고 명확하게 표현할 수 있다는 점이 매력적이었고, 데이터 처리 과정을 단순화할 수 있다는 장점도 궁금했습니다. 결국, 파이썬 프로그래밍 효율성을 높이는 핵심 기법이라는 것을 인지하고 학습하게 되었습니다.

내가 헷갈린 지점#

리스트 컴프리헨션에서 if와 if-else의 위치에 따라 결과가 완전히 달라져서 어떤 조건을 어디에 써야 하는지 처음에는 헷갈렸습니다. 특히 if-else를 사용하여 값을 변환하는 부분은, 기존의 필터링 기능과 어떻게 다른지 파악하는 데 시간이 걸렸습니다. 조건에 따라 값을 바꾸는 것을 기존의 필터링과 구분해서 생각해야 한다는 점을 깨닫는 데 어려움이 있었습니다.

시도한 코드 / 예시#

members = [
    {'name': 'Alice', 'team': '개발팀', 'salary': 6500},
    {'name': 'Bob', 'team': '기획팀', 'salary': 5200},
    {'name': 'Carol', 'team': '영업팀', 'salary': 6100},
    {'name': 'Derek', 'team': '개발팀', 'salary': 4800},
    {'name': 'Eve', 'team': '분석팀', 'salary': 3600},
]

# 연봉에 따라 라벨링 변환
salary_grade = ['높음' if m['salary'] >= 5000 else '낮음' for m in members]
print(salary_grade)  # 출력: ['높음', '높음', '높음', '낮음', '낮음']

결과와 해석#

리스트 컴프리헨션은 간결하게 리스트를 생성하는 방법인데, if를 사용하면 특정 조건을 만족하는 요소만 선택해서 새로운 리스트를 만들 수 있어 편리하다. 반면, if-else를 사용하면 모든 요소를 포함하면서 각 요소의 값을 조건에 따라 변경할 수 있어, 필터링 외 다른 변환 작업에도 활용할 수 있다. 이 두 가지의 차이점을 명확히 이해하는 것이 리스트 컴프리헨션을 효과적으로 사용하는 핵심이다.

정리된 이해#

리스트 컴프리헨션은 간결하게 새로운 리스트를 만드는 강력한 방법인데, if는 필터링을, if-else는 값 변환을 위해 사용된다는 점을 헷갈렸었다. if는 조건을 만족하는 요소만 선택하고, if-else는 모든 요소를 포함하되 조건에 따라 다른 값을 할당하는 역할을 한다는 것을 명확히 이해했다. 앞으로는 이 차이점을 기억하고 상황에 맞게 활용해야겠다.

2. 필터링#

왜 이걸 보게 됐나#

원래 리스트 컴프리헨션을 사용할 때, 단순히 간단한 변환이나 연산만 하는 데 익숙했어요. 그런데 복잡한 조건에 따라 항목을 걸러내거나, 각 항목의 값을 조건에 따라 다르게 설정해야 하는 상황에 부딪히면서, 필터링 개념이 필요하다는 것을 깨달았습니다. 특히, 기존 코드에서 조건을 만족하는 항목만 선택하는 방식과 모든 항목을 처리하면서 값만 변환하는 방식의 차이를 명확히 이해하고 적용하는 데 어려움을 느껴 학습하게 되었습니다.

내가 헷갈린 지점#

처음에는 리스트 컴프리헨션 뒤에 if를 붙이면 필터링만 된다고 생각했는데, if-else를 사용하면 필터링도 된다고 착각했습니다. 그래서 if-else를 써서 특정 조건을 만족하는 값만 추출하려고 시도하다가 원하는 결과가 나오지 않아 어려움을 겪었습니다. if-else는 단순히 값을 변환하는 용도로 사용해야 한다는 점을 늦게 깨달았습니다.

시도한 코드 / 예시#

members = [
    {'name': 'Alice', 'team': '개발팀', 'salary': 6500},
    {'name': 'Bob', 'team': '기획팀', 'salary': 5200},
    {'name': 'Carol', 'team': '영업팀', 'salary': 6100},
    {'name': 'Derek', 'team': '개발팀', 'salary': 4800},
    {'name': 'Eve', 'team': '분석팀', 'salary': 3600},
]

# 연봉이 5000 이상인 멤버 이름만 필터링
high_earners = [m['name'] for m in members if m['salary'] >= 5000]
print(high_earners)  # 출력: ['Alice', 'Bob', 'Carol']

결과와 해석#

리스트 컴프리헨션에서 if를 사용하면, 특정 조건을 만족하는 요소만 새 리스트에 포함시킬 수 있습니다. 예를 들어, members 리스트에서 salary가 5000 이상인 사람들의 이름만 추출하여 high_earners 리스트를 만들 수 있습니다. 이렇게 하면 원본 리스트의 모든 요소를 검토하지 않고, 원하는 조건에 맞는 요소만 빠르게 선택할 수 있습니다.

정리된 이해#

리스트 컴프리헨션에서 if는 주어진 조건을 만족하는 요소들만 골라내어 새로운 리스트를 만드는 필터링 역할을 수행합니다. 즉, if 뒤의 조건이 참인 경우에만 해당 요소를 포함시키고, 거짓인 요소는 버리는 것입니다. 이를 통해 불필요한 데이터를 제거하고 원하는 정보만 추출할 수 있습니다.

3. 값 변환#

왜 이걸 보게 됐나#

데이터 분석 프로젝트에서 팀원들의 연봉을 기준으로 급여 등급을 나누는 작업을 진행해야 했는데, 단순히 특정 연봉 이상인 사람만 선택하는 것이 아니라, 모든 팀원의 급여를 분석하기 위해 값 변환이 필요했습니다. 기존의 필터링만으로는 연봉에 따른 세부적인 분석을 할 수 없어서, 값 변환을 통해 연봉 구간별로 등급을 부여하는 방법을 익히게 되었습니다. 이 과정을 통해 데이터 가공의 유연성을 높이고 싶었습니다.

내가 헷갈린 지점#

처음에는 if-else를 사용하여 필터링을 하려고 했는데, 결과가 예상과 달라서 당황했었다. 모든 항목이 유지되면서 값이 바뀌는 방식이 익숙하지 않았고, if와 if-else의 역할이 겉으로 보이는 구조와는 다르게 완전히 다른 개념이라는 것을 이해하는 데 시간이 걸렸다. if는 항목 선택, if-else는 값 변환이라는 점을 명확히 인지하는 데 집중해야 했다.

시도한 코드 / 예시#

# 연봉에 따라 라벨링 변환
salary_grade = ['high' if m['salary'] >= 6000 else ('medium' if m['salary'] >= 4000 else 'low') for m in members]
print(salary_grade)  # 출력: ['high', 'medium', 'high', 'medium', 'low']

결과와 해석#

연봉 5000 이상이면 ‘고연봉’, 아니면 ‘일반’으로 표시하는 변환을 수행했습니다. if-else 구문 안에서 m['salary'] >= 5000 조건을 평가하여 각 멤버의 연봉에 따른 라벨을 정했습니다. 이렇게 하면 기존 멤버 목록을 유지하면서 새로운 라벨 정보가 추가된 리스트를 얻을 수 있습니다.

정리된 이해#

리스트 컴프리헨션 내에서 if-else를 사용하면 기존 리스트의 모든 요소를 포함하지만, 각 요소에 대해 조건에 따라 다른 값을 부여할 수 있습니다. 즉, 원래 리스트의 구조를 유지하면서 요소의 값을 조건부로 바꿔주는 역할을 수행합니다. 이를 통해 새로운 리스트를 생성하는 동시에 기존 데이터의 정보를 활용할 수 있습니다.

4. 라벨링#

왜 이걸 보게 됐나#

데이터 분석 프로젝트에서 팀원들의 연봉 수준을 명확하게 파악하고 싶었어요. 단순히 숫자로만 비교하는 것보다, 연봉 수준을 쉽게 이해할 수 있도록 ‘높음’, ‘보통’, ‘낮음’과 같은 라벨링을 적용하면 팀 전체의 연봉 상황을 한눈에 파악하기 편할 것 같았습니다. 그래서 연봉을 기반으로 데이터를 라벨링하는 방법을 익히게 됐습니다.

내가 헷갈린 지점#

처음에는 ‘라벨링’이라는 단어가 단순히 값을 표시하는 것 정도로 생각했어요. 그래서 연봉을 기반으로 등급을 매기는 것도 필터링의 일종이라고 착각했습니다. 하지만 예제를 보니까 조건에 따라 값을 바꾸는 변환 과정이라는 것을 알게 됐죠.

시도한 코드 / 예시#

salary_grade = ['low' if s < 4000 else 'medium' if s < 6000 else 'high' for s in [6500, 5200, 6100, 4800, 3600]]
print(salary_grade) # 출력: ['high', 'medium', 'high', 'medium', 'low']

결과와 해석#

연봉이 5000 이상이면 ‘고연봉’, 아니면 ‘일반’으로 라벨링을 했습니다. if-else 구문 안에서 연봉 조건을 확인하고, 그 결과에 따라 적절한 라벨을 지정하여 새로운 리스트를 만들 수 있었습니다. 이 방법은 원본 데이터의 모든 요소를 유지하면서 조건에 따른 변환을 수행하는 데 유용합니다.

정리된 이해#

연봉에 따라 멤버들을 ‘고연봉’, ‘중연봉’, ‘저연봉’으로 분류하는 라벨링 작업을 수행합니다. 리스트 컴프리헨션 내에서 if-else를 사용하여 각 멤버의 연봉을 확인하고, 그 결과에 따라 적절한 라벨을 부여하여 새로운 리스트를 생성합니다. 이를 통해 기존 데이터를 기반으로 다양한 정보를 생성하고 활용할 수 있습니다.

총평#

오늘 전체에서 배운 것#

리스트 컴프리헨션에서 if는 조건을 만족하는 항목만 선택하는 필터링 역할을 하고, if-else는 모든 항목을 유지하면서 조건에 따라 값을 변환하는 데 사용된다는 것을 명확히 이해하게 되었다. 특히 if가 뒤에 오는 경우와 if-else가 앞에 오는 경우의 차이점을 제대로 구분할 수 있게 되어, 앞으로 리스트 컴프리헨션을 활용한 코딩이 더 수월해질 것 같다.

다음에 조심할 것#

리스트 컴프리헨션에서 if와 if-else의 위치를 헷갈리지 않도록, if는 필터링용, if-else는 값 변환용이라는 점을 명확히 기억해야겠다. 특히 if-else를 사용할 때, 조건문의 결과가 새로운 리스트의 요소가 된다는 점을 잊지 않도록 주의해야 해.

다음 복습 주제#

리스트 컴프리헨션 내에서 if-else를 활용한 값 변환이 조건문 구조에 대한 더 깊은 이해가 필요할 것 같아, 다른 예제를 통해 좀 더 확실하게 숙달하고 싶다. 특히 복잡한 조건문과 결합했을 때 가독성을 유지하는 방법도 연구해봐야겠다.
