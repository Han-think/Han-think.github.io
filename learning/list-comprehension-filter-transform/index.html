1. if 조건의 이해와 사용#

왜 이걸 보게 됐나#

리스트 컴프리헨션을 활용하면서 특정 조건을 만족하는 데이터만을 추출하는 방법을 이해하고 싶었습니다. 실제 데이터 처리 시 필터링 기능이 중요하다고 느껴 이 부분을 집중적으로 학습했습니다.

내가 헷갈린 지점#

if가 리스트 컴프리헨션의 어느 위치에 있어야 하는지 명확히 구분하지 못했습니다. 특히, if가 리스트 컴프리헨션 내에 위치해야 하는지, 아니면 조건을 체크하는 별도의 구문으로 사용되어야 하는지 혼동이 있었습니다.

시도한 코드 / 예시#

다양한 조건을 적용해 보면서 이해를 시도했습니다.

코드 예시:

# 팀원들의 연봉 필터링 예시
members = [
    {'name': 'Alice', 'team': '개발팀', 'salary': 6500},
    {'name': 'Bob', 'team': '기획팀', 'salary': 5200},
    {'name': 'Carol', 'team': '영업팀', 'salary': 6100},
    {'name': 'Derek', 'team': '개발팀', 'salary': 4800},
    {'name': 'Eve', 'team': '분석팀', 'salary': 3600},
]

# 연봉이 5000 이상인 멤버만 필터링
filtered_members = [m for m in members if m['salary'] >= 5000]
print(filtered_members)  # 출력: [{'name': 'Alice', 'team': '개발팀', 'salary': 6500}, {'name': 'Bob', 'team': '기획팀', 'salary': 520
