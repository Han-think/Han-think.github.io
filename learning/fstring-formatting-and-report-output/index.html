1. f-string 포맷팅#

왜 이걸 보게 됐나#

f-string은 단순히 변수 삽입을 넘어 데이터의 가독성을 높이는 포맷팅 기능을 제공하여, 숫자 정렬 및 천 단위 구분자 삽입 등 다양한 표현이 가능함을 이해하고자 합니다.

내가 헷갈린 지점#

포맷 옵션 (:<, :>, ,)의 구체적인 작동 방식과 적용 방법에 대해 명확한 이해가 필요했습니다. 특히 숫자 정렬과 천 단위 구분자의 효과를 정확히 파악하는 데 어려움이 있었습니다.

시도한 코드 / 예시#

# 팀 데이터 리스트 정의
teams = [
    ('개발팀', 3, 16900),
    ('기획팀', 2, 9500),
    ('영업팀', 2, 9700),
    ('분석팀', 2, 9700),
]

# 헤더 출력
print(f'팀명:<8 팀인원:>4 연봉합계(만원):>14')  # 테이블 헤더 설정
print('-' * 30)  # 구분선 출력

# 팀 데이터 출력
for team_name, count, total in teams:
    print(f'{team_name:<8} {count:>4} {total:>14,}')  # 각 팀 데이터 포맷팅 및 출력

결과와 해석#

팀명:     팀인원     연봉합계(만원):
------------------------------
개발팀     3          16,900
기획팀    2          9,500
영업팀    2          9,700
분석팀    2          9,700
------------------------------

정리된 이해#

f-string을 사용하여 팀 데이터를 테이블 형태로 가독성 있게 출력하는 방법을 실습했습니다. :<, :>, , 옵션을 통해 숫자 정렬과 천 단위 구분자를 적용하여 데이터의 시각적 표현을 향상시켰습니다.

2. 왼쪽 정렬 포맷#

왜 이걸 보게 됐나#

왼쪽 정렬 포맷은 데이터 표의 일관성과 가독성을 높이기 위해 사용되며, 특히 팀 이름이나 팀명과 같은 텍스트 데이터를 일정한 너비로 정렬하여 시각적으로 깔끔하게 표현할 수 있습니다. 이를 통해 사용자는 정보를 빠르게 파악할 수 있습니다.

내가 헷갈린 지점#

처음에는 :<N 옵션이 정확히 어떤 역할을 하는지 이해하는 데 어려움이 있었습니다. 특히, 각 옵션이 실제 출력에서 어떻게 적용되는지 구체적인 예시 없이는 혼동이 따랐습니다. 그러나 실습을 통해 텍스트의 왼쪽 정렬이 어떻게 이루어지는지 명확히 이해할 수 있었습니다.

시도한 코드 / 예시#

# 팀 데이터 리스트 정의
teams = [
    ('개발팀', 3, 16900),
    ('기획팀', 2, 9500),
    ('영업팀', 2, 9700),
    ('분석팀', 2, 9700),
]

# 헤더 출력
print('팀명:<8' '인원':>4' '연봉합계(만원)':>14')  # 헤더 설정 시 직접 문자열 연결
print('-' * 30)  # 구분선 출력

# 팀 데이터 출력
for team_name, count, total in teams:
    print(f'{team_name:<8} {count:>4} {total:>14,}')  # 각 팀 데이터 포맷팅 및 출력

결과와 해석#

출력 결과: 팀명 인원 연봉합계(만원) ──────────────────────────────────── 개발팀 3 16,900 기획팀 2 9,500 영업팀 2 9,700 분석팀 2 9,700

정리된 이해#

왼쪽 정렬 포맷은 특히 텍스트 데이터를 일정한 너비로 정렬하여 표 형식의 데이터 표현을 개선하는 데 효과적입니다. 위 코드 예시를 통해 팀명과 인원, 연봉합계를 왼쪽 정렬 및 오른쪽 정렬, 천 단위 쉼표 적용을 통해 가독성 높은 테이블을 생성할 수 있음을 확인할 수 있습니다.

3. 오른쪽 정렬 포맷#

왜 이걸 보게 됐나#

오른쪽 정렬 포맷은 데이터의 시각적 정리를 통해 가독성을 향상시키는 데 중요하며, 특히 숫자 데이터의 경우 천 단위 구분자와 함께 사용하면 더욱 효과적입니다. 이를 통해 보고서나 테이블 형태의 출력물이 더 명확해집니다.

내가 헷갈린 지점#

처음에는 다양한 포맷 옵션의 구체적인 적용 방법과 그 차이를 이해하는 데 어려움이 있었습니다. 특히 왼쪽과 오른쪽 정렬 옵션의 차이와 천 단위 구분자의 역할에 대해 명확히 파악하는 데 시간이 필요했습니다.

시도한 코드 / 예시#

# 팀 데이터 출력 예시
teams = [
    ('개발팀', 3, 16900),
    ('기획팀', 2, 9500),
    ('영업팀', 2, 9700),
    ('분석팀', 2, 9700),
]

# 오른쪽 정렬 포맷팅 적용
for team_name, count, total in teams:
    print(f'{team_name:>10} {count:>3} {total:>12,}')  # 팀명 오른쪽 정렬, 인원 왼쪽 정렬, 연봉합계 오른쪽 정렬 및 천 단위 구분자 적용

결과와 해석#

출력 결과: 팀명 인원 연봉합계(만원)

개발팀 3 16,900 기획팀 2 9,500 영업팀 2 9,700 분석팀 2 9,700

정리된 이해#

오른쪽 정렬 포맷은 특히 숫자 데이터를 포함한 테이블 형식의 출력에서 가독성을 크게 향상시킵니다. :>N 옵션을 사용하여 특정 열을 오른쪽 정렬하면 데이터의 일관성과 시각적 명확성이 개선되며, , 옵션은 숫자의 가독성을 더욱 높입니다.

4. 천 단위 쉼표#

왜 이걸 보게 됐나#

천 단위 쉼표 기능을 이해하고 실제 데이터 포맷팅에 적용하는 방법을 학습하여 숫자의 가독성을 높이는 방법을 익히고자 합니다.

내가 헷갈린 지점#

천 단위 쉼표 옵션 ,가 어떻게 정확히 작동하는지와 다른 포맷 옵션들과의 차이점을 명확히 파악하는 데 어려움이 있었습니다.

시도한 코드 / 예시#

# 팀 데이터 리스트 정의
teams = [
    ('개발팀', 3, 16900),
    ('기획팀', 2, 9500),
    ('영업팀', 2, 9700),
    ('분석팀', 2, 9700),
]

# 천 단위 쉼표 적용 예시
for team_name, count, total in teams:
    print(f"{team_name:<10} {count:>6} ${total:,}")  # 연봉합계에 천 단위 쉼표 적용

# 출력 결과 예시:
# 팀명    인원   연봉합계(€)
# 개발팀   3      16,900
# 기획팀   2      9,500
# 영업팀   2      9,700
# 분석팀   2      9,700

결과와 해석#

출력 결과: 팀명 인원 연봉합계(€) 개발팀 3 16,900 기획팀 2 9,500 영업팀 2 9,700 분석팀 2 9,700

정리된 이해#

천 단위 쉼표 옵션 ,를 사용하여 연봉합계를 가독성 있게 포맷팅하는 방법을 실습했습니다. 이를 통해 숫자 데이터가 더 직관적으로 표현되는 것을 확인할 수 있었습니다.

총평#

오늘 전체에서 배운 것#

f-string을 이용해 변수 값 삽입 뿐 아니라 데이터 가독성을 높이는 포맷팅 기능을 익혔다. 왼쪽 정렬, 오른쪽 정렬, 천 단위 쉼표 기능을 포함한 다양한 포맷 옵션을 이해하고 적용할 수 있게 되었다.

다음에 조심할 것#

포맷 옵션 :<N, :>N, ,의 구체적인 작동 방식을 정확히 파악하는 것이 중요하다. 특히 숫자 정렬과 가독성 향상을 위한 쉼표 사용법에 주의해야 한다.

다음 복습 주제#

실습을 통해 f-string의 활용 범위를 확장하고 실제 데이터 출력 포맷팅에 적용하는 능력을 향상시켰다. 팀 데이터 예시를 통해 테이블 형태의 데이터 표현이 얼마나 효과적인지 확인했다.
