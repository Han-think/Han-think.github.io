1. NumPy와 SymPy: 수학 수식을 코드로 변환하는 실질적인 가이드#

무엇을 배웠나#

NumPy와 SymPy를 사용할 때, 수식을 코드로 변환하는 방식과 각 라이브러리의 역할을 명확히 구분하는 것이 중요하다는 것을 배웠습니다. NumPy는 숫자 배열을 빠르게 계산하고, SymPy는 상징 변수를 포함한 수식을 처리하는 데 사용됩니다. 예를 들어 행렬 곱셈은 NumPy에서는 @ 기호를 사용하고, 상징 변수를 포함하는 행렬 곱셈은 SymPy를 사용해야 합니다.

헷갈렸던 점#

수학 수식을 코드로 옮기는 과정에서, 특히 행렬 곱셈이나 행렬식 계산처럼 단순해 보이는 부분에서도 NumPy와 SymPy를 어떻게 활용해야 하는지 감이 잘 잡히지 않았습니다. NumPy는 숫자 계산에, SymPy는 상징 변수를 다루는 데 사용된다는 것은 알겠는데, 둘을 언제 어떻게 결합해야 하는지 구체적인 상황에 맞춰 적용하는 것이 어려웠습니다. 결국 코드를 보면서 따라 해보는 수밖에 없다는 생각이 들었습니다.

정리된 이해#

NumPy는 숫자를 이용해서 빠르게 계산하는 데 쓰고, SymPy는 문자 변수를 포함한 복잡한 수식을 다루는 데 사용하는구나. 예를 들어, 수학의 Av = λv 같은 수식은 NumPy에서는 A @ v 와 lam * v 로 나누어서 표현해야 하고, SymPy를 사용하면 상징적인 변수를 이용해서 행렬식을 계산할 수 있다는 것을 알게 되었다. 이제는 각 라이브러리의 역할과 기능을 명확히 구분해서 활용할 수 있을 것 같다.

import numpy as np

# 숫자 배열 생성
A = np.array([[1, 2], [3, 4]])
print("Original Matrix:\n", A)

# 전치 연산
A_T = A.T
print("Transposed Matrix:\n", A_T)

# 행렬 곱셈
B = np.array([[5, 6], [7, 8]])
result_np = A @ B
print("NumPy Matrix Multiplication:\n", result_np)

2. Pandas 조건 필터링과 데이터 개수 계산하기#

무엇을 배웠나#

Pandas에서 조건 필터링과 데이터 개수 계산을 할 때 중첩된 코드 구조 때문에 혼란스러웠지만, 열 선택, 조건 검사, 행 추출, 개수 계산의 단계를 나누어 생각하니 이해가 명확해졌다. Boolean indexing을 활용하여 데이터를 필터링하고 비교 연산자를 사용하여 조건을 설정하는 방법을 익혔다. 특히 NaN 값은 조건 검사 시 자동으로 제외되는 점을 기억해야겠다.

헷갈렸던 점#

처음에는 df[df['Age'] >= 18]처럼 중첩된 대괄호 구조가 어떻게 작동하는지 이해하기 어려웠다. 특히 어떤 부분이 조건을 나타내는지 파악하는 데 시간이 걸렸다. 설명이 길어져서 문제의 핵심인 조건에 맞는 데이터 추출과 개수 세기라는 부분을 놓치고 있었다.

정리된 이해#

Pandas에서 조건 필터링은 먼저 특정 열의 값들을 선택하고, 그 값들이 조건을 만족하는지 확인한 후, 조건을 만족하는 행 전체를 추출하는 방식으로 작동한다. 추출된 행의 개수를 len() 함수를 사용하여 쉽게 계산할 수 있으며, 열에 결측치가 있는 경우 조건 검사에서 자동으로 제외된다. Boolean Indexing을 활용하여 데이터 프레임에서 원하는 데이터를 효율적으로 선택할 수 있다.

import pandas as pd

# 타이타닉 데이터프레임 예시 (실제 데이터를 사용하되, 예시용으로 간단화)
data = {
    'PassengerID': [1, 2, 3, 4],
    'Name': ['Alice', 'Bob', 'Charlie', 'David'],
    'Age': [25, None, 30, 22]
}
df = pd.DataFrame(data)

# 연령이 25세 이상인 승객 수 계산
adult_passengers = df[df['Age'] >= 25]
num_adults = len(adult_passengers)

print(f"25세 이상 승객 수: {num_adults}")

3. Pandas .map()을 활용한 데이터 변환 가이드#

무엇을 배웠나#

Pandas의 .map() 함수를 사용해 Series 객체의 각 요소를 변환하는 방법을 배웠어요. 함수를 적용할 때 else 구문을 사용할 경우, 예상치 못한 값에 대한 처리가 제대로 되는지 확인해야 한다는 점을 깨달았습니다. 특히 .map()은 각 데이터 포인트를 개별적으로 함수에 전달하여 변환한다는 점을 이해하게 되었습니다.

헷갈렸던 점#

.map() 함수가 어떻게 전체 열을 빠르게 처리하는지 처음에는 이해하기 어려웠고, else 조건문에서 예외처리를 제대로 하지 않으면 의도하지 않은 값들이 묶여 변환될 수 있다는 점을 간과했습니다. 특히 함수 내부의 else 조건이 예상치 못한 데이터 값에 미치는 영향에 대해 더 주의해야겠다는 생각이 들었습니다.

정리된 이해#

.map() 함수는 Series의 각 요소를 함수에 적용하여 변환된 결과를 반환하며, 각 데이터 포인트를 독립적으로 처리한다고 이해했다. else절을 사용할 때는 예외 처리를 고려하여 예상치 못한 값이 있을 경우를 대비해야 함을 알게 되었다. 이를 통해 범주형 데이터를 효율적으로 전처리하고, 코드의 안정성을 높일 수 있을 것 같다.

def transform(text: str) -> int:
    if text == 'male':
        return 0
    else:
        return 1  # 주의: 'else'만 있으면 'female' 외 다른 값도 모두 '1'로 변환될 수 있음

# 데이터프레임에 함수 적용
df['Sex'] = df['Sex'].map(transform)

4. 행렬의 순위, 역행렬, 행렬식: 초보자를 위한 이해#

무엇을 배웠나#

행렬의 Rank는 행/열의 개수가 아닌, 실제로 독립적인 정보를 담고 있는 행/열의 개수라는 것을 알게 되었습니다. 또한, 행들이 서로 배수 관계에 있어 중복 정보를 가지는 경우 Rank가 낮아지는 것을 이해하게 되었습니다. 특히 3x3 행렬식 계산에서 복잡한 부호 변화의 이유를 명확히 이해하는 데 어려움이 있었지만, 이 노트 정리 과정을 통해 조금이나마 개념을 구체화할 수 있었습니다.

헷갈렸던 점#

Rank이 독립적인 정보의 개수를 의미한다는 건 이해했지만, 행들 간의 의존성을 시각적으로 파악하는 게 어려웠어요. 특히 행렬식 계산할 때, -3x 같은 항이 어디서 튀어나왔는지 감이 잘 안 잡혔습니다. 예제 코드를 봐도 그 과정이 복잡하게 느껴져서 바로 이해가 안 됐어요.

정리된 이해#

Rank는 행렬이 가진 정보의 독립적인 양을 나타내며, 행 또는 열이 서로 배수 관계에 있으면 Rank는 줄어듭니다. 3x3 행렬식 계산에서 나타나는 복잡한 항들은 행렬 내 원소들의 다양한 곱셈과 부호 변화에서 비롯됩니다. 행렬의 Rank는 행렬이 담고 있는 핵심 정보를 얼마나 가지고 있는지 알려주는 중요한 지표입니다.

import numpy as np

a = np.array([[1, 2, 3]])
b = np.array([[2, 4, -2]])
M = a.T @ b
rank = np.linalg.matrix_rank(M)

5. 직교여공간: 개념 이해와 확인 방법#

무엇을 배웠나#

직교여공간(W⊥)을 이해하는 데 어려움을 겪었는데, W의 기저 벡터와의 조합 가능성 확인과 W와 직교하는지 확인을 구분하는 것이 중요했습니다. W⊥에 속하는지 확인하려면 후보 벡터와 W의 기저 벡터들의 내적이 모두 0인지 확인해야 한다는 것을 알게 되었습니다. 책상과 막대기 비유를 통해 직교여공간 개념을 더 명확하게 이해할 수 있었습니다.

헷갈렸던 점#

처음에는 직교여공간의 정의에서 “모든 벡터와 직각"이라는 부분이 어떤 의미인지 와닿지 않았습니다. 특히 어떤 벡터를 기준으로 직각인지, 혹은 그 벡터가 주어진 공간 안에 포함되는지 확인하는 것인지 헷갈렸습니다. 이로 인해 직교여공간의 개념 자체를 제대로 이해하지 못하고 넘어갈 뻔 했습니다.

정리된 이해#

직교여공간은 특정 부분공간과 직교하는 모든 벡터들의 집합으로, 그 부분공간의 모든 벡터와 내적이 0이 되는 벡터들을 포함합니다. 후보 벡터가 직교여공간에 속하는지 확인하려면, 해당 벡터가 부분공간의 기저 벡터들과 모두 직교하는지(내적이 0인지) 확인해야 합니다. 쉽게 말해, 책상면에 수직인 방향(직교여공간)에 있는 벡터는 책상면(부분공간)의 모든 벡터와 수직인 관계를 갖습니다.

import numpy as np

# 기저 벡터들로 이루어진 부분공간 W
w1 = np.array([1, 0, 0])  # xy 평면의 x축 방향
w2 = np.array([1, 1, 0])  # xy 평면의 대각선 방향

# 후보 벡터들
candidates = {
    "(2,1,0)": np.array([2, 1, 0]),
    "(0,1,0)": np.array([0, 1, 0]),
    "(0,0,1)": np.array([0, 0, 1])
}

6. 데이터 분석 문제 해결을 위한 단계별 가이드#

무엇을 배웠나#

데이터 분석 실습 문제를 해결할 때 최종 결과를 먼저 확인하고, 필요한 열과 변환 규칙을 명확히 정리하는 단계별 접근법이 중요함을 알게 되었다. 특히, 문제에서 제시된 함수와 문법을 활용하여 코드를 채우는 방식이 효율적이며, 이는 향후 데이터 분석 프로젝트에도 적용 가능할 것이다. 앞으로는 문제 해석 시간을 줄이고, 더욱 명확하게 지시를 내릴 수 있도록 노력해야겠다.

헷갈렸던 점#

처음에는 문제 설명과 함수 설명이 섞여 있어서 어떤 코드를 찾아야 할지 파악하는 데 어려움을 느꼈다. 기존에 알고 있던 문법과 새로운 문제 형식을 동시에 이해해야 해서 기존 지식도 다시 생각해봐야 할 것 같았다. 특히 어떤 열을 다뤄야 하는지, 어떤 조건을 적용해야 하는지 명확히 정리하는 과정이 중요했다는 것을 깨달았다.

정리된 이해#

데이터 분석 실습 문제를 풀 때 최종 결과, 대상 열, 조건, 처리 방식을 명확히 정의하고, 제시된 함수와 문법을 활용하여 코드를 채워나가는 단계별 접근법이 필요하다. 이러한 접근 방식은 데이터 분석 프로젝트나 경진대회 문제 해결에도 적용 가능하며, AI 에이전트에게 지시할 때도 명확한 정보를 제공하여 오류를 줄일 수 있다.

df['Sex'] = df['Sex'].map({'male': 0, 'female': 1})

7. 고윳값, SVD, 대각화: 개념과 활용법#

무엇을 배웠나#

고유벡터와 고윳값의 관계, 그리고 행렬 분해(특히 SVD)를 통해 고유벡터를 찾는 과정을 좀 더 명확하게 이해하게 되었습니다. SVD를 사용한 고유벡터 계산 과정과 정규화의 필요성, 그리고 대각화 개념까지 정리하면서 행렬 연산에 대한 직관이 조금 더 잡힌 것 같습니다. 앞으로는 코드를 단순히 따라하는 것이 아니라, 이 개념들을 바탕으로 이해하며 적용해나가야겠다는 생각이 듭니다.

헷갈렸던 점#

고유벡터 계산 과정이 수동 계산과 SVD를 이용한 계산 사이의 연결이 잘 안 보여서 당황했고, 특히 정규화 과정이 왜 그렇게 해야 하는지 이해가 부족했습니다. 고유벡터를 구하는 과정을 SVD를 통해 찾는다는 개념 자체가 처음에는 낯설었습니다.

정리된 이해#

고유벡터는 행렬 변환 시 방향이 변하지 않는 벡터이고, SVD를 통해 행렬의 null space 방향을 찾을 수 있으며, 이 때 정규화를 통해 벡터를 일관된 크기로 조정합니다. SVD는 행렬을 분해하여 고유벡터 후보를 얻는 방법이며, 이를 통해 행렬의 특성을 파악하고 대각화할 수 있습니다. 최종적으로 대각화는 행렬을 고유벡터와 고윳값으로 분해하여 행렬의 구조를 더 잘 이해할 수 있도록 돕습니다.

_, _, Vt = np.linalg.svd(M)
v = Vt[-1]  # 왜 마지막 행인가?
v = v / v[np.abs(v).argmax()]  # 정규화 이유와 방법 이해 필요

8. 불변-종속 멀티모달 메모리 설계: 초보자의 이해와 실습#

무엇을 배웠나#

초보자 관점에서 불변-종속 멀티모달 메모리 설계 시 데이터 처리 구조와 모델 구축의 현실성을 제대로 이해하지 못했던 점을 깨달았습니다. 핵심 원칙인 불변량 우선, 종속성 분리, 피드백 갱신을 바탕으로 3B급 VLM, LLM, Python 엔진, 메모리 DB를 결합하여 데이터의 불변 구조를 보존하고 종속 정보를 관리하는 시스템을 구축할 수 있음을 알게 되었습니다. 이미지에서 음악을 생성하는 예시를 통해 데이터의 불변량을 추출하고 이를 파생 특징으로 계산하는 과정을 이해했습니다.

헷갈렸던 점#

데이터 처리 과정에서 행렬 연산만으로 모든 것을 해결할 수 있다고 생각했는데, 데이터 자체의 구조를 이해하고 불변하는 특징을 보존하는 것이 훨씬 중요하다는 것을 깨달았습니다. 또한, 처음부터 멀티모달 모델을 구축하는 것이 현실적이지 않다는 점을 인지하는 데 시간이 걸렸습니다.

정리된 이해#

불변-종속 멀티모달 메모리 설계에서 데이터 처리의 핵심은 행렬 연산보다는 데이터의 본질적인 구조와 불변량을 보존하는 것에 있다는 것을 깨달았습니다. 3B급 모델을 처음부터 만드는 것보다 기존 모델을 활용하여 실용적인 접근 방식을 선택하는 것이 더 효율적이며, 시스템은 불변 구조를 유지하면서 종속 정보를 분리하고 피드백 루프를 통해 지속적으로 개선되어야 합니다.

# 예시: 파생 특징 계산 (실제 구현은 더 복잡할 수 있음)
def calculate_derived_features(color_contrast, line_density, directional_stability):
  """
  간단한 예시로, 실제 계산은 더 복잡한 모델을 사용해야 함.
  """
  chaos = 0.5 * color_contrast + 0.3 * line_density - 0.2 * directional_stability
  tension = 0.2 * color_contrast + 0.7 * line_density - 0.1 * directional_stability
  movement = 0.3 * color_contrast + 0.4 * line_density - 0.3 * directional_stability
  return chaos, tension, movement

오늘 오후 전체에서 배운 것#

오늘 오후에는 NumPy, SymPy, Pandas 등 다양한 라이브러리를 활용한 데이터 분석 및 행렬 연산, 그리고 불변-종속 멀티모달 메모리 설계에 대한 개념을 익혔습니다. 특히 데이터 분석 문제 해결 시 단계별 접근법과 행렬 연산의 기본 원리를 명확히 이해하고, 불변-종속 메모리 설계의 핵심 원칙을 적용하는 방법을 배웠습니다. 앞으로는 이론 학습에 더해 실제 코드 적용과 개념적 이해를 병행하며 실력 향상을 도모해야겠습니다.

다음에 조심할 것#

Pandas .map() 함수 사용 시 else 구문을 활용할 때 예상치 못한 값에 대한 처리가 제대로 이루어지는지 꼼꼼히 확인해야겠고, 행렬식 계산처럼 복잡한 개념은 반복적으로 정리하면서 확실하게 이해해야겠다. 불변-종속 멀티모달 메모리 설계처럼 복잡한 시스템 구조를 이해하려면, 단순히 개념을 암기하는 것보다 실제 구현 사례를 통해 데이터 흐름과 상호작용을 파악하는 것이 중요하다고 생각한다.
