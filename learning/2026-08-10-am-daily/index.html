1. HTTP, REST, AJAX, Axios: 초보자를 위한 핵심 개념 정리#

무엇을 배웠나#

HTTP, REST, AJAX, Axios 개념이 헷갈렸는데, 각 개념의 역할과 계층 구조를 명확하게 정리했다. HTTP는 통신 규칙, REST는 설계 방식, AJAX는 통신 기술, Axios는 JavaScript에서 HTTP 요청을 쉽게 하도록 돕는 라이브러리라는 것을 이해하게 되었다. 특히 상태 코드를 통해 요청 문제와 서버 오류를 구분하는 것이 중요함을 깨달았다.

헷갈렸던 점#

HTTP, REST, AJAX, Axios가 모두 웹 관련 용어라서 비슷하게 들리고, 각각이 어떤 역할을 하는지 명확하게 구분되지 않았던 것 같아 어려웠다. 특히 상태 코드, 특히 4xx 에러가 서버 문제인지, 아니면 내 요청에 문제가 있는 건지 헷갈렸다.

정리된 이해#

웹 데이터를 주고받는 기본 규칙은 HTTP이고, HTTP를 활용한 효율적인 API 설계 방식이 REST이다. AJAX는 페이지 새로고침 없이 서버와 데이터를 교환하는 기술이며, Axios는 자바스크립트에서 이러한 HTTP 요청을 쉽게 할 수 있도록 도와주는 도구이다. 이러한 개념들을 정리하고 실습을 통해 이해도를 높였다.

// Axios를 사용한 간단한 GET 요청 예시
const axios = require('axios');

axios.get('https://api.example.com/data')
  .then(response => {
    console.log('데이터:', response.data);
  })
  .catch(error => {
    console.error('오류:', error);
  });

2. Axios API 활용 및 데이터 렌더링 실습#

무엇을 배웠나#

Axios API 실습을 통해 각 API마다 응답 구조가 다르고, 그 구조에 맞춰 데이터를 추출하는 과정이 중요하다는 것을 알게 되었습니다. 응답 데이터 확인 및 가공 단계를 거쳐 원하는 데이터를 HTML에 렌더링하는 방법을 익혔습니다. 앞으로는 API 응답 구조를 꼼꼼히 확인하고, 그에 맞춰 데이터 추출 코드를 작성해야 한다는 점을 깨달았습니다.

헷갈렸던 점#

처음 API 실습을 할 때는 응답 데이터가 예상과 다를 경우, 어디서부터 어떻게 접근해야 할지 막막했습니다. 각 API마다 데이터 구조가 달라서, 응답을 받아서 확인하는 과정이 반복적으로 필요했습니다. 어떤 API는 바로 원하는 데이터가 data 안에 있었지만, 다른 API는 여러 단계의 중첩 구조를 거쳐야 했습니다.

정리된 이해#

Axios를 사용한 API 호출은 사용법 자체는 간단하지만, 각 API의 응답 데이터 구조에 따라 데이터 접근 방법이 크게 달라질 수 있다는 것을 알게 되었다. 응답 데이터의 구조를 꼼꼼히 확인하고 필요한 데이터를 추출하는 과정이 중요하며, 이는 각 API마다 다른 접근 방식을 요구한다.

3. Posts 데이터 결합 및 자동채점 문제점#

무엇을 배웠나#

분산된 Posts, Users, Comments 데이터를 ID를 기준으로 결합하는 실습을 진행했는데, 코드는 문제없이 작동했지만 자동채점 시스템에서 계속 실패했습니다. 자동채점 시스템의 정확한 요구사항을 파악하고, 반환값 형태와 데이터 구조가 시스템의 기대치에 부합하도록 수정해야 한다는 것을 깨달았습니다. 이 과정에서 JavaScript의 Promise, map, reduce를 활용하여 데이터를 효율적으로 처리하는 방법을 복습했습니다.

헷갈렸던 점#

처음에는 Promise.all()을 사용해서 동시 요청을 하는 부분에서 데이터가 어떻게 합쳐지는지 감이 잘 안 잡혔다. 또, 자동채점 시스템이 Promise가 아닌 특정 형태의 Array를 요구한다는 것을 왜 정확히 파악하지 못했는지도 궁금하다. 결국 데이터 결합의 논리적인 흐름은 이해했지만, 자동채점 시스템의 요구사항을 충족시키는 형식을 맞추는 데 어려움을 겪었다.

정리된 이해#

여러 데이터 소스를 결합하는 과정을 실습하며 Promise.all()과 reduce 함수를 활용하여 posts, users, comments 데이터를 통합하는 방법을 익혔습니다. 하지만 자동채점 시스템과의 계약 조건 불일치로 인해 예상치 못한 문제에 직면했고, 반환값 형태와 데이터 구조에 대한 정확한 요구사항을 파악하는 것이 중요함을 알게 되었습니다. 앞으로는 자동채점 시스템의 요구사항을 명확히 이해하고, 이에 맞춰 코드를 작성해야 함을 깨달았습니다.

const createUserMap = (users) => {
  return users.reduce((userMap, user) => {
    userMap[user.id] = user;
    return userMap;
  }, {});
};
