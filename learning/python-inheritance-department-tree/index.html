1. 상속의 이해#

왜 이걸 보게 됐나#

프로그래밍 수업에서 상속의 개념을 이해하고 실제 프로젝트에 적용하는 방법을 배우고자 이 주제를 탐구하게 되었습니다. 복잡한 조직 구조를 프로그래밍으로 구현하면서 상속의 중요성을 실감했습니다.

내가 헷갈렸던 지점#

상속 구조를 적용하면서 부모 클래스와 자식 클래스 간의 역할 분담과 데이터 관리 방식이 명확하지 않았습니다. 특히, 각 팀 클래스가 부모 클래스의 메서드를 어떻게 활용하고 고유한 기능을 추가해야 하는지 이해하는 데 어려움이 있었습니다.
