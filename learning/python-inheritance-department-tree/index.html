1. 상속 구조#

왜 이걸 보게 됐나#

상속 구조를 통해 코드 중복을 줄이고, 공통 기능과 팀별 특화 기능을 효과적으로 관리할 수 있다는 점을 이해하고 싶었습니다. 특히, 각 팀 클래스가 부모 클래스의 기능을 어떻게 활용하고 확장하는지 구체적으로 파악하고자 했습니다.

내가 헷갈린 지점#

2. 부모 클래스 속성#

왜 이걸 보게 됐나#

부모 클래스 속성 이해를 통해 다양한 팀 클래스들이 공통 기능과 팀 특화 기능을 효과적으로 관리할 수 있음을 깨닫고자 함.

내가 헷갈린 지점#

상속 구조에서 부모 클래스와 자식 클래스 간의 역할 분담이 명확하지 않아 초기에는 혼란스러웠음. 특히, 공통 속성과 메서드가 어떻게 실제 팀 클래스에 적용되는지 이해하는 데 어려움이 있었음.

시도한 코드 / 예시#

class Department:  # 부모 클래스
    def __init__(self, team_name, budget):
        self.team_name = team_name  # 공통 속성
        self.budget = budget
        self.members = []  # 공통 메서드

    def add_member(self, member):
        self.members.append(member)
        # 공통 메서드 예시

    def remove_member(self, member):
        self.members.remove(member)

    def show_members(self):
        print(f"{self.team_name} 팀 멤버: {', '.join(self.members)}")

class DevTeam(Department):
    def __init__(self, team_name, budget, tech_stack):
        super().__init__(team_name, budget)  # 부모 클래스 초기화 호출
        self.tech_stack = tech_stack  # 팀 특화 속성

    def code_review(self):
        print(f"{self.team_name} 팀 코드 리뷰 진행 중")
    # 팀 특화 메서드

정리된 이해#

부모 클래스 Department는 모든 팀이 공유하는 속성과 메서드를 정의하고, 자식 클래스 DevTeam은 이를 상속받아 특화된 속성과 메서드를 추가함으로써 효율적인 코드 관리와 확장성을 달성할 수 있음을 보여줌.
