1. 여러 React 입력과 상태 관리하기#

무엇을 배웠나#

React에서 입력 필드와 상태를 연결하는 방법을 배우면서, 단일 입력은 useState로 간단히, 여러 입력은 객체 상태로 묶어서 관리해야 함을 알게 되었다. onChange 이벤트 핸들러에서 e.target.value를 통해 입력 값을 가져와 상태를 업데이트하는 과정이 중요하며, Spread Operator를 사용하여 객체 상태를 안전하게 업데이트하는 방법을 익혔다. React의 상태가 value 속성을 통해 직접 관리된다는 점도 명확하게 이해하게 되었다.

헷갈렸던 점#

처음에는 왜 useState로 초기화된 변수에 계속해서 value 속성을 넣어줘야 하는지, 그리고 여러 개의 입력 필드를 다룰 때 상태를 객체 형태로 묶어야 하는 이유가 잘 이해가 되지 않았다. 특히 onChange 이벤트에서 e.target.value를 어떻게 활용해야 하는지, 그리고 Spread Operator를 이용한 상태 업데이트가 직관적으로 다가오지 않았다.

정리된 이해#

React에서 입력 필드와 상태를 연결할 때, 단일 입력은 useState로 간단히 관리하지만 여러 입력은 객체 상태로 묶어 관리해야 한다는 점을 이해했습니다. onChange 이벤트 핸들러에서 e.target.value를 통해 입력값을 가져와 setInputs 함수와 Spread Operator를 사용하여 상태 객체를 업데이트하는 방식이 핵심이며, React의 상태가 UI의 value 속성을 직접 관리한다는 점이 중요합니다. 이러한 이해를 바탕으로 다양한 입력 필드를 다루는 React 컴포넌트를 만들 수 있을 것 같습니다.

import { useState } from "react";

function InputComponent() {
    const [inputValue, setInputValue] = useState('');

    const handleChange = (e) => {
        console.log(e.target.value); // 현재 입력값 확인
        setInputValue(e.target.value); // 상태 업데이트
    };

    return (
        <div>
            <input type="text" value={inputValue} onChange={handleChange} />
            <h3>입력 내용 : {inputValue}</h3>
        </div>
    );
}

2. React Ref와 State: 값 관리와 DOM 조작의 차이점#

무엇을 배웠나#

React에서 useRef와 useState의 역할을 명확히 구분하는 방법을 익혔습니다. useState는 입력값의 변화를 추적하고 UI를 갱신하는 데 사용되고, useRef는 DOM 요소 자체를 직접 조작하는 데 활용된다는 것을 알게 되었습니다. 이를 통해 input 요소의 값 관리와 DOM 조작을 분리하여 컴포넌트를 이해하고 구현할 수 있게 되었습니다.

헷갈렸던 점#

Ref 개념을 배우는 과정에서 State가 갑자기 다시 등장해서 학습 흐름이 끊기는 듯한 느낌을 받았고, 코드에 TAB 버튼이 포함되어 있지만 실제 기능은 구현되지 않은 점이 혼란스러웠다. State와 Ref의 차이점을 명확하게 이해하지 못해 각 개념의 역할을 제대로 파악하지 못했다.

정리된 이해#

State는 input 요소의 값과 관련된 상태를 관리하고 UI를 갱신하는 역할을 합니다. 반면 Ref는 특정 DOM 요소에 직접 접근하여, focus()와 같은 DOM 레벨의 동작을 수행할 수 있도록 해줍니다. 즉, State는 값의 변화를 추적하고 UI를 업데이트하는 데 사용되고, Ref는 DOM 요소 자체를 조작하는 데 사용됩니다.

오늘 오전 전체에서 배운 것#

React 입력 필드와 상태 관리를 통해 여러 입력값을 객체 상태로 묶어 관리하고, useRef를 사용하여 DOM 요소를 직접 조작하는 방법을 익혔습니다. useState는 값 관리, useRef는 DOM 조작이라는 명확한 역할 구분을 통해 React 컴포넌트의 동작 방식을 더 깊이 이해하게 되었습니다. 이제 입력값 관리와 DOM 조작을 분리하여 React 컴포넌트를 구현할 수 있을 것 같습니다.

다음에 조심할 것#

객체 상태를 활용한 여러 입력 필드 관리는 응용력을 키워야겠고, 특히 Spread Operator를 통해 안전하게 업데이트하는 습관을 들여야겠다. useRef를 사용할 때 useState와 혼동하지 않도록 명확히 구분해서 사용해야 더 효율적인 코드를 작성할 수 있을 것 같다.
