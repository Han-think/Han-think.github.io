1. CSS 스타일 우선순위: 캐스케이드와 구체성 이해#

무엇을 배웠나#

CSS 캐스케이드 과정에서 선택자의 구체성이 규칙 적용 순서보다 우선한다는 것을 명확히 이해하게 되었다. 단순히 코드가 나중에 작성된 순서대로 적용되는 것이 아니라, 구체적인 선택자가 우선하며, 구체성이 같을 때만 작성 순서가 영향을 미친다는 점을 알게 되었다. 실습 과정에서 문법 오류를 통해 CSS 코딩의 세심함을 다시 한번 깨닫게 되었다.

헷갈렸던 점#

CSS 규칙 적용 순서가 단순히 작성 순서대로 되는 게 아니라 선택자의 구체성이 중요해서 헷갈렸고, 특히 구체적인 선택자와 덜 구체적인 선택자가 충돌할 때 어떤 게 적용되는지 명확히 이해하지 못했다. 또한 실습 과정에서 문법 오류로 인해 스타일이 제대로 적용되지 않아 혼란스러웠다.

정리된 이해#

CSS 캐스케이드 방식은 여러 스타일 규칙이 충돌할 때 브라우저가 최종 스타일을 결정하는 과정이며, 단순히 작성 순서가 아닌 선택자의 구체성을 먼저 비교하여 우선순위를 결정한다. 구체성이 동일한 경우에만 작성 순서가 영향을 미치고, 상속된 스타일보다 직접 지정된 스타일이 우선 적용된다.

<!DOCTYPE html>
<html>
<head>
  <title>CSS Cascade Example</title>
  <style>
    p { color: red; }
    .highlight { color: blue; }
    h3 { color: green; }
    header h3 { color: orange; } /* 구체적 선택자 */
  </style>
</head>
<body>
  <p>This is a paragraph.</p>
  <p class="highlight">This paragraph has a class.</p>
  <h3>This is an h3 heading.</h3>
  <header>
    <h3>This is an h3 inside a header.</h3>
  </header>
</body>
</html>

설명:

  • <p> 태그는 color: red;가 적용됩니다.
  • <p class="highlight"> 태그는 color: red; 대신 클래스 .highlight에 의해 color: blue;가 적용됩니다 (클래스는 태그보다 구체적).
  • <h3> 태그는 color: green;가 적용됩니다.
  • header 내의 <h3> 태그는 color: orange;가 적용됩니다 (헤더를 포함하는 더 구체적인 선택자). header h3가 h3 보다 구체적이므로 orange가 green보다 우선합니다.

2. CSS 크기, 글꼴, 배경, 테두리 및 스프라이트 실습 워크노트#

무엇을 배웠나#

CSS 크기 단위, 배경 이미지 속성, 테두리 적용 시 박스 모델 고려, 그리고 스프라이트 이미지 좌표 설정 방식에 대한 개념을 명확히 이해하게 되었다. 특히 px는 고정 값, %는 상대 값이란 점과 스프라이트 이미지의 음수 좌표 활용법을 제대로 알아차렸다. 앞으로는 이러한 내용을 바탕으로 CSS를 더 정확하게 활용할 수 있을 것이다.

헷갈렸던 점#

크기 단위에 대한 설명이 상대적 값과 고정 값이 뒤섞여 있어서 어떤 값이 무엇을 의미하는지 헷갈렸고, 배경 이미지 속성들을 구분해서 사용할 때 어떤 속성을 먼저 설정해야 하는지 막혔다. 테두리 적용 후 요소의 전체 크기를 계산할 때 박스 모델을 제대로 반영하지 못해서 계산이 틀어졌고, 스프라이트 이미지에서 음수 좌표가 왜 사용되는지 명확하게 이해하지 못했다.

정리된 이해#

CSS 크기를 조절할 때 px은 고정된 크기를, %는 부모 요소에 상대적인 크기를 나타내므로 상황에 맞게 선택해야 한다. 배경 이미지를 설정할 때는 background 속성을 이용해 여러 설정을 한 번에 지정할 수 있으며, 테두리는 박스 모델에 포함되어 요소의 전체 크기를 계산할 때 고려해야 한다. 마지막으로, CSS 스프라이트는 음수 좌표를 사용하여 이미지의 특정 부분을 보여주는 기술이다.

/* 예시: px 단위 사용 */
.box {
  width: 100px;
  height: 50px;
}

/* 예시: % 단위 사용 */
.child {
  width: 50%; /* 부모 요소 너비의 50% */
}

/* 예시: background 속성 축약형 사용 */
.element {
  background: url("image.png") no-repeat top left;
}

/* 예시: 테두리 적용 후 요소 크기 계산 */
/* 요소의 원래 너비가 100px이고 테두리가 5px라면 전체 너비는 110px이 된다. */
.bordered {
  width: 100px;
  border: 5px solid black;
}

/* 예시: CSS 스프라이트 좌표 사용 */
/* 왼쪽에서 20px, 위에서 10px 떨어진 위치의 이미지를 표시 */
.sprite {
  background: url("sprite.png") 0 0;
  background-position: -20px -10px;
}

3. CSS 박스 모델: Margin, Padding, Border 완벽 이해#

무엇을 배웠나#

CSS 박스 모델의 구성 요소인 content, padding, border, margin의 역할과 각각이 요소의 전체 크기에 어떤 영향을 미치는지 명확히 이해하게 되었다. 특히 width 속성만으로는 요소의 실제 보이는 너비가 결정되지 않고, padding과 border가 추가되어 전체 너비가 커질 수 있다는 점을 깨달았다. 이제는 요소의 크기를 계산할 때 이러한 요소들을 모두 고려해야 함을 알게 되었다.

헷갈렸던 점#

처음에는 width 값을 설정해도 실제 보이는 크기가 항상 같을 거라고 생각해서 혼란스러웠습니다. padding과 border가 width에 영향을 준다는 것을 인지하지 못했고, margin이 요소 자체의 크기인지, 아니면 다른 요소와의 간격인지 헷갈렸습니다.

정리된 이해#

CSS 박스 모델은 콘텐츠, 패딩, 테두리, 마진으로 구성되며, width나 height 값을 설정할 때 패딩과 테두리가 추가되어 실제 보이는 크기가 달라질 수 있다는 점을 이해해야 합니다. margin은 요소 외부 공간을 만들어서 다른 요소와의 간격을 조절하는 역할을 하고, 패딩과 테두리는 요소 자체의 크기에 영향을 줍니다. 이 개념들을 명확히 이해하고 활용해야 원하는 레이아웃을 만들 수 있습니다.

<div class="box">
  내용
</div>

.box {
  width: 300px;
  height: 300px;
  padding: 10px; /* 좌우 및 상하 각각 10px */
  border: 5px solid black; /* 좌우 및 상하 각각 5px */
}

4. CSS 레이아웃 기본: Block, Inline, Position 이해#

무엇을 배웠나#

인라인 요소는 너비와 높이 속성을 적용할 수 없고, 마진 병합 규칙 때문에 예상과 다르게 동작할 수 있다는 점을 알게 되었다. 또한 부모 요소의 마진은 자식 요소에 영향을 주며, absolute positioning은 부모 요소의 위치에 따라 달라질 수 있다는 점을 깨달았다. 마진과 위치 속성의 차이를 명확히 이해하고, 각 속성의 역할을 구분하여 적용하는 것이 중요하다는 것을 배웠다.

헷갈렸던 점#

Inline 요소에 width나 height를 적용할 수 없다는 설명이 있었는데, 왜 특정 속성이 적용되지 않는지 더 자세히 알고 싶었습니다. 마진 병합 규칙이 직관적이지 않아서, 수직 마진이 합쳐지지 않는 이유를 이해하는 데 어려움을 겪었습니다. 또한, position: absolute; 사용 시 부모 요소를 기준으로 위치하는 조건이 항상 명확하지 않다고 느꼈습니다.

정리된 이해#

Inline 요소는 내용 흐름에 따라 배치되며, width나 height를 지정해도 콘텐츠 크기만 조절되고 요소 자체의 크기는 변하지 않습니다. 마진 병합은 수직 마진의 경우 합쳐지지 않고, 더 큰 값으로 적용되어 예측하기 어려운 레이아웃을 만들 수 있습니다. Absolute positioning은 항상 기준점을 찾지만, 기준점이 없는 경우 뷰포트를 기준으로 위치하며, 부모 요소의 위치도 영향을 줄 수 있습니다.

<!-- Inline 요소의 width/height 적용 제한 예시 -->
<div style="width: 200px; height: 100px; border: 1px solid black;">
  <a href="#" style="width: 150px; height: 50px; background-color: lightblue; padding: 10px;">링크</a>
</div>
<!-- 링크는 width와 height를 무시함.  padding만 적용 -->

<!-- 마진 병합 예시 -->
<div style="margin-bottom: 150px; background-color: lightcoral;"></div>
<div style="margin-top: 100px; background-color: lightgreen;"></div>
<!-- 두 요소 사이의 거리는 150px이 *아니다*.  마진이 병합된다. -->

<!-- 부모-자식 마진 상호작용 예시 -->
<div style="margin-bottom: 200px; border: 1px solid black;">
  <p style="margin-top: 100px; background-color: yellow;">자식 요소</p>
</div>
<!-- 자식 요소의 top margin은 부모 요소의 bottom margin과 병합된다.-->

<!-- Absolute Positioning 예시 -->
<div style="position: relative; border: 1px solid black; width: 300px; height: 150px;">
  <div style="position: absolute; top: 10px; left: 10px; background-color: lightblue; width: 50px; height: 20px;">절대 위치</div>
</div>
<!-- <div>는 기준점이며, 절대 위치 요소는 이 <div>를 기준으로 배치됨. -->

<!-- margin vs. top 속성 비교 예시 -->
<div style="margin-top: 1000px; background-color: lightgray; width: 200px; height: 50px;">margin-top 적용</div>
<div style="position: relative; top: 100px; background-color: lightblue; width: 200px; height: 50px;">top: 100px 적용</div>
<!-- margin-top은 요소 외부 공간을 조정. top은 요소 자체의 위치를 조정. -->

5. float, clear, 레이아웃 초기화: 초보자를 위한 CSS 정리#

무엇을 배웠나#

CSS 레이아웃에서 float 속성과 딥러닝의 float32 데이터 타입을 혼동했던 부분을 명확히 구분하게 되었고, float 요소 배치 후 발생하는 문제와 clear 속성의 역할을 이해하게 되었다. 또한 모든 요소에 margin: 0; padding: 0;을 적용하는 * 선택자의 사용에 대한 주의사항을 인지하게 되었다. 이제 CSS 레이아웃에 대한 기본적인 이해가 좀 더 명확해졌다.

헷갈렸던 점#

CSS 레이아웃에서 float 속성과 딥러닝에서 사용하는 float32 데이터 타입이 같은 단어임에도 완전히 다른 의미로 사용되어 혼동되었고, float 요소를 사용했을 때 뒤따르는 요소들의 배치가 왜 예상과 다르게 나타나는지 이해하기 어려웠습니다. clear 속성이 정확히 어떤 역할을 하는지, 그리고 * 선택자를 이용한 여백 초기화가 어떤 영향을 미치는지 명확하게 파악하지 못했습니다.

정리된 이해#

CSS 레이아웃에서 float은 요소를 텍스트 흐름에서 벗어나 좌우로 배치하는 기능이고, 딥러닝에서는 float32가 부동 소수점 데이터 타입을 의미하는 완전히 다른 개념입니다. float 요소를 사용하면 이후 요소들이 예상치 못한 위치로 이동할 수 있는데, 이 문제를 해결하기 위해 clear 속성을 사용하여 이전 float 요소의 영향을 없애고 요소를 배치할 수 있습니다. 전체 선택자 *를 사용하여 여백과 패딩을 초기화하는 것은 간편하지만, 모든 요소에 영향을 주므로 신중하게 사용해야 합니다.

.left {
  float: left;
}

import numpy as np
data = np.float32([1.0, 2.0, 3.0])

.content {
  float: left;
}

.footer {
  clear: both;
}

* {
  margin: 0;
  padding: 0;
}

총평#

오늘 오후 전체에서 배운 것#

오늘 CSS 학습을 통해 스타일 우선순위, 박스 모델, 레이아웃 기본 원리를 확실히 다질 수 있었다. 특히 CSS의 다양한 속성들이 예상치 못한 방식으로 동작할 수 있다는 점을 깨닫고, 코딩 시 세심함을 기해야 함을 알게 되었다. 앞으로 CSS를 활용하여 웹 페이지를 만들 때 오늘 배운 내용들을 토대로 더욱 정확하고 효율적인 개발을 할 수 있을 것이다.

다음에 조심할 것#

CSS 스타일 우선순위에서 구체성 계산을 꼼꼼히 하고, 코드를 작성할 때 예상치 못한 문법 오류가 발생하지 않도록 세심하게 검토해야겠다. 특히 px, % 단위, 배경 이미지, 테두리 적용 시 박스 모델을 항상 염두에 두고, 레이아웃 초기화 시 * 선택자의 사용이 가져올 부작용을 고려해야겠다.

다음 복습 주제#

CSS 스타일 우선순위와 구체성 규칙을 좀 더 다양한 예제를 통해 복습해서 머릿속에 확실히 체화해야겠다. 특히 inline 요소의 마진 병합 규칙과 absolute positioning의 동작 원리에 대한 심층적인 이해가 필요하다고 생각한다.
