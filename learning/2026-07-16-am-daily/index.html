1. 머신러닝과 딥러닝 개념 정리 및 Pipeline OS 적용 이해#

무엇을 배웠나#

머신러닝과 딥러닝의 차이를 명확히 이해하게 되었는데, 머신러닝은 사람이 직접 피처를 선택하고 가공하는 반면 딥러닝은 모델이 데이터로부터 패턴을 스스로 학습한다는 점이 핵심이다. 특히 Pipeline OS에서 LLM을 활용하는 방식을 통해 인간의 의도와 AI의 능력을 융합하는 시스템 구축이 가능하다는 점을 깨달았다. 앞으로는 피처 엔지니어링 기법과 딥러닝 기반 문장 생성 알고리즘을 활용하여 프로젝트에 적용해 보려 한다.

헷갈렸던 점#

머신러닝과 딥러닝이 명확히 구분되는 것처럼 느껴지지 않았고, 특히 프로젝트에서 인간의 개입 정도와 모델의 역할이 모호하게 느껴졌다. Pipeline OS에서 딥러닝 기술이 어떻게 활용되는지, 그리고 LLM과 규칙 기반 시스템이 어떻게 협력하는지 이해가 부족했다. 이 두 가지 기술을 어떻게 구체적으로 결합하는지 파악하는 데 어려움을 겪었다.

정리된 이해#

머신러닝은 사람이 직접 특징을 선택하고 가공하는 반면, 딥러닝은 신경망 구조와 데이터만으로 모델이 스스로 패턴을 학습합니다. Pipeline OS는 인간의 의도와 AI 생성 능력을 융합하는 운영체계로, LLM을 활용하여 소설 생성 과정을 지원하며 규칙 기반 시스템과 함께 작동합니다. 앞으로는 피처 엔지니어링 실습을 통해 머신러닝과 딥러닝의 차이를 직접 경험하고 싶습니다.

# 예시: 소설 데이터셋에서 장르별 키워드 추출 및 전처리 (가정)
from collections import Counter
import re

def extract_keywords(text, stop_words):
  """텍스트에서 키워드 추출"""
  text = re.sub(r'[^\w\s]', '', text).lower()  # 특수문자 제거 및 소문자 변환
  words = text.split()
  filtered_words = [word for word in words if word not in stop_words]
  word_counts = Counter(filtered_words)
  return word_counts.most_common(10)

# 예시 데이터 (실제 데이터셋으로 대체)
text = "로맨스 소설은 아름다운 사랑 이야기와 감동적인 결말을 제공합니다."
stop_words = ['은', '는', '과', '의', '를', '가', '이']

keywords = extract_keywords(text, stop_words)
print(keywords)

2. 퍼셉트론의 구조와 활성화 함수 이해#

무엇을 배웠나#

퍼셉트론의 각 뉴런이 여러 입력 신호를 받아 가중합과 편향을 계산하고, 활성화 함수를 통해 최종 출력값을 생성한다는 것을 이해하게 되었다. 활성화 함수는 단순한 스위치 역할뿐만 아니라 다양한 값을 만들어내는 중요한 역할을 한다는 점도 명확해졌다. 뉴런들이 모여 층을 이루고, 각 층의 출력이 다음 층의 입력으로 전달되는 구조도 파악했다.

헷갈렸던 점#

활성화 함수가 그냥 0 또는 1을 내놓는 단순한 스위치인 줄 알았고, 뉴런이 여러 입력을 동시에 처리하는 계산 단위인지, 아니면 각 뉴런이 개별적으로 동작하는지 명확하지 않았다. 특히 각 뉴런이 어떻게 여러 입력 신호를 결합하여 하나의 출력을 내는지가 이해가 안 갔다.

정리된 이해#

퍼셉트론의 뉴런은 여러 입력 신호들을 가중치와 편향을 통해 조합하고, 활성화 함수를 거쳐 최종적으로 하나의 값을 출력하는 계산 단위입니다. 활성화 함수는 입력 값을 비선형적으로 변환하여 복잡한 패턴을 학습할 수 있도록 돕고, 여러 뉴런들이 층을 이루어 출력을 결합하여 전체적인 판단을 내립니다. 예를 들어 계단 함수는 간단한 스위치 역할을 하지만, 다양한 활성화 함수는 더 풍부한 값들을 생성할 수 있습니다.

# Python으로 뉴런 동작 시뮬레이션 (계단 활성화 함수 사용)

def neuron_step(inputs, weights, bias):
    """
    뉴런의 동작을 시뮬레이션합니다.

    Args:
        inputs: 입력 값 리스트
        weights: 가중치 리스트
        bias: 편향 값

    Returns:
        활성화 함수 적용 후 출력 값
    """
    z = sum(w * x for w, x in zip(weights, inputs)) + bias
    return 1 if z >= 0 else 0

# 예시
inputs = [2, -1]
weights = [0.5, -0.3]
bias = 0.1

output = neuron_step(inputs, weights, bias)
print(f"출력 값: {output}")

무엇을 배웠나#

도함수의 의미를 정확히 이해하고, 경사하강법이 단순히 포물선을 따라 내려가는 것이 아니라 복잡한 손실 지형 속에서 파라미터를 조정하는 과정임을 알게 되었다. 특히 최솟값 이후 손실 함수 변화에 대한 오해를 풀고, 학습률이 경사하강법의 경로에 미치는 영향을 고려해야 한다는 점을 명확히 했다. 앞으로는 이러한 이해를 바탕으로 실제 신경망 학습에 적용해 볼 계획이다.

헷갈렸던 점#

최솟값을 지나면 손실 함수가 역전되는 것처럼 느껴졌는데, 사실 경사하강법은 최솟값 근처에서도 계속 최소값 방향으로 움직이는구나. 경사하강법이 항상 단순한 포물선을 따라 직행한다고 생각했는데, 실제로는 손실 지형이 훨씬 복잡해서 다양한 경로를 만들 수 있구나.

정리된 이해#

도함수는 현재 지점에서의 기울기를 알려주고, 경사하강법은 이 기울기를 따라 파라미터를 조절하여 손실 함수를 줄이는 방식이야. 손실 지형이 복잡하더라도 경사하강법은 계속해서 현재 위치에서의 기울기를 따라 움직이며 최소값을 찾아가려고 노력하는 거지.

4. 벡터, 행렬, 텐서와 은닉층 기초 다지기#

무엇을 배웠나#

벡터, 행렬, 텐서의 기본적인 개념과 그 구조를 명확히 이해하게 되었다. 특히 행렬의 컬럼과 행 구분, 그리고 은닉층 내 노드와 층의 관계를 제대로 파악하게 되어서 신경망 구조에 대한 이해도가 높아졌다. 앞으로는 이 지식을 바탕으로 더 복잡한 개념들을 학습하는 데 도움이 될 것 같다.

헷갈렸던 점#

벡터와 행렬의 컬럼과 행을 구분하는 게 잘 안 됐고, 그림에서 원 하나가 어떤 의미를 가지는지 파악하는 데 어려움이 있었어. 특히 신경망에서 노드와 층, 은닉층과 노드의 관계가 얽혀서 전체 구조를 이해하는 데 꽤 애를 먹었어.

정리된 이해#

5. PyTorch 모델 구조: 상속과 forward 메서드 이해#

무엇을 배웠나#

PyTorch 모델을 만들 때 nn.Module을 상속받아야 하는 이유와 forward() 메서드의 역할을 명확히 이해하게 되었어. nn.Module을 상속받으면 PyTorch가 레이어 관리, 파라미터 추적, GPU 지원 등 다양한 기능을 쉽게 활용할 수 있고, forward() 메서드는 모델의 데이터 처리 흐름을 정의해줘. 모델 인스턴스를 직접 호출하면 forward() 메서드가 자동으로 실행된다는 점도 알게 되었어.

헷갈렸던 점#

모델을 만들 때 왜 nn.Module을 상속받아야 하는지, 그리고 forward 메서드를 직접 호출하지 않고도 모델이 어떻게 작동하는지 처음에 잘 몰랐습니다. 모델 인스턴스를 직접 호출했을 때 어떤 함수가 실행되는지 이해하는 데 시간이 걸렸고, 상속의 필요성에 대한 명확한 이유를 파악하기 어려웠습니다.

정리된 이해#

PyTorch 모델은 nn.Module을 상속받아 레이어 관리, 파라미터 추적, GPU 지원 등 다양한 기능을 활용하고, forward() 메서드를 통해 입력 데이터가 모델을 거치는 과정을 정의합니다. 모델 인스턴스에 직접 입력값을 넘기는 방식으로 forward() 메서드가 자동으로 호출되어 코드를 간결하게 만들 수 있습니다.

6. 단층 퍼셉트론 구현과 Step 활성화 함수 이해#

무엇을 배웠나#

퍼셉트론의 기본 구조와 Step 활성화 함수를 직접 구현하면서 코드 작성 순서에 대한 혼란을 겪었지만, 실습을 통해 목표가 복잡한 신경망 학습이 아닌 퍼셉트론의 기본 계산 과정을 이해하는 데 있음을 알게 되었습니다. Step 함수는 초기 퍼셉트론에서는 유용하지만, 현대 신경망의 기울기 기반 학습에는 한계가 있다는 것을 이해했습니다. 코드를 단계별로 나누어 작성하는 것이 중요하며, 퍼셉트론의 작동 원리를 명확히 이해하는 데 중점을 두어야 한다는 점을 배웠습니다.

헷갈렸던 점#

코드 구조를 어떻게 시작해야 할지 몰라서 import 부터 클래스 정의 순서까지 감이 잘 안 잡혔어. Step 함수가 학습 과정에서 제대로 작동할 수 있을까, 특히 역전파 과정에서 문제가 생기진 않을까 걱정했었어. 전체적인 그림을 어떻게 그려야 할지, 그리고 각 요소들이 어떻게 연결되는지 명확하지 않았어.

정리된 이해#

퍼셉트론의 기본 구조를 이해하고 직접 구현해보는 과정에서 전체적인 코드 구조를 잡는 데 어려움을 겪었지만, 실습 목표가 복잡한 학습보다는 기본적인 계산 과정을 파악하는 것이라는 점을 명확히 했습니다. Step 함수는 초기 퍼셉트론에서는 유용하지만, 현대 신경망에서의 복잡한 학습에는 미분 불가능한 특성으로 인해 제한적으로 사용될 수 있다는 것을 알게 되었습니다.

import torch
import torch.nn as nn
import matplotlib.pyplot as plt

class StepActivation(nn.Module):
    def forward(self, x):
        return torch.where(x >= 0, torch.ones_like(x), torch.zeros_like(x))
