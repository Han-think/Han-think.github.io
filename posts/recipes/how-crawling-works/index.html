크롤링은 어떻게 페이지를 넘어가나 — 명령어와 구조로 읽는 웹 수집

겁나 살벌해 보이는 웹 크롤링. 사실 URL 규칙 하나 잡으면 끝입니다. 페이지네이션 구조부터 데이터 저장까지, 코드가 실제로 뭘 하는지 단계별로 읽어봅니다.
2026년 5월 27일 · 4 min

이 글의 관점
크롤링 코드를 처음 보면 복잡해 보입니다.
하지만 실제로 코드가 하는 일은 “브라우저가 하는 것을 그대로 따라 하는 것” 입니다.
브라우저가 주소 치고 → 페이지 받고 → 내용 읽는 것처럼요.

1. 크롤러가 페이지를 넘기는 방법 — URL 패턴#

브라우저로 books.toscrape.com을 직접 열어보면 이런 URL이 보입니다:

http://books.toscrape.com/catalogue/page-1.html   ← 1페이지
http://books.toscrape.com/catalogue/page-2.html   ← 2페이지
http://books.toscrape.com/catalogue/page-3.html   ← 3페이지

패턴이 보이죠? 숫자만 바뀝니다.

크롤러는 이 규칙을 이용해서 반복문으로 URL을 만들어냅니다:

for page_num in range(1, 6):          # 1, 2, 3, 4, 5
    url = f"http://books.toscrape.com/catalogue/page-{page_num}.html"
    # → 이 주소로 요청을 보냄

이게 전부입니다. 페이지 넘기기 = URL 숫자 바꾸기.

2. 페이지를 “받아오는” 코드#

브라우저는 주소창에 URL을 치면 서버에서 HTML을 받아옵니다.
Python의 requests가 이걸 코드로 합니다:

import requests

url = "http://books.toscrape.com/catalogue/page-1.html"
response = requests.get(url)    # 브라우저가 주소 치는 것과 동일

print(response.status_code)    # 200 → 정상, 404 → 없는 페이지
print(response.text[:500])     # HTML 내용 앞부분 출력

response.text를 출력하면 브라우저 개발자 도구(F12)에서 보이는 HTML이 그대로 나옵니다.

3. HTML에서 원하는 데이터 찾기 — CSS 선택자#

HTML은 이런 구조로 되어 있습니다:

<article class="product_pod">
  <h3>
    <a title="A Light in the Attic" href="...">A Light in the ...</a>
  </h3>
  <p class="price_color">£51.77</p>
  <p class="star-rating Three"></p>
  <p class="availability">In stock</p>
</article>

BeautifulSoup은 이 구조를 CSS 선택자로 찾아줍니다:

from bs4 import BeautifulSoup

soup = BeautifulSoup(response.text, "html.parser")

# article.product_pod 안에 있는 모든 책 카드
books = soup.select("article.product_pod")

for book in books:
    title = book.select_one("h3 > a")["title"]   # 제목
    price = book.select_one("p.price_color").text  # 가격 (£51.77)
    
    print(title, price)

CSS 선택자 읽는 법:

선택자 의미
article.product_pod class가 product_pod인 <article>
h3 > a <h3> 바로 아래 <a>
p.price_color class가 price_color인 <p>

브라우저 개발자도구(F12 → Elements)에서 원하는 요소를 우클릭 → “Copy selector"하면 선택자를 바로 얻을 수 있습니다.

4. 전체 흐름 — 5페이지 수집의 실제 구조#

시작
  │
  ├─ for page_num in 1..5:
  │     │
  │     ├─ URL 생성
  │     │   "page-{N}.html"
  │     │
  │     ├─ requests.get(url)
  │     │   → HTML 텍스트 수신
  │     │
  │     ├─ BeautifulSoup 파싱
  │     │   → article 태그들 추출
  │     │
  │     ├─ for article in articles:
  │     │     → 제목, 가격, 별점, 재고 수집
  │     │     → books 리스트에 추가
  │     │
  │     └─ time.sleep(1)   ← 서버 부하 방지
  │
  └─ books 리스트 반환
       → 총 100권 (20권/페이지 × 5페이지)

코드로 보면:

import requests, time
from bs4 import BeautifulSoup

BASE = "http://books.toscrape.com"
books = []

for page_num in range(1, 6):
    url = f"{BASE}/catalogue/page-{page_num}.html"
    response = requests.get(url)
    soup = BeautifulSoup(response.text, "html.parser")
    
    for article in soup.select("article.product_pod"):
        title = article.select_one("h3 > a")["title"]
        price = article.select_one("p.price_color").text.replace("£", "")
        rating_class = article.select_one("p.star-rating")["class"][1]
        # class="star-rating Three" → ["star-rating", "Three"] → "Three"
        
        books.append({
            "title": title,
            "price": float(price),
            "rating": rating_class,
        })
    
    time.sleep(1)  # 1초 대기 (예의 바른 크롤링)

print(f"수집 완료: {len(books)}권")  # → 수집 완료: 100권

5. 상세 페이지로 이동 — 링크 따라가기#

목록 페이지엔 기본 정보만 있습니다. 설명·카테고리·UPC는 각 책의 상세 페이지에 있어요.

<!-- 목록 페이지의 링크 -->
<a href="../../catalogue/a-light-in-the-attic_1000/index.html">

이 상대 경로를 절대 URL로 변환해서 다시 요청합니다:

rel = article.select_one("h3 > a")["href"]
# "../../catalogue/a-light-in-the-attic_1000/index.html"

rel = rel.replace("../", "")
# "catalogue/a-light-in-the-attic_1000/index.html"

detail_url = f"{BASE}/{rel}"
# "http://books.toscrape.com/catalogue/a-light-in-the-attic_1000/index.html"

detail = requests.get(detail_url)
detail_soup = BeautifulSoup(detail.text, "html.parser")

# 카테고리는 breadcrumb에서
# Home > Books > Poetry > A Light in the Attic
breadcrumbs = detail_soup.select("ul.breadcrumb li")
category = breadcrumbs[-2].get_text(strip=True)  # "Poetry"

6. 데이터 저장 — JSON 파일#

수집한 데이터는 json.dump()로 파일에 저장합니다:

import json

with open("books.json", "w", encoding="utf-8") as f:
    json.dump(books, f, ensure_ascii=False, indent=2)

저장된 books.json 구조:

[
  {
    "title": "A Light in the Attic",
    "price": 51.77,
    "rating": "Three",
    "category": "Poetry",
    "upc": "a897fe39b1053632",
    "description": "It's hard to explain a Shel Silverstein poem..."
  },
  ...
]

이 JSON을 나중에 불러다가 Hugo .md 파일로 변환하면 블로그 포스트가 됩니다.

핵심 요약#

크롤링 = 브라우저가 하는 일을 코드로 반복

1. URL 규칙 파악    → page-{N}.html 처럼 패턴이 있다
2. requests.get()  → HTML 받아오기
3. BeautifulSoup   → CSS 선택자로 원하는 요소 추출
4. 반복문           → 100페이지든 1000페이지든 같은 방식
5. 저장             → JSON / CSV / DB

살벌해 보이지만 결국 “규칙 찾기 + 반복” 입니다.

이 블로그의 BookCrawler 파이프라인은 위 원리로 books.toscrape.com 5페이지(100권)를 수집하고,
자동으로 Hugo 블로그 포스트로 변환해서 GitHub Pages에 5분 간격으로 올립니다.
