[이미지 AI] Stable Diffusion · Intel Arc에서 IPEX로 돌리기

NVIDIA 없이 Intel Arc GPU로 Stable Diffusion을 실행하는 검증된 환경 레시피 · IPEX-LLM과 diffusers 연동
2026년 5월 27일 · 2 min

목표#

Intel Arc GPU(A770, A750, 내장 Arc 포함)에서 Stable Diffusion을 실행한다. NVIDIA 없이도 가능하다. 단, 환경 설정이 까다롭다.

이 레시피의 전제#

  • Windows 11 (22H2+)
  • Intel Arc GPU (드라이버 최신 버전)
  • Python 3.11 (3.12는 일부 패키지 미지원)
  • conda 환경 권장

환경 구성#

# conda 환경 생성
conda create -n sd-ipex python=3.11 -y
conda activate sd-ipex

# Intel Extension for PyTorch (IPEX) 설치
pip install torch==2.1.0 torchvision==0.16.0 --index-url https://download.pytorch.org/whl/cpu
pip install intel_extension_for_pytorch==2.1.10+xpu --extra-index-url https://pytorch-extension.intel.com/release-whl/stable/xpu/us/

# diffusers 및 관련 패키지
pip install diffusers==0.25.1 transformers==4.37.2 accelerate==0.26.1
pip install invisible-watermark safetensors omegaconf

동작 확인#

import torch
import intel_extension_for_pytorch as ipex

# XPU (Intel GPU) 감지
print(torch.xpu.is_available())   # True여야 함
print(torch.xpu.device_count())   # 사용 가능한 XPU 수

이미지 생성 예제#

import torch
import intel_extension_for_pytorch as ipex
from diffusers import StableDiffusionPipeline

device = "xpu" if torch.xpu.is_available() else "cpu"

pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5",
    torch_dtype=torch.float16 if device == "xpu" else torch.float32
)
pipe = pipe.to(device)

# 첫 실행은 모델 다운로드로 시간 걸림 (~4GB)
image = pipe(
    "a serene Korean traditional garden, ink painting style",
    num_inference_steps=20,
    guidance_scale=7.5
).images[0]

image.save("output.png")

알려진 문제#

증상 원인 해결
xpu not available 드라이버 미설치 Intel Arc 드라이버 재설치
OOM 오류 VRAM 부족 num_inference_steps 줄이기
느린 속도 CPU fallback XPU 확인 후 재시도
