[음악 AI] Magenta — 처음 만난 AI 작곡, 그리고 벽

Google Magenta로 시작한 AI 작곡 여정 · 실패와 돌파구 · 검증된 로컬 환경 레시피
2026년 5월 27일 · 3 min

왜 Magenta였는가#

AI가 예술을 만들 수 있는가?

Google Brain 팀이 2016년 이 질문을 들고 나왔습니다. 그게 Magenta입니다.

접근 방식은 이랬습니다.

스칼라 함수 기반
+ RNN (순환 신경망)
+ 딥러닝 + 머신러닝 조합
→ 학습 출력을 예술(음악/그림)로

단순히 “AI가 소리를 낸다"가 아니라, 학습한 패턴의 출력이 음악적 구조를 갖추는 것을 목표로 했습니다.

처음 이걸 알았을 때, 직접 해보고 싶었습니다.

첫 번째 벽 — NVIDIA 필수#

설치를 시작했습니다. 그런데 바로 막혔습니다.

CUDA → NVIDIA GPU 필수

NVIDIA가 없으면 사실상 진행이 안 됐습니다. 당시엔 NVIDIA 없이 로컬 AI를 돌리는 방법이 거의 공유되지 않던 시절이었습니다.

두 번째 시도 — Jetson Nano#

엣지 디바이스로 우회해보려 했습니다. NVIDIA Jetson Nano.

그런데 여기서도 막혔습니다.

TensorFlow → Jetson Nano 환경에서 설치/동작 불가

Magenta는 TensorFlow에 깊이 의존합니다. Jetson Nano의 ARM 환경 + 당시 TF 버전 조합이 맞지 않았습니다.

결국 포기했습니다.

2년 후 — 돌파구#

시간이 지나 HuggingFace를 뒤지다가 발견했습니다.

SkyTNT/midi-model

Magenta의 RNN 방식이 아닌 Transformer 기반 MIDI 생성 모델입니다. 핵심은 두 가지였습니다.

① Seed 방식 생성

  • 이미 학습된 모델을 HuggingFace에서 다운로드
  • Python 함수 형태로 출력만 하는 구조
  • GPU 없이 CPU로 동작 가능한 가벼운 모델

② ABC 악보 형식 → MIDI 출력

  • ABC notation (텍스트 기반 악보 표기법)으로 출력
  • MIDI 파일로 저장
  • 웹페이지에서 바로 재생 가능
HuggingFace 모델 로드 → seed 입력 → ABC 출력 → MIDI 변환 → 웹 재생

GPU 없이, 로컬에서, 실제로 돌아갔습니다.

Magenta가 “왜 AI 음악인가"를 알게 해줬다면,
midi_composer는 “GPU 없이도 된다"는 걸 알게 해줬습니다.

⚠️ ONNX 방식으로 Intel 가속을 지원하지만,
CUDA 요구 조건이 걸리는 경우가 있어 환경에 따라 다릅니다.
XPU(Intel Arc + IPEX) 조합으로 우회하는 방법이 현실적입니다.

더 깊이 — LoRA 튜닝#

기본 모델에서 한 단계 더 나아갔습니다.

Jupyter Notebook
+ Google Colab A100
→ 내 데이터로 LoRA 파인튜닝
→ 로컬에서 튜닝된 모델 연결

내가 원하는 스타일로 튜닝한 모델을 로컬에서 직접 쓸 수 있게 됐습니다.

환경 레시피 (검증 완료)#

# Python 3.9 권장 (3.11+ 에서 오류 가능)
conda create -n magenta python=3.9 -y
conda activate magenta

# Magenta 설치
pip install magenta

# 확인
python -c "import magenta; print(magenta.__version__)"

패키지 조합:

패키지 역할 필수
magenta 핵심 라이브러리 ✅
tensorflow 자동 설치 (magenta 의존) ✅
note-seq MIDI 처리 ✅
pretty-midi MIDI 분석/편집 선택
pyfluidsynth MIDI → 오디오 변환 선택

⚠️ conda 권장 이유
TensorFlow 의존성이 복잡합니다.
pip + venv만으론 충돌 가능성이 높습니다.

이 경험이 준 것#

Magenta → midi_composer를 거치며 알게 된 것들:

GPU 없이도 가능한 구조가 있다
→ CPU용 경량 모델, Transformer 기반

HuggingFace가 탐색 공간이다
→ 검색하면 나온다, 단 찾는 법을 알아야 한다

ABC → MIDI → 오디오 변환 파이프라인
→ 나중에 AudioCraft, MusicGen으로 이어짐

그리고 Intel 환경의 가능성을 발견하기 시작했습니다.

처음: NVIDIA 없으면 불가
↓
Intel IPEX 발견 → Intel GPU(Arc)에서 가속 가능
↓
OpenVINO + NPU 지원 → AI Boost NPU 활용
↓
XPU 통합 → CPU + iGPU + NPU 전부 활용
↓
지금: Intel Core Ultra 125H 환경에서
      로컬 소설 생성 모델 극한 구현 중

이 여정이 지금 이 블로그의 출발점입니다. “방법이 없어서 직접 찾았다” — 그 경험을 기록합니다.
