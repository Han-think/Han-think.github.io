[음악 AI] AudioCraft — Meta의 AI 음악 생성, 로컬 설치

Meta AudioCraft(MusicGen)을 로컬에서 설치하고 텍스트로 음악을 생성하는 레시피 · 패키지 의존성 지뢰밭 해결
2026년 5월 27일 · 2 min

AudioCraft란#

Meta가 공개한 오디오 생성 프레임워크다. 텍스트 프롬프트로 음악(MusicGen), 효과음(AudioGen), 고품질 오디오(EnCodec)를 만든다.

"upbeat jazz with piano and drums, 120bpm"
→ .wav 파일 생성

요구 사양#

항목 최소 권장
VRAM 4 GB 8 GB
RAM 8 GB 16 GB
Python 3.9 3.10

AudioCraft는 Python 3.11 이상에서 설치 실패하는 경우가 많다. conda로 3.10 환경을 별도 구성하는 것을 강하게 권장.

설치 (검증된 경로)#

# 1. Python 3.10 conda 환경
conda create -n audiocraft python=3.10 -y
conda activate audiocraft

# 2. PyTorch (CUDA 12.1 기준)
pip install torch==2.1.0 torchaudio==2.1.0 --index-url https://download.pytorch.org/whl/cu121

# 3. AudioCraft 설치
pip install audiocraft==1.3.0

# 4. 의존성 확인
python -c "import audiocraft; print('OK')"

자주 만나는 오류#

ERROR: No matching distribution found for demucs==4.0.0

→ pip install demucs==4.0.1로 먼저 설치 후 재시도

AttributeError: module 'torch' has no attribute 'isin'

→ PyTorch 버전 문제. 2.0.0 이상으로 재설치

첫 음악 생성#

import torchaudio
from audiocraft.models import MusicGen
from audiocraft.data.audio import audio_write

model = MusicGen.get_pretrained("small")   # 300M 파라미터
model.set_generation_params(duration=8)    # 8초

descriptions = ["energetic Korean folk music with gayageum"]
wav = model.generate(descriptions)

# 파일 저장
audio_write("my_music", wav[0].cpu(), model.sample_rate, strategy="loudness")

Intel Arc에서는?#

현재 AudioCraft는 CUDA 기반으로 설계되어 있어 Intel Arc에서 직접 실행이 어렵다. CPU 모드는 가능하지만 4B 이상 모델은 실용적이지 않다.

NVIDIA GPU 또는 Google Colab 환경을 권장.
