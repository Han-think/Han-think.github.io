BookCrawler — 웹 크롤링부터 블로그 자동 발행까지

2026년 5월 27일 · 2 min
⬇ BookCrawler 소스 다운로드 (ZIP · 전체 파이프라인)

개요#

books.toscrape.com에서 책 정보를 수집해 Hugo 블로그에 5분 간격으로 자동 발행하는 파이프라인입니다.
스크레이핑 → 변환 → Git 자동화 → 스케줄링까지 전 과정을 Python 모듈로 구성했습니다.

파이프라인 구조#

run.py  (진입점 · argparse)
  │
  ├─ pipeline.py  (오케스트레이터)
  │    ├─ PHASE 1 ─ scraper.py       ← requests + BeautifulSoup4
  │    │             queue_manager.py ← books.json / queue.json 관리
  │    │
  │    └─ PHASE 2 ─ scheduler.py     ← schedule 라이브러리 (5분 주기)
  │                  converter.py    ← dict → Hugo .md (TOML front matter)
  │                  publisher.py    ← Hugo build + git push (subprocess)
  │
  └─ config.py  (URL, 경로, 상수 중앙 관리)

모듈별 역할#

scraper.py — 수집 (requests + BeautifulSoup4)#

from scraper import scrape_books_with_details

books = scrape_books_with_details(pages=5, limit=10)
# [{"title": "...", "price": 12.34, "rating": 4, "category": "Mystery", ...}, ...]
  • page-{N}.html 목록 → article.product_pod 파싱
  • 상세 페이지 → 카테고리(breadcrumb), 설명, UPC 추출
  • requests.Session 재사용 + time.sleep(1) (예의 바른 크롤링)

converter.py — 변환#

from converter import save_markdown
from datetime import datetime, timezone, timedelta

path = save_markdown(book, pub_date=datetime.now(timezone(timedelta(hours=9))))
# → content/posts/book-reviews/2026-05-27_a-light-in-the-attic.md

Hugo TOML front matter 생성:

+++
title      = "A Light in the Attic"
date       = "2026-05-27T10:00:00+09:00"
categories = ["books"]
tags       = ["book-review", "poetry", "rating-4"]
rating     = 4
rating_emoji = "⭐⭐⭐⭐"
+++

publisher.py — 발행 (subprocess)#

from publisher import publish_post

publish_post("A Light in the Attic")
# 1. hugo --minify
# 2. git add content/ public/
# 3. git commit -m "📚 [BookCrawler] A Light in the Attic"
# 4. git push origin main

Windows에서 subprocess.run()으로 git / hugo 명령을 실행합니다.

scheduler.py — 스케줄링 (schedule 라이브러리)#

from scheduler import run_scheduler

run_scheduler(interval_min=5, posts_to_upload=5)
# 5분마다 _upload_one() 호출 → 5회 완료 후 자동 종료

schedule.every(5).minutes.do(작업) → 10초 poll 루프로 구동합니다.

실행 방법#

# 패키지 설치
pip install -r requirements.txt

# 전체 파이프라인 (수집 + 5분 간격 발행 × 5회)
python run.py

# 수집만 (books.json + queue.json 생성)
python run.py --mode scrape

# 발행만 (기존 큐 사용)
python run.py --mode publish

# 옵션 조합
python run.py --pages 3 --posts 3 --interval 2

데이터 흐름#

books.toscrape.com
    │  requests.get()
    ▼
List[Dict]  →  books.json   (전체 원시 데이터)
                    │
                    ▼
              queue.json    (발행 대기 FIFO 큐)
                    │  5분마다 pop
                    ▼
              .md 파일 생성  →  hugo --minify  →  git push
                                                      │
                                              GitHub Pages 배포
                    │
              posted.json   (완료 UPC 기록, 중복 방지)

사용 라이브러리#

라이브러리 버전 용도
requests ≥2.31 HTTP 크롤링
beautifulsoup4 ≥4.12 HTML 파싱
schedule ≥1.2 인터벌 스케줄링

모두 pip install -r requirements.txt 한 번으로 설치됩니다.

이 파이프라인은 Python 자동화 학습 목적으로 제작했으며,
크롤링 대상 사이트(books.toscrape.com)는 스크레이핑 연습용으로 공개된 사이트입니다.
