[환경구성] LearningLog Kit — 학습 노트를 블로그로 자동 발행하는 파이프라인

강의자료와 개인 학습 노트(.md)를 폴더에 넣으면 LLM이 정리 → 블로그 초안 → 발행까지 자동으로 해주는 파이프라인 도구. pip 설치 + 웹 UI로 누구나 5분이면 시작.
2026년 5월 30일 · 3 min

무엇을 만드나#

매일 배운 것을 기록하고 싶지만, 정리하고 블로그에 올리는 과정이 번거롭다.

LearningLog Kit은 그 과정을 자동화한다.

00_inbox/personal_notes/ 에 노트(.md)를 넣는다
        ↓  LLM (Gemini / Groq / Ollama)
사실 추출 → 워킹 노트 → 블로그 초안
        ↓
블로그 발행 (draft → publish)

설치부터 발행까지 버튼 클릭만으로 가능하다.

다운로드#

⬇ LearningLog Kit 다운로드 (ZIP · v0.3.2)

pip install ./learninglog-kit-v0.3.2.zip[web,gemini] 로 바로 설치할 수 있습니다.

가장 쉬운 시작 — 웹 UI#

pip install "./learninglog-kit-v0.3.2.zip[web,gemini]"
learninglog ui

브라우저(http://127.0.0.1:8765)가 열리면:

1. [폴더 구조 생성] 클릭        → 작업 폴더 자동 세팅
2. Gemini 선택 → API 키 붙여넣기 → [저장 + 테스트]
3. 00_inbox/personal_notes/ 에 노트(.md) 넣기
4. [① intake] → [② extract] → [③ publish] 클릭

터미널 명령을 몰라도 됩니다. 설치·설정·실행이 전부 화면 안에서 끝납니다.

API 키는 어디서 — Gemini 무료#

가장 간단한 무료 옵션은 Google Gemini입니다.

1. https://aistudio.google.com/app/apikey  접속 (구글 계정)
2. [Create API key] 클릭
3. AIzaSy... 키 복사 → 웹 UI에 붙여넣기

무료 한도: 하루 1,500회 요청 (매일 자정 초기화). 개인 학습 노트에는 충분합니다.

⚠️ API 키는 메신저·GitHub·SNS에 공유하지 마세요.

헷갈렸던 것 — 로컬 vs 클라우드#

처음엔 “로컬 모델(Ollama)을 꼭 깔아야 하나?” 싶었다.

정리하면 선택지는 세 가지다.

방식 비용 특징
Gemini / Groq 무료 (한도) 설치 불필요, API 키만. 빠름
Ollama 완전 무료 로컬 실행, 인터넷 불필요, 프라이버시

핵심: 클라우드 API는 컨텍스트가 커서 긴 노트도 한 번에 처리되고, 로컬은 데이터가 PC를 벗어나지 않는다. 목적에 따라 고르면 된다.

정리된 이해 — 파이프라인 구조#

intake   : 00_inbox 스캔 → 등록 (중복 자동 감지)
extract  : LLM 처리 → 사실 추출 + 워킹 노트 + 블로그 초안
publish  : draft:false + ai_assisted 마킹 → 블로그로 복사 + 빌드 + 발행

각 단계는 상태 장부(CSV)로 추적되어, 이미 처리한 노트는 다시 처리하지 않는다.

설치 ↔ 제거 (install ↔ uninstall)#

개념 명령
설치 pip install "...learninglog-kit-v0.3.2.zip[web,gemini]"
데이터만 정리 (재시작용) learninglog clean
완전 제거 (프로그램+데이터) learninglog uninstall 
learninglog clean             # 생성 데이터만 정리 (패키지 유지)
learninglog uninstall         # 데이터 정리 + 패키지 제거 (한 번에)

00_inbox/ 의 원본 노트는 어떤 경우에도 자동 삭제되지 않습니다. 안전하게 보존됩니다.

실습 — 하루 학습 기록 흐름#

오전 수업 → Gemini에게 "오늘 배운 것 정리해줘" → PN_날짜_01_주제.md
오후 수업 → 같은 방식                          → PN_날짜_02_주제.md

수업 후:
learninglog ui → [intake] → [extract] → [publish]
→ 오늘 학습 2편이 블로그에 자동 발행

한 번에 다 넣기보다 강의 시간 단위로 나눠 정리하는 것을 권장합니다. LLM이 맥락을 더 정확히 처리합니다.

초보자 키워드#

  • 파이프라인(pipeline): 입력 → 처리 → 출력이 단계로 이어진 자동 흐름. 검색어 data pipeline
  • API 키(API key): 외부 AI 서비스를 쓸 때 신원을 증명하는 비밀 문자열. 검색어 gemini api key
  • front matter: 마크다운 글 맨 위 --- 사이의 설정(제목·날짜·카테고리). 검색어 hugo front matter
