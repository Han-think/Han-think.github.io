그린존 2 — 공공자료를 모으고 기준을 맞추다

자료를 많이 모으는 것보다 대상 지역과 기준 시점, 자료가 설명하는 범위를 확인하는 일이 먼저였던 이유.
2026년 10월 26일 · 2 min

문제와 목표 — 자료를 모으기 전에 범위를 정했다#

지도와 분석을 만들려면 지역 경계, 건물·주거 현황, 도로와 보호시설, 폐기물 배출 안내와 통계가 필요했다. 팀은 공공데이터포털, 서울 열린데이터광장, 통계지리정보서비스와 관련 기관의 공개 자료를 살펴 신월1동 범위에서 활용 가능한 자료를 확인했다.

여기서 중요한 것은 자료 파일을 쌓는 일이 아니었다. 각 자료가 어느 지역을 포함하는지, 언제 갱신됐는지, 무엇을 측정하거나 설명하는지 확인해야 서로 다른 자료를 같은 뜻으로 오해하지 않는다.

구조와 결정 — 서로 다른 자료는 같은 기준이 아니었다#

경계와 건물 정보는 대상 위치를 정리하는 데 쓰였고, 도로와 보호시설 정보는 거점 후보를 비교하는 조건으로 활용했다. 폐기물 배출 자료는 안내와 수요를 생각할 때 참고했지만, 모든 자료가 신월1동만의 동일한 기간·단위로 제공되지는 않았다.

그래서 광역 통계는 신월1동 실측값처럼 표현하지 않고 참고자료로 다뤘다. 공공자료라는 이유만으로 최신성이나 현장 정확성이 자동으로 보장되는 것도 아니다. 자료마다 기준일과 범위를 확인하고, 해석에 필요한 전제를 기록하는 일이 먼저였다.

구현과 확인 — 공개 글에는 범주와 한계를 남긴다#

팀 분석에 사용한 자료는 행정 경계, 건물·주거 현황, 도로·보호시설, 폐기물 안내·통계 범주로 소개한다. 원본 파일과 내부 가공 세부는 이 글에서 공개하지 않는다. 필요한 경우 팀 저장소의 공개 문서와 해당 공공기관 페이지에서 확인하는 구조로 두었다.

또한 데이터가 알려주는 사실과 우리가 분석 편의를 위해 둔 가정을 나눴다. 예를 들어 주거 현황은 잠재 수요를 비교하는 참고값이지, 실제 배출량을 직접 측정한 값이 아니다.

한계와 다음 단계 — 이번 편의 정리#

데이터 분석은 자료를 내려받는 순간 끝나지 않았다. 기준과 범위를 서로 맞추고, 부족한 부분은 추정이나 미확인으로 남겨야 결과를 설명할 수 있었다.
