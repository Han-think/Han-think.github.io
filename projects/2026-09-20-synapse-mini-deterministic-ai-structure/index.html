Synapse mini — AI에게 프로젝트의 구조를 맡기지 않기

왜 만들었는가#

작은 모델에게 프로젝트 전체를 설명하고, 여러 파일을 한꺼번에 만들게 하면 처음에는 그럴듯해 보인다. 하지만 시간이 지나면 파일의 역할이 섞이고, 이미 결정한 전제가 조용히 바뀌며, 무엇이 완료된 상태인지 사람도 다시 확인해야 한다.

나는 이 문제를 모델의 능력 부족만으로 보고 싶지 않았다. 모델이 프로젝트의 구조, 파일 목록, 각 파일의 책임, 완료 판정까지 모두 기억해야 하는 방식 자체가 불안정하다고 생각했다.

그래서 이번에는 반대로 설계했다. 프로젝트의 모양은 Python 코드와 파일로 고정하고, 모델은 필요한 한 칸의 내용만 제안하게 하는 것이다.

Synapse mini가 하는 일#

공개 저장소에는 Synapse의 작은 읽기 전용 버전인 Synapse mini를 올렸다.

핵심 동작은 세 가지다.

  1. plan: 아이디어를 결정적인 파일 목록으로 바꾼다.
  2. check: 기존 폴더를 읽고 각 파일에 실제 작성된 내용이 있는지 확인한다.
  3. demo: 파일 경로와 내용 제안을 실제로 쓰지 않고 판정한다.

같은 아이디어와 같은 프리셋을 넣으면 같은 계획이 나와야 한다. 모델이나 네트워크가 없어도 핵심 계획과 검사는 실행된다. 모델을 연결하더라도 모델의 출력은 바로 상태가 되지 않고, 먼저 제안으로 남는다.

프로젝트: Han-think-Studio/synapse-current

구조를 모델 밖에 두기#

Synapse에서 가장 중요하게 둔 경계는 구조와 내용의 분리다.

  • synapse/core/는 무엇이 존재해야 하고 무엇을 작성된 것으로 볼지 결정한다.
  • domain_packs/_presets/는 분야별 파일 목록과 각 파일의 목적을 가진다.
  • _mini/synapse_mini.py는 코어를 호출하는 CLI다.
  • _mini/fill_with_local_model.py만 모델과 통신한다.

이렇게 나누면 모델이 파일 목록을 다시 만들거나, 완료 여부를 스스로 선언하거나, 프로젝트 전체의 결정을 대신할 수 없다. 모델은 한 번에 하나의 슬롯을 채우고, 최종 판정은 별도의 정본 검사기가 담당한다.

읽기 전용으로 시작한 이유#

자동화는 곧바로 파일을 수정하는 기능부터 만들기 쉽다. 하지만 나는 먼저 읽기 전용으로 만들었다.

읽기 전용이면 계획과 실제 상태의 차이를 확인할 수 있고, 모델이 잘못 제안해도 기존 작업을 덮어쓰지 않는다. 무엇보다 “실행이 끝났다”와 “결과가 좋다”를 분리할 수 있다.

모델이 JSON을 반환했다고 해서 내용이 충분하다는 뜻은 아니다. 형식은 맞지만 빈 문장일 수도 있고, 템플릿을 그대로 되풀이할 수도 있다. Synapse mini에서는 실행 스크립트가 결과를 만들고, 정본 검사기가 구조적 준비 상태를 판정한다.

만들면서 확인한 것#

이번 프로젝트를 만들면서 가장 크게 확인한 것은, 작은 모델을 잘 쓰는 방법이 더 긴 프롬프트가 아닐 수 있다는 점이다.

모델에게 프로젝트 전체를 기억시키는 대신, 코드가 파일 목록과 역할과 순서를 관리하게 하면 모델은 한 번에 작은 작업만 수행한다. 그 결과 요청은 짧아지고, 결과는 읽기 쉬워지고, 실패 이유도 기록할 수 있다.

또한 retry도 같은 요청을 다시 보내는 것이 아니라, 검사기가 계산한 실패 이유를 다음 요청에 반영해야 의미가 생긴다. 구조를 먼저 고정했기 때문에 무엇이 비었고 어떤 조건을 통과하지 못했는지 설명할 수 있다.

다음 단계#

현재 공개 버전은 pre-release이고, 구조 계획과 콘텐츠 검사를 보여주는 작은 진입점이다. 원래 작업 중인 Synapse 전체 시스템은 더 많은 오케스트레이션과 상태 관리, 로컬 모델 연결을 포함하지만, 공개 저장소에는 핵심 원칙을 이해할 수 있는 범위만 분리했다.

앞으로는 다음을 더 확인하고 싶다.

  • 여러 도메인 프리셋에서 같은 검사 원칙이 유지되는가
  • 모델 공급자가 바뀌어도 코어의 판정이 흔들리지 않는가
  • 구조 검사가 실제 창작 작업의 문체와 의도를 방해하지 않는가
  • 읽기 전용 경계를 유지하면서 어느 단계까지 자동화를 확장할 수 있는가

Synapse는 결국 “AI로 더 많이 만들기”보다, 무엇을 AI에게 맡기지 않을지 먼저 정하는 실험에 가깝다. 이번 공개는 그 설계를 실제 파일과 실행 가능한 작은 도구로 꺼내놓은 첫 버전이다.
