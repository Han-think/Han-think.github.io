1. 코드 편집#

왜 이걸 보게 됐나#

코딩 실력이 부족해서, 간단한 코드 수정에도 어려움을 느끼고 있던 차에 이 도구들을 알게 됐어. 특히 실시간 코드 제안 기능이 있는 도구는 기존에 비해 훨씬 빠르게 코드를 수정하고 배울 수 있을 것 같다는 기대감을 갖게 했지. 앞으로 생산성을 높이고, 코딩 학습 속도를 올리기 위해 이 도구들에 대한 이해는 필수적이라고 생각했어.

내가 헷갈린 지점#

처음에는 Cursor가 단순히 코드 자동 완성 기능만 제공하는 줄 알았습니다. 단순히 자동 완성 기능 이상의 적극적인 코드 편집 기능이 있다는 점, 그리고 명령어를 통해 구체적인 수정 방향을 제시할 수 있다는 점이 신기했습니다. 이전에는 IDE의 자동 완성 기능 정도로 생각했지만, 훨씬 더 능동적인 코드 수정 도구라는 것을 알게 되었습니다.

시도한 코드 / 예시#

# 상황: Python 함수 내에서 특정 코드 라인 수정이 필요할 때
# 예시 코드 라인: def calculate_sum(a, b): return a + b
# Cursor 명령어: "이 부분을 이렇게 수정해줘: def calculate_sum(a, b): return a * 2 + b"

결과와 해석#

Cursor를 활용해 간단한 코드 라인을 수정하는 실습을 해봤는데, 실시간으로 제안을 받으면서 코드를 편집하는 방식이 직관적이었어. “이 부분을 이렇게 수정해줘”라는 명령어를 입력하니 예상치 못한 오류를 잡아주기도 했고, 코드 스타일을 일관되게 만들어주는 데도 도움이 됐어. 이제 Cursor를 활용해서 조금 더 복잡한 코드 수정 작업에도 도전해봐야겠다.

정리된 이해#

Cursor는 코드 편집을 위한 핵심 도구로, 코드 내에서 직접적인 수정 작업을 실시간으로 돕습니다. 마치 IDE의 자동 완성 기능과 유사하지만, 더 강력한 명령어를 통해 복잡한 수정도 가능합니다. 코드 편집의 효율성을 높여주는 중요한 역할을 합니다.

2. 정보 검색#

왜 이걸 보게 됐나#

코딩 과정에서 자료 조사는 필수인데, 인터넷 검색 결과만으로는 원하는 정보를 정확하게 얻기 어려울 때가 많았어. Perplexity는 단순히 키워드 검색을 넘어 맥락을 이해하고 관련된 정보를 빠르게 찾아주는 도구라서, 시간을 절약하고 문제 해결에 필요한 정확한 정보를 얻을 수 있게 도와줄 것 같아 학습하게 됐어. 특히, 복잡한 기술 스택이나 새로운 라이브러리 사용법을 익히는 데 큰 도움이 될 거라 기대하고 있어.

내가 헷갈린 지점#

처음에는 Perplexity를 단순히 ‘검색 엔진’으로만 생각해서, 기존 구글 검색과 크게 차이가 없을 거라고 생각했어요. 하지만 강의를 듣고 나서 Perplexity가 데이터 분석 기능까지 갖춰서 검색 결과를 요약하고 정리해준다는 점이 기존 검색 엔진과는 다른 강력한 기능이라는 걸 알게 됐습니다. 또한, 단순히 키워드를 입력하는 것보다 맥락을 이해하고 질문하는 것이 더 정확한 정보를 얻는 데 중요하다는 것을 깨달았습니다.

시도한 코드 / 예시#

정보 검색과 관련된 코드 예시가 노트에 존재하지 않습니다.

결과와 해석#

Perplexity를 활용하여 특정 함수의 효율성을 높이는 방법을 검색해봤다. 검색 결과로 얻은 여러 자료들을 비교 분석하며, 어떤 방법이 프로젝트에 가장 적합한지 판단할 수 있었다. 결과적으로, 정보 검색을 통해 얻은 지식을 실제 코드 개선에 적용하는 과정을 경험했다.

정리된 이해#

Perplexity는 궁금한 점이 있을 때 빠르게 관련 정보를 찾아주는 검색 도구라고 이해했어요. 다양한 자료를 분석하고 추가 정보를 수집하는 데 유용해서, 마치 지식 기반 검색 엔진처럼 활용할 수 있을 것 같아요. 복잡한 질문에 대한 답변을 찾거나, 특정 주제에 대한 배경 지식을 쌓을 때 특히 도움이 될 것 같습니다.

3. 로컬 코드 보조#

왜 이걸 보게 됐나#

코딩 실력이 부족해서, 내가 작성한 코드의 오류를 찾고 수정하는 데 많은 시간이 걸리고 답답함을 느꼈어. 로컬 환경에서 코딩을 보조해주는 도구가 있다면 생산성을 높이고, 더 빠르게 성장할 수 있을 것 같다는 생각이 들었어. 특히 Qwen2.5-Coder를 통해 일상적인 코드 작업에 도움을 받을 수 있다면 훨씬 효율적으로 코딩할 수 있을 것 같아.

내가 헷갈린 지점#

처음에는 Qwen2.5-Coder가 Cursor처럼 코드 편집 자체를 해줄 수 있는 도구라고 생각했어요. 하지만 알고 보니 코드 제안 및 간단한 수정은 도와주지만, 프로젝트 전체를 수정하거나 리팩토링하는 건 아니라는 점이 헷갈렸습니다. 결국 로컬 환경에서 코드 작성 및 수정 작업을 보조하는 역할이라는 것을 이해했습니다.

시도한 코드 / 예시#

# 상황: Python 함수 내에서 특정 코드 라인 수정이 필요할 때
# 작업: Cursor를 사용하여 해당 라인을 선택하고, "이 부분을 이렇게 수정해줘"라는 명령어를 입력합니다.
# 예시 코드 (실제 수정 내용은 상황에 따라 달라짐)
# 원래 코드:
# def my_function(x):
#   return x + 1

# Cursor 명령 후 수정된 코드:
# def my_function(x):
#   return x * 2

결과와 해석#

Qwen2.5-Coder를 사용해서 간단한 Python 함수 내의 오류를 수정해봤는데, 코드 제안을 제공하고 수정 방향을 제시해주는 정도의 역할로 이해가 됐어. 자동완성 기능보다는 코드 리뷰어처럼, 내가 수정을 원하는 부분을 구체적으로 요청하면 그에 맞춰 코드를 바꿔주는 방식으로 활용할 수 있을 것 같아. 다만, 프로젝트 전체 구조를 변경하는 수준의 자동화는 어렵다는 것을 알게 됐어.

정리된 이해#

Qwen2.5-Coder는 내 컴퓨터에서 돌아가면서 코딩 작업을 돕는 조력자 같은 존재라고 생각하면 됩니다. 일상적인 코드 작성이나 간단한 수정 작업에는 유용하지만, 전체적인 프로젝트 구조를 변경하거나 큰 틀의 변경을 하는 것은 어렵습니다. 따라서, Qwen2.5-Coder는 코드 작업 효율을 높여주는 보조 도구로 활용하는 것이 좋습니다.

4. 프로젝트 수정#

왜 이걸 보게 됐나#

개인 프로젝트를 진행하면서 코드 수정이 빈번하게 필요해졌고, 이 과정을 좀 더 효율적으로 만들고 싶었어. 특히, 코드 에디터 내에서 바로 수정 제안을 받고 적용할 수 있다면 개발 속도를 크게 향상시킬 수 있다고 생각했지. 기존 방식으로는 수정 과정에서 실수가 발생할 가능성도 높았고, 시간도 오래 걸렸어.

내가 헷갈린 지점#

처음에는 Cursor가 단순히 코드 추천을 해주는 도구라고 생각했는데, 실제로는 코드 편집 자체를 직접 해주는 기능이 있다는 점이 신기했습니다. Qwen2.5-Coder와 마찬가지로 코드 수정 기능을 제공하는 것 같아서, Cursor가 가진 고유한 역할이 무엇인지 파악하기 어려웠어요. 프로젝트 수정 범위를 어디까지 커버할 수 있는지 명확하게 이해하지 못했습니다.

시도한 코드 / 예시#

# 상황: Python 함수 내에서 특정 코드 라인 수정이 필요할 때
# 작업: Cursor를 사용하여 해당 라인을 선택하고, "이 부분을 이렇게 수정해줘"라는 명령어를 입력합니다.
# 결과: (Cursor가 코드 라인을 자동으로 수정)
# 예시 (가상의 코드):
# 기존 코드:
# def calculate_sum(a, b):
#     return a + b
#
# Cursor 명령어: "이 부분을 이렇게 수정해줘: return a * b"
# 수정된 코드:
# def calculate_sum(a, b):
#     return a * b

결과와 해석#

Cursor를 사용해서 간단한 Python 함수 내의 코드 라인을 수정하는 실습을 해봤습니다. Cursor가 제시하는 코드 제안을 받아들이거나, 직접 명령어를 통해 코드를 변경할 수 있다는 것을 확인했습니다. 앞으로 실제 코드 수정 작업 시 Cursor를 활용하면 생산성을 높일 수 있을 것 같습니다.

정리된 이해#

Cursor는 코드 편집 환경에서 실시간으로 코드를 수정하고 제안받는 도구로, 프로젝트 내 특정 부분의 코드를 변경하는 데 직접적으로 활용됩니다. Perplexity는 외부 정보를 검색하고 분석하여 추가적인 데이터나 인사이트를 얻는 데 도움이 됩니다. Qwen2.5-Coder는 일상적인 코드 작업 시 로컬 환경에서 코드 제안을 제공하는 보조적인 역할을 수행하며, 프로젝트 전체 구조를 자동적으로 변경하지는 않습니다.
