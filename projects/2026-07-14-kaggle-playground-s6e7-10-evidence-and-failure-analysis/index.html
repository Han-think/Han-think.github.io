10. 무엇이 실제로 영향을 줬나#

강한 긍정 요인#

  1. CatBoost의 범주형·비선형 모델링
    • 단독 OOF 0.949408로 LGB/XGB보다 크게 높았다.
  2. LightGBM과 CatBoost의 오류 상쇄
    • 약한 단독 LightGBM도 Blend에서는 가치가 있었다.
  3. 클래스 prior와 decision 보정
    • Balanced Accuracy 구조를 반영하지 않은 raw argmax는 경쟁력이 없었다.
  4. 외부 고득점 anchor
    • Public 0.95112로 로컬 챔피언보다 약 0.00107 높았다.
  5. 매우 높은 신뢰도의 희소 행 교정
    • Run 18의 한 행이 Public 0.95113을 만들었다.

좁은 영역에서만 의미 있었던 요인#

  • STEP_GE6500 targeted gate
  • fit -> at-risk cutoff 0.80 tail
  • ExactTE
  • 개발 표본의 OVR_BA_RULE

이들은 일부 검증에서는 양수였지만 전체 Blend, 독립 확인 또는 Public에서 제한이 드러났다.

반복적으로 부정적이었던 요인#

  • 광범위 robust bin과 interaction
  • 30개에서 21개로 특성 축소
  • CatBoost seed 확률 평균
  • 외부 원본 50k augmentation
  • logistic stacking
  • 건강축 LDA 주입
  • at-risk/unhealthy pairwise
  • Accuracy CatBoost 전역 10% 주입

끝까지 미해결인 요인#

  • Run 16 한 행
  • Run 17 한 행
  • Run 17_1의 AB/AC/BC
  • Run 22_1의 두 행

이들의 Public 표시점수는 기준과 같았다. 같은 다섯 자리 숫자는 정답 라벨의 증거가 아니다.

11. 실패를 분류한 방식#

모든 실패가 같은 실패는 아니었다.

소표본 우연#

  • Run 03의 sleep interaction
  • 특정 seed/fold에서만 강한 domain interaction

대응: seed 반복과 disjoint sample을 사용했다.

탐색-확인 과적합#

  • OVR: +0.000227 -> -0.000526
  • ExactTE: nested 양수 -> Public 음수

대응: 탐색 표본과 확인 표본을 분리했다.

단독 모델과 최종 조합의 불일치#

  • Targeted CatBoost 단독 +0.000023
  • 최종 Blend -0.000078

대응: 모델 단독 점수가 아니라 실제 최종 소비자 점수를 확인했다.

Accuracy와 Balanced Accuracy의 불일치#

  • Run 21은 정답 순증가 +511인데 BA -0.000330
  • Run 22는 575행 회수, 40행 손실인데 BA -0.000012

대응: 행 수가 아니라 클래스별 가치와 손익분기 정밀도를 계산했다.

Public 점수의 식별 불가능성#

  • 같은 소수점 다섯 자리 점수로 한두 행 효과를 판정할 수 없었다.
  • AB/AC/BC 세 점수가 같으면 개별 block 효과를 해독할 수 없다.

대응: 추가 Public probing을 중단하고 OOF 또는 해석 가능한 단일 변경에 집중했다.

12. 증거 등급을 따로 둔 이유#

실험 결과를 한 줄의 점수로만 기록하면 몇 주 뒤에 무엇이 확정됐는지 알기 어렵다. 그래서 다음 등급을 사용했다.

등급 의미 예시
A Public 점수가 통제된 변경 후 실제로 달라짐 Run 18
B 새 fold, seed 또는 disjoint 행에서도 양수 Run 10_3, Run 22_1
C 개발 OOF에서만 양수 Run 14
D 고정 또는 전체 OOF 음수 Run 19, 21, 23, 24
E Public 다섯 자리 표시가 동일해 미해결 Run 16, 17, 17_1, 22_1
F 준비했지만 실행하지 않음 Run 25, 26

이 구분 덕분에 좋아 보였던 것과 실제로 확인된 것을 섞지 않을 수 있었다.

총평#

실패는 한 종류가 아니었다. 소표본 우연, 탐색-확인 과적합, 단독 모델과 최종 Blend의 불일치, Accuracy와 Balanced Accuracy의 불일치, Public 반올림으로 인한 식별 불가능성을 구분하자 다음 실험을 계속할지 멈출지 판단할 수 있었다.
