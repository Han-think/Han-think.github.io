Kaggle Playground S6E7 개인 도전 - 8. 피처 실험과 앙상블은 왜 검증에서 무너졌나

Run 01~15의 피처 엔지니어링, Exact Target Encoding, seed ensemble, OVR, 외부 데이터 증강을 탐색과 독립 확인으로 구분해 검증했다.
2026년 7월 15일 · 4 min

이번 편은 좋아 보이는 아이디어를 많이 만든 기록이 아니라, 그 아이디어가 새 fold와 분리된 표본에서도 살아남는지 확인한 기록이다.

목차#

    1. Run 01~07_1: 건강 신호를 찾다
    1. Run 08~11: 로컬 최고점이 Public 최저점이 되다
    1. Run 12~15: 앙상블을 더 복잡하게 만들면 좋아질까
  • 총평

4. Run 01~07_1: 건강 신호를 찾다#

Run 01 — 통계 검정#

8개의 통계 검정과 효과 크기를 비교했다.

  • 가장 강한 수치형 신호는 sleep_duration이었다.
  • 가장 강한 범주형 신호는 stress_level이었다.
  • 걸음 수와 운동 시간도 의미 있는 순서를 보였다.

이 단계는 모델을 고르는 단계가 아니라, 이후 실험의 방향을 정하는 EDA였다.

Run 02 — 공통 조건 모델 screen#

13개 모델을 주로 50k, 3-fold 조건에서 빠르게 비교했다. HistGradientBoosting이 0.901402로 quick benchmark 1위였다.

이 값은 최종 모델 성능이 아니라, 어떤 모델 계열이 데이터 구조를 어느 정도 잡는지 보기 위한 기준선이었다.

Run 03과 Run 04 — 수면 상호작용의 착시#

수면, 에너지, 심박수와 걸음 수, 흡연 관련 파생 특성을 만들었다.

Run 03의 한 표본에서는 sleep-quality interaction이 +0.000675를 기록했다. 꽤 좋아 보였다.

하지만 Run 04에서 3개 seed와 반복 fold로 확인하자 이 interaction은 -0.000035 또는 -0.000354가 됐다. 대신 더 단순한 sleep score가 +0.000263 정도를 유지했다.

첫 번째 명확한 경고였다.

한 번 강하게 나온 상호작용은 발견이지 증명이 아니다.

Run 05 — 조건부 신호 지도#

전체 690,088행을 사용해 전역·조건부 mutual information을 검사했다.

대략적인 신호 순서는 다음과 같았다.

sleep > steps > exercise > BMI >> heart rate, water intake

심박수와 물 섭취량은 직관적으로 중요해 보였지만 목표와의 추가 정보량은 크지 않았다.

Run 06 — 30개를 21개로 줄이면 좋아질까#

증거가 약한 특성을 제거한 21개 특성과 포괄적인 30개 특성을 비교했다.

결과는 -0.000361이었다. 21개로 줄인 쪽이 나빴다.

약한 특성도 트리 모델 안에서는 다른 특성과 조합되어 보조 역할을 할 수 있었다. 이후 기본값은 30개 특성을 유지하는 것으로 정했다.

Run 07과 07_1 — Exact Target Encoding#

21개의 exact-value target encoding 특성을 추가했다.

고정 beta 1.0에서는 +0.000124로 효과가 작았다. 하지만 beta를 두 fold에서 선택하고 남은 fold에서 평가하는 nested 방식에서는 다음 결과가 나왔다.

delta = +0.000619
3/3 seeds positive
7/9 held-out folds positive
median beta = 1.15

이 시점에서 ExactTE는 가장 유망한 새 구조였다. 그래서 전체 5-fold로 승격했다.

5. Run 08~11: 로컬 최고점이 Public 최저점이 되다#

Run 08 — ExactTE 전체 학습#

51개 특성, beta 1.15로 전체 5-fold를 수행했다.

Local OOF = 0.949961
Kaggle Public = 0.94981

로컬은 기존 기준보다 좋아졌지만 Public 0.95005를 넘지 못했다.

Run 08_1 — 로컬 0.950192, Public 0.94924#

저장된 확률에 beta 1.00을 적용하자 로컬 OOF는 더 올라갔다.

Local OOF = 0.950192
Kaggle Public = 0.94924

이번 실험 전체에서 가장 인상적인 숫자였다. 가장 높은 로컬 점수가 가장 낮은 Public 점수로 연결됐다.

이는 단순히 Public 운이 나빴다는 말로 끝낼 일이 아니었다.

가능한 원인은 다음과 같았다.

  • Exact value가 합성 데이터의 train 특유 패턴을 과하게 포착했을 수 있다.
  • 같은 OOF에 beta와 class decision을 반복적으로 노출했을 수 있다.
  • Public subset의 경계 행 구성이 전체 train과 달랐을 수 있다.
  • 확률 자체는 좋아졌지만 최종 hard label 경계가 Public에 불리했을 수 있다.

Run 09 — 조금만 섞으면 괜찮을까#

기존 Blend에 ExactTE 확률을 20%, 25%, 30% 주입했다.

ExactTE 비중Local OOFPublic
20%0.9500190.94974
25%0.9500820.94973
30%0.9501190.94967

로컬은 비중이 커질수록 좋아졌지만 Public은 비중이 커질수록 나빠졌다.

이 단계에서 ExactTE 재검색은 중단했다.

Run 10~10_3 — 넓은 특성보다 좁은 gate#

robust bin과 광범위 interaction을 추가했지만 결과는 각각 -0.000361, -0.000345였다.

대신 유독 강했던 seed42/fold2를 부검하자 활동량이 높은 특정 영역에서 interaction이 유리한 패턴이 보였다. 이를 바탕으로 STEP_GE6500이라는 좁은 gate를 고정했다.

개발 표본과 겹치지 않는 100k에서 다음 결과가 나왔다.

STEP_GE6500, gamma=0.75
delta = +0.000269
fold wins = 2/3

하지만 전체 690,088행으로 확장한 Run 11에서는 Targeted CatBoost 단독이 +0.000023이었고, 최종 Blend는 -0.000078이었다.

이 실험은 두 번째 중요한 교훈을 남겼다.

최종 소비자가 Blend라면 단독 모델 개선만 확인해서는 안 된다.

6. Run 12~15: 앙상블을 더 복잡하게 만들면 좋아질까#

Run 12 — 재최적화와 stacking#

각 outer fold 안에서 Blend alpha를 다시 최적화하고 logistic stacking도 시험했다.

결과는 기존 fixed Blend 0.949873이 여전히 1위였다.

best logistic stack = 0.949777
reoptimized arithmetic blend = 0.949714
legacy fixed blend = 0.949873

복잡한 meta model이 이미 잘 맞춰진 오류 상쇄를 깨뜨렸다.

Run 13과 13_1 — seed ensemble#

100k 행에서 3개 sample seed × 3개 model seed × 3-fold, 총 27 fit을 돌렸다.

초기 평균 delta는 -0.000089였다. 그나마 좋아 보였던 seed 42와 2026의 50:50 조합을 이전 개발 행과 겹치지 않는 새 100k에서 확인했다.

결과는 -0.000517, 1/3 fold 승리였다.

같은 구조의 seed 다양성은 기대한 만큼의 오류 다양성을 만들지 못했다.

Run 14와 14_1 — One-vs-Rest의 반전#

세 클래스에 대해 별도 CatBoost를 학습하는 One-vs-Rest 방식은 최초 100k에서 다음 결과를 냈다.

delta = +0.000227
fold wins = 2/3

하지만 이전 개발·확인 행을 모두 제외한 fresh 150k에서는 다음과 같이 뒤집혔다.

delta = -0.000526
fold wins = 0/3
at-risk recall delta = -0.001684

이것은 가장 명확한 탐색-확인 과적합 사례였다.

Run 15 — 원본 50k 증강#

대회의 영감이 된 원본 Student Health 데이터 50k를 낮은 가중치로 fit-only 추가했다.

delta = -0.000176
fold wins = 1/3

분포가 비슷하다는 것과 생성 규칙이 같다는 것은 다른 문제였다. 외부 행은 경계를 넓히기보다 흐렸다.

총평#

ExactTE는 로컬 OOF를 0.950192까지 올렸지만 Public에서는 0.94924로 내려갔다. seed ensemble과 OVR도 첫 탐색에서는 가능성이 보였지만 독립 확인에서 무너졌다. 이 과정에서 탐색 결과와 승격 가능한 증거를 분리하는 기준이 생겼다.
