첫 Kaggle House Prices 도전: 4개의 선형 분석과 4개의 LLM 관점

첫 Kaggle House Prices 프로젝트를 5편의 시리즈로 나누어 정리한 입구 글
2026년 7월 6일 · 2 min

프로젝트 요약#

첫 Kaggle House Prices 프로젝트는 단순히 제출 파일 하나를 만든 작업이 아니라, 같은 문제를 여러 선형 분석 트랙으로 비교하고 4개의 LLM 관점을 해석 보조자로 붙여 검증한 프로젝트였다. 목표는 Ames 주택 특성 데이터로 SalePrice를 예측하고, local CV와 Kaggle public score 사이의 차이를 설명할 수 있는 제출 후보를 고르는 것이었다.

최종 후보는 Advanced linear v3였다. 이 모델은 고차원 one-hot feature 공간에서 RobustScaler와 LassoCV를 사용했고, local 5-fold log-RMSE 0.110139, Kaggle public score 0.12607을 기록했다. 이후 검증 감사에서는 단순 전처리 누수보다 Neighborhood 분포 차이와 저가 주택 구간 약점이 public gap에 더 가깝다는 결론을 얻었다.

시리즈 구성#

이 프로젝트는 한 글로 끝내면 핵심이 흐려져서 5편으로 나눴다.

  1. 프로젝트 개요와 제출 결과
  2. Pipeline 문법이 왜 중요했는가
  3. 4개의 선형 분석 트랙 비교
  4. 4개의 LLM 관점으로 실험 읽기
  5. 검증 감사와 다음 액션 플랜

왜 프로젝트로 분리했나#

학습로그에서는 그날그날 헷갈린 점과 교정된 이해가 중요하다. 반면 이 작업은 데이터셋, 문제 정의, EDA, pipeline, 모델 비교, 제출, 검증 감사, 다음 액션까지 이어진 하나의 완성형 작업이다. 그래서 learning이 아니라 projects에 두는 것이 맞다.

회고#
