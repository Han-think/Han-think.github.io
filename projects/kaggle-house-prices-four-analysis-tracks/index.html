Kaggle House Prices 2: 4개의 선형 분석 트랙 비교

단순 선형, 강의형 Lasso, 고급 LassoCV, 조합형 선형 모델을 역할별로 비교
2026년 7월 6일 · 2 min

왜 4개의 분석으로 나눴나#

처음에는 모델을 여러 개 돌려서 점수만 비교하면 된다고 생각했다. 하지만 House Prices 프로젝트에서 중요한 것은 모델 이름이 아니라 각 모델이 어떤 문제를 드러내는가였다.

이번 프로젝트의 4개 분석 트랙은 다음 역할을 가졌다.

트랙 대표 모델 CV mean CV std 역할
기존 단순 선형 LinearRegression 0.137385 0.020864 최소 기준선
오늘 강의형 fixed-alpha Lasso 0.110197 0.008190 동일 조건 모델·이상치 비교
내 고급 선형 LassoCV + RobustScaler 0.110139 0.007380 규제 강도 선택과 제출 후보
조합형 RidgeCV + LassoCV + ElasticNetCV 0.110585 0.007720 선형 모델 간 상보성 점검

1. 기존 단순 선형#

LinearRegression은 가장 단순한 기준선이었다. 이 모델은 규제가 없기 때문에 one-hot feature가 늘어난 뒤 계수가 불안정해졌다. test 최대 예측이 약 13,676,626까지 튀었고 fold 편차도 컸다.

이 모델의 역할은 좋은 점수를 내는 것이 아니었다. 이후 모델들이 무엇을 개선했는지 보여주는 출발점이었다.

2. 오늘 강의형 Lasso#

강의형 분석에서는 같은 5-fold CV, 같은 전처리, 같은 이상치 정책에서 여러 모델을 비교했다. 특히 Id 524와 1299 같은 GrLivArea 고면적·저가격 이상치를 어떻게 다루느냐가 중요했다.

fixed-alpha Lasso는 단순 선형보다 훨씬 안정적이었다. 규제를 통해 불필요한 feature의 영향력을 줄였고, one-hot feature가 많은 상황에서 계수 폭주를 막았다.

3. 내 고급 선형 v3#

v3에서는 alpha를 사람이 하나 고정하지 않고 LassoCV로 내부 CV를 돌려 선택했다. 또한 이상치에 덜 민감한 RobustScaler를 붙였다.

model = Pipeline([
    ('scaler', RobustScaler()),
    ('model', LassoCV(
        alphas=np.logspace(-5, -2, 40),
        cv=5,
        max_iter=20000,
        random_state=42
    ))
])
v3 모델 CV mean CV std
RidgeCV + RobustScaler 0.112278 0.008393
LassoCV + RobustScaler 0.110139 0.007380
ElasticNetCV + RobustScaler 0.110187 0.007387

LassoCV와 ElasticNetCV는 거의 비슷했지만, 이번 제출 후보는 가장 낮은 CV mean을 보인 LassoCV로 정했다.

4. 조합형 선형 모델#

조합형은 RidgeCV, LassoCV, ElasticNetCV의 OOF 예측을 가중 평균했다. 기대는 서로 다른 선형 모델이 서로 다른 오류를 보완하는 것이었다.

하지만 결과는 best single보다 약간 나빴다. 이유는 세 모델이 모두 비슷한 feature 공간과 비슷한 선형 가정을 공유했기 때문이다. 즉 오류 구조가 충분히 다르지 않았다.

앙상블은 모델 수가 아니라 서로 다른 오류가 있어야 이득이 생긴다.

비선형 모델과의 비교#

HistGradientBoostingRegressor도 비교했다. 이 모델은 비선형 관계와 임계값을 자동으로 잡을 수 있지만, 이번 데이터와 feature 설계에서는 0.125700 ± 0.008490 수준이었다.

현재 feature 설계에서는 규제 선형 모델이 더 효율적이었다. 다만 비선형 모델은 이후 앙상블 후보로 남길 가치가 있다.

분석 트랙에서 얻은 결론#

  • 단순 선형은 실패 기준을 만들었다.
  • 강의형 Lasso는 규제와 이상치 정책의 효과를 보여줬다.
  • v3 LassoCV는 규제 강도 선택과 scaling을 체계화했다.
  • 조합형은 비슷한 선형 모델만 섞는 것으로는 이득이 작다는 점을 보여줬다.
  • 비선형 모델은 복잡하지만, 현재 데이터 크기와 feature에서는 선형보다 안정적이지 않았다.
