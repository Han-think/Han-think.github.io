1. GitHub 저장소 설정 이해하기#

왜 이걸 보게 됐나#

코드 관리와 버전 제어를 위한 안정적인 플랫폼이 필요했고, GitHub가 그러한 역할을 수행할 수 있다는 것을 알게 되었습니다.

내가 헷갈린 지점#

다양한 설정 명령어와 옵션들이 복잡하게 느껴졌습니다. 특히 git remote add와 git push 과정에서 오류 발생 시 원인 파악이 어려웠습니다.

시도한 코드 / 예시#

# GitHub 저장소 초기화 및 설정
git init
git add .
git commit -m "초기 커밋"
git remote add origin https://github.com/yourusername/your-repo.git
git push -u origin main

결과와 해석#

명령어들이 정상적으로 실행되면서 로컬 저장소가 원격 GitHub 저장소와 연결되었습니다. 그러나 네트워크 문제로 인해 git push 단계에서 오류가 발생하기도 했습니다.

정리된 이해#

GitHub는 코드와 문서를 안전하게 저장하고 버전 관리를 통해 협업을 용이하게 해줍니다. git init, git add, git commit, git remote, git push 명령어는 저장소 생성부터 원격 저장소에 코드 배포까지의 기본 흐름을 제공합니다.
