Kaggle House Prices 4: 검증 감사와 다음 액션 플랜

local CV와 Kaggle public score 차이를 검증 감사로 해석하고 다음 실험을 정리
2026년 7월 6일 · 2 min

왜 검증 감사를 했나#

v3 LassoCV의 local CV는 0.110139였지만 Kaggle public score는 0.12607이었다. 차이는 +0.015931이었다. 이 차이를 그냥 “public에서 망했다"로 끝내면 다음 실험으로 이어지지 않는다.

그래서 검증 방식을 여러 개로 바꿔보며 gap의 원인을 좁혔다.

검증 방식 비교#

random CV와 CV-safe random CV가 거의 같았다는 점은 중요했다. 이 결과는 최종 v3 성능이 단순한 fold-preprocessing optimism 때문만은 아니라는 근거가 됐다.

반대로 Neighborhood를 그룹으로 잡았을 때 점수가 크게 나빠졌고, 이 결과는 Kaggle public score에 훨씬 가까웠다.

가격대별로 보면 하위 20% 주택 구간의 오차가 가장 컸다.

이 결과는 모델이 평균적인 주택에는 비교적 안정적이지만, 저가 주택 구간에서는 오차가 커진다는 뜻이다.

약한 구간: Neighborhood#

Neighborhood 기준으로는 IDOTRR, ClearCr, OldTown, Sawyer, StoneBr 등이 높은 오차를 보였다. 이 구간들은 제거 대상이 아니라 다음 실험의 진단 대상이다.

Neighborhood GroupKFold가 public score와 가까워졌다는 점은, public set의 지역 분포가 random CV와 다를 가능성을 보여준다.

제출 파일 QA#

제출 파일은 sample_submission과 같은 shape, 컬럼, Id 순서를 유지해야 한다.

확인한 항목은 다음과 같다.

1. Id 개수와 순서가 sample_submission과 같은가?
2. SalePrice에 결측값이 없는가?
3. SalePrice가 0 이하로 내려가지 않는가?
4. train에서 제거한 이상치 정책이 test 행 제거로 이어지지 않았는가?
5. 최종 파일명이 제출 후보와 일치하는가?

다음 액션 플랜#

다음 v4에서는 세 가지를 우선 확인한다.

  1. 저가 주택 구간 전용 feature와 loss 관점 점검
  2. Neighborhood interaction과 위치 기반 그룹 안정성 개선
  3. LassoCV 유지 여부와 HGB/앙상블 재비교

이번 검증에서 얻은 결론#

local CV가 좋다는 것은 출발점일 뿐이다. public score가 나빠졌을 때는 모델을 무작정 바꾸기보다, 검증 방식이 어떤 실제 상황을 반영하지 못했는지 확인해야 한다.

이번 프로젝트에서는 Neighborhood GroupKFold가 public gap을 설명하는 가장 강한 단서였다. 그래서 다음 실험은 더 복잡한 모델을 바로 추가하기보다, 지역 분포 차이와 저가 주택 구간을 더 잘 다루는 방향으로 가야 한다.
